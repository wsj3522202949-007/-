# 人物学：让角色自己长出命运引擎

人物学管一件事：读者为什么肯跟着你的人看三百年。
答案不在剧情多炸。答案在角色像个真人，会在你写的处境里做出只有他才干得出来的选择。
本篇直接服务两本在写小说：《难得夫妻是少年》（女频·都市言情·青梅竹马）与《重生千禧：从高中毕业开始造芯片》（男频·科技重生爽文）。

## 1. 人物认知系统（七维拆人）

别用"性格"这种空词。把一个人拆成七个零件，缺一个他就会变成纸片。
写之前先在这七格里填字，写的时候才不会人设漂移。

### 1.1 动机（他到底要什么）
动机分两层：表层想要（wants）和里层需要（needs）。
表层是剧情推力，里层是弧光终点。两者打架，故事才转。
填空：他现在最想拿到手的是______；但他真正缺的是______。

### 1.2 创伤（他的"鬼"）
创伤别拿来卖惨。它的活儿是解释他为什么这样想。
Lisa Cron 在《Story Genius》里叫它 misbelief 的成形事件：一个具体过去时刻，让他信了一条错的世界观（来源见第 8 节）。
填空：______岁那年，发生了______；从那以后他认定______。

### 1.3 决策顺序（他先做哪件事）
这是最容易被忽略、也最见人的一格。两个人面对同一件事，先后顺序不同，就是两种人。
填空：遇到麻烦，他的顺序是 ①______ ②______ ③______。

### 1.4 诚实边界（他对谁撒谎）
没人全诚实，也没人全说谎。边界画清楚，关系才有张力。
填空：他对______永远说真话；对______习惯性编造；唯独______这件事他骗自己。

### 1.5 压力下反应（炸了什么样）
平静时人人体面。看他在第三种危机里的动作，才知道他是谁。
填空：被当众羞辱时他会______；利益被抢时他会______；在乎的人出事时他会______。

### 1.6 表达风格（他怎么说话）
口音、语速、用词、沉默方式，都是人设的身份证。
填空：他高频词是______；急了爱说______；被夸奖时他会______。

### 1.7 至少三个反差（让他立体）
单一标签是扁的，反差才是活的。每个主要角色至少备三个反差。
反差别写成自相矛盾。它是同一内核在不同场景露出的两面。
填空：①对外______ / 对她（他）______。②在______上精明 / 在______上犯傻。③对敌人______ / 对家人______。

## 2. 角色弧：平弧 / 正弧 / 负弧

> 弧光类型学到此为止；**弧光怎么落地到情节**（每场戏逼一句错信 / 转折场景模板 / 配角弧·反派弧 / 卷级弧光节奏 / 弧光×爽点×金手指）见 `人物弧光.md`。

角色弧 = 这个人的内在认知，在故事里走了哪条路。
K.M. Weiland 在《Creating Character Arcs》里把弧分成三类，每类都挂在三幕结构上（来源见第 8 节）。

### 2.1 正弧（Positive Change Arc）
主角开局抱着一个错信（Lie），结尾挣脱它，抱住真相（Truth）。
Weiland 的结构节点，直接对应三幕：
- 铺垫：亮出 Lie，交代 Ghost（创伤事件）。
- 第一情节点：一场"掀翻世界"的大事，把他推进不可回头。
- 中点：一个反转式揭示，"moment of grace"，他第一次瞥见真相。
- 第三情节点：最大惨败，他被迫直视真相。
- 高潮：他选择真相，并用它解决问题。
- 收尾：他活在真相里，不再活在谎里。

### 2.2 平弧（Flat Arc）
主角开局就握着真相，全程不被说服。他的任务是拿真相去撞世界的谎。
典型如《饥饿游戏》凯特尼斯、《真探》里的硬骨头。
写法要点：第二幕是"试探的中段"，世界用 Lie 围攻他，他不退，反而把身边人一个个拉到真相这边。
网文里多数"无敌流""老爷爷流"男主走平弧，爽点来自"我本就对，你们慢慢醒"。

### 2.3 负弧（Negative Change Arc）
主角没挣脱 Lie，反而被它吞掉。三种变体：
- 幻灭弧：知道了残酷真相，但活得更空。
- 坠落弧：死抱 Lie 不放，被毁。
- 腐化弧：主动抛弃真相，投靠 Lie。
反派和悲剧配角常用。注意：负弧不等于"坏结局随便写"，每一步下沉都要有因果。

### 2.4 Lisa Cron 的内在认知转变
Cron 不谈"弧类型"，她只盯一件事：主角的 misbelief（错信）怎么被剧情逼到崩。
她的操作链（来源见第 8 节）：
- 先写主角过去：哪件事让他信了这句错话。
- 再定 misbelief：一句他深信、但故事要拆穿的歪理。
- 设"what if"情境：逼他拿这句歪理去撞南墙。
- 等"aha moment"：他亲历反例，自己改了世界观。
Cron 的金句是：剧情只是压力机，压的是主角脑子里的那句错话。
所以你每写一场戏，先问：这场在逼他哪句错信？没逼，这场就废了。

### 2.5 网文"人设不崩"纪律
爽文最怕中途变了一个人，读者立刻弃书。三条铁律：
- 铁律一：核心决策顺序从头到尾不能变，变要写"为什么变"。
- 铁律二：反差可以露两面，但不能今天狠明天圣母，除非 Trauma 被新事件改写。
- 铁律三：金手指放大他的本色，不给他换性格。林川用芯片赚钱，骨子里还是那个"先记账再翻脸"的林川。

## 3. 关系动力学：四差公式与拉扯写法

两个人的戏好不好看，不看他们多配，看这四差乘起来有多大。

### 3.1 关系公式
关系张力 = 信息差 × 期待差 × 损失差 × 未完成事件

- 信息差：A 知道 B 不知道的。谁瞒着谁，戏就从哪冒。
- 期待差：A 以为关系是这样，B 以为关系是那样。错位越狠越好笑或越疼。
- 损失差：这段关系要是黄了，各自会丢掉什么。损失越大，拉扯越真。
- 未完成事件：一句没说出口的话、一笔没算清的账、一个没赴的约。它让关系永远"差一步"。

四差里任意一个归零，关系就死了。写之前给每对关系打四个分（0–10），乘积低于 200 的，要么加料要么砍掉。

### 3.2 拉扯三拍：差点得到 / 差点失去 / 再差一点
这是青梅竹马、暧昧、宿敌通用的最省力的糖与刀。
- 差点得到：手快碰到了，门铃响，收回去。
- 差点失去：误会说出口，对方转身，又被一件事拽回来。
- 再差一点：明明只差一句"我喜欢你"，他偏说"饭好了"。
每章关系线至少走一拍，读者才会追着翻。

### 3.3 爽点循环：铺垫 → 反转 → 碾压 → 余波
关系线和打脸线共用这套发动机（男频尤其要背熟）：
- 铺垫：先立一个"他不行"的预期（反派嘲讽、数据难看）。
- 反转：真相或底牌亮出来，预期翻面。
- 碾压：用实力或信息差一次性压过去，给数字、给后果。
- 余波：赢完不立刻收，写对手的狼狈、围观者的嘴脸、主角的下一个小目标。

## 4. 网文人设速成三板斧

网文节奏快，读者三行定生死。人设必须一眼记住、三章立住。

### 4.1 标签反差
先贴一个最强标签，再打一个反标签。
例：林川 = "省理工辍学摆摊仔" + "脑子里装着 2024 年的芯片产业"。
例：许知意 = "八面玲珑咖啡店老板娘" + "在陆时宴面前是闯祸就躲背后的小孩"。
规则：反差得服务内核，不能为反而反。两个标签底下得是同一个怕失去的人。

### 4.2 金手指人格化
金手指别只当外挂，把它写成"有脾气的能力"。
林川的"未来记忆"人格化：它只给产业节点，不给具体操作，逼他亲手踩坑；它像债主，用一次就问他"你爸救出来没"。
好处：金手指有了代价和性格，主角就不会无敌到无聊，爽点也有了刹车片。

### 4.3 反派智商守恒
反派可以坏，不能蠢。蠢反派是爽文最大的出戏源。
守恒公式：反派的每一步都得是"在他认知里最优选"，主角赢要靠信息差或技术代差，不能靠对手自杀。
例：千禧里卡林川的代理商，不突然发疯降价。他算准 2001 年 MPU 缺货，想用断供逼林川让股份。

## 5. 升级版人物卡模板（可填空）

复制这份卡，每个主要角色填一份。填不出"三个反差"的，角色还没活。

```
【角色名】________  外号/小名：________
【一句话定位】他是一个________的人，因为________。

【核心目标】
表层想要：________（这一步剧情推着他走）
里层需要：________（弧光终点才补上）

【核心创伤】
________岁，________事件，从此他认定：________。

【决策顺序】遇事先做①____ ②____ ③____。

【诚实边界】
对____说真话 / 对____编谎 / 对____自欺。

【压力下反应】
被羞辱：____。被抢利：____。在乎的人出事：____。

【表达风格】
高频词：____。急了爱说：____。被夸时：____。

【三个反差】
①对外____ / 对她（他）____。
②在____上精明 / 在____上犯傻。
③对敌人____ / 对家人____。

【弧线类型】正弧 / 平弧 / 负弧（圈一个）
他的 Lie（错信）：________。他的 Truth（真相）：________。

【关系四差】与____：信息差__ 期待差__ 损失差__ 未完成事件________。
```

## 6. 实战范例

### 6.1 《难得夫妻是少年》青梅人设：许知意

定位：八面玲珑的咖啡店老板娘，在青梅竹马陆时宴面前是闯祸就躲背后的小孩。

核心目标：表层想守住"我们家"（她、奶奶、陆时宴这个小圈子）；里层需要是承认"我离不开你"。

核心创伤：8 岁父母离异，被扔到奶奶家。她从此认定"亲近的人迟早走"，用闹腾掩盖在意。

决策顺序：先确认陆时宴在不在 → 再想自己要什么 → 最后才开口。

诚实边界：对客人、对员工嘴硬；对陆时宴偶尔漏真话；唯独"我需要你"这四个字她骗自己这辈子不需要。

压力下反应：一慌就笑，越笑越说胡话；真急了反而沉默，把门一关。

表达风格：碎嘴、爱起外号（叫他"宴宴崽"），用玩笑把真心话包三层。

三个反差：①对外谈笑风生接全桌客 / 对他闹脾气就往他背后躲。②算账精确到分、月底报表零误差 / 在自己感情上装了十年糊涂。③敢怼全公司难缠的股东 / 不敢看陆时宴失落的眼神超过两秒。

具体事件演示（拉扯三拍 + 爽点循环）：
- 高考填志愿那天，陆时宴偷偷把第二志愿改成和她同校。她翻到表，嘴上"谁要你多事"，转头把自己的表也改成了同城。这是"差点得到"，两人都没说破。
- 28 岁，陆家安排相亲。她笑着帮他挑领带，当晚关了店哭到三点，第二天肿着眼说"这条领带丑"。这是"差点失去"。
- 多年后奶奶病危，她撑着店又撑着医院，陆时宴一句"回家吧，有我"把她钉在原地。这是"再差一点"，她差一句"我需要你"，最后说的是"汤我熬了"。

### 6.2 《重生千禧》林川：科技树 + 救父动机

定位：省理工辍学、在华强北摆摊修手机的仔，脑子里装着 2024 年的芯片全产业链。

核心目标：表层先攒钱、再救父、再造出国产芯片；里层需要是"这一次，家不能散"。

核心创伤：前世 2003 年父亲林国栋在镇电子厂被欠薪 8 个月共 2.3 万；2004 年 3 月为凑母亲 6 万心脏支架手术费借了高利贷；4 月 17 日父亲骑摩托送外卖撞渣土车，ICU 17 天，欠债 23 万，林川从省理工辍学去深圳修手机。重生回来，他认定的错信是"老实人只能被吃"。这一世他要改成"我先活下来，再掀桌子"。

科技树（时间线钉死，写时不飘）：
- 2000 年夏：倒卖二手电脑，攒 1.8 万。
- 2001 年：组装复读机 / MP3，毛利 40%。
- 2003 年：切入 MCU 烧录代工，养住父亲医疗费。
- 2005 年：做 ARM 学习板，卖给高校，单价 280，月出 400 块。
- 2008 年：自研电源管理 IC。
- 2012 年：中芯国际 0.18μm 流片首颗 MCU，良率 61%。

决策顺序：先钱 → 再人 → 再技术 → 面子最后。

诚实边界：对父亲谎称"在深圳坐办公室"，其实在华强北摆摊；对合伙人老周全说实话技术底牌；对自己不骗。他知道父亲那场车祸的日期，所以 2004 年 4 月他寸步不离。

压力下反应：被坑先记账再翻脸，不当场发作；真到父亲出事那种级别，他反而异常安静，手稳得吓人。

表达风格：话少，爱用数字和"先 X 后 Y"；被夸就转移话题到电路图。

三个反差：①前世社恐辍学生 / 今生敢当众拍桌谈价格。②对敌人冷到骨里 / 对父亲跪着一勺勺喂饭。③理工直男却记得母亲每顿药名和剂量。

爽点循环演示（救父支线）：
- 铺垫：2004 年 3 月，债主上门，邻居说"林家这回挺不过去了"。
- 反转：林川拿出 2003 年偷偷留的 MCU 代工尾款 3.6 万 + 学习板订单，当场还了高利贷利息。
- 碾压：他算准 4 月 17 日父亲会出门，提前把摩托卖了换公交卡，那天的渣土车撞的是空车，父亲改坐公交，毫发无伤。
- 余波：父亲懵着问"你咋知道我不该骑车"，林川只说"做梦梦见的不吉利"。读者爽，但钩子留着：他救了人，还差 6 万手术费没着落。

## 7. 两本小说落点清单

### 《难得夫妻是少年》落点
- 许知意走正弧：错信"亲近的人会走"→ 结尾承认"我需要你，你也没走"。
- 陆时宴可走平弧：他早信"我们是一家的"，全程用行动把许知意拉过来。
- 每章关系线至少一拍拉扯（差点得到 / 差点失去 / 再差一点）。
- 三个反差卡死：对外老板娘 / 对他小孩；算账精 / 感情糊涂；怼股东 / 躲眼神。
-  traumatic 事件 8 岁父母离异，是她所有"闹腾"的因，改写要写新事件。

### 《重生千禧》落点
- 林川走平弧：重生时已经信"我要救家造芯片"，剧情是拿这真相去撞世界的谎（技术封锁、资本碾压）。
- 救父是全书第一个爽点循环，必须在第 3 章前走完，给数字给后果。
- 科技树时间线钉死，每跨一步写清年份、金额、良率，别让金手指飘。
- 反派智商守恒：代理商算准缺货断供，林川赢靠代差，不靠对手犯傻。
- 金手指人格化：未来记忆只给节点不给操作，用一次问一次"你爸救出来没"。
