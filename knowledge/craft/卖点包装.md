## 一、卖点是什么：一句话卖点公式

卖点不是"这本书讲什么"，是"**读者为什么该把时间给你**"。所有包装（书名/简介/金句）都是这句话的变体。

**一句话卖点公式**：

```
给[目标读者]的[情绪承诺]，靠[独特设定/反差]，在[关键冲突]中兑现。
例（重生千禧）：给爽文读者的"信息差碾压爽"，靠"重生千禧+造芯金手指"，在"技术封锁与商战"中兑现。
例（难得夫妻）：给言情读者的"青梅回甘"，靠"少年夫妻×成年重逢反差"，在"误会×掉马"中兑现。
```

**三个检验**：① 删掉书名读者还懂不懂你要给啥爽？不懂=卖点虚。② 和同品类比，你的"独特设定"够锋利吗？不够=淹没。③ 关键冲突一句话说清吗？说不清= premise 弱。

**反例**："这是一个关于成长与爱的故事"——零卖点，谁都像，谁都不点。

## 二、书名学：平台差异与四准则

好标题四条（Reedsy 编辑部，web核验）：① 引发好奇（提问式/反差式）；② 匹配品类（让读者一眼知道是不是他的菜）；③ 长度克制（能当缩略图看清、能口口相传）；④ 可作营销决策（比封面更先入眼）。

**网文平台书名差异（结合 platforms/ 数据红线）**：

| 平台 | 书名偏好 | 例子走向 |
|---|---|---|
| 番茄 | 短、狠、爽点外露、口语化 | 《重生千禧：从高中毕业开始造芯片》偏长，番茄向可压成《重生之我在千禧造芯片》 |
| 起点 | 概念感、世界观词、中二燃 | 《诡秘之主》《斗破苍穹》式"名词+冲突" |
| 晋江 | 人设/关系锚、文艺留白 | 《某某》《某某年某某事》式人名/关系 |
| 盐言 | 悬疑/强情节钩子、短促 | 一句话悬念式 |
| 七猫 | 口语、直给、下沉友好 | 大白话爽点 |

**铁律**：书名里埋"核心爽点关键词"，让算法分类和读者检索都对得上。男频塞"重生/系统/战神/神豪"，女频塞"甜/撩/婚后/青梅"，别用纯文艺虚词（除非晋江向）。

## 三、简介学：黄金前三句钩子 + 平台风格 + 避坑

简介是"销售页第一屏"。Reedsy 七步法（web核验）：钩子 → 主角 → 冲突与赌注 → 语气匹配 → 权威(如需) → 可比作品 → 狠改到极致。关键是**第一句就是钩子**，因为很多页面只露第一行（Amazon "Read more" 前）。

**黄金前三句结构（网文版）**：

```
句1（钩子）：一个反差/一个悬念/一个承诺 → "重生回1999，他做的第一件事是把邻居家的废收音机拆了。"
句2（主角+冲突）：主角什么人、面对什么局 → "落魄高考生×信息差金手指，要在技术封锁年代造出第一颗芯。"
句3（赌注/承诺）：不看的损失 → "当他造出良率61%的样品，整个行业才想起：这个人，来自未来。"
```

**平台简介风格**：
- 番茄：前 3 句必须炸，直接给"爽点承诺+反差"，不铺垫；
- 起点：可稍铺设定，但第 1 段内必出核心冲突；
- 晋江：重人设与关系张力，"她和竹马""掉马后才发现"；
- 盐言：悬疑/情感钩子前置，短句密度高。

**简介三忌**：① 剧透结局（钩子变剧透，读者不走）；② 堆设定名词（读者 CPU 占满）；③ 文艺腔自嗨（"时光荏苒岁月如梭"——直接划走）。简介是电影预告片，不是梗概。

## 四、金句与人设一句话卖点

**金句**：不是每章结尾硬塞"鸡汤收尾"（那是 AI 味黑名单行为，见最强去AI味铁律），是**角色在高压下自然迸出的、可截图的台词**。好金句=人物性格的浓缩。例："我造的不是芯片，是当年他们不让我进的实验室的门禁卡。"——主角动机一句话立住。

**人设一句话卖点（角色卡必备）**：

```
主角：___（标签），想要___（Want），需要___（Need），最怕___。
例（重生千禧男主）：落魄技术宅重生者，想要证明前世憋屈，需要学会信任伙伴，最怕重蹈孤独老死。
例（难得夫妻女主）：嘴硬心软青梅，想要岁月静好，需要直面当年逃离的真相，最怕被看穿脆弱。
```

Want/Need 拧着写，角色才有拉扯（见西方理论原典溯源·Wants and Needs）。

## 五、追读转化包装：章末 / 书评区 / 伪更新

包装不只发生在"书页"，发生在**每一次读者交互界面**。

- **章末**：用五类强钩子之一（信息炸弹/危机降临/决策时刻/打脸预示/身份暴露），别写"下章预告"（平台规则禁止括号预告，且掉价）。
- **书评区/说的话**：作者 active 互动（回复、发花絮）提升追读黏性；盐言/番茄尤其吃"作者人设"。
- **伪更新/番外**：主线卡时发"角色小传/世界观补"维持热度，但别用废番外凑字数（读者识破反噬）。
- **封面与标题缩略图**：书名在手机封面要能看清（Reedsy 提醒：缩略图太小没人认得出标题）。

**数据闭环**：简介点击率低→改句1钩子；完读率低→改前三章包装与开篇；追读率低→改章末钩子（详见 platforms/ 各平台红线）。

## 七、两本小说落点

**《重生千禧》**：一句话卖点="信息差碾压造芯爽"。书名番茄向可压短；简介句1直接给"重生千禧拆废收音机"的反差钩子，句3给"良率61%惊动行业"的赌注。人设男主 Want/Need 如上。章末钩子已升级为"信息炸弹+危机"（见 Phase5 第010章）。

**《难得夫妻是少年》**：一句话卖点="青梅回甘×成年重逢反差"。书名偏晋江人设向（可保留《难得夫妻是少年》的少年感）。简介重"竹马×掉马×当年真相"的关系张力，不堆设定。金句走"克制人物"路线（她别过脸耳根红），不硬煽。章末钩子用"似有若无的暧昧"续命（见节奏与留白·女频落点）。
