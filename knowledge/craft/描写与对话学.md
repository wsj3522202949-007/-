## 一、描写：让读者自己看见，别替他下结论

告诉读者"林晚很伤心"，读者只会点个头。让读者看见林晚把筷子撂在碗边、汤晃出来一点、盯着油花不动筷，读者自己会难过。

Stephen King 在《On Writing》里讲：描写始于作者想象，终于读者脑中（来源见文末）。Chekhov 说得更狠：别告诉我月亮在发光，给我看碎玻璃上的反光。

核心公式就一句：
描写 = 具体动作 + 感官细节 + 可见后果，用来替换情绪标签和抽象名词。

爽点循环也能套进描写：铺垫（写憋屈的具体画面）→ 反转（画面和预期反着来）→ 碾压（主角一个动作压住全场）→ 余波（旁观者差异化反应）。

## 二、五感写法：每个感官带出不同东西

新手爱堆视觉，写完"她很美"就卡住。五个感官各有分工，挑两三个用，别全上。

| 感官 | 带出什么 | 填空例子 |

  - methods/网文写作最强SOP.md
---|
| 视觉 | 空间、时间、变化 | 下午四点的光打在沈舟侧脸，他左耳后一颗小痣 |
| 听觉 | 权力、距离、停顿 | 沈舟没接话，客厅只剩冰箱的嗡嗡声 |
| 触觉 | 身体真实反应 | 林晚握着冰易拉罐，水珠顺手指淌进袖口 |
| 嗅觉 | 记忆、过去 | 楼道一股炒辣椒味，和高中晚自习后那摊一样 |
| 味觉 | 紧张、恐惧、亲密 | 陈星河咬到舌尖，铁锈味在嘴里散开 |

记住一条：具体到后果。别写"沈舟很愤怒"，写"他把杯子往桌上一磕，杯底水溅出来，洇湿了林晚摊开的简历"。杯子、水、简历，都是读者能看见的后果。

## 三、对话：潜台词、权力、差异化反应

对话不是聊天，是两个人博弈（xs91 对话教程把权力感拆成四个问题：谁主导话题、谁回避、谁话多、谁先沉默，来源见文末）。

潜台词三层写法：
1. 口是心非：嘴上说"我没事"，手在抖。
2. 言外之意：不说"我爱你"，说"路上小心"，声音比平时轻半度。
3. 权力博弈：谁先开口谁占上风，谁沉默谁是武器。

同一场冲突，配角要给不同反应。铁律要求分成四类：巴结、观望、嫉妒、恐惧。只写主角一个人爽，读者记不住。

对话后面接动作、停顿、沉默，别接作者跳出来解释。writingtips.net 的"延迟反应"技法：重话扔出去，先写墙上钟走、写他捏了捏空杯，再让对方开口。

网文对话节奏：短、密、带信息。每句要么推进剧情，要么暴露判断，要么改关系。重要信息别直接说，绕个弯子让读者自己拼。

## 四、正反范例（AI味 vs 人味）

描写反面（AI味，黑名单全中）：
```
那一刻，林晚仿佛被一种说不清的悲伤包裹，沈舟的眼神宛如深潭，
折射出岁月里无法言说的羁绊，彰显了青梅竹马之间深沉而克制的爱意。
```
命中：那一刻、仿佛、宛如、折射出、彰显、一种…的感觉、表演腔。

描写正面（人味）：
```
林晚把冰可乐贴在他手背上。沈舟缩了一下，没抽手。
"你手一直这么凉，"他说，"从小就这样。"
```

对话反面（AI味）：
```
沈舟非常生气地说："我根本不在乎你跟谁在一起。"
林晚悲伤地回答："可是我很在乎你。"
```
问题：情绪词替角色说完了，读者没活干。

对话正面（人味，难得夫妻语境）：
```
"这封面都磨白了。"林晚指了指他书架最上层那本蓝皮笔记本。
沈舟没回头，继续擦桌子："忘了。"
"忘了多少年？"
他停了三秒。"你数得清？"
```

## 五、自检清单（填空式）

描写自检清单：
- [ ] 这句话里有没有"很/非常/十分"？有就删。
- [ ] 情绪词（愤怒/悲伤/温柔）被动作替掉了吗？
- [ ] 有没有至少两个感官细节（视/听/触/嗅/味）？
- [ ] 抽象名词（爱/命运/时光）落到具体物件上了吗？
- [ ] 读者能看见后果吗？比如杯子裂了、汤洒了、纸湿了。

对话自检清单：
- [ ] 这句能不能"不说破"？能就压一层。
- [ ] 谁主导话题？谁在躲？权力谁高谁低？
- [ ] 对话后面接的是动作/停顿/沉默，还是作者跳出来解释？
- [ ] 同一冲突下，配角A和配角B反应一样吗？不一样才真。
- [ ] 重要信息绕弯子了吗？直给的那句删掉重来。

## 六、两本小说落点

《难得夫妻是少年》：用精准刺痛对话。
别写"你变了"这种总结。用具体物件戳。林晚翻出沈舟还存着她高考失利那年写的纸条：
```
"这纸条都黄了。"她捏着那张便签。
沈舟伸手要拿回来："扔了吧。"
"你留了十一年。"
```
刺痛来自数字"十一年"和他"伸手要拿回来"的动作，不靠形容词。

《重生千禧：从高中毕业开始造芯片》：系统吐槽 + 冷静碾压。
铺垫：2000年7月，芯片厂总工周明当众说陈星河那版0.35微米版图是外行画的。
反转：陈星河点开U盘里的仿真波形。
碾压："第三道光罩套刻误差累计三点七微米，你们良率上不了四成。"系统在他脑子里响了一声：【宿主，您又在不小心装逼了。】
余波：周明手里的保温杯顿在半空，旁边两个技术员对看一眼，没人敢接话。

## 七、收尾钩子

上面这套描写和对话，放进章里还得挑位置。你写的那句"沈舟没回头"，到底该放章首、章中还是章尾？放错位置，刺痛感当场减半。下一模块讲结构学怎么排这三幕，先把本篇两条清单存进你的写作前自检。
