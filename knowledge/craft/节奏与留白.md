## 一、节奏本质：读者呼吸曲线

节奏不是"写得快慢"，是**读者情绪的呼吸频率**。爽点学那条"期待→释放→回落"曲线，落到单章和单段，就是呼吸：吸气（压）、憋气（顶点）、呼气（爆）、松气（回落）。读者追更上瘾，是因为你控制了他的呼吸，不是他在自己喘。

三个尺度分开管：全篇靠卷纲的谷底—反转—高潮（见结构学）；跨章靠"连续三章必小上升"（见爽点学）；**章内/段内是本篇主战场**——一章 3000 字呼吸约 4–6 次，一段 3–5 行呼吸一次。

**一句话记住**：节奏是"作者替读者安排呼吸"，不是"自己写得顺不顺"。你顺但读者喘不上气，就是崩了。

## 二、张弛比：用数字管松紧

张=压力/动作/冲突；弛=缓冲/日常/内心/风景。纯张读者累，纯弛读者睡。给一个可算比例做自检尺。

**单元张弛比（一卷约 8–15 万字）**

```
常规爽文：  3:1 ~ 4:1   （偏张留人）
女频言情：  2:1 ~ 3:1   （弛更高，给情绪发酵）
悬疑/权谋： 4:1 ~ 5:1   （长期紧绷，弛只塞在回落模块）
```

用法：写完一卷回头数，张弛比 > 6:1 读者疲劳掉追读；< 1.5:1 失去推力像泡温水。

**章内张弛比（3000 字章）**：张（0–300 钩子、1500–2500 释放）≈ 1500 字；弛（蓄力慢镜、2500–3000 余波）≈ 1500 字。注意"蓄力"是**慢张**（压而不爆），真正"弛"只在回落模块。一章全无弛，读者读完像跑完八百米，第三章就弃。

**反例**：连写 12 章商战无缓冲→追读断崖（脱敏+疲劳）；连写 10 章日常无冲突→书架比掉、算法限流；一章全对话吵架→完读率崩在 60%。

## 三、信息密度：每千字的载荷上限

信息密度 = 单位字数里塞的"新设定/新人物/新概念"数。新手怕读者不懂，一章塞三势力五功法两往事，读者不是不懂，是**处理不过来**。

**密度红线（千字计）**

| 类型 | 新概念上限 | 超限后果 |
|---|---|---|
| 黄金三章 | ≤1 个核心设定 | 塞多读者划走 |
| 普通推进章 | ≤2 个 | 记不住、回头率掉 |
| 设定揭露章 | ≤3 个，且配例子 | 必须马上用，否则白塞 |
| 战斗/动作章 | 0 个 | 此时任务是"爽"不是"教" |

**铁律**：每个新名词须在 3 章内被使用或兑现，否则是噪音（见第四节）。密度过低=水（一章只讲吃饭想心事、零状态变化）；密度过高=糊（同时抛新地图+新反派+新体系，读者 CPU 占满只记得"好乱"）。修复：设定拆到 3 章分发，每章只喂一个，喂完立刻用。

> 实例（《庆余年》风格示意）：范闲进京都首章只立"私生子+神秘老师"，不解释是谁；牛栏街刺杀隔两章才来且直接变动作戏。一次一勺、喂完就打，即密度控制。

## 四、留白：不写比写更狠

留白不是偷懒不写，是**故意不写满**，让读者用想象补全。写三分、留七分。

**三种功效**：①余味——打完脸不写得意，写"他关上门，屋里安静得能听见钟摆"，爽自己长出来；②悬疑——真相临门一脚不写，断在"她终于看清那张脸——"，留白即钩子；③克制人物——大悲不嚎，写"他把手里杯子轻轻放下"，越收读者越炸。

**契诃夫之枪的反面：别乱承诺**（web核验）。契诃夫："第一幕挂上的枪，第三幕必须响；不响就别挂。"（来源见文末）翻译：你花一段写"墙上一把镶宝石的刀"，读者就等它派用场，结局没响=被骗=注水；反之你需要结局用毒，就别结局才掏，前面某章轻轻挂上（他母亲是药师、袖中总有怪味）。**留白是"不解释"，不是"埋了不兑现"。**

**网文尺度**：付费按字/按章，留白过头=没内容。章末留白允许（强钩子一种）；章中情绪留白短、1–2 段内收回；全书级留白只留给"已埋伏笔的回收"，不留给"作者没想好"的空洞。

## 五、跳切：三种剪法

跳切 = 不写过渡，直接切到下一个有戏瞬间。最忌"然后他走进去、坐下、看了看四周"的过渡废话。

**时间跳切**：`废：他回家睡了一觉，次日吃早饭，然后去公司。` → `剪：他回到家。// 次日清晨，公司会议室。` 无戏时段一刀剪，空行或"次日"标记。

**场景跳切**：A 场景戏吃完（状态变了）立刻切 B，不写"告别、出门、上车"。多线并行时必备。

**视角跳切（慎用）**：男主切反派视角透底，造"读者知主角不知"的信息差。但网文别频繁切 POV，否则认主不清。规则：**一条主线锁死主角视角，只在大节点切一次反派/配角当信息炸弹**（如《全职高手》叶修打爆新人后，下一镜切老板办公室"春易老盯着战报脸色沉"，张力凭空多一层）。

## 六、拖剧情 / 水章识别：五盏红灯

写完自查，亮一盏要修，亮两盏以上基本是水。

```
□ 红灯1：本章角色处境/关系/认知三状态无一变化（废戏判定，见结构学）
□ 红灯2：连续 800 字无冲突、无新信息、无钩子（密度≈0）
□ 红灯3：过渡废话（走路/吃饭/醒来/天气）占超 1/3 篇幅
□ 红灯4：纯铺垫无小爽点/小钩子（纯蓄力超 1 章必崩）
□ 红灯5：跳过本章主线理解零损失（可删测试）
```

**可删测试最狠**：整章删掉，故事断了吗？没断就不该存在。

**水章常见伪装**：旅游章（纯写景无事件）、回忆章（大段倒叙不推现在）、聊天章（唠嗑无信息增量）、修炼章（"又练一年实力大增"——直接跳切"一年后"）。

## 七、水章修复手术

识别出水章，先看能改成药还是只能砍。四台手术：

1. **塞钩子（最轻）**：戏有但结尾平，最后 200 字砸信息炸弹/危机钩（见结构学五类强钩子），从"可跳"变"必追"。
2. **提密度（中等）**：过渡废话换信息。原"吃早饭想心事"→"边啃馒头边翻出三年前旧合同，落款名字让他手指一颤"，同篇幅密度 0 变 1 且埋伏笔。
3. **剪跳切（中等）**："走路—进门—落座—寒暄"剪成"他推门进去，包厢里坐着要债的人"，省下字数给真戏。
4. **整章融合（最重）**：连续两章水合成一章，A 章钩子挪 B 章开头，A 有用 300 字并入 B，其余删。

**卡文陷阱**：卡文时最易写水（不知下一步就写发呆回忆凑字数）。遇到卡文先找原因，别用水章拖延（见大纲工程·卡文急救）。

## 九、两本小说落点

**《难得夫妻是少年》（女频）**：张弛比 2:1~3:1，甜章后必接酸章（慢张）别纯糖灌。每章一个新关系变量（误会/旧物）即可。留白主用克制人物+余味：两人差点亲上没亲，断在"她把脸别过去，耳根红了"比"心跳如雷"高级。跳切多跳日常，戏留给重逢/误会/掉马。水章重点：聊天章、旅游章（靠手术1救）。

**《重生千禧》（男频）**：张弛比 3:1~4:1，密度可略高但单章新概念仍≤2。数字即信息（跑分/良率/金额），每个必"被使用"——写 61% 良率，后要有"因 61% 才拿到订单"兑现，否则噪音。留白主用悬疑（"他想起 2004.4.17 那个日期，没说 why"）+克制人物（救父成功不嚎，写"蹲下把脸埋进膝盖"）。跳切用于多线（技术/商战/家庭）并行。水章重点：修炼章、采购章（手术3剪成一镜带过）。
