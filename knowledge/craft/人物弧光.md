# 角色弧光设计（人物弧）

> **适用场景**：写长篇怕人物"扁平/中途变了一个人/读完没成长感"；想让配角有记忆点、反派有下沉因果；想让"爽点"不只是打脸、而是"他终于做对了"的印证。
> **本模块定位**：`人物学.md` §2 已给弧光类型学（平弧/正弧/负弧 + Cron 的 misbelief）。本模块不重复类型，专讲**弧光怎么落地到情节**——每一场戏逼一句错信、每个转折落成一场戏、配角弧/反派弧怎么写、长篇里弧光怎么按卷推进、弧光怎么和爽点/金手指/情绪曲线咬合。配 `模板库.md §2.1 弧光栏`。
> **关联文件**：[人物学.md](./人物学.md)（弧光类型学·认知系统七维）· [结构学.md](./结构学.md)（三幕/Scene-Sequel）· [爽点与情绪曲线.md](./爽点与情绪曲线.md) · [大纲工程.md](./大纲工程.md)（卷纲切分）· `模板库.md §2.1`

## 一、一句话：弧光是"内在认知走了哪条路"

人物学 §2 已定义：正弧 = 挣脱错信抱住真相；平弧 = 握着真相去撞世界的谎；负弧 = 被错信吞掉。

本模块只补一句关键的：**弧光不是"结尾写一句他变了"，是每一场戏都在压他那句错信。** Lisa Cron 的金句——"剧情只是压力机，压的是主角脑子里的那句错话"——是弧光落地的唯一操作法则。

所以判断一场戏值不值得写，先问：**这场在逼他哪句错信？** 没逼，这场就废了（和人物学 §2.4 一致，这里把它变成可执行的写稿纪律）。

---

## 二、弧光 × 情节：硬绑定映射表

把弧光的三幕节点，逐一翻译成"这一场戏主角在经历什么"。写细纲时照这张表填，弧光自然长出来，不靠结尾硬转。

| 弧光节点 | 情节对应（这场戏发生什么） | 主角内在变化 |
|---|---|---|
| **Ghost（创伤事件）** | 开篇前已发生，用 1 个具体物件/细节回带（别写回忆杀长段落） | 他曾信了某句错话 |
| **Lie（错信）亮出** | 铺垫段：他用这句错话做决策，读者一眼看出"他活在自己的谎里" | 错信稳固 |
| **第一情节点** | 一场"掀翻世界"的大事变，把他推进不可回头 | 错信第一次被撼动 |
| **中点（moment of grace）** | 一个反转式揭示，他第一次瞥见真相的可能 | 裂痕出现 |
| **第三情顶点** | 最大惨败，他被迫直视"错信害了他" | 错信崩塌 |
| **高潮** | 他选择真相，并用它解决外部危机 | 抱住真相 |
| **收尾** | 他活在真相里做的新决定（一个动作即可，不靠独白） | 弧光闭合 |

> 网文节奏纪律：每个节点必须同时推进**外部情节**和**内部认知**，二选一就散。读者追的是"他怎么赢"，但记住的是"他怎么变"。

## 三、弧光转折点场景模板

每个弧光节点落成一场戏时，用这张卡（和 `大纲工程.md` 的细纲卡同源，多两格"认知"）：

```
【弧光节点】Ghost / Lie / 第一情节点 / 中点 / 第三情顶点 / 高潮 / 收尾
【外部】目标___ / 阻力___ / 行动___ / 后果___ / 新状态___
【内部】本场逼他的错信：___
       他嘴上/行动上怎么护住这句错信：___
       这场埋下的"反例"种子（日后戳破用）：___
【钩子】这一场结束时，读者知不知道他错了？（知道→期待他何时醒；不知道→埋悬念）
```

**写稿铁律**：写完一场，回看"内部"两格——如果这场没动他的认知，要么补一句错信护体/裂痕，要么删。爽文尤其容易"全程打脸但人设零成长"，读者追到后期会觉得"这人从头到尾没变，只是越来越强"，弃书率高。

## 四、配角弧与反派弧

主角是 Spine，配角是 Ribs。扁平配角 = 只有功能没弧光；好配角 = 一句话能说出"他为什么是这个样"。

### 4.1 配角弧三种用法
- **成长弧配角**：跟主角对照，主角走正弧、他走平弧或负弧，反差照出主题（如忠仆始终信错人）。
- **平弧配角**：握着真相的"定海神针"，在主角崩时拉他一把（无敌流里常是老爷爷/师父）。
- **功能弧配角**：只为推主线存在，给"记忆点"即可，不必硬写弧光——但记忆点要来自**行为反差**，不是标签（见人物学·人设三板斧）。

### 4.2 反派弧（≠脸谱化）
最烂的反派是"为坏而坏"。给反派一条**负弧**：他也有自己的 Lie，他信"强权即真理""弱者活该"，并为此付出因果代价。读者未必同情，但会觉得"这人自洽"。
- 反派弧下沉每一步都要有因果，别突然降智送人头。
- 高阶写法：反派和主角信**同一句错话的不同版本**，撞到一起才炸（主题对撞）。

## 五、卷级弧光节奏（长篇专属）

短篇弧光可在一章走完；**长篇（如 300 万字级）弧光绝不能一章闭环**，否则"他变了"太廉价。按卷推进：

- **卷纲切分 = 弧光阶段切分**：每一卷对应弧光的一个阶段（卷1 错信稳固 / 卷2 第一次裂痕 / 卷3 中点瞥见 / 卷4 惨败 / 卷5 选择 / 卷6 活在真相）。卷纲的"承诺"里写清：本卷主角认知推进到哪。
- **男频平弧怎么写**：平弧男主"我本就对"，弧光不在"他变"，而在"世界慢慢承认他是对的"。爽点 = 每次世界被他撞醒的瞬间。金手指放大他的本色（人物学铁律三），不给他换性格。
- **女频正弧怎么写**：常用"关系变量"推进弧光——她和某人的关系每推进一步，她对自己/世界的错信就松一寸（详见 `副线设计.md` 感情线作为弧光载体）。

> 检查法：写完一卷，问"这卷结尾主角对那句错信，比卷首信得更多还是更少？"没变化，这卷弧光空转。

## 六、弧光 × 爽点 × 金手指 × 情绪曲线

四者不是并列，是**同一条绳子的四段**：

- **金手指**：放大主角本色，不换性格（人物学铁律三）。林川用芯片赚钱，骨子里还是"先记账再翻脸"的林川——金手指是让他"更敢做自己"，不是变成另一个人。
- **爽点**：是"他终于用真相/本色做对了"的印证。读者爽，是因为"憋了这么久他终于活明白了"。纯打脸无弧光支撑，爽感会钝。
- **情绪曲线**：弧光的至暗 = 情绪曲线低谷（第三情顶点惨败）；弧光高潮 = 情绪峰顶。两者必须重合，否则"爽得没重量"。
- **章末钩子**：弧光裂痕处最适合断章——读者既盼他醒，又怕他醒不来。

## 七、人物卡·弧光栏（填空，对齐 `模板库.md §2.1`）

```
【弧光类型】正弧 / 平弧 / 负弧（圈一个）
【核心错信 Lie】一句他深信、故事要拆穿的歪理：___
【创伤 Ghost】哪件事让他信了这句错话（具体场景，1 句话）：___
【弧光终点】结尾他抱住什么真相（动作，不靠独白）：___
【卷级推进】卷1___ / 卷2___ / 卷3___ / 卷4___ / 卷5___ / 卷6___（每卷认知推进到哪）
【金手指×本色】金手指放大他哪一面，绝不给他换：___
```

## 八、两本小说落点

**《重生千禧》（男频·平弧）**：林川的 Lie 不是"我没能力"，而是"凡事亲力亲为才稳"——重生后他用芯片/系统杠杆化这一切，但骨子里"先记账再翻脸"不变。弧光不在"他变好"，在"世界一次次承认他是对的"（商战卷/技术封锁卷的爽点即弧光印证）。卷纲按赛道切换切，每卷弧光阶段 = 世界被撞醒的程度。

**《难得夫妻是少年》（女频·正弧·关系变量驱动）**：女主/关系线的弧光用"误会→旧物→掉马→同居"四个关系变量推进——每个变量推进一步，她对"我们只是青梅"的错信就松一寸。这是本书亮点（少年期占 1/3 篇幅），弧光载体是感情线而非外部危机，写细纲时把"关系变量"和"认知推进"绑在同一张卡上（见 `副线设计.md` §6）。
