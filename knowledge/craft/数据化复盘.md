# 数据化复盘（用数据指路，不凭感觉改）

> **适用场景**：开书后有后台数据、追读/完读掉了不知道改哪、凭手感改稿越改越差、想用 A/B 测开头、每周想做一次结构化复盘。
> **本模块定位**：`SKILL.md` §十六 已给数据复盘体系框架（指标/诊断流程/决策表/A-B/模板）。本模块把它**深拆成可执行的复盘手册**——指标字典、诊断树、用数据反推创作问题、周复盘流程、平台差异、两本书各自该盯什么。配 `模板库.md §8 数据复盘周表`。

## 一、为什么必须数据复盘

连载期最忌"凭感觉改"——你觉得这章写得好，数据可能说读者看到第 3 段就跑了。**让数据指路，不是让数据替你写**。数据是诊断仪，不是方向盘：它告诉你"哪病了"，药方还是创作方法论（节奏/爽点/钩子/人设）。

核心纪律（SKILL §16）：**改完多等一周再看，不刚改一天就下结论。** 单章波动有噪声，趋势才有信号。

## 二、核心指标字典

| 指标 | 定义 | 看什么 | 预警信号 |
|---|---|---|---|
| **完读率** | 一章从头读到尾的比例 | 内容抓不抓人 | 某章骤降 → 从上一章开始改（毒点常在前一章埋下） |
| **追读率** | 看这章的人里多少看下一章 | 持续吸引力 | 持续下滑 → 节奏/钩子出问题 |
| **章末跳出** | 读到章末就走、不点下一章 | 章尾钩子强度 | 高 → 章末钩子弱（见 `章法与钩子学.md`） |
| **收藏** | 长期价值认同 | 人设/主线钩子 | 涨不动 → 人设记忆点/主线吸引力不足 |
| **推荐票** | 情绪认同强度 | 爽点/高光 | 某章暴涨 → 这章做对了，复制 |
| **段评/章说** | 读者原话（最真实） | 毒点/爽点定位 | 高频"尬/毒/水" → 定位毒点 |
| **首秀（番茄）** | 新书前 N 章的推荐曝光转化 | 开篇切入点 | 首秀不过 → 前 3 章切入点/爽点密度（签约痛点） |
| **均订（起点）** | 稳定订阅数 | 中期留存 | 掉订 → 中段节奏/副线散 |

> 平台差异：番茄重**追读+完读+首秀**（算法推流靠读完率），起点重**均订+月票**（付费深度），晋江重**收藏+积分+长评**（见 `platforms/` 各篇）。同一本书切平台，盯的指标权重不同。

## 三、数据诊断树（哪掉查哪）

```
看曲线：哪章明显下滑？
  → 从上一章看起（毒点常在前一章埋下）
  → 定位病因：
      完读率掉 + 章末跳出高  → 章末钩子弱 → 重写入尾（章法与钩子学·章尾13式）
      追读率掉但完读稳      → 节奏太快 → 插心理/环境/生理反应撑开（节奏与留白）
      收藏不涨              → 人设记忆点/主线钩子不够 → 回炉 人物学/大纲工程
      段评集中吐槽某角色    → 减戏份或改人设（反馈驱动）
      某章完读骤降          → 这章之前有逻辑硬伤/虐无必要/水章 → 删或圆
  → 改完多等一周再看，不刚改一天下结论
```

**决策表（扩展 SKILL §16.3）**：

| 数据现象 | 动作 |
|---|---|
| 完读率掉、章末跳出高 | 章末加悬念/反转/期待 |
| 追读率掉但完读稳 | 节奏太快，插心理/环境/生理反应撑开 |
| 收藏不涨 | 人设记忆点/主线钩子不够，回炉 |
| 段评集中吐槽某角色 | 减戏份或改人设 |
| 推荐票某章暴涨 | 记下这章做对的爽点，复制配方 |
| 首秀不过 | 前 3 章重刷：切入点+爽点密度+去 AI 味（签约三痛点） |

## 四、用数据反推创作问题

数据是表象，根因在创作四要素，按信号反查：

- **钩子弱**（章末跳出高）→ `章法与钩子学.md`：章尾 13 式里挑合适的，禁"下章预告"括号。
- **节奏平/太快**（追读掉但完读稳）→ `节奏与留白.md`：坑-铲-花园、张弛呼吸、砍水章。
- **爽点不够**（推荐票平、收藏涨不动）→ `爽点与情绪曲线.md`：情绪公式、十大爽点引擎、爽点密度表。
- **人设崩**（段评吐槽）→ `人物学.md` 人设不崩三铁律 + `人物弧光.md`。
- **副线散**（中期掉订）→ `副线设计.md`：占比自检、汇流节点。

## 五、A/B 与实验

- **多版开头**：前 3 章写 2–3 个切入点，小范围测完读率，留胜者（番茄首秀尤其适合）。
- **读者反馈闭环**：每章发 1–2 个专属读者，收集"主角叫啥/想干啥/在干啥"三问（SKILL §11.7），段评即免费焦点小组。
- **实验记录**：在 `写作进度.md` 或周表记"本次测试 → 结论"，别靠记忆。例："第 12 章试章尾悬念式 vs 反转式，悬念式追读 +3%，留反转"。

## 六、周复盘流程（对照 `模板库.md §8`）

每周固定 30 分钟，填一次数据复盘周表：

1. **指标快照**：本周追读/完读/收藏/段评趋势（画一条线，看趋势不盯单点）。
2. **下滑章节定位**：哪章掉，从上一章找毒点，记病因。
3. **读者反馈闭环**：段评高频词归类（爽/尬/毒/水/催更）。
4. **A/B 与实验**：本周做了什么测试，结论是什么。
5. **下周动作**：改哪几章、试什么新钩子，写成待办。

> 节奏纪律：改完等一周再评判，避免被单日噪声带节奏（也见 `卡文急救.md` 型8：数据焦虑别边写边盯）。

## 七、两本小说数据关注点

- **《重生千禧》（男频·番茄/起点）**：盯**追读率+首秀**（科技重生爽文靠前 3 章切入点过首秀）；中段掉订查"副线散/承诺跳票"（伏笔账本）；技术线时间锚（2004 等真实节点）出错会掉完读，靠段评抓硬伤。
- **《难得夫妻是少年》（女频·晋江/番茄）**：盯**收藏+段评情绪**（女频重关系拉扯的"爽感"在段评里最明显）；少年期占 1/3 篇幅是亮点，完读率在这段应高；掉收藏查"感情线拉扯节奏"是否断（见 `副线设计.md` §6）。
