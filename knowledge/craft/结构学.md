## 一、结构体系总览：七种骨架怎么选

七种骨架不是七选一，是七把不同刻度的尺。长线用大尺，场戏用小尺。下面每张表都按"主张 / 关键刻度 / 网文落地 / 一句话记住"拆。

### 1. 三幕 / 多幕结构（Syd Field，1979）

**主张**：完整故事分建置、对抗、结局。第一幕建置世界与人物，结尾用"情节点一"把主角推进不可回头的局；第二幕对抗最长，中段用"中点"劈成上下两半；第三幕收束。比例约 25%／50%／25%。

**网文落地**：直接等于"卷宗结构"的放大版。第一幕 = 开篇卷（黄金三章到第一个小高潮），第二幕 = 发展卷群（换地图、升级、感情线），第三幕 = 收尾卷（最终战、真相、落幕）。"情节点一"就是主角被动卷入的那件事。

**一句话记住**：起承转合只是名字，真正有用的是"中点把故事劈成两半"。

### 2. Save the Cat 15 节拍表（Blake Snyder，2005）

**主张**：把主流电影拆成 15 个固定节拍，从开场画面到终场画面，连占比都标好。最关键的发明是"乐趣与游戏"（Fun and Games）节拍：这是读者买票要看的核心承诺，必须足量兑现（来源：savethecat.com、chapter.pub 节拍详解）。

**15 格顺序**：开场画面 → 主题呈现 → 建置 → 催化剂 → 辩论 → 进入第二幕 → B 故事 → 乐趣与游戏 → 中点 → 坏蛋逼近 → 一无所有 → 灵魂暗夜 → 进入第三幕 → 终场 → 终场画面。

**网文落地**：15 节拍 = 一卷的节奏模板。开场画面 = 卷首钩子，催化剂 = 卷内第一个冲突触发，中点 = 卷中反转（假胜或假败），一无所有 = 卷底谷底，终场画面 = 卷末新状态呼应卷首。重点盯"乐趣与游戏"：每卷必须有一个让读者进来就为了满足的具体爽点。

**一句话记住**：节拍表是诊断尺，不是填空卷；哪格空了，哪段就塌了。

### 3. 英雄之旅（Joseph Campbell《千面英雄》1949 / Christopher Vogler《作家之旅》1992）

**主张**：坎贝尔从全球神话提炼出"单一神话"，原始 17 步，归为启程、启蒙、回归三幕。
沃格勒压成 12 步给编剧用：平凡世界 → 冒险召唤 → 拒绝 → 导师 → 跨越门槛 → 考验盟友敌人 → 接近洞穴 → 磨难 → 奖赏 → 回归之路 → 复活 → 携宝归来（来源：authorflows.com、monomythonline.com）。

**网文落地**：男频升级流、系统流、重生逆袭的天然骨架。平凡世界 = 重生前的憋屈，冒险召唤 = 金手指觉醒，导师 = 老教授/系统/前世记忆，磨难 = 第一次技术或商战硬仗，携宝归来 = 身份曝光或产业成型。

**一句话记住**：它管"人怎么变"，不管"爽不爽"；爽感要另配网文节奏。

### 4. Pixar Story Spine（Kenn Adams 1991，皮克斯采用）

**主张**：用一串因果句把故事锁死：Once upon a time（从前）… Every day（每天）… Until one day（直到一天）… Because of that（因为这样）… Because of that（因为这样）…
Until finally（直到最后）… And ever since then（从此以后）（来源：storytellingdb.com、writeforanimation.com）。

**网文落地**：最适合写"一句话梗"和"卷首一句话钩"。Every day 用来立人设常态，Until one day 是开篇爆点，Because of that 的链条就是"爽点循环"的因果链，缺一环读者就出戏。

**一句话记住**：它逼你写清"因为所以"，治的是剧情散架。

### 5. Snowflake Method 雪flake 法（Randy Ingermanson）

**主张**：从一句话开始，像科赫雪花分形一样一层层放大：1 句摘要 → 1 段（5 句）摘要 → 人物一页 → 1 页概要 → 人物概要 → 4 页概要 → 人物图表 → 全场景清单 → 每场景摘要 → 动笔（来源：ingermanson.com、blog.chapter.pub）。

**网文落地**：给"设定狂魔"和"卡文专业户"用。先写 15 字以内的句子，再扩成 5 句（建置／转折点 1／中点／转折点 2／结局）。写不完雪flake 前 3 步别动笔，能少写 10 万字废稿。

**一句话记住**：从中心往外长，别从第一页往后挤。

### 6. K.M. Weiland 三幕结构法

**主张**：在三幕里塞进精确节拍与百分比（来源：helpingwritersbecomeauthors.com 结构时机文）：
钩子 1% → 激励事件 12% → 第一情节点 25% → 第一个挤压点 37% → 中点 50% → 第二个挤压点 62% → 第三情节点 75% → 高潮 88% → 结局 100%。
挤压点（Pinch Point）是反派秀肌肉、提醒主角代价的地方。

**网文落地**：这是你"卷内节拍表"的精确版。把一卷当一部电影，25% 处放卷内第一情节点（不可回头），50% 处放卷中反转，75% 处放卷底谷底，88% 处放卷高潮。

**一句话记住**：它给你的是"百分比路标"，治的是节奏前松后紧。

### 7. 网文卷宗结构（本土实战）

**主张**：总纲 → 卷纲 → 章纲三层（来源：storyalter.com 网文大纲指南）。黄金三章定生死：第一章立刻出事，第二章给金手指与行动，第三章给小回报+章末钩子。
每 10 章一个完整单元（冲突 → 施压 → 反转 → 爽点 → 钩子），每 5 万字一个小高潮（来源：今日头条网文六件事文）。

**网文落地**：这是前面所有西方骨架的"压缩执行版"。一卷 = 一个英雄之旅的小循环 = 一次雪flake 的段落放大 = 一张 Save the Cat 节拍表的落地。

**一句话记住**：西方骨架管"不散"，卷宗结构管"不掉人"，两样都得要。

### 选骨架决策清单（填空）

```
我的书类型：［男频／女频］ ［题材］
核心卖点一句话：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
主角要的"变"是什么：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
选骨架：
  □ 长线成长变形明显 → 英雄之旅 + Weiland 百分比
  □ 单元剧/换地图爽文 → 卷宗结构 + Save the Cat 卷内节拍
  □ 重人设轻剧情 → Pixar Spine 立常态 + 卷宗节奏
  □ 设定复杂易崩 → Snowflake 前 3 步先锁死
```

## 二、场戏发动机：Scene & Sequel（德怀特·斯万）

德怀特·斯万在《Techniques of the Selling Writer》（1965）里把最小的叙事单元拆成两块：Scene（行动）和 Sequel（反应）。经典模型是：

- **Scene（场戏）**：目标 Goal → 冲突 Conflict → 灾难 Disaster
- **Sequel（续篇）**：反应 Reaction → 困境 Dilemma → 决定 Decision

这套模型翻译成网文作者能直接用的五步，就是：**目标 → 阻力 → 行动 → 后果 → 新状态**。下面逐格拆。

### 五步落地的定义

**目标**：本场戏主角明确要拿到什么具体东西。必须"能被拍照验证"，不能是"想证明自己"这种虚的。虚的拆成具体动作：想证明爱她 → 具体目标是当众送她那枚攒了三个月钱的戒指。

**阻力**：挡路的对手、环境或自身缺陷。规则只有一条：只有一方能赢。两人抢同一个女孩，只有一个能牵手；主角想拦炸弹，反派想引爆炸弹，只能活一个。阻力要具体、要升级，不是"有点困难"。

**行动**：主角为拿目标做的对抗动作。斯万原式里行动嵌在冲突升级里，我们单独拎出来，方便写打戏和商战。行动要让读者看见主角"在搏"，不是坐着想。

**后果**：本场戏的结果。三条路：没拿到目标／拿到了但捅出新问题／表面拿到其实亏了。斯万叫它"灾难"，不一定要死人，但一定要"有事发生"。没有后果的场戏 = 废戏。

**新状态**：角色处境、关系或认知变了。这一步是桥，自然引出下一场的"目标"，也就是 Sequel 里"决定"的落点。新状态不写清，下一章就接不上。

### 五步和斯万原式的对应

```
斯万 Scene：   目标 Goal ──→ 冲突 Conflict ──→ 灾难 Disaster
网文五步：     目标 ──────→ 阻力(冲突) ──────→ 后果(灾难)

斯万 Sequel：  反应 Reaction ──→ 困境 Dilemma ──→ 决定 Decision
网文五步：     (新状态里含反应与困境) ──────────→ 新状态 = 下场目标
```

### 正范例（用《重生千禧》示意）

目标：男主想用暑假倒卖翻新电脑，攒出第一笔启动资金 8000 元。
阻力：二手市场老板故意拿翻新机当原装卖，还放话"学生仔懂个屁"，旁边两个地痞盯上他。
行动：男主当场拆机，报出具体型号参数和翻新痕迹，把老板怼到哑口，价格压到 3200 一台。
后果：当天净赚 8000，但地痞记住了他"这小子有点门道，得盯死"。
新状态：有了本钱，也多了一群敌人。下一章目标自然变成"怎么避开地痞把货卖出去"。

### 反范例（新手常踩）

目标：男主想"变得更强"。（虚，拍不了照）
阻力：训练很辛苦。（不是只有一方能赢的对抗）
行动：他练了一整天。（坐着想式，没搏）
后果：他变强了。（没有"灾难"，没有事发生）
新状态：他更强了。（没变关系没变认知，下一章接不上）
这一段读者看完的感觉是"然后呢"，这就是废戏的典型长相。

### 爽点循环怎么塞进五步

铺垫（目标+阻力立住憋屈）→ 反转（行动里主角亮出超出预期的手段）→ 碾压（后果里反派崩溃/主角通杀）→ 余波（新状态里围观者震惊、仇人后悔、伏笔埋下）。四步缺一环，爽感掉一半。

## 三、大纲五层分离：设定 / 大纲 / 细纲 / 正文 / 追踪

很多书写到 30 万字崩，不是不会写，是五层混在一起。把五层切开，每层只干一件事。

### 第一层：设定层（一次性，不进正文）

装世界观规则、金手指边界、人物底层档案、时间线大事表。作用：写的时候随时查，不靠脑子记。

**禁忌**：绝对不能直接搬进正文开头当 info-dump。设定是给作者看的字典，不是给读者看的前言。

### 第二层：大纲层（总纲 + 卷纲）

装主线节点与转折点，用 Weiland 百分比或字数标好。一卷一弧，明确卷首钩子、卷中反转、卷底谷底、卷末新状态。

**字段**：卷序 ／ 卷名 ／ 核心冲突 ／ 起止字数 ／ 卷内第一情节点（25%）／ 中点（50%）／ 第三情节点（75%）／ 卷高潮 ／ 卷末新状态。

### 第三层：细纲层（写章前填）

每章一张卡，写目标／阻力／后果／新状态／钩子类型。这是本模块的核心产物，写正文前必填。

**字段**：章号 ／ 本章目标 ／ 阻力 ／ 行动要点 ／ 后果 ／ 新状态 ／ 章末钩子（五选一）／ 爽点级别（小/中/大）。

### 第四层：正文层（写出来的字）

只管把细纲变成有画面、有情绪、有对话的文字。不要在正文层临时发明大设定、大转折，那是大纲层的事。

**纪律**：正文里改了关键走向，立刻回第三层改细纲，再回第二层改卷纲。否则三层对不上，后面必崩。

### 第五层：追踪层（写章后填）

装已埋伏笔表、角色状态变更表、爽点分布表、平台数据复盘。这是改稿和续写的弹药库。

**字段**：伏笔 ID ／ 埋入章 ／ 回收章（预留）／ 爽点分布（章号+级别）／ 追读异常章（掉点那一章标红）。

### 反例：混层的惨状

把世界观设定写进第一章开头（设定层混进正文层）→ 读者前三行划走。把爽点分布表写在细纲里（追踪层混进细纲层）→ 细纲变报表，没法用。把临时想的反转直接写进正文不补大纲（正文层越权）→ 30 万字后主角人设前后打架。

## 四、结构健康检查、废戏判定、节奏切换

### 结构健康检查清单（逐条打勾）

```
□ 开场 300 字内有人物+冲突，没有大段背景介绍
□ 第一章出事，第三章给小回报+章末钩子
□ 每卷有卷首钩子、卷中反转、卷底谷底、卷末新状态
□ 主角每个大决定都是"主动选"，不是被推着走
□ 中点（50%）有范式反转，不是平推
□ 每 3–5 章至少一个小爽点，没断过
□ 每章结尾都有五类强钩子之一，没有"下章预告"括号
□ 连续三个情绪型章节后，插了一个信息型或动作型章节
□ 所有伏笔在追踪层有 ID 和回收章
```

### 废戏判定（一句话砍章）

问自己一句：**这场戏之后，角色的状态变了吗？**

状态指三种之一：处境变了（钱/地位/地盘）、关系变了（敌/友/恋）、认知变了（他看世界的方式）。三种都没变，这场戏删掉不影响故事，就是废戏。

再细一点：把每章的后果和新状态两栏拉出来看。如果"后果"写的是"他继续想办法"，"新状态"写的是"他还是那样"，这一章就是注水，砍。

### 节奏切换规则

情绪型章节：内心戏、感情戏、悲伤/甜蜜慢镜头。连写三章情绪型，读者脑子发胀，追读掉。

规则：**连续三个情绪型章节后，必须插一个信息型或动作型章节**。

- 信息型：抛出新设定、新数字、新身份线索（信息炸弹）。
- 动作型：打脸、商战交锋、逃跑、反转现场（碾压）。

反过来也成立：连续三章动作型不喘气，读者累，要在中间塞一个短情绪型当喘息。张弛交替，别一条道冲到底。

### 章末五类强钩子（禁用"下章预告"括号）

1. **信息炸弹**：章末甩一个重磅信息，读者不翻下一章睡不着。例："他翻开日记本最后一页，上面画着一张和自己一模一样的脸。"
2. **危机降临**：威胁已经到了门口。例："门外传来脚步声，那是三个不该出现在这里的人。"
3. **决策时刻**：主角必须二选一，两个都不好。例："是继续烧钱做高端芯片，还是先做低端套件？天亮前要定。"
4. **打脸预示**：反派刚放完狠话，主角手里已经握着反转的牌。例："昨天骂他穷酸的同桌，还不知道他桌上那块板子值县城一套房。"
5. **身份暴露**：伪装要破了，或真实身份被认出。例："有同学认出他，就是网上那个芯片少年，消息正传回原高中。"

**禁用写法**："（欲知后事如何，且听下回分解）"、"(下章揭晓)"、"（悬念留到明天）"。这种括号等于替读者按了退出键。

## 五、填空模板：细纲模板 + 卷纲模板

### 细纲模板（每章一张，写前填）

## 六、范例：《重生千禧》第 4–10 章结构拆解

以下为结构示意（非真实剧情），用来示范"每章填目标/阻力/后果/新状态 + 钩子 + 爽点循环"怎么落。男主重生回 2000 年，刚高考完，带未来半导体知识，从倒卖翻新机攒启动资金起步。

### 第 4 章

目标：暑假倒卖翻新电脑，攒出第一笔 8000 元。
阻力：二手市场老板拿翻新机当原装卖，放话"学生仔懂个屁"，两痞盯上他。
行动：当场拆机报参数压价，3200 一台吃下。
后果：当天净赚 8000，但被地痞盯死。
新状态：有本钱也多了敌人。下章目标＝避开了把货卖出。
钩子：**危机降临**（地痞放话"这小子敢来就废他"）。爽点：小（首胜）。

### 第 5 章

目标：转线上论坛卖配件，避开地痞。
阻力：论坛大佬质疑"高中生懂个屁硬件"。
行动：发一篇超前的 DDR 内存选购帖，列具体时序参数。
后果：帖子爆了，深圳一家贸易公司私信要货。
新状态：拿到第一张 B2B 订单意向。下章目标＝用预付款进货。
钩子：**信息炸弹**（对方报出某型号芯片走私价，远超他认知）。爽点：小（被认可）。

### 第 6 章

目标：用订单预付款进第一批货。
阻力：供货商要现款，预付款不够；找发小合伙被半信半疑。
行动：用未来行情说服发小投 5000，货发到却被海关扣。
后果：资金链断，货扣在海关，要约谈家长。
新状态：跌入谷底，信任也险些碎。下章目标＝自证清白保货。
钩子：**危机降临**（海关通知涉嫌走私，要约谈家长）。爽点：中（压抑到位，为后续反弹蓄力）。

### 第 7 章

目标：证明清白并保住货。
阻力：成年人根本不信一个高中生。
行动：拿出提前打印的海关合规文件和"造学习机"真实用途说明。
后果：海关放行，还夸他"少见的有谱少年"。
新状态：货到手，圈内传出"这少年靠谱"的口碑。下章目标＝把芯片知识变现。
钩子：**打脸预示**（当初质疑他的论坛大佬主动私信求合作）。爽点：中（铺垫→反转→碾压→余波走完）。

### 第 8 章

目标：做一块教学用 MCU 开发板，把知识变钱。
阻力：没产线，手工焊接良率低。
行动：白天跑华强北找代工，晚上画电路图。
后果：第一版点亮，但成本太高卖不动。
新状态：技术跑通，商业卡住。下章目标＝降价走量。
钩子：**决策时刻**（继续烧钱做高端，还是先做低端套件？）。爽点：小（技术爽）。

### 第 9 章

目标：降价做学生套件走量。
阻力：大厂山寨低价倾轧。
行动：用未来开源生态思路做教程社区，绑定职业学校。
后果：三所职高下单 200 套，月流水破 5 万。
新状态：小团队成型，少年老板初具雏形。下章目标＝回校前定型不露馅。
钩子：**身份暴露**（同学认出他"就是网上那个芯片少年"，消息传回原高中）。爽点：大（第一桶金+身份悬念）。

### 第 10 章

目标：趁暑假结束前定型产品，回校不露馅。
阻力：班主任要他交"暑期实践报告"，会扒出生意。
行动：用合规外壳包装成"青少年科创项目"交差。
后果：班主任大赞，还推荐他参加省赛。
新状态：身份安全，且拿到省赛跳板。下卷目标＝省赛里碰未来宿敌。
钩子：**信息炸弹**（省赛名单里出现未来宿敌的名字）。爽点：中（暗爽+新线开启）。

**这一串的节奏数**：4–6 章是"压抑蓄力"（铺垫），7–9 章是"反转碾压"（爆发），10 章收余波并开新线。连续三章情绪/慢章（6 谷底、7 反应、8 技术慢镜）后，第 9 章用动作型大爽点劈开，正是第四节切换规则的应用。

## 七、两本小说落点

### 《难得夫妻是少年》（女频·都市言情·青梅竹马）

**骨架选型**：Pixar Spine 立"青梅竹马常态" + 卷宗结构管甜虐节奏 + Weiland 百分比管长线不散。

**场戏五步怎么用**：每章目标必须是"两人关系往前拱一步"的具体动作（不是"想靠近她"）。阻力多用"误会与第三方"制造酸爽。后果常走"拿到但捅出新问题"（和好了但前任出现）。

**钩子偏好**：多用"身份暴露"（掉马/被撞见）和"危机降临"（误会加深/家长反对），少用信息炸弹。每章 3000–4000 字，甜章后必接一个酸章做反差。

**爽点循环**：女频爽点是"守得云开"，不是打脸。铺垫（误会憋屈）→ 反转（他其实一直在）→ 碾压（用行动让你无话可说）→ 余波（读者磕到糖）。每 3–5 章一个小糖点，每卷一个大糖点（确认关系/解除误会）。

**五层分离重点**：设定层锁死"青梅时间线"和"两家关系史"；追踪层记"误会台账"，每一条误会必须标回收章，否则读者记仇。

### 《重生千禧：从高中毕业开始造芯片》（男频·科技重生爽文）

**骨架选型**：英雄之旅（重生=携宝归来变体）+ 卷宗结构 + Save the Cat 卷内节拍。每卷一次"技术/商战小循环"。

**场戏五步怎么用**：目标永远具体带数字（赚 8000、点亮开发板、月流水 5 万）。阻力用"现实阻碍+看不起他的人"。后果走"碾压"路线多，但每隔几章插一次"一无所有"谷底防麻木。

**钩子偏好**：信息炸弹（未来知识差）和打脸预示（当初嘲他的人后来跪）是主力。每章 3000–4000 字，章末必有钩子，飞卢式密度可压缩到 3 章一周期，起点式可拉到 15–20 章再爆。

**爽点循环**：标准"压抑 60% + 铺垫 20% + 爆发 10% + 释放 10%"。别一上来就无敌，让读者跟着憋完再爽。数字要具体，"三天赚三百万"比"赚了很多"有冲击力。

**五层分离重点**：设定层锁死"2000 年真实技术/价格/政策边界"，这是科技文的生命线，错一处读者喷。追踪层建"伏笔-回收"表，重生者的每次"未卜先知"都要有出处，不能当万能钥匙。
