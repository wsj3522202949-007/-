## 一、大纲五层分离

大纲不是"写完往格里填"，是五个**不同尺度、不同生命周期**的文档，各管各的，别混。混到一起的结果：要么细纲写成梗概（没戏），要么卷纲写成逐章流水账（没法宏观调）。

```
第1层 点子层（一句话 + 核心爽点公式）   → 决定"写不写"
第2层 卷纲层（卷名 + 卷爽点承诺 + 卷末新状态）→ 决定"大节奏"
第3层 分卷层（本卷每章一句话 + 情绪走向）→ 决定"本卷推进"
第4层 细纲层（每章 Scene-Sequel 卡）    → 决定"章内戏"
第5层 追踪层（伏笔账本 + 数据复盘）      → 决定"不漏不崩"
```

**铁律**：上层没定，不写下层。卷纲飘着就写细纲，必卡文（见第五节）。但允许"小步快跑"——前 3 卷定死，第 4 卷起只定卷纲，细纲边写边补，留弹性给读者反馈（男频尤其要靠追读数据调后续）。

**反例**：新手一上来写"全书 300 章细纲"——三个月后设定推翻，全废；或完全无纲"写到哪算哪"，第 80 章人设崩、伏笔忘兑现、主线失踪。

## 二、从一句话到卷纲：雪花法本土化 + 七点倒推

**雪花法（Randy Ingermanson，web核验）**：从一句话摘要出发，像科赫雪花一样层层展开——1 句 → 1 段(5 句) → 每角色 1 页 → 1 页 Synopsis → 角色 Synopsis → 4 页长 Synopsis → 角色圣经 → 场景清单 → 每场景计划 → 开写。核心两原则：分而治之（divide-and-conquer）+ 自顶向下（top-down），越早发现漏洞越便宜（来源见文末）。

**本土化改造（网文版 10 步）**：

```
1. 一句话故事（≤15字，含核心冲突，不写人名写"目标"）→ 例："重生回千禧，用信息差造芯逆袭"
2. 一段话（5句：现状/触发/中点反转/谷底/新状态）
3. 主角小传1页（Want错的药 / Need解药 / 金手指 / 最大恐惧）
4. 反派/系统小传1页（它要什么、靠什么压主角）
5. 一卷一句话 × N（每卷一个爽点承诺）
6. 卷纲：每卷"承诺→兑现→新状态"三行
7. 长 Synopsis（全书 4 页，标出每个伏笔埋点）
8. 角色圣经（口癖/决策模式/关系网，防人设崩）
9. 场景清单（全书章名 + 类型：铺垫/反转/碾压/余波）
10. 每章 Scene-Sequel 卡（见第四节）→ 开写
```

**七点倒推（Dan Wells / Reedsy，web核验）**：Hook→转折1→加压1→中点(反应转行动)→加压2→转折2(发现钥匙)→结局，**从结局倒推**。网文用法：先写"终局一句话"（主角变什么样），再倒推首章状态让首尾反差最大（废柴↔封神），中点当全书分水岭（之前被推着走、之后主动出击）。

> 一句话记住：雪花管"怎么长出来"，七点管"怎么从后往前锁死"。两法叠用，开写前漏洞清零。

## 三、分卷与卷纲模板：卷 = 一个爽点承诺的闭环

卷不是"字数到了就切"，是**一个完整爽点承诺的闭环**：读者进这卷是为了看某件事，看完这件事状态变了，才肯进下一卷。

**卷纲三行模板**：

```
【第N卷 · 卷名】
承诺：本卷给读者什么爽/什么悬念（必须具体，如"第一次靠技术碾压同行"）
兑现：第几章兑现、怎么兑现（不许跳票，跳票=注水）
新状态：卷末主角/局势变成什么（必须和卷首反差）
```

**一卷节奏（对标 Save the Cat 15 节拍，见结构学）**：
卷首钩子(0%) → 催化剂(15%) → 蓄力(15–40%) → 中点假胜/假败(50%) → 反派加压(60–85%) → 谷底(85%) → 卷末爆发+新状态(100%)。

**卷间钩子**：每卷结尾必须留"下一卷承诺"的钩子（信息炸弹/危机/身份暴露），否则读者合卷不点下一卷。男频每 3–5 卷换一次地图/赛道，防审美疲劳；女频每卷推进一个关系变量（误会/掉马/同居）。

## 四、细纲写法：每章一张 Scene-Sequel 卡

细纲的最小单位不是"这章写啥"，是**一章一张 Scene-Sequel 卡**（德怀特·斯万，见结构学第二章）。写细纲时把每章拆成：Goal(目标)/Conflict(冲突)/Setback(挫折) 的 Scene，接 Reaction(反应)/Dilemma(困境)/Decision(决定) 的 Sequel。

**细纲卡模板**：

```
【第__章 · 章名】
类型：□铺垫 □反转 □碾压 □余波
Scene：目标___ / 冲突___ / 挫折___
Sequel：反应___ / 困境___ / 决定(引出下章)___
爽点/钩子：___（五类强钩子之一）
状态变化：角色处境/关系/认知 哪一变？□是 □无(废章预警)
字数预算：___（2600–3400）
```

**用法**：卡填不满（无冲突无决定）的章，先别写，回去改卷纲——多半是上层承诺没给足。一章至少 1 个 Scene + 1 个 Sequel，纯 Sequel 闷、纯 Scene 累。

## 五、卡文急救：五种卡法对应解法

> 完整速查急救包（卡文 8 型 + 15 分钟恢复写作流 + 止血/作死动作 + 卡文诊断卡）见 `卡文急救.md`。

卡文不是"文笔不行"，是**某层断点**，对症才有用。

```
□ 卡法1：上层没定（卷纲飘）→ 解法：回第二节补卷纲三行，别硬写
□ 卡法2：承诺跳票（伏笔忘了兑现）→ 解法：查伏笔账本，要么兑现要么摘掉
□ 卡法3：纯铺垫无小爽点（蓄力超1章必崩）→ 解法：插一个"小碾压/小打脸"续命
□ 卡法4：人设崩（角色行为违背小传）→ 解法：回角色圣经，改行为或改小传
□ 卡法5：用发呆回忆凑字数（最毒）→ 解法：跳切+塞信息，见节奏与留白·水章修复
```

**治本法**：卡文时最忌"不知道下一步就写环境描写/回忆杀凑字数"——那是把断点藏进水章。先定位五种卡法哪一种，修上层，再写。

## 六、多线收束与伏笔账本

长书（300 万字级如《重生千禧》）必有多线（技术/商战/家庭/感情）。不记账必炸。

**伏笔账本（追踪层核心）**：

```
| 伏笔 | 埋于(章) | 类型(枪/承诺/人设) | 兑现(章) | 状态 |
| 父亲的咳嗽 | 009 | 情感承诺 | ___ | 待兑现 |
| 系统支线外部势力 | 010 | 危机枪 | ___ | 待响 |
```

**收束规则**：① 契诃夫之枪——挂了必响，不响就摘（见节奏与留白）；② 多线在"中点"和"终局"前必须汇流一次，否则读者觉得在追两本书；③ 每 30–50 章做"伏笔兑现审计"，漏掉的要么补要么摘。

**数据复盘（追踪层另一半）**：每卷完看追读率/完读率（见 platforms/ 数据红线），掉则回卷纲调承诺，不是回细纲修词。

【卷纲层】第N卷：承诺___ / 兑现(章__)_ / 新状态___
【细纲层】第__章卡：类型___ / 目标___ / 冲突___ / 挫折___ / 决定___ / 钩子___ / 字数___

## 八、两本小说落点

**《重生千禧》（男频·300万字/6卷）**：点子层已定（重生千禧造芯）。卷纲按"赛道切换"切——卷1废品站淘宝/卷2第一桶金/卷3产业成型/卷4商战/卷5技术封锁突围/卷6封神，每卷一个爽点承诺闭环。伏笔账本重点管"技术线时间锚"（2004.4.17 等真实节点）与"系统支线外部势力"。卡文多因"承诺跳票"（写了设定没兑现），查账本优先。

**《难得夫妻是少年》（女频·青梅竹马）**：卷纲按"关系变量"切——误会/旧物/掉马/同居各成卷。细纲卡重"Sequel 的情绪反应"（她为什么别过脸），轻纯动作。伏笔账本管"少年期物件/约定"的回收（这是本书亮点，少年期占 1/3 篇幅）。卡文多因"纯铺垫无小钩"，插一个"似有若无的暧昧"续命。
