## 一、世界观分层：六层怎么搭

世界观是一套互相咬合的系统。动物理层一下，社会、经济、文化层跟着晃。改一处的涟漪会到处跑（来源：zsc.github.io 第9章"分层架构"；cipherwrite 世界观蓝图）。

下面六层按"地基→应用"排。你不用六层都写满，但动笔前必须知道哪层是这本的"主引擎"。

### 1. 物理层（地基）

自然法则、地理、气候、资源分布、稀缺物。
问自己：重力多少？有没有冬天？哪样东西全天下只有一处产？稀缺物就是现成的冲突发生器（来源：anima-roleplay 资源冲突表）。

**网文落地**：别写"风景优美"。写"镇上只有一口甜水井，张家占了井，李家每天多走三里路"。稀缺一落地，矛盾自己长出来。

### 2. 社会层（政治 + 阶层）

谁掌权、怎么掌、谁想抢、法律怎么执行、阶层能不能爬。
问自己： throne 之下谁在干活？ Guards 是贪是廉？ 老百姓是认命、造反、还是躺平？这一层定的是每场公开戏的"空气"（来源：cipherwrite 经济与治理段）。

**网文落地**：反派嚣张的底气，往往来自社会层"他舅是局长"。先把权力链画清，打脸才打得有分量。

### 3. 规则层（魔法 或 科技）

超常能力的"接口定义"。玄幻叫魔法/修炼，科幻叫科技/系统，现实向可以"几乎没有规则层"。
关键判断（Sanderson 第一定律，见第二节）：这套能力是用来"解冲突"的，还是只用来"造氛围"的？（来源：brandonsanderson.com；coppermind）

**网文落地**：男频升级流、系统流，规则层就是主战场，必须硬、必须可量化。女频现实文规则层极薄，把力气挪到社会层和文化层。

### 4. 历史层（三层记忆）

神话层（老得成传说，角色会为"当年到底怎样"吵架）、制度记忆层（写进课本的建国/大战）、活记忆层（角色亲身经历、各有各的说法）。
最有力的是活记忆层：同一件事，爹和叔讲出两个版本，戏就来了（来源：auctore 历史公式）。

**网文落地**：别写"一百年前打过一场大仗"。写"97年那场下岗，老周分到了机床，老王什么都没分到，两家从此不走动了"。具体年份 + 具体后果 = 世界活了。

### 5. 文化层（软件）

权力怎么算、男女角色、生死观、禁忌、艺术审美、日常吃喝穿。
禁忌是文化最锋利的边：它划出"什么话不能讲"，角色一越界，读者立刻感到压强（来源：auctore 文化段；anima-roleplay）。

**网文落地**：青梅竹马文最吃"邻里怎么看两人""家长为什么反对"。把文化层写成具体规矩，男女主每一次靠近/逃离都有了重量。

### 6. 经济层（血液循环）

通货是什么、谁印钱、什么稀缺、贸易走哪条路、魔法/科技怎么改了日常。
一句话：谁控制钱，谁就控制世界，哪怕 throne 上坐的是别人（来源：cipherwrite；anima-roleplay 经济段）。

**网文落地**：升级流里"资源可视化"是命根（见第四节）。现实文里"房价、工资、彩礼"就是经济层的具体钉子。

**六层速记**：物理定边界，社会定权力，规则定超能，历史定伤疤，文化定规矩，经济定脉搏。改一层，回去查其他五层有没有被波及。

→ 落点见第七节，两本书的主引擎完全不同。

## 二、硬设定 vs 软设定：规则一致性 + 信息释放节奏

### 1. 硬设定 vs 软设定：先选光谱位置

Sanderson 第一定律原文："作者用魔法（或任何超常能力）解决冲突的能力，与读者对该系统的理解程度成正比。"（来源：brandonsanderson.com；coppermind）

翻译成人话：

- **硬设定（Hard）**：规则写死，读者和角色都懂。角色用能力解困，读者觉得"这步我也能猜到"，爽点是"聪明地用规则"。例：Mistborn 的金属镕金术，吃哪块金属、能干嘛、烧完了就没，全明示。
- **软设定（Soft）**：神秘、不解释、造敬畏。它能"造问题"，但**不该用来解主要冲突**，否则像天降救兵（deus ex machina），读者觉得被糊弄。例： Tolkien 的甘道夫，从不给说明书；魔戒是霍比特人靠意志力毁掉的，咒语从头到尾没插手。
- **混合光谱**：大多书落在中间。Harry Potter 偏硬（咒语有谱），但"爱"和"预言"留软。权游前软后硬，角色懂越多，世界越硬。

**网文落地铁律**：你的金手指要是"解冲突的主工具"，就必须走硬设定。系统流、科技树、修炼等级，规则不透明 = 读者不信任 = 弃书。

### 2. 规则一致性：把设定当合同，背景板会塌

sagascope 把魔法系统定义为"作者与读者的合同"，给出不可漂移的五根锚：cost（代价）、limit（限制）、channel（谁能用、为什么）、scarcity（资源/时间/能量稀缺）、consequence（世界怎么反噬）。漂移任意一根，信任崩（来源：sagascope 硬软魔法一致指南）。

**自检三问（写每章前过一遍）**：
- 这能力上次要付的代价，这次还在付吗？
- 上次的边界，这次被悄悄撑大了吗？
- 上次用完后世界的反应，这次逻辑接得上吗？

**漂移救法（3选1）**：补付代价（让代价影响后面某个选择）；锁死例外（临时buff 但换来另一种 cost）；改走社会/商业解法，不用超能解（来源：sagascope）。

### 3. 信息释放节奏：用场景 show，别用设定 dump

"Show, don't tell" 最早可追到契诃夫给兄弟的信："别告诉我月光照耀，展示碎玻璃上的反光。" 海明威的冰山理论补一刀：作者懂的八分之七藏在水下，读者会自己感觉到（来源：creativewritingauthority；jerichowriters；en.wikipedia-on-ipfs）。

**冰山法（cipherwrite）**：你懂世界 100%，只展示当前场景相关的 10%。读者要的是"细节背后有深度"的实感，不是听你讲课。

**四类落地技法（配反例）**：

| 技法 | 做（show） | 别（tell/dump） |
|------|-----------|----------------|
| 感官具体 | 苏念把冰棍纸绕在手指上，绕了三圈没舍得扔 | 苏念很舍不得夏天过去 |
| 行为替标签 | 男主把两人合照塞进钱包最里层，又拿出来看一眼 | 男主其实很在意她 |
| 对话潜台词 | "你妈昨天又问我爸，你俩到底算什么。" | "我们关系很暧昧" |
| 具体名词 | 一辆后视镜用胶带缠着的红色永久牌 | 一辆旧自行车 |

**反面教材（设定 dump）**：连续两段"世界观说明"，主角站在那念设定。读者跳读，节奏断，代入碎。

**释放节奏口诀**：能力先在场景里"露一小角"（promise）→ 隔几章"用一次并显代价"（proof）→ 关键章"改变一个重要决定"（consequence）。合同先立信，后给大招（来源：sagascope "promise→proof→consequence" 工坊）。

→ 金手指怎么立这套合同，看第三节。

## 三、金手指 / 系统设定边界：避免"无敌→无聊"

### 1. 病根：无敌 = 失去代价与不确定

主角一刀秒全场，读者第三张就困。Sanderson 第二定律："限制比能力更有戏（Limitations > Powers）。" 你的系统**不能做什么**，比它能做什么更抓人（来源：coppermind；brandonsanderson.com）。

 Superman 无聊，因为无敌。 Superman 遇上氪石才有戏，因为有了"会输"的可能。

### 2. 三个必须拧死的旋钮

**① 限制（Limitation）**：系统硬不能做的。例：科技树只给图纸不给钱；修炼到某层必须"心魔劫"才能进。限制逼角色绕路、逼作者写巧思。

**② 代价（Cost）**：每次使用要付的。身体代价（头痛/掉发/折寿）、资源代价（烧金属/耗电）、社会性代价（暴露后被盯上）。无代价的爽是 cheat code，冲突变虚无（来源：sagascope；chapter.pub）。

**③ 成长曲线（Growth Curve）**：怎么从弱到强。关键在每升一级解锁新玩法，数字翻倍最没劲（见第四节 CSDN 三界九境）。

> Sanderson 还有第零定律：规则要绑死，但爽感要留着。别为了严谨把金手指写成填表（来源：coppermind Zeroth Law）。

### 3. 限制 / 弱点 / 代价的区别（别混）

coppermind 拆得清：
- **限制（Limitation）**：系统本身不能做的（不能隔空取物、只能在阳光下用）。
- **弱点（Weakness）**：敌人能拿捏你的（氪石式；但别只会写"遇 X 就废"，写点新鲜的）。
- **代价（Cost）**：你用就得付的（金属烧完、寿命递减）。

网文里最稳的是"限制 + 代价"组合；弱点留给反派当杀手锏。

### 4. 防数值崩坏：横向升级 > 纵向膨胀

CSDN 实战框架（"三界九境"）三条铁律，专治 500 万字后战力崩：
- **差距可控**：同阶数值差最多 3 倍，永远能靠计谋/组队/道具补。别搞每级 10 倍的指数膨胀。
- **用维度代替数值**：跨大阶靠多一种打法，不靠数字翻倍（人界拼内力，仙界拼因果）。升级 = 解锁新玩法。
- **战力绑叙事功能**：每个等级必须对应"能干什么新事"，不能只为打架更狠（来源：blog.csdn.net 战力体系设计）。

### 5. 金手指边界填空卡（写细纲前填）

```
金手指名：__________
① 它能做（3条封顶）：__________ / __________ / __________
② 它硬不能做（限制）：__________
③ 每次用付什么代价（cost）：__________
④ 敌人能拿捏它的点（weakness）：__________
⑤ 成长靠什么（资源/事件）：__________
⑥ 第1级→第2级解锁的"新玩法"是：__________
⑦ 明确禁区（绝不让它干的事）：__________
```

**爽点循环接这里**：金手指每次出手前，必须有可指认的铺垫（憋屈/信息差/代价）→ 反转（预期落空）→ 碾压（干脆反制）→ 余波（配角差异化反应 + 新钩）。铺垫越实，碾压越爽（来源：叙事学经典与网文理论融合.md 爽点循环段）。

→ 数值化怎么把"等级-战力-资源"转成闭环，看第四节。

## 四、经济系统 / 力量体系数值化：等级-战力-资源闭环

### 1. 为什么数值化有效

Progression Fantasy / LitRPG 的核心：成长可量化、可追踪。数字是承重墙，撑起整本，不是刷在表面的花。读者追的就是"看数字往上涨"的确定感（来源：litrpgcritic；eternal-lib；nouscraft）。

中文网文"升级流"早把这套玩透：
- **数值锚定**：所有战力对比用具体数字（"李翰岳一万九千斤"对"刘问一万五千一百斤"），杜绝模糊，读者对成长进度有掌控感。
- **资源可视化**：击杀/搜尸/谈判后即时报数（"六十八两""一千二百三十四两"），把抽象成长变成可触摸的资本数据（来源：ubook 升级流百科）。

### 2. 等级-战力-资源 闭环模型

```
打怪/做事 ──得资源──▶ 升等级 ──涨战力──▶ 解锁新地图/新资源
   ▲                                                  │
   └──────────── 再投入，闭环转起来 ◀─────────────────┘
```

- **等级（Level）**：进度条。解锁能力与新玩法，不只把数字撑大。
- **战力（Power）**：可量化对比。用具体指标锚定（斤数、良率、月产能、单价），别写"战力 9999"糊弄。
- **资源（Resource）**：升级燃料 + 通货。钱、材料、人脉、经验、研发点都算。

**闭环演示（男频）**：代工赚第一桶金（资源）→ 解锁 Lv.1 节点（等级）→ 量产分立器件（产业能力=战力）→ 利润+技术难题积攒研发点（资源）→ 解锁 Lv.2（等级）……

### 3. 战力必须绑叙事功能

CSDN 给的对照（抄去用）：

| 等级 | 能干什么 | 叙事功能（新玩法） |
|------|---------|------------------|
| 炼气 | 感知灵气 | 探秘境 |
| 筑基 | 御剑飞行 | 跨地图移动 |
| 金丹 | 能炼丹 | 经济系统（卖丹） |
| 化神 | 撕裂空间 | 穿位面 |

升级 = 解锁新体验。数字变大只是副产品。每升一级，让读者看到"世界打开一扇新门"。

### 4. 通货与稀缺：经济层是隐藏冲突引擎

定三件事（来源：cipherwrite；anima-roleplay）：
- **通货是什么**：金币/加隆/信用点/人民币。谁控制供给，谁就掌实权。
- **什么稀缺**：稀缺 = 冲突。芯片良率、稀有矿、一线城市户口、高考名额，全是稀缺物。
- **超能怎么改了日常**：能治病，寿命和战争就变；能瞬移，城市和墙就废。让日常反映超能，世界才真。

**数值化三铁律（汇总）**：①差距可控，别指数膨胀；②用维度代替数值，每级新玩法；③战力绑叙事功能。

## 六、范例：《重生千禧》千禧开局 + 科技树系统设定边界

下面用《重生千禧》演示一整套边界设计。主角演示名"陈舟"（高中生，2000 年 7 月刚毕业），按你实际人名替换即可。系统沿用库内已定："科技树系统，首任务三个月攒出第一颗国产 MCU，奖励未来十年专利图纸"。

### 1. 物理层锚（真实 2000 年）

千禧年、拨号上网 56K、网吧 2 元/小时、深圳电子厂代工、高考刚结束。
稀缺物：流片机会（找代工厂要排队、要钱）、可靠元器件（走私货多假货）。

### 2. 规则层：科技树系统（硬设定，合同立死）

**它能做（封顶 3 条）**：
- 给"方法论与图纸"：从分立器件到先进制程的路线树。
- 发"节点任务"：完成真实技术里程碑才解锁下一层。
- 记"研发点 RP"：每解决一个真实难题 +RP，每赚 1 万利润 +X RP。

**它硬不能做（限制）**：
- 不给成品、不给钱、不替你打架、不替你搞人际关系。
- 超前太多会因"现实产业链前置不足"锁死（如直接要 7nm，系统弹：材料/光刻机/人才均无，解锁失败）。

**每次用的代价（cost）**：
- 身体：大规模调用未来知识会信息过载，头痛、失眠、掉发（具体，可描写）。
- 社会：过早暴露超前技术，引来外资盯梢或相关部门约谈（社会性代价）。

**敌人能拿捏的弱点（weakness）**：
- 系统不干预资本与政策。对手用"专利围堵 + 断供 + 地方保护"卡他，这才是真威胁。降智小怪读者一眼看穿。

**成长资源**：启动资金（毕业礼/兼职/代工利润）+ RP + 人脉。

### 3. 等级-战力-资源闭环（具体数值演示）

| 等级 | 节点名 | 解锁新玩法 | 战力量化（产业能力） | 升这级要的资源 |
|------|--------|-----------|-------------------|--------------|
| Lv.1 | 第一颗国产 MCU | 能设计 8 位微控制器 | 样片跑通，0.35μm，良率__% | 3 个月 + 流片费约【】+ RP__ |
| Lv.2 | 分立器件量产 | 自建小产线，月产能__颗 | 月营收__万，反哺研发 | 代工利润 + 产线租金 |
| Lv.3 | 芯片design 全流程 | 自主 layout，摆脱外包 | 可接客户定制单 | 客户定金 + 团队 |
| Lv.4 | 晶圆制程突破 | 碰成熟制程，建厂 | 良率/月产能双指标 | 大笔融资 + 政策批文 |
| Lv.5 | 国产替代生态 | 拉上下游，成链 | 生态话语权 | 全链整合 |

**关键设计**：每升一级是"打开新玩法"（从样片到量产到建厂到生态），不靠数字翻倍。对手从"看不起的高中毕设"逐级长成"外资巨头"，加的是维度，不是血量。

### 4. 信息释放节奏（promise→proof→consequence）

- promise（第1章）：陈舟脑子里炸开科技树，首任务"三个月攒国产 MCU"，读者知道他有底牌。
- proof（第3–4章）：他试做样片，信息过载头痛到吐，流片费凑不齐，读者看到代价和边界。
- consequence（第8章左右）：第一颗 MCU 跑通，父亲从"不务正业"改观，但外资代理盯上他，新钩=量产资金从哪来。

### 5. 爽点循环演示（开篇）

铺垫：陈舟家境一般，毕业被某专家当众嘲"高中生也想造芯片？"；反转：系统觉醒，但只给知识不给钱，他得自己从代工赚第一桶金；碾压：用 80 年代库存元件 + 自画 layout 做出能跑的 8 位 MCU，当场打脸专家；余波：专家傻眼、父亲改观、同学传开，新钩落在"流片量产的钱谁出"。

→ 完整结构拆解见[结构学.md 第六节](../../knowledge/craft/结构学.md)。

## 七、两本小说落点

### 《难得夫妻是少年》（女频·都市言情·青梅竹马）

**主引擎层：社会层 + 文化层 + 经济层**（规则层极薄，是现实向）。
- 物理层：千禧年前后中国小城，老校区、家属院、小卖部、自行车。
- 社会层：两家家长关系、邻里怎么看"青梅竹马"、谁家先买房谁说话硬气。
- 文化层：苏念的"男人都靠不住"错误信念（来源：叙事学经典与网文理论融合.md）；男主长期是"看似哥们实为导师"的变形者，拉扯爽感来自这里。
- 经济层：房价、工资、彩礼、两家家底差，是现实向的"稀缺与冲突"。
- 信息释放：别 dump 背景。用"苏念把两人合照塞进钱包又拿出来看"这种动作 show 感情，用家长一句"你俩到底算什么" show 文化压强。
- 钩子落点：每章末用"关系拉扯"类钩（差点得到又差点失去），少用危机降临。

### 《重生千禧：从高中毕业开始造芯片》（男频·科技重生爽文）

**主引擎层：规则层（科技树）+ 经济层 + 物理层**。
- 物理层：真实 2000 年，千禧/入世/互联网萌芽/高考，当史料用，别架空。
- 规则层：科技树系统走硬设定，合同立死（见第六节），读者要能"跟着算 RP、预判解锁"。
- 经济层：启动资金→代工利润→融资→产业链，资源可视化（每笔钱报数）。
- 战力=产业能力：用良率/月产能/单价锚定，不写"战力 9999"。
- 信息释放：系统能力先在场景露角，隔章显代价，关键章改决定，禁止开局大段说明。
- 禁忌（库内已列）：别降智外资反派（要真有威胁）、别机械降神（系统给知识不给天降军队）、别把世界写小（对手要配得上成长）。

**两本共用一条铁律**：世界观是生成冲突的机器，当装饰用读者一眼出戏。哪层是主引擎，力气就砸哪层；其余层用冰山法藏 90%，只亮当前场景要的 10%。
