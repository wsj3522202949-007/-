## 六、读者爽感心理学

### 6.1 爽感来源

```
代入感：
├─ 主角=我
├─ 身份认同
├─ 情感共鸣
└─ 经历相似

反差萌：
├─ 弱→强
├─ 被看不起→逆袭
├─ 信息差：我知道你不知道
└─ 打脸：出人意料

情感满足：
├─ 爱情：甜宠/虐恋
├─ 友情：兄弟/闺蜜
├─ 亲情：家人/羁绊
└─ 成就感：升级/成功
```

### 6.2 爽感节奏

```
爽点密度：
├─ 前3章：必须出第一个小爽点
├─ 每章：至少一个小爽点
├─ 每5章：一个中爽点
├─ 每20章：一个大爽点
└─ 结局：圆满大爽点

爽点类型：
├─ 小爽：打脸/逆袭/信息差
├─ 中爽：升级/突破/成功
├─ 大爽：名场面/高潮/圆满
└─ 节奏：抑→扬→爽感拉满
```

### 6.3 代入感建立

```
代入感要素：
├─ 主角视角：第一人称或紧贴主角
├─ 困境共鸣：被欺负/被误解/被陷害
├─ 情感连接：读者能理解主角动机
├─ 成长弧光：主角从弱到强
└─ 结局满足：大团圆或逆袭

代入感技巧：
├─ 开篇聚焦主角
├─ 困境具体化
├─ 情感细节
├─ 反差对比
└─ 名场面设计
```

### 6.4 爽点营造公式

```
核心公式：
被欺负（抑）→ 读者代入情绪 → 出人意料反击（扬）→ 爽感拉满

关键点：
├─ 爽不能无脑
├─ 必须让读者明白：为什么被欺负？动机？反击合理性？
├─ 支线必须服务主线
├─ 诗词/才华展示只是锦上添花
└─ 不能写太多导致主线停滞
```
