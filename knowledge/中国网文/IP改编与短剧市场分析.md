```

├─ 有声书：播放分成（入门级）

├─ 动画改编：授权费+分成（高级）
├─ 影视改编：授权费+分成+署名（顶级）

├─ 游戏改编：授权费+分成（高风险高回报）
└─ 出版：版税+稿费（传统）
```

## 三、短剧改编实操指南

### 3.1 5步改编流程

```
1. 列可拍名场面
   ├─ 全书冲突最密、人设最出圈的3-5个场景
   ├─ 改编方先看这个
   └─ 钩子清单

2. 拆单元剧结构
   ├─ 每集1-2分钟、一集一反转
   ├─ 长线埋钩改成"每集独立小爽+主线贯穿"
   └─ 节奏要快

3. 前置冲突与人设
   ├─ 书名/开篇前3章就要有"可被拍"的强设定
   ├─ 别慢热
   └─ 冲突前置

4. 情绪密度审计
   ├─ 逐章标"爽点/虐点"
   ├─ 密度低于短剧标准的章节是删减重灾区
   └─ 密度要高

5. 版权归属先谈
   ├─ 改编抽成制作方常仅6%-20%
   ├─ 签约前把"改编授权范围+分成比例+署名"写进合同
   └─ 别等爆了再争
```

## 四、版权合同避坑

### 4.1 必看条款

```
必看条款：
├─ 买断 vs 保底 vs 分成
├─ 独家/非独发（海草）
├─ 签约年限
├─ IP/短剧授权
└─ AI条款

坑点提醒：
├─ 买断：长尾与你无关
├─ 保底：天花板低
├─ 独家：绑平台
├─ 晋江：5年起步
├─ 短剧：制作方常仅6-20%分成
└─ AI：人类创意>50%否则违约
```

### 4.2 合同条款详解

```
买断 vs 保底 vs 分成：
├─ 买断：一次性结清，长尾与你无关
├─ 保底：首字算钱，天花板低
├─ 分成：赌长线，潜力大
└─ 建议：能拿分成尽量别全买断

独家/非独发（海草）：
├─ 独家：绑平台，推荐权重高但不可多铺
├─ 非独：可发别家，但权重降
└─ 建议：根据目标选择

签约年限：
├─ 晋江：签人不签书，5年起步
├─ 起点：5年版权
├─ 番茄：按合同
└─ 建议：看清年限和违约责任

IP/短剧授权：
├─ 制作方常仅6%-20%分成
├─ 可能拿走改编决策权
├─ 署名权需明确约定
└─ 建议：改编抽成多少？我有无否决权/署名？

AI条款：
├─ 部分合同要求"人类创意>50%"
├─ 纯AI生成可能违约/封禁
└─ 建议：AI辅助的边界在哪？
```

### 4.3 合同谈判技巧

```
谈判要点：
├─ 分成比例：争取更高分成
├─ 授权范围：明确改编范围
├─ 署名权：必须保留
├─ 否决权：争取改编决策权
├─ 违约责任：看清违约条款
└─ 期限：争取更短期限

谈判策略：
├─ 了解市场行情
├─ 了解自身价值
├─ 争取有利条款
├─ 保留谈判余地
└─ 必要时拒绝
```
