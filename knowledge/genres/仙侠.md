# 仙侠分题材作战手册

> 对接 craft/ 五大模块（结构学·人物学·爽点与情绪曲线·章法与钩子学·世界观构建）。本文"黄金三章/五类强钩子/爽点循环"口径与 craft/ 完全一致，可直接套用。

## 一、题材定位与核心爽点
仙侠是"东方修真体系+长生问道+因果轮回"的容器，比玄幻更吃文化底色（道家术语、宗门礼法、渡劫因果）。读者来图三样：长生逆旅的阶层跃迁、对"大道/天道"的哲学遐想、有血有肉的问道共鸣（来源：今日头条《2025-2026仙侠玄幻最火十本》）。

核心爽点公式：凡俗/伪灵根开局 → 得仙缘（掌天瓶/玄鉴/天机盘）→ 一级级破境逆天改命。这是"凡人也能求长生"的代餐，读者代入的是"我命由我不由天"。

仙侠长盛原因：修真境界（炼气→筑基→金丹→元婴→化神→渡劫）天然适合长篇，且比玄幻多一层"问道悟理"的精神纵深。近年细分爆发：凡人流（《凡人修仙传》）、苟道流（《苟道逍遥录》）、家族流（《玄鉴仙族》）、权谋仙侠（《烟雨楼》）、志怪修仙（《志怪书》）。

对齐 craft/爽点与情绪曲线：仙侠的"预期×反差×代价×延迟满足"里，代价多体现为天劫/寿元/心魔/因果业力，延迟体现在破境前的漫长苦修与机缘铺垫。

## 二、黄金三章模板（开篇300字强冲突示例 + 前三章节奏表）
按 craft/章法与钩子学 的黄金三章分工落地。

第一章（300字暴击）：把主角扔进修真界的"死局"，身份一句话点明，困境具体到"马上身死道消"。

反面："天玄大陆分炼气筑基金丹三境，陆尘资质平平……"（全设定零情绪）。

正面："陆尘跪在青冥宗验灵台，测灵石亮起灰光——四伪灵根，掌门当场判他杂役终身。唯一能改命的筑基丹，被师兄陆明当众夺了去，'废物也配求长生？'"

第二章（压力拉满）：困境推更糟（仇家追杀/宗门大比在即），金手指首次暗示（掌天瓶/神秘铜镜）。别提前打脸，攒情绪。

第三章（爽点落地）：小胜给甜头（催熟一株灵草反杀），抛更大悬念（身世/秘境），强钩子收尾。

口诀背死：一章出身+死局+钩子，二章追杀+仙缘+期待，三章反杀+甜头+新谜。

仙侠章尾优先用"破境预示"和"因果炸弹"，别用软悬疑拖节奏。

前三章节奏表：
| 章 | 事件 | 钩子类型 | 爽点引擎 |
| 1 | 测灵受辱+夺丹 | 危机降临 | 逆袭铺垫 |
| 2 | 逃亡+金手指现 | 信息炸弹 | 探索 |
| 3 | 灵草反杀 | 破境预示 | 碾压 |

## 三、爽点节奏与情绪曲线
仙侠最强五种（引用 craft/爽点与情绪曲线 十大引擎）：

1. 逆袭：读者爽在凡骨爬向长生路。触发：开局资质够低、打压够实，每步有具体战绩（韩立四伪灵根逆袭）。

2. 问道：读者爽在悟出专属大道。触发：给一段"众人皆迷我独醒"的悟道戏，写透主角的道心选择。

3. 破境：读者爽在肉眼可见变强。触发：每次破境要天劫+心魔+稀缺资源三重加码，别无限刷怪。

4. 探索：读者爽在揭开秘境/上古传承。触发：给一块别人没碰的禁地/残图/洞府。

5. 反转：读者爽在认知被大道重建。触发：先立读者坚信的"正道"，再用铁证推翻（仙魔一念）。

每场爽戏走 craft"铺垫→反转→碾压→余波"四段：反派嘲讽≥3次（铺垫）→主角亮仙缘（反转）→当众破境碾压（碾压）→配角重站队+新因果（余波）。

引擎轮换：逆袭→问道→破境→反转，每轮代价加码（天劫→心魔→因果业力），防脱敏。

爽点密度按 craft 5.1：300字一个小刺激，3000字一个小高潮。破境戏别写满整章才爽，渡劫中段就得有释放。

## 四、人设锚点
主角模板（《凡人修仙传》韩立式）：资质平庸但有独家金手指（掌天瓶催熟）+谨慎隐忍+重因果。爽点在低风险高信息差逆袭，不是龙傲天。

重要配角模板：引路人（亦正亦邪的老怪/师尊，给机缘也埋坑）+ 红颜知己/道侣（共治因果而非挂件）+ 家族/宗门群像（《玄鉴仙族》李家代有才人出）。

反派模板：伪善正道（以"天道"之名行掠夺）+ 宿敌天骄（资源碾压的嫡传）+ 心魔化身（主角贪嗔的具象）。反派要有"合理的恶"，别降智。

## 五、毒点避坑清单
读者与编辑最反感五件事（交叉自平台拆解）：

1. 开篇大段铺设定（境界/宗门谱系，读者前300字划走）。

2. 主角出场晚（配角抢戏三千字）。

3. 金手指拖到第五章（读者没盼头就走）。

4. 主角圣母心泛滥（修真界讲因果杀伐，滥善出戏）。

5. 章末无钩子（"嗯知道了"然后弃书）。

反面："陆尘是青冥宗杂役，修炼十年还是炼气一层，这日风和日丽……"（背景+风景，零冲突）。
正面：直接让掌门把杂役令拍他脸上，读者自动问"他怎么翻"。

## 六、章末钩子范式
仙侠适配三式（对齐 craft/章法与钩子学）：

1. 破境预示式：刚悟出关键功法，天劫云已压顶。"他刚运转周天，九霄之外，第一道劫雷已凝。"

2. 因果炸弹式：揭出当年灭门真凶竟是授业恩师。"掌门递来的玉简上，刻着他父母临终前的求救血字。"

3. 身份暴露式：神秘金手指被人盯上，马甲将掉。"铜镜里那道残魂轻笑：'你以为，宗门为何独留你一命？'"

## 八、本章题材自检清单（可勾选）
- [ ] 第一章是否300字内抛出身份+死局+钩子？
- [ ] 金手指是否在前三章亮明且带代价（天劫/因果）？
- [ ] 修真境界是否可量化、破境有稀缺资源支撑？
- [ ] 反派是否有"合理的恶"而非降智工具人？
- [ ] 每章中段是否有一次情绪/爽点释放？
- [ ] 章末是否用了破境/因果/身份三式之一？
- [ ] 是否避免大段铺设定、主角晚出场、圣母心？
