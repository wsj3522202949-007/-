# 明星分题材作战手册

> 对接 craft/ 五大模块（结构学·人物学·爽点与情绪曲线·章法与钩子学·世界观构建）。本文"黄金三章/五类强钩子/爽点循环"口径与 craft/ 完全一致，可直接套用。本篇从《文娱分题材作战手册》单拆深化，专注"偶像养成/饭圈生态/顶流人设/资本运作"，区别于文娱的"影视导演/华娱复兴"向（电影、编剧、票房那条线另属文娱.md）。

## 一、题材定位与核心爽点

明星/偶像文是"娱乐圈/偶像产业+人设经营+饭圈与资本博弈"的容器。读者看的是"如果我能操控人设、玩转流量、把黑粉转成死忠"。代入感来自"懂圈层的画面感"——打投、出圈舞台、热搜博弈、资源博弈这些只有追星族看得懂的细节（web核验：晋江娱乐圈强区多为"合约恋爱/顶流×新人"甜文，如《别蹭我热度》收藏3.2万、评分9.4；番茄《纯属娱乐：系统演我半辈子》86万字靠"全能大明星系统+资本博弈"跑量；七猫"明星娱乐"分类有《说好的当顶流，转头你成国士了》94万字完结）。

核心爽点公式：被雪藏/糊穿/全网黑 → 靠作品或人设经营逆袭 → 把看不起自己的资本和黑粉按在热搜上。这是"流量变现+话语权夺回"的代餐。

对齐 craft/爽点与情绪曲线：明星文的"预期×反差×代价×延迟满足"里，代价多体现为人设崩塌风险/资本捆绑/舆论反噬，延迟体现在"打歌→出圈→登顶→国民度"的漫长爬升。

长盛原因：明星文天然有量化成长（粉丝数、热搜位、身价、奖项）又比文娱导演向更"贴脸共情"，选秀、饭圈打投、顶流人设、资本运作都提供持续冲突源（web核验：七猫"明星娱乐"类目与"男频黑科技+系统逆袭"交叉吸量明显）。

## 二、黄金三章模板

按 craft/章法与钩子学。明星文第一章就要"羞辱现场+人设/作品高光"同时成立。

第一章（300字强冲突示例）："沈折被公司通知雪藏那天，超话里飘满'糊咖活该'四个字。他撕了解约函，手机弹出热搜：#沈折滚出娱乐圈#。当晚他戴着面具直播清唱一首未发表demo，副歌刚起，弹幕从骂到沉默再到刷屏'这是谁'。而审阅录像的，正是当初把他资源让给师弟的经纪人，指尖停在暂停键上：'这嗓子……藏了三年？'"

反面："娱乐圈是个名利场，光影交错，无数人追逐星梦……"（全背景零情绪）。

正面：直接让主角用一首歌/一个镜头打出反直觉高光，读者自动问"他到底还能不能红回来"。

第二章（压力拉满）：旧公司加码、黑稿预热、资本施压，金手指（后世作品库/系统）首次小用。别提前无敌，攒"人设翻盘"的爽。

第三章（爽点落地）：一次舞台/单曲出圈证明自己，抛更大悬念（顶流对家下场、资本封杀令），强钩子收尾。

## 三、爽点节奏与情绪曲线

明星文最强四种（引用 craft/爽点与情绪曲线 十大引擎）：
1. 打脸：曾经否你的人口服心服。触发：反派把话说满（"你火不了"）当众再用作品砸回。
2. 逆袭：糊咖登顶。触发：每步有数据（粉丝数/热搜位/身价/奖项），肉眼可见变红。
3. 反转：看似黑料实为实锤对手。触发：先立"主角完了"再用物证推翻（人设崩塌反杀）。
4. 行业揭秘：看穿饭圈/资本黑幕（打投注水、数据造假、资源置换），主角用硬实绩破局。

每场爽戏走 craft"铺垫→反转→碾压→余波"：嘲讽≥3次（铺垫）→亮作品/亮底牌（反转）→出圈炸场（碾压）→资本加码+新盟友/新对家（余波）。

铁律（craft 5.3）：连续三章必须一个小上升。明星版：N章被黑→N+1章经营人设→N+2章出圈+晋级。爽点密度按 craft 5.1：300字一个小刺激（一句歌词/一个热搜），每章中段给一次舞台/人设高光。

## 四、人设锚点

主角模板：被雪藏的天才/重生糊咖/系统 holder，金手指是"作品库或人设经营洞察"，不是无脑加人气。讨喜点：双商在线、对作品较真、不矫情不虐主。参考《这个明星很想退休》式"顶流想退圈却越红"的反差设定、《重生之娱乐圈》式"重生逆袭+资源博弈"写法（说明用途，勿抄未授权内容）。

重要配角模板：①一个"被主角带飞的坑队友/糊咖妹"，负责情绪与笑点；②懂行的毒舌经纪人/乐评人，前期否定后期真香；③饭圈"大粉"，承担读者视角吐槽与打投推力。

反派模板：①资本封杀（流量巨头买水军断资源）；②碰瓷营销（网红带节奏黑）；③资源操盘手（让资源给亲信、雪藏异己）。让读者恨的是"用资源和钱压人"，不是脸谱恶。

## 五、毒点避坑清单

1. 开篇大段娱乐圈背景/术语零冲突（前300字划走）。
2. 主角无敌无代价（作品库白送爆款，三天脱敏）。
3. 写实圈黑幕过度（潜规则/色情擦边），触红线。
4. 感情线喧宾夺主（明星变纯言情），男频出戏。
5. 强行塞冷门作品当神作（无铺垫硬火），逻辑断。
6. 章末无钩子（"演出圆满"弃书）。
7. 把明星写成文娱导演向（电影/编剧/票房），那是文娱.md的坑，本篇聚焦偶像/艺人个体。

反面："沈折是天才歌手，写很多好歌，圈内都认可……"（旁白灌设定）。

正面：直接写经纪人指尖停在暂停键、镜头推近他发白的指节。

## 六、章末钩子范式（明星适配三式）

1. 名场面预告钩：亮后世经典名/前奏不放全（"那首全网循环的歌只清唱了半句"），钩"完整版多炸"。
2. 反派吃瘪钩：看不起他的人脸色骤变/热搜反转，钩"下章怎么收场"。
3. 危机伏笔钩：资本下封杀令/黑稿凌晨发，钩"明天拿什么翻盘"。

优先"名场面预告+反派吃瘪"，少用悬疑软钩（番茄吃快钩）。

## 七、代表平台与数据参考（web核验）

- 番茄：男频需金手指（系统/重生/后世作品库），女频需情感线。签约"三次机会制"（2/5/8万字）；编辑看题材对口、300字内出冲突。验证期8万字7天，书架比≥33%、追更比≥35%及格；首秀10万字14天（web核验：番茄作家助手、头条《番茄推荐机制》）。明星/系统流《纯属娱乐：系统演我半辈子》86万字连载。红线：涉黄政军暴黑、亲缘血缘感情线、男主军人/军婚/高干。
- 起点：文娱含明星向，都市娱乐分类成熟；读者偏大重内容。审核同番茄红线。电竞/明星交叉系统流（如"全能大明星系统"）在此跑量。
- 晋江：女频娱乐圈强区，需强情感线（双星/合约恋爱/破镜）。拒傻白甜，要"双强+反转+成长"（web核验：盐选/晋江过稿方向）。《别蹭我热度》收藏3.2万、评分9.4为标杆。适合"娱乐圈言情"而非纯男频爽文。
- 七猫：⚠️关键红线——男频"坚决不收同人、文娱题材"（web核验：头条《不同平台门槛指南》）。明星文在七猫可走男频"明星娱乐+系统逆袭"交叉标签（如《说好的当顶流，转头你成国士了》94万字），但纯文娱复兴流会被拒；女频偏爱强情绪、前300字抓人、保底友好。
- 盐言：明星适合强冲突短篇（选秀黑幕/过气逆袭/被雪藏归来），第一人称强推；硬门槛≥8000字、1–1.2万字优；前100字抛冲突、300字悬念、每800字反转、每3000字付费卡点（web核验：盐选过稿方向）。红线：未成年恋爱（选秀注意选手年龄！）、血腥暴力、低俗擦边、历史虚无、无脑重生降权。

## 八、本章题材自检清单（可勾选）

- [ ] 开篇300字内是否"被雪藏/被嘲/全网黑"的具体冲突？
- [ ] 金手指有无代价（资本围剿/人设崩塌风险），非白送爆款？
- [ ] 名场面是否写给有铺垫的作品，有诞生细节而非硬火？
- [ ] 是否避红线（非未成年恋爱/非潜规则色情/非军婚高干）？
- [ ] 平台是否对齐（男频金手指/女频情感/七猫避纯文娱标签）？
- [ ] 每章中段有无"舞台/人设高光+释放"，非全章八卦？
- [ ] 章尾是否用三式钩之一？
- [ ] 感情线是否服务主线，未喧宾夺主？
