# 谍战分题材作战手册

> 对接 craft/ 五大模块。聚焦情报战/潜伏/特工/密码破译/反间谍/双面间谍/红色谍战，区别于"军旅"宏观战场向——只讲谍报智斗的微观博弈。

## 一、题材定位与核心爽点
谍战是"封闭空间+信息博弈+身份伪装"的容器。读者看的是"在刀尖上用脑子赢"，代入感来自"密码/暗号/伪装的专业细节+信仰重量"（web核验：《谍影风云》372万字评分9.7、《秘战无声》286万字评分9.5技术流手搓电台、《风声》麦家起点首发28.6万字开创"封闭别墅+48小时倒计时"范式）。

核心爽点公式：孤身潜伏 → 用密码/伪装/情报差破局 → 让敌人查到死都查不到自己头上。这是"信息差碾压"的代餐，区别于军旅的"战术武力碾压"——谍战爽在"敌人比你强、但你比他先知道一步"。

对齐 craft/爽点与情绪曲线：谍战的"预期×反差×代价×延迟满足"里，代价多体现为身份暴露/同志牺牲/人格撕裂，延迟体现在"潜伏多年才收网"。

长盛原因：情报天然有"谜题+倒计时"结构，适合章末钩子；又分密码流（破译）、潜伏流（伪装）、反间谍流（抓内鬼）、双面间谍流（多头下注）、红色谍战（信仰线）五支，各吃不同爽点（web核验：起点谍战订阅3000+即精品，《我的谍战岁月》595万字连载中，多重马甲流称"马甲流天花板"）。

## 二、黄金三章模板
按 craft/章法与钩子学。谍战第一章要把主角按进"身份随时暴露+信息差生死"的现场。

第一章（300字强冲突示例）："裘庄的钟敲了第三下。李宁玉把密码本塞进茶壶底的夹层时,门锁响了。王田香推门进来,手里捏着一张电报纸：'李科长,昨晚那条'老鬼'的情报,是从你这间房发出去的。'窗外,伪军的巡逻车正绕着别墅转第二圈。四十八小时倒计时,才过了三个钟头。"

反面："抗战时期，中华民族到了最危险的时候，无数无名英雄潜伏在敌人心脏……"（历史抒情，零动作）。
正面：直接让审讯者/叛徒/电报把暴露危机拍脸上，读者自动问"他怎么脱身"。

第二章（压力拉满）：敌方加码，主角用专业小破局。可写一次密码误导/一次身份切换/一次反侦察，让懂行读者点头。别提前大反击，攒"智斗"的爽。
第三章（爽点落地）：一次漂亮的情报传递或嫁祸给甜头，抛更大悬念（更大鱼/双面间谍/信仰考验），强钩子收尾。

## 三、爽点节奏与情绪曲线
谍战最强四种（引用 craft/爽点与情绪曲线 十大引擎）：
1. 权谋：读者爽在算无遗策。触发：先亮棋盘（谁和谁利益冲突），再让主角落子，最后揭开全盘布局。
2. 反转：读者爽在认知重建（谁是内鬼/谁是双面）。触发：先立读者坚信的判断，用物证（密码本/烟灰/胃内容物）推翻。
3. 逆袭：读者爽在底层/被贬者翻盘。触发：开局够低（小巡警/电讯员）、打压够实，每步有具体情报战果。
4. 碾压：读者爽在以信息差抹平实力差。触发：写透敌人从自信到崩溃，配"他早就知道"的回溯。

每场爽戏走 craft"铺垫→反转→碾压→余波"：敌方试探/内鬼告密≥3次（铺垫）→主角亮底牌（反转）→当众破局或嫁祸四件套（碾压）→地位抬升+新强敌/身份更险（余波）。

铁律（craft 5.3）：连续三章必须一个小上升。谍战版：N章暴露危机露头→N+1章专业蓄力（破译/伪装/反侦察）→N+2章小胜+更大棋局。爽点密度按 craft 5.1：300字一个小刺激，每章中段给一次密码/暗号/心理博弈高光。

## 四、人设锚点
主角模板：被低估的专业者（电讯员/巡警/译电员/下岗特工），金手指是"密码天赋+反侦察认知+信仰"，不是无脑武力。可加穿越/系统但"不替代脑子"（web核验：《谍影风云》国安精英穿越持先知布局，《迷踪谍影》微表情专家当人形测谎仪）。
重要配角：一个"伯乐上级/死忠联络员/亦敌亦友的对手课长"，补人情和信仰重量。
反派模板：高智商课长/抢功同僚/双面间谍。让读者恨又敬的是"他们职业素养极高、主角赢得不容易"（web核验：《暗夜风声》反派高克俭非脸谱化、职业素养极高）。

## 五、毒点避坑清单
1. 开篇大段历史背景或人物履历（读者前300字划走）。
2. 主角无脑金手指（谍战读者吃智商，不吃龙傲天；web核验：《我的谍战岁月》无穿越系统、靠谋略破局被评"硬核"）。
3. 谍战逻辑漏洞（身份漏洞、密码硬伤、反侦察常识错误）。
4. 反派降智（敌特一查就崩，主角赢得太轻松，读者出戏）。
5. 章末无钩子（一次行动完就完，读者弃书）。
6. 历史节点/人物瞎编（抗战红线，web核验：七猫征文要求"懂政策、懂技术、懂人情"）。
7. 信仰线空心（红色谍战没有信仰重量，只剩权谋就成了黑吃黑）。

反面："李宁玉从小聪明过人，长大后成为一名优秀的特工……"（背景+履历，零冲突）。
正面：直接写密码本塞进茶壶、审讯者推门进来、倒计时三个钟头。

## 六、章末钩子范式（谍战适配三式）
1. 危机降临式："译电员手抖着递来密件：'内部有鬼，名单上……有你的名字。'"（身份暴露）
2. 信息炸弹式："王田香盯着那枚被缴获的徽章,脸色白了：'这手法,是当年那个被我放走的共产党。'"（认知反转）
3. 打脸预示式："审讯室的灯灭了又亮。李宁玉把茶壶端起来,听见王田香对外面说：'放人——但跟上,二十四小时。'"（破局+新危机）

- 番茄：算法驱动（web核验），8万字评估、10万字首秀、验证期7天书架比≥33%、追更比≥35%、前10章完读率<8%腰斩。谍战属慢热，靠章中钩子拉完读；《谍战:从麦兰捕房开始》80万字"租界版潜伏"为力作。
- 七猫：免费+广告，谍战多归历史/军事；4轮测试推荐，收稿要求开篇2万字+大纲+申请表。
- 晋江：偏"谍战+言情"或女主特工，积分榜驱动，新晋榜限注册30天、3万字申签（web核验）。
- 盐言：男频探索向，悬疑/谍战短篇1-2万字，开篇3000字内立"人设+冲突+悬念"。

## 八、本章题材自检清单（可勾选）
- [ ] 开篇300字内暴露危机+身份同框
- [ ] 主角金手指是密码/伪装/反侦察（非无脑武力）
- [ ] 谍战逻辑自洽、身份无漏洞、密码经得起挑
- [ ] 前三章"危机→蓄力→小胜+更大棋局"上升
- [ ] 反派高智商、主角赢得不容易
- [ ] 信仰线有重量（红色谍战尤其）
- [ ] 每章中段有智斗高光，章末有钩子
- [ ] 平台收稿要求（字数/大纲/完读率）已对齐
