# 穿越分题材作战手册

> 对接 craft/ 五大模块（结构学·人物学·爽点与情绪曲线·章法与钩子学·世界观构建）。本文"黄金三章/五类强钩子/爽点循环"口径与 craft/ 完全一致，可直接套用。

## 一、题材定位与核心爽点
穿越是"现代认知/记忆降维打击异世界"的容器，子类含穿书/穿古/穿未来/双重生/快穿。读者来图三样：身份反差的掌控感、用已知改变命运的爽感、对"如果我是他"的代入遐想。

核心爽点公式：现代人/重生者 → 携知识或记忆入场 → 碾压旧秩序、纠正遗憾。这是"我比所有人先知"的代餐，读者代入的是"换我上也行"。

穿越长盛原因：门槛极低、兼容一切类型（历史/玄幻/言情/种田），且天然带"信息差"金手指。细分：穿书（改命原书炮灰）、穿古（知识降维）、双重生（双向遗憾修补）、快穿（单元任务）。

对齐 craft/爽点与情绪曲线：穿越的"预期×反差×代价×延迟满足"里，代价多体现为身份错位/规则反噬/记忆偏差，延迟体现在布局见效前的隐忍。

## 二、黄金三章模板（开篇300字强冲突示例 + 前三章节奏表）
按 craft/章法与钩子学 的黄金三章分工落地。

第一章（300字暴击）：把主角扔进穿越现场的"死局"，身份一句话点明，困境具体到"马上身死/社死"。

反面："大梁王朝分九品中正，沈落穿越成罪臣之女……"（全背景零情绪）。

正面："沈落睁眼就在刑场，原主刚被定为谋逆诛九族。监斩官念到她名字时，人群里亲哥哥正递上亲手写的罪证——穿书第一天，她就得在自己人的刀下活下来。"

第二章（压力拉满）：危机扩散（家族倾轧/原书剧情追杀），金手指首次暗示（预知剧情/现代技能）。别提前打脸，攒信息差。

第三章（爽点落地）：小胜给甜头（用一句先知破解死局），抛更大悬念（原书男主将提前登场），强钩子收尾。

口诀背死：一章穿越+死局+钩子，二章危机+先知+期待，三章破局+甜头+新谜。

穿越章尾优先用"剧情偏差"和"身份暴露"，别用软悬疑拖节奏。

前三章节奏表：
| 章 | 事件 | 钩子类型 | 爽点引擎 |
| 1 | 刑场穿书+亲哥反水 | 危机降临 | 逆袭铺垫 |
| 2 | 家族倾轧+先知现 | 信息炸弹 | 探索 |
| 3 | 一句破解死局 | 剧情偏差 | 碾压 |

## 三、爽点节奏与情绪曲线
穿越最强五种（引用 craft/爽点与情绪曲线 十大引擎）：

1. 逆袭：读者爽在炮灰改命。触发：开局身份够低、原书碾压够狠，每步用信息差翻盘。

2. 降维：读者爽在知识碾压。触发：用现代认知（经营/科技/制度）破古代难题，写透"他们没想到"的惊讶。

3. 弥补：读者爽在纠正遗憾。触发：重生文先立前世之痛，再用今生选择治愈。

4. 反杀：读者爽在打脸原书反派。触发：反派按原剧情傲慢出招，被主角先知反制。

5. 反转：读者爽在剧情偏离原轨。触发：先立原书走向，再用主角干预推翻。

每场爽戏走 craft"铺垫→反转→碾压→余波"四段：反派按原剧情嘲讽≥3次（铺垫）→主角亮先知（反转）→当众破局碾压（碾压）→原书角色重站队+新偏差（余波）。

引擎轮换：逆袭→降维→弥补→反转，每轮代价加码（身份暴露→规则反噬→记忆偏差），防脱敏。

爽点密度按 craft 5.1：300字一个小刺激，3000字一个小高潮。穿越文开局即强冲突，别铺垫适应过程。

## 四、人设锚点
主角模板（《庆余年》范闲式/穿书女主式）：带现代思维或前世记忆，表面低调实则布局。爽点在"所有人蒙眼、唯我清醒"，不是龙傲天。

重要配角模板：原书角色（被主角改写命运的炮灰/反派，产生羁绊）+ 双重生对象（双向救赎而非单方面）+ 系统/向导（发任务也埋坑）。

反派模板：原书命运推手（按剧本行事的势力）+ 识破穿越的追查者 + 宿敌（同样握信息的竞争者）。反派要有"合理的恶"，别降智。

## 五、毒点避坑清单
读者与编辑最反感五件事（交叉自平台拆解）：

1. 开篇大段写"适应古代"（读者要征服不要生存，慢热即原罪）。

2. 主角穿越后还窝囊忍三年（番茄算法前3章留存定流量，拖则停推）。

3. 金手指拖到第五章（信息差没盼头就走）。

4. 原书角色降智配合主角（反差爽感来自对手够强）。

5. 章末无钩子（"嗯知道了"然后弃书）。

反面："沈落穿越成罪臣之女，她花了一个月熟悉宅斗规矩，这日天气晴好……"（背景+日常，零冲突）。
正面：直接把刀架她脖子上，读者自动问"她怎么用先知活"。

## 六、章末钩子范式
穿越适配三式（对齐 craft/章法与钩子学）：

1. 剧情偏差式：主角一动，原书走向偏移。"她拒婚的话音未落，远处本该三年后才出现的男主，已策马到了巷口。"

2. 身份暴露式：穿越被识破，马甲将掉。"那谋士盯着她脱口而出的现代谚语，轻声道：'姑娘，你并非此世之人吧。'"

3. 系统预警式：任务失败倒计时，规则反噬将至。"腕间烙印骤亮，冰冷的提示弹出：距离原主死亡线，还剩十二时辰。"

## 七、代表平台与数据参考（web核验）
- 番茄：穿越以3.4亿阅读量断层第一（web核验：今日头条番茄分类数据）。番茄算法以"前3章留存率"定流量分配，第一章必须抛强冲突/高悬念/极致反差；新书榜未断更是上榜前提，建议日更4000-6000字、存稿≥20章。细分方向：极致系统流（即时反馈）、硬核建设流（秩序重建）、无敌/无限流（力量代偿）。
- 起点：2025年7月新书推荐由PK四轮改为"流量包"模式，新书有7天试水+21-42天培育期（web核验：文汇报2025-09-25算法改革）。起点偏"老白"，推崇逻辑严谨的穿越历史。
- 晋江：女频穿越（清穿等）女性读者偏好度67%、清穿仅10%（web核验：番茄2020读者偏好调研）。重"情感+命运改写"，穿书/双重生吃香。
- 盐言故事：短篇爆款代表，20万字以下甚至万字级（web核验：2024网文年度盘点）。适合快穿单元剧、穿书短打。
- 数据红线：穿越禁魔改真实历史人物重大定性、禁宣扬封建糟粕；重生复仇需因果合理，避免无脑虐亲。

## 八、本章题材自检清单（可勾选）
- [ ] 第一章是否300字内抛出穿越+死局+钩子？
- [ ] 金手指（先知/记忆/系统）是否前三章亮明且带代价？
- [ ] 信息差是否用来破局而非自嗨铺垫？
- [ ] 原书/原世界反派是否够强（不降智）？
- [ ] 每章中段是否有一次情绪/爽点释放？
- [ ] 章末是否用了剧情偏差/身份暴露/系统预警三式之一？
- [ ] 是否避免慢热适应、窝囊忍辱、价值观红线踩线？
