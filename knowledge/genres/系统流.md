# 系统流分题材作战手册

> 对接 craft/ 五大模块。本文"黄金三章/五类强钩子/爽点循环"口径与 craft/ 完全一致。系统流是"金手指母题"而非单一题材，本文把它从《重生》《游戏》《文娱》《都市》抽出来独立成篇。

## 一、题材定位与核心爽点

系统流是"金手指母题"——给主角超自然外挂界面（系统/面板/任务/成就/签到/抽奖/直播/神级选择/神级天赋/开局一个XX），用"即时反馈+量化成长+目标导引"三件套驱动叙事。它不设题材，只设玩法底层，可嫁接任何题材。

核心爽点公式：觉醒系统 → 接任务/领奖励 → 数值肉眼涨 → 碾压旧我与他者。这是"游戏化人生"代餐，读者代入"我的努力能被量化看见"。

长盛原因：①即时反馈每章给甜头不靠长铺垫；②量化成长面板把变强变可数进度条脱敏慢；③目标导引系统发任务天然给下一段方向作者不空转；④模块无限拼装（任务/签到/抽奖/选择/直播切换即出新味）。

分题材嫁接（母题独立成篇关键）：系统+都市（神豪/相亲/开店，爽点在用系统打脸现实看不起的人，如《都市神农的逆袭》"系统任务·改良灌溉"）；系统+文娱（文抄公/才华/热度，爽点在后世作品被系统定价解锁）；系统+游戏（面板/血条/爆装，爽点在机制洞察越级，见游戏手册）；系统+重生（系统叠前世记忆双金手指，如《重生99，从给学霸当老师开始》）。

金手指侧写法说明（引用不抄）：《超级神基因》式基因系统把升级写成异兽图鉴收集；《全球高武》式数值面板战力气血明码标价碾压直观；《我有一身被动技》式被动挂机不操作也自动变强制造反差爽；《诡秘之主》金手指侧是"序列晋升面板+魔药消化任务"，用失控二级惩罚给量化成长设代价。

## 二、黄金三章模板

系统流第一章就"觉醒+首任务"同框，别铺世界观。

第一章（300字强冲突示例）："陈默跪在工地，包工头甩工资条：'干不完这栋，一分没有。'脑中炸蓝光：【打工系统激活。任务：今日搬砖3000块。奖励：体质+1，金币×50。失败：扣三天饭钱。】他盯三秒扛起砖就跑——系统说搬快了有速度加成。"

反面："蔚蓝星球上，人类觉醒名为系统的能力……"（全设定零人）。正面：把觉醒钉在主角"马上完蛋"危机里，读者自动问"这挂能救他吗"。

第二章（压力拉满）：任务遇现实阻碍（包工头加码），小奖励到账数据微涨，攒期待，别提前无敌。第三章（爽点落地）：小任务闭环给首甜头（体质+1打脸质疑者），抛更大任务/隐藏成就，强钩收尾。

## 三、爽点节奏与情绪曲线

系统流最强五种（引 craft/十大引擎）：①升级（面板数字跳最直给，每次涨稀缺可见）；②碾压（系统加持越级，夸大代差写透对手从轻蔑到绝望）；③收集/解锁（成就/图鉴/抽奖开箱，给"别人没解锁"稀有项）；④打脸（被否者用系统结果闭嘴，反派把话说满当众砸回）；⑤反转（系统真相/任务陷阱，先立"系统是福利"用铁证推翻）。

每场爽戏走 craft"铺垫→反转→碾压→余波"：嘲讽≥3次（铺垫）→系统亮底牌/完成任务（反转）→数据碾压四件套（碾压）→新任务+更强对手（余波）。铁律（craft 5.3）：连续三章必一小上升。系统版：N接任务→N+1推进涨数据→N+2闭环打脸+新任务。密度按 craft 5.1：300字小刺激，每章中段给一次奖励释放。

## 四、人设锚点

主角模板：被现实压住的小人物（社畜/学生/底层），金手指是"系统holder"非天生强者。讨喜：双商在线、会薅系统羊毛、不圣母。
系统人格化（系统流独有）：写成毒舌AI/傲娇精灵/抠门老爷爷/抽风任务机，互动本身即笑点爽点（参考《系统很抽象，还好我也是》"系统穿越了但人没穿越"错位喜剧），防工具化，是系统文区别于普通金手指的关键。
反派模板：现实压人者（包工头/富少/资本）+系统任务 antagonist（失败惩罚/敌对宿主）。让读者恨"用规则压人"，非脸谱恶。

## 五、毒点避坑清单（系统流专属）

1. 任务设计无聊：搬水100次、签到领肥皂，无冲突无目标，读者秒睡。任务必须绑具体危机+打脸。
2. 奖励无聊：给"经验+1"无实感，要"体质+1徒手掰弯钢筋"具象反馈。
3. 系统变保姆：替主角想好一切铺好路，主角成傀儡爽感归零。系统发任务给资源，决策血性归主角。
4. 数值崩坏：前期战力5、中期99999999无限膨胀，碾压失参照。设同阶对标+世界上限锚定。
5. 系统说话像说明书：大段面板堆成账本节奏断。面板一月亮一次关键项足矣。
6. 章末无钩子（任务不递进就弃书）。

反面："系统提示：本系统含任务、商城、抽奖三大模块……"（整章说明书）。正面：直接写失败惩罚倒计时，读者替主角捏汗。

## 六、章末钩子范式（系统流适配三式）

1. 任务预告钩："系统：检测到S级隐藏任务【手撕包工头】，时限24h，失败抹除账户。"（倒计时+越级）
2. 信息炸弹钩："系统提示：解锁基因图谱，你上上代序列嵌着一段非人类代码。"（身份谜团）
3. 打脸预示钩："包工头看监控里搬砖超标三倍的人，茶杯裂了：'这小子被什么附身了？'"（地位反转前兆）

优先任务预告+信息炸弹，少用悬疑软钩（番茄吃快钩）。

## 七、代表平台与数据参考（web核验）

- 番茄：纯算法驱动（web核验）。签约"三次机会制"2/5/8万字各一次申请（2026规则，web核验）；男频要金手指，系统流天然对口。验证期满8万字开7天，书架比≥33%、追更比≥35%及格（web核验）；首秀14–21天PK，首日吸量<200或完读率<10%失首秀资格（web核验）。系统流属"都市脑洞/末世/规则怪谈"高流量品类，"系统+古代科举""系统+直播打赏"被点名推荐（web核验）。
- 起点：系统流是玄幻/都市/游戏常青标签。2025年7月改"试水期7天流量包+培育期21–42天"替代旧PK四轮（web核验 文汇报）。新书6万字获7天等额流量包，追读率定档（web核验）。平台收"系统装反了""开局签到逆天系统""我加载了神秘学面板"等变体（web核验 起点首页）。
- 晋江：系统文偏言情向，需强情感线+双强反转，纯男频爽系统归无CP小众（web核验）。适合系统+娱乐圈言情/年代情。
- 盐言：短篇幻想向收系统/规则怪谈，第一人称强推；硬门槛≥8000字，前100字抛冲突、每800字反转、每3000字付费卡点（web核验）。适合"系统逼我做XX"强冲突短篇。
- 七猫：男频收系统/异能/网游，编辑组明确收系统文；4轮测试，开篇2万字+大纲（web核验）。但男频拒文娱题材，系统+文娱男频在七猫走不通（web核验）。

## 八、本章题材自检清单（可勾选）

- [ ] 系统觉醒是否钉在主角"马上完蛋"危机里（非慢热铺垫）？
- [ ] 任务是否绑具体危机+具体打脸，非无聊日常？
- [ ] 奖励是否具象化（体质+1能掰弯钢筋），非数字账本？
- [ ] 系统是否人格化（毒舌/傲娇/抠门），非说明书？
- [ ] 系统是否只发任务给资源、决策归主角（非变保姆）？
- [ ] 数值是否设同阶对标+世界上限，未无限膨胀？
- [ ] 每章中段有奖励释放，章尾用三式钩之一？
- [ ] 平台收稿要求（男频金手指/女频情感/七猫避文娱）已对齐？
