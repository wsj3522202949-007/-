# 📅 日任务模板

> 使用本模板创建日任务文件。

---

## 使用方法

1. 复制本文件，重命名为 `YYYY-MM-DD.md`（如 `2026-08-02.md`）
2. 填写任务内容
3. 保存到 `goals/daily/` 目录

---

## 模板内容

```yaml
---
id: goal-daily-YYYY-MM-DD
type: index
area: 索引
status: active
tags: [索引, 日任务, YYYY-MM-DD]

```
