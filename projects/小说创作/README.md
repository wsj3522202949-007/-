# 《重生后，前夫跪着求复合》项目说明

## 一、项目概述

```
书名：《重生后，前夫跪着求复合》
类型：重生+甜宠+打脸逆袭
平台：七猫小说
目标：月入1000+
字数：约18万字（180章，每章1000字）
```

## 三、核心卖点

```
三重爽点叠加：
├─ 重生逆袭：女主重生改变命运
├─ 打脸复仇：手撕白莲花+渣男
├─ 甜宠新欢：男主宠女主上天
└─ 目标读者：女性读者，18-35岁
```

## 四、人物设定

```
女主：苏晚晴
├─ 25岁，苏氏集团千金
├─ 重生前被渣男和闺蜜害死
├─ 重生后聪明、坚韧、有仇必报
└─ 目标：夺回苏氏集团，手撕渣男

男主：陆景深
├─ 28岁，陆氏集团总裁
├─ 冷峻、深情、护妻狂魔
├─ 前世暗恋女主，今生主动追求
└─ 帮女主复仇，宠女主上天

渣男：顾承轩
├─ 27岁，顾氏集团少东家
├─ 虚伪、自私、贪婪
├─ 利用女主夺取苏氏集团
└─ 最终破产跪求复合

白莲花：林诗雨
├─ 25岁，假千金
├─ 虚伪、心机深、嫉妒心强
├─ 与渣男勾搭，陷害女主
└─ 最终身败名裂
```

## 五、剧情主线

```
第一卷：重生觉醒（1-30章）
├─ 女主重生，拒绝渣男求婚
├─ 初遇男主，开始合作
├─ 识破白莲花，开始布局
└─ 第一次打脸，渣男慌张

第二卷：初露锋芒（31-60章）
├─ 女主展现商业才能
├─ 识破白莲花更多阴谋
├─ 与男主感情升温
└─ 第二次打脸，渣男失去股份

第三卷：步步为营（61-100章）
├─ 女主步步紧逼
├─ 渣男和白莲花计划失败
├─ 男主表白女主
└─ 第三次打脸，渣男崩溃

第四卷：全面反击（101-150章）
├─ 女主全面反击
├─ 白莲花身份被揭穿
├─ 渣男跪求复合被拒
└─ 夺回苏氏集团

第五卷：甜蜜结局（151-180章）
├─ 女主夺回苏氏集团
├─ 与男主结婚
├─ 渣男和白莲花身败名裂
└─ 圆满结局
```

## 六、投稿指南

```
步骤1：注册账号

└─ 完善个人信息

步骤2：创建作品
├─ 点击"创建作品"

└─ 上传封面

步骤3：上传内容
├─ 上传开篇3章（约6000字）

├─ 审核通过后签约
├─ 确认分成比例
└─ 开始日更
```

### 6.2 书名和简介

```
书名：《重生后，前夫跪着求复合》

简介：
苏晚晴重生了，重生到三年前，重生到一切还没有开始的时候。
前世，她被渣男顾承轩利用，被白莲花闺蜜林诗雨陷害，最终失去苏氏集团，失去所有。
这一世，她要让所有伤害过她的人，付出代价！
拒绝渣男求婚，手撕白莲花，夺回苏氏集团，顺便再谈个甜甜的恋爱。
只是，那个冷峻的男人，你为什么总是缠着我？
"做我的女人，我帮你复仇。"
"好，我答应你。"
只是，这个男人，好像比想象中更宠她......
```
