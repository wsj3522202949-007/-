# 小说选题分析

## 一、平台选择：七猫小说

```
选择理由：
├─ 保底最稳定：5-7元/千字
├─ 从首字算钱：新人友好
├─ 风险最低：断更才扣全勤
└─ 适合新人：门槛低
```

## 二、题材选择：重生+甜宠+打脸逆袭

```
选择理由：
├─ 重生：信息差爽点，经典题材
├─ 甜宠：情感满足，稳定需求
├─ 打脸逆袭：爽感拉满，读者最爱
└─ 组合优势：三重爽点叠加

市场数据：
├─ 重生题材：热度⭐⭐⭐⭐（+10%）
├─ 甜宠题材：热度⭐⭐⭐⭐（+15%）
├─ 打脸逆袭：永恒经典
└─ 七猫热门：下沉市场最爱
```

## 三、书名选择

```
最终选择：《重生后，前夫跪着求复合》
├─ 重生元素：明确
├─ 打脸元素：跪着求复合
├─ 甜宠元素：隐含
├─ 悬念元素：为什么跪？
└─ 爽感元素：强
```

## 四、核心卖点

```
核心卖点：
├─ 重生逆袭：女主重生改变命运
├─ 打脸前夫：前夫后悔跪求复合
├─ 甜宠新欢：男主宠女主上天
├─ 白莲花反派：手撕绿茶
└─ 家族复仇：夺回属于自己的一切

目标读者：
├─ 女性读者：70%
├─ 年龄：18-35岁
├─ 偏好：甜宠/逆袭/打脸
└─ 平台：七猫
```
