# 《重生后，前夫跪着求复合》大纲

## 一、人物设定

### 1.1 女主：苏晚晴

```
基本信息：
├─ 姓名：苏晚晴
├─ 年龄：25岁（重生前28岁）
├─ 身份：苏氏集团千金（重生前被夺走）
├─ 性格：聪明、坚韧、有仇必报
├─ 金手指：重生记忆+前世经验
└─ 目标：夺回属于自己的一切，手撕白莲花

前世经历：
├─ 被白莲花闺蜜陷害
├─ 被渣男前夫利用
├─ 失去家族企业
├─ 最终惨死
└─ 重生回到25岁

重生后改变：
├─ 不再天真善良
├─ 学会保护自己
├─ 主动出击复仇
├─ 遇到真爱
└─ 逆袭人生
```

### 1.2 男主：陆景深

```
基本信息：
├─ 姓名：陆景深
├─ 年龄：28岁
├─ 身份：陆氏集团总裁（隐藏身份：陆家继承人）
├─ 性格：冷峻、深情、护妻狂魔
├─ 外貌：俊美无俦、气场强大
└─ 与女主关系：前世擦肩而过，今生相遇相知

前世：
├─ 曾暗恋女主
├─ 因错过而遗憾
└─ 今生主动追求

今生：
├─ 一眼认定女主
├─ 默默守护
├─ 在女主需要时出现
├─ 宠女主上天
└─ 帮女主复仇
```

### 1.3 渣男前夫：顾承轩

```
基本信息：
├─ 姓名：顾承轩
├─ 年龄：27岁
├─ 身份：顾氏集团少东家
├─ 性格：虚伪、自私、贪婪
├─ 目的：利用女主夺取苏氏集团
└─ 结局：失去一切，跪求复合

前世：
├─ 娶女主是为了苏氏集团
├─ 与白莲花闺蜜勾搭
├─ 夺走苏氏集团
├─ 抛弃女主
└─ 最终破产

今生：
├─ 继续接近女主
├─ 被女主识破
├─ 逐渐失去一切
├─ 后悔跪求复合
└─ 被女主拒绝
```

### 1.4 白莲花闺蜜：林诗雨

```
基本信息：
├─ 姓名：林诗雨
├─ 年龄：25岁
├─ 身份：林氏集团千金（实际上是假千金）
├─ 性格：虚伪、心机深、嫉妒心强
├─ 目的：夺取女主的一切（男人、财富、地位）
└─ 结局：身败名裂

前世：
├─ 表面是女主闺蜜
├─ 暗中勾引渣男
├─ 陷害女主
├─ 夺走女主的一切
└─ 最终上位

今生：
├─ 继续伪装
├─ 被女主一一识破
├─ 计划全部失败
├─ 身份被揭穿
└─ 身败名裂
```

## 二、世界观设定

```
故事背景：
├─ 现代都市
├─ 四大家族：苏氏、陆氏、顾氏、林氏
├─ 商业帝国：四大家族掌控城市经济
├─ 重生时间线：女主25岁，重生前28岁
└─ 核心冲突：家族企业争夺+情感纠葛

核心设定：
├─ 重生：女主重生回到25岁
├─ 信息差：女主知道未来3年发生的事
├─ 商战：四大家族企业争夺
├─ 情感：女主与男主/前夫的情感纠葛
└─ 复仇：女主复仇白莲花和渣男
```

## 三、剧情主线

### 3.1 主线剧情

```
第一卷：重生觉醒（1-30章）
├─ 女主重生回到25岁
├─ 发现自己即将被渣男求婚
├─ 决定不再重蹈覆辙
├─ 拒绝渣男求婚
├─ 与男主初次相遇
└─ 开始布局复仇

第二卷：初露锋芒（31-60章）
├─ 女主展现商业才能
├─ 开始保护苏氏集团
├─ 识破白莲花的伪装
├─ 与男主感情升温
├─ 渣男开始慌张
└─ 第一次打脸

第三卷：步步为营（61-100章）
├─ 女主步步紧逼
├─ 白莲花计划失败
├─ 渣男失去苏氏股份
├─ 男主表白女主
├─ 女主接受男主
└─ 第二次打脸

第四卷：全面反击（101-150章）
├─ 女主全面反击
├─ 白莲花身份被揭穿
├─ 渣男破产跪求复合
├─ 女主拒绝渣男
├─ 男主帮女主夺回苏氏
└─ 大结局

第五卷：甜蜜结局（151-180章）
├─ 女主夺回苏氏集团
├─ 与男主结婚
├─ 渣男和白莲花身败名裂
├─ 女主人生逆袭
└─ 圆满结局
```

### 3.2 支线剧情

```
支线1：商业线
├─ 苏氏集团危机
├─ 女主拯救公司
├─ 商战对决
└─ 夺回控制权

支线2：情感线
├─ 女主与男主相遇
├─ 感情升温
├─ 误会与和解
└─ 最终在一起

支线3：复仇线
├─ 识破白莲花
├─ 揭露渣男真面目
├─ 打脸复仇
└─ 身败名裂

支线4：家族线
├─ 苏氏家族内斗
├─ 女主夺回家族地位
├─ 家族复兴
└─ 圆满结局
```

## 五、爽点设计

```
爽点类型：
├─ 打脸爽：手撕白莲花+渣男
├─ 逆袭爽：从被欺负到逆袭
├─ 甜宠爽：男主宠女主上天
├─ 复仇爽：复仇成功
└─ 成功爽：事业成功

爽点节奏：
├─ 前3章：重生觉醒+初遇男主
├─ 每5章：一个小爽点
├─ 每10章：一个中爽点
├─ 每30章：一个大爽点
└─ 结局：圆满大爽点
```
