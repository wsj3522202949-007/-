# 重生2010万物估值系统

## 一、项目概述

**一句话卖点**：给爽文读者的"信息差碾压爽"，靠"重生2010+万物估值系统"，在"商战与技术投资"中兑现。

**目标读者**：番茄男频，喜欢都市重生、系统流、科技流的读者

**平台策略**：番茄免费阅读+广告分成模式，追求完读率和追读率

## 二、核心设定

### 2.1 主角设定
- **姓名**：林辰
- **年龄**：重生时22岁（2010年大学毕业）
- **前世**：普通程序员，996到35岁猝死，一生平庸
- **重生节点**：2010年6月，大学毕业前夕
- **金手指**：万物估值系统

### 2.2 系统设定
- **名称**：万物估值系统
- **功能**：看到任何物品/公司的实时估值、未来涨跌曲线
- **限制**：每天3次，消耗认知点（专注工作/学习恢复）
- **代价**：使用过度会头痛、注意力下降
- **成长**：估值准确度随使用次数提升，后期解锁批量估值、趋势预测

### 2.3 世界观
- **时间线**：2010-2030年，真实历史事件为背景
- **地点**：江城市（虚构二线城市，原型武汉+南京）
- **核心冲突**：信息差优势 vs 现实阻碍（资金、人脉、政策）

## 三、故事主线

### 3.1 主线剧情
1. **第一卷（0-30万字）**：捡漏起步
   - 从旧货市场捡漏开始，赚到第一桶金
   - 救治重病父亲，解决家庭危机
   - 初步建立人脉，进入投资圈

2. **第二卷（30-100万字）**：投资布局
   - 投资房产、股票、初创公司
   - 与竞争对手博弈，商战打脸
   - 建立自己的投资公司

3. **第三卷（100-200万字）**：产业升级
   - 进入科技产业，投资芯片、AI、新能源
   - 参与国家重大项目
   - 从投资人转型为产业领袖

4. **第四卷（200-300万字）**：巅峰之路
   - 面对国际巨头竞争
   - 系统升级，解锁新能力
   - 成为行业传奇

### 3.2 爽点循环
- **铺垫**：别人看不起的小东西，系统显示高估值
- **反转**：用极低价格买入/投资
- **碾压**：价值暴涨，打脸质疑者
- **余波**：新的机会/敌人出现

## 四、数据目标

### 4.1 番茄平台指标
- **前三章完读率**：冲50%
- **追读率**：稳定在15%以上
- **日更字数**：6000字（拿全勤）
- **首秀前存稿**：10万字+

### 4.2 收入预期
- **全勤奖**：600-800元/月
- **广告分成**：日均1万有效阅读，月收入3000-15000元
- **星火奖**：完读率达标，1000-2000元
