# 万物估值系统设定

## 一、系统基本信息

### 1.1 系统名称
**万物估值系统**（简称"估值系统"）

### 1.2 系统来源
- **激活条件**：主角林辰重生时，因前世遗憾太深（一生平庸、35岁猝死），灵魂携带强烈执念激活
- **激活时间**：2010年6月15日，林辰大学毕业前夕
- **激活方式**：林辰触碰一件旧物时，系统自动绑定

### 1.3 系统界面
- **视觉呈现**：只有林辰能看到的半透明蓝色面板
- **显示内容**：物品名称、当前估值、未来涨跌曲线、置信度
- **交互方式**：意念控制，无需语音或手势

## 二、核心功能

### 2.1 基础估值（初始功能）
```
【物品名称】：民国青花瓷碗
【当前估值】：￥150
【未来估值】：￥8,500（3年后）
【涨跌幅度】：+5567%
【置信度】：87%
【估值依据】：稀缺性+收藏市场回暖+同类拍品成交记录
```

### 2.2 公司估值（10级解锁）
```
【公司名称】：某初创科技公司
【当前估值】：￥500万
【未来估值】：￥50亿（10年后）
【涨跌幅度】：+100000%
【置信度】：72%
【关键节点】：2012年获得A轮融资，2015年上市
```

### 2.3 趋势预测（30级解锁）
- 能看到行业整体趋势
- 预测政策变化对市场的影响
- 识别周期性机会

### 2.4 批量估值（50级解锁）
- 同时估值多个物品
- 快速筛选高价值目标
- 提高效率，节省使用次数

## 三、限制与代价

### 3.1 使用次数限制
- **每日次数**：3次（初始）
- **恢复方式**：每日0点重置
- **升级效果**：每10级增加1次，上限10次/日

### 3.2 认知点消耗
- **消耗量**：每次使用消耗10点认知点
- **认知点上限**：100点（初始）
- **恢复方式**：
  - 专注工作/学习：+5点/小时
  - 深度思考：+10点/小时
  - 充足睡眠：+30点/夜
  - 特殊物品（后期）：直接恢复

### 3.3 身体代价
- **轻度使用**：无明显影响
- **过度使用**（单日超过5次）：头痛、注意力下降
- **严重透支**（认知点<10时强行使用）：短暂昏迷、记忆混乱
- **长期代价**：频繁透支会导致神经系统损伤

### 3.4 准确度限制
- **初始准确度**：70-80%
- **影响因素**：
  - 物品稀缺性：越稀缺越准
  - 时间跨度：越远越不准
  - 信息完整度：信息越全越准
- **提升方式**：使用次数增加、系统升级

## 四、系统人格

### 4.1 性格特点
- **语气**：机械音，但带轻微调侃
- **态度**：对林辰的"捡漏"行为有时会吐槽
- **示例对话**：
  - "宿主，你又在看垃圾？"
  - "这个估值...你确定要买？"
  - "恭喜，这是你今天第一次正确的判断。"

### 4.2 成长变化
- **初期**：冷冰冰的机械音
- **中期**：偶尔调侃，带点人情味
- **后期**：像朋友一样交流，会主动提醒风险

## 五、升级路线

### 5.1 等级系统
| 等级 | 解锁功能 | 升级条件 |
|------|----------|----------|
| 1-10 | 基础估值 | 使用次数达到100次 |
| 11-20 | 公司估值 | 成功投资3家公司 |
| 21-30 | 趋势预测 | 投资回报率达到1000% |
| 31-40 | 隐藏信息 | 发现10个隐藏价值物品 |
| 41-50 | 批量估值 | 单日估值超过20次 |
| 51+ | 终极形态 | 完成系统主线任务 |

### 5.2 升级奖励
- 每次升级：认知点上限+10
- 每10级：每日使用次数+1
- 特定等级：解锁新功能

## 六、系统与剧情的配合

### 6.1 爽点循环
- **铺垫**：系统显示某物品估值暴涨
- **反转**：林辰用低价买入
- **碾压**：价值暴涨，打脸质疑者
- **余波**：新机会/敌人出现

### 6.2 冲突设计
- **系统限制**：次数有限，不能无限使用
- **代价**：过度使用会付出身体代价
- **对手**：有人能察觉到林辰的"异常"能力
- **风险**：系统估值不是100%准确，有失误可能

### 6.3 成长曲线
- **前期**：靠捡漏小物件积累资金
- **中期**：投资公司、房产、股票
- **后期**：参与国家项目、对抗国际巨头

## 七、写作要点

### 7.1 系统描写原则
- **不要**：每次都详细描写系统界面
- **要**：只在关键节点展示系统
- **要**：用系统吐槽增加趣味性
- **要**：让系统成为推动剧情的工具，不是万能外挂

### 7.2 金手指人格化
- 系统要有"脾气"，不是冷冰冰的工具
- 系统会吐槽、会提醒、会调侃
- 系统与林辰的关系像朋友，不是主仆

### 7.3 代价与限制
- 每次使用都要有代价感
- 不能让系统成为万能钥匙
- 要让读者感受到"用系统是要付出代价的"
