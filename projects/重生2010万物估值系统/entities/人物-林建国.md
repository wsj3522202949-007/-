# 林建国人物卡

## 一、基本信息

### 1.1 身份信息
- **姓名**：林建国
- **年龄**：52岁（2010年）
- **身份**：江城市国营机械厂下岗工人
- **现状**：重病在身，需要手术
- **债务**：因治病欠债80万

### 1.2 外貌特征
- **身高**：175cm
- **体型**：消瘦，因病憔悴
- **面容**：沧桑，皱纹深，但眼神坚毅
- **穿着**：朴素，旧工装

## 二、人物拆解

### 2.1 动机
- **表层想要**：活下去，看到儿子成才
- **里层需要**：不成为儿子的负担
- **最怕**：拖累家庭，让儿子为自己牺牲

### 2.2 背景故事
- **过去**：国营机械厂技术骨干，勤勤恳恳工作30年
- **转折**：工厂改制下岗，失去收入来源
- **现状**：重病缠身，需要高额手术费
- **遗憾**：没能给儿子更好的生活

### 2.3 性格特点
- **沉默寡言**：不善表达，但心里都明白
- **倔强**：不愿麻烦别人，不愿成为负担
- **愧疚**：对儿子有愧疚，觉得自己没用
- **骄傲**：为儿子考上大学感到骄傲

### 2.4 与林辰的关系
- **愧疚**：觉得自己没给儿子好的条件
- **骄傲**：儿子考上985大学
- **担忧**：担心儿子为了自己牺牲前途
- **和解**：后期理解儿子的选择，为儿子骄傲

### 2.5 角色弧光
- **起点**：重病，愧疚，觉得自己是负担
- **转折**：手术成功，看到儿子的成长
- **终点**：理解儿子，为儿子骄傲，和解

- **示例**：

- **病房场景**：虚弱但努力微笑
