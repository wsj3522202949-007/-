# 前三章细纲

## 第一章：重生觉醒

### 基本信息
- **章节号**：第1章
- **字数目标**：3000字
- **核心任务**：重生+系统激活+即时危机
- **爽点引擎**：逆袭铺垫
- **章末钩子**：系统激活

### 场景设计

#### 场景一：重生瞬间（300字）
- **时间**：2010年6月15日，下午3点
- **地点**：江城大学宿舍
- **氛围**：闷热，窗外蝉鸣
- **动作**：林辰从床上惊醒，满头大汗
- **内心独白**："这是...2010年？"

**开头钩子**：
```
"重生回2010年，我做的第一件事是把邻居家的废手机拆了。"
```

#### 场景二：系统激活（500字）
- **触发**：林辰触碰旧手机
- **系统界面**：半透明蓝色面板
- **系统提示**："万物估值系统激活"
- **第一次估值**：旧手机估值显示

**系统对话**：
```
"宿主，你终于醒了。"
"这是什么？"
"万物估值系统，能看到任何物品的价值。"
```

#### 场景三：即时危机（800字）
- **危机**：父亲重病，家里欠债80万
- **压力**：竞争对手已拿到进口代理
- **时间**：距离债务到期还有30天
- **情绪**：焦虑、绝望、但有一丝希望

**对话**：
```
"林辰，你爸的病不能再拖了。"
"我知道，妈。"
"还有那80万的债..."
"我会想办法的。"
```

#### 场景四：第一次使用（500字）
- **物品**：室友的旧电脑
- **系统显示**：估值暴涨（因为硬盘里有珍贵数据）
- **限制**：每天只能用3次
- **代价**：使用后头痛

**系统吐槽**：
```
"宿主，你又在看垃圾？"
"这个...估值多少？"
"￥5000，但你确定要买？"
```

#### 场景五：章末钩子（400字）
- **钩子类型**：信息炸弹
- **内容**：系统提示"距离下一个估值暴涨节点还有7天"
- **悬念**：什么物品会暴涨？
- **情绪**：期待、紧张

**章末钩子**：
```
"系统提示：距离下一个估值暴涨节点还有7天。"
"是什么东西？"
"你确定要知道？代价是今天的最后一次使用次数。"
```

### 爽点循环
- **铺垫**：重生，获得系统
- **反转**：系统有限制，不是万能
- **碾压**：第一次看到估值，有希望
- **余波**：新的问题出现

### 数据预估
- **完读率**：目标50%
- **追读率**：目标15%
- **钩子强度**：强

## 第二章：第一次估值

### 基本信息
- **章节号**：第2章
- **字数目标**：3000字
- **核心任务**：第一次使用系统+危机升级
- **爽点引擎**：探索铺垫
- **章末钩子**：危机降临

### 场景设计

#### 场景一：旧货市场（600字）
- **时间**：2010年6月16日，上午
- **地点**：江城市汉口区旧货市场
- **氛围**：嘈杂、混乱、但有机会
- **动作**：林辰带着系统来到旧货市场
- **内心独白**："这里...到处都是宝贝？"

**场景描写**：
```
旧货市场的气味扑面而来——灰尘、旧木头、还有一点霉味。
林辰推了推眼镜，眼前的世界突然变了。
每一个摊位上，都漂浮着半透明的蓝色数字。
```

#### 场景二：第一次估值（800字）
- **物品**：一个破旧的青花瓷碗
- **系统显示**：当前估值￥150，未来估值￥8500
- **限制**：钱不够，只有200元
- **决策**：要不要买？

**系统对话**：
```
"这个碗，估值多少？"
"当前￥150，三年后￥8500。"
"涨50多倍？"
"但你只有200元，买了就没钱吃饭了。"
```

#### 场景三：竞争对手出场（600字）
- **人物**：张伟，竞争对手的儿子
- **冲突**：张伟也看中了那个碗
- **羞辱**："林辰，你也懂古董？"
- **压力**：张伟有钱，可以轻松买下

**对话**：
```
"林辰，你也懂古董？"
"我..."
"别浪费时间了，这个碗我要了。"
```

#### 场景四：系统限制（400字）
- **问题**：今天已经用了2次，只剩1次
- **代价**：使用后头痛加重
- **选择**：要不要用最后一次？

**系统提示**：
```
"宿主，你今天的使用次数只剩1次。"
"我知道。"
"使用后会有轻微头痛，确定要继续？"
```

#### 场景五：章末钩子（600字）
- **钩子类型**：危机降临
- **内容**：父亲病情突然加重
- **时间**：距离手术还有3天
- **情绪**：绝望、但必须坚持

**章末钩子**：
```
手机突然响了。
"林辰，你爸...你爸他..."
"妈，怎么了？"
"医生说，必须尽快手术，否则..."
```

### 爽点循环
- **铺垫**：旧货市场，到处是机会
- **反转**：系统有限制，不能无限使用
- **碾压**：看到估值，有希望
- **余波**：父亲病情加重，危机降临

### 数据预估
- **完读率**：目标50%
- **追读率**：目标15%
- **钩子强度**：强

## 第三章：第一桶金

### 基本信息
- **章节号**：第3章
- **字数目标**：3000字
- **核心任务**：第一桶金+打脸+强钩子
- **爽点引擎**：碾压
- **章末钩子**：信息炸弹

### 场景设计

#### 场景一：借钱（500字）
- **时间**：2010年6月16日，下午
- **地点**：宿舍、银行
- **动作**：林辰借钱凑够买碗的钱
- **情绪**：紧张、但必须成功

**对话**：
```
"兄弟，借我500块。"
"林辰，你疯了？买那个破碗？"
"相信我，这碗值钱。"
```

#### 场景二：买碗（600字）
- **地点**：旧货市场
- **动作**：林辰用300元买下青花瓷碗
- **打脸**：张伟嘲笑"花300买个破碗"
- **系统显示**：估值确认，三年后￥8500

**对话**：
```
"林辰，你真花300买这个破碗？"
"是的。"
"哈哈哈，你真是傻子。"
```

#### 场景三：鉴定（800字）
- **地点**：古董店
- **动作**：林辰拿碗去鉴定
- **结果**：碗是真品，价值￥8000
- **打脸**：张伟目瞪口呆

**鉴定师**：
```
"这个碗...是民国青花瓷，保存完好。"
"值多少钱？"
"市场价8000左右，如果拍卖，可能更高。"
```

#### 场景四：第一桶金（500字）
- **结果**：碗卖出8000元
- **意义**：第一桶金
- **情绪**：激动、但保持冷静
- **决定**：用这笔钱救父亲

**内心独白**：
```
8000元。
这是林辰重生后的第一桶金。
不多，但够了。
够救父亲了。
```

#### 场景五：章末钩子（600字）
- **钩子类型**：信息炸弹
- **内容**：系统提示"下一个估值暴涨节点：3天后，旧货市场"
- **悬念**：什么物品会暴涨？
- **情绪**：期待、紧张

**章末钩子**：
```
"系统提示：下一个估值暴涨节点：3天后，旧货市场。"
"是什么东西？"
"一个看起来像垃圾的东西。"
"价值多少？"
"如果操作得当...100万。"
```

### 爽点循环
- **铺垫**：张伟嘲笑，别人看不起
- **反转**：碗是真品，价值8000
- **碾压**：打脸张伟，获得第一桶金
- **余波**：新的机会出现，更大的挑战

### 数据预估
- **完读率**：目标50%
- **追读率**：目标15%
- **钩子强度**：强
