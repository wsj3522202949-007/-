# 番茄投稿材料

## 一、书名方案

### 1.1 主推书名
**《重生2010：我有一个万物估值系统》**

**优势**：
- 包含"重生"关键词，吸引重生题材读者
- 包含"系统"关键词，吸引系统流读者
- 包含"万物估值"，点明金手指特色
- 包含"2010"，年代感明确

### 1.2 备选书名
1. **《重生2010：万物皆可估值》**
   - 更简洁，更口语化
   - 突出金手指功能

2. **《重生2010：从捡漏开始的逆袭》**
   - 突出"捡漏"和"逆袭"
   - 更接地气

3. **《重生2010：我能看到万物价值》**
   - 直接说明金手指
   - 更直白，更吸引人

### 1.3 番茄书名优化建议
- **长度**：10-15字最佳
- **关键词**：重生、系统、逆袭、捡漏
- **风格**：口语化、直白、有悬念

## 二、简介方案

### 2.1 主推简介
```
重生回2010年，林辰做的第一件事是把邻居家的废手机拆了。
不是因为他疯了，而是因为他能看到——
这部手机三年后价值8000元。
万物估值系统激活，任何物品的当前估值、未来涨跌，一目了然。
从旧货市场捡漏开始，到投资房产、股票、初创公司，
从欠债80万到身价百亿，
林辰用信息差碾压整个时代。
当别人还在为房价焦虑时，他已经布局了下一个十年。
当别人还在为工作发愁时，他已经建立了商业帝国。
重生2010，万物皆可估值，万物皆可逆袭。
```

### 2.2 简介优化要点
- **第一句**：钩子，吸引读者
- **第二句**：解释，不要让读者困惑
- **第三句**：金手指，点明核心
- **第四句**：发展，展示成长
- **第五句**：高潮，吸引读者
- **最后一句**：总结，强化记忆

### 2.3 备选简介
```
【版本二】
重生回2010年，林辰获得了一个神奇的系统——
能看到任何物品的当前价值和未来涨跌。
旧货市场的破碗，三年后价值8000；
街边的小公司，十年后估值百亿。
从捡漏开始，到投资布局，到建立商业帝国，
林辰用信息差碾压整个时代。
当别人还在为生活焦虑时，他已经实现了财务自由。
重生2010，万物估值，万物逆袭。

【版本三】
2010年，林辰重生了。
带着前世35年的记忆，和一个神奇的系统——
万物估值系统。
任何物品，都能看到它的当前价值和未来涨跌。
从旧货市场捡漏开始，
到投资房产、股票、初创公司，
从欠债80万到身价百亿，
林辰用信息差改变了命运。
重生2010，这次我要逆天改命。
```

## 五、番茄投稿流程

### 5.1 准备工作
1. 注册番茄作家助手账号
2. 完成实名认证
3. 准备书名、简介、封面

### 5.2 投稿流程
1. 写满2万字
2. 申请签约
3. 等待审核（通过率约60%）
4. 签约通过后继续更新

### 5.3 首秀流程
1. 写到8万字申请推荐评估
2. 评估通过后进入7天验证期
3. 验证期满10万字进入首秀
4. 首秀期每天稳定6000字

## 六、数据目标

### 6.1 签约前
- **字数**：2万字
- **完读率**：>50%
- **目标**：通过签约审核

### 6.2 首秀前
- **字数**：10万字
- **完读率**：>40%
- **追读率**：>15%
- **目标**：进入首秀期

### 6.3 首秀期
- **日更**：6000字
- **完读率**：>30%
- **追读率**：>15%
- **目标**：获得稳定流量
