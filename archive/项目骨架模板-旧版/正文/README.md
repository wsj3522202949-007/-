# 正文目录（L2 正文层）

> 一章一文件，只放最终稿。命名：`第NNN章-章节标题.md`（NNN 三位零填充）。**每章必须带 frontmatter**（规范见 [示例章节](第001章-示例章节.md)）。

## 命名规范
```
第NNN章-章节名.md
```
- NNN 三位零填充：第 001 章、第 010 章、第 100 章。
- 一章一文件，不合并、不塞草稿 / 素材。
