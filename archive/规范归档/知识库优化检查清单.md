## 八、最佳实践参考

### 8.1 链接最佳实践

1. **使用双向链接**：确保链接是双向的
2. **使用别名**：为常用术语创建别名
3. **使用相对路径**：使用相对路径而非绝对路径
4. **避免断链**：定期检查并修复断链

### 8.2 标签最佳实践

1. **使用嵌套标签**：如 `#writing/plot`
2. **使用标签组**：为相关标签创建组
3. **避免标签膨胀**：定期清理未使用的标签
4. **使用标签别名**：为标签创建别名

### 8.3 图谱最佳实践

1. **使用颜色分组**：区分不同类型的文件
2. **使用过滤器**：减少显示的节点
3. **使用标签高亮**：找到目标文件
4. **定期优化**：定期清理和优化图谱

### 8.4 性能最佳实践

1. **隐藏附件**：在图谱设置中隐藏附件
2. **隐藏未解析链接**：在图谱设置中隐藏未解析链接
3. **限制节点数量**：使用过滤器限制显示的节点
4. **使用 CSS 优化**：减少动画、提高性能
