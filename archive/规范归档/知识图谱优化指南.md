# 知识图谱优化指南

> 本指南介绍如何使用 Obsidian 知识图谱进行高效导航和知识发现。

---

## 一、图谱视图配置

### 1.1 颜色分组

| 目录 | 颜色 | 说明 |
|---|---|---|
| methods/ | 蓝色 | 方法论文件 |
| tools/ | 绿色 | 工具卡片 |
| knowledge/ | 紫色 | 知识实体 |
| schema/ | 橙色 | 规范文件 |
| projects/ | 红色 | 项目文件 |
| ai/ | 青色 | AI 专用资源 |

### 1.2 标签高亮

| 标签 | 颜色 | 说明 |
|---|---|---|
| #去AI味-S | 红色 | 顶级工具 |
| #去AI味-A | 橙色 | 优秀工具 |
| #去AI味-B | 黄色 | 中等工具 |
| #去AI味-C | 灰色 | 低质量工具 |

### 1.3 过滤器

| 过滤器 | 查询 | 说明 |
|---|---|---|
| 核心文件 | `path:methods OR path:knowledge OR path:schema OR path:ai OR path:projects` | 显示核心文件 |
| 工具卡片 | `path:tools/cards` | 显示工具卡片 |
| MOC 文件 | `type:moc` | 显示 MOC 导航文件 |
| 高价值工具 | `tag:#去AI味-S OR tag:#去AI味-A` | 显示高价值工具 |
| 排除归档 | `-path:archive` | 排除归档文件 |

## 二、图谱导航技巧

### 2.1 快速定位

1. **按目录定位**：使用颜色分组快速找到目标目录
2. **按标签定位**：使用标签高亮找到特定类型的文件
3. **按类型定位**：使用过滤器显示特定类型的文件

### 2.2 关系发现

1. **查看连接线**：连接线表示文件之间的关系
2. **查看节点大小**：节点大小表示链接数量
3. **查看聚类**：聚类表示相关文件的集合

### 2.3 路径发现

1. **从 MOC 出发**：MOC 文件是导航枢纽
2. **跟随链接**：通过链接发现相关文件
3. **查看反向链接**：使用反向链接面板查看引用

---

## 三、图谱优化建议

### 3.1 链接优化

- **增加链接密度**：目标 70-80% 链接密度
- **使用双向链接**：确保链接是双向的
- **使用别名**：为常用术语创建别名

### 3.2 标签优化

- **使用嵌套标签**：如 `#writing/plot`
- **使用标签组**：为相关标签创建组
- **避免标签膨胀**：定期清理未使用的标签

### 3.3 性能优化

- **隐藏附件**：在图谱设置中隐藏附件
- **隐藏未解析链接**：在图谱设置中隐藏未解析链接
- **限制节点数量**：使用过滤器限制显示的节点

---

## 四、常见问题

### 4.1 图谱太密集

- 使用过滤器减少显示的节点
- 使用颜色分组区分不同类型的文件
- 使用标签高亮找到目标文件

### 4.2 找不到文件

- 使用搜索功能
- 使用反向链接面板
- 使用图谱的路径发现功能

### 4.3 图谱性能差

- 隐藏附件和未解析链接
- 限制显示的节点数量
- 使用 CSS 优化图谱性能
