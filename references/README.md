# references/ — 参考资料与外部素材

> **冻结职责**：外部来源的参考资料，无论是否已被吸收到 methods/ 或 knowledge/。
> **禁止放入**：自创的方法论（→methods/）、项目正文（→projects/）、知识实体（→knowledge/）。

## 目录结构

| 目录 | 内容 | 文件数 |
|---|---|---|
| `方法论素材/` | 49 篇原始写作指南（01-09 分类） | 49+ |
| `外部Skill蒸馏/` | 外部 Skill 原始框架摘要 | 10+ |
| `在线调研/` | 原始 web 调研数据（HTML/TXT） | 40+ |
| `原始来源包/` | 外部 Skill 源代码包（Humanizer-zh 等） | 100+ |
| `general/` | 非小说类通用资料 | 0 |

## 使用方式

1. **方法论素材**：这些是 distillation 的源头，已被吸收到 `methods/` 和 `knowledge/` 中的成品方法论。原始素材保留在此供溯源。
2. **外部Skill蒸馏**：外部 Skill 的框架摘要，吸收映射见 `外部Skill蒸馏/00_总索引_外部Skill蒸馏.md`。
3. **在线调研**：原始 web 调研数据，HTML/TXT 格式，不做链接修复。
4. **原始来源包**：外部项目的完整源代码包，归档保留，不参与机检。

## 与其他目录的关系

| 目录 | 关系 |
|---|---|
| `methods/` | 从本目录素材蒸馏出的成品方法论 |
| `knowledge/` | 从本目录素材蒸馏出的结构化知识 |
| `archive/` | 本目录是参考资料（活跃），archive/ 是废弃内容（只读） |
