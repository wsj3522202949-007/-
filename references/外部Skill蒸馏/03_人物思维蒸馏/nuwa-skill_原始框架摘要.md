# 03_人物思维蒸馏\nuwa-skill_原始框架摘要.md

> 用途：把 `nuwa-skill` 的人物蒸馏框架保留成原始对照层；不直接当小说设定表，而是作为《人物思维蒸馏法.md》的 upstream schema 来源。
> 来源说明：本地仓库路径为 `E:\小说\小说sill\nuwa-skill-main`；网络复核时上游 `nuwa-skill` 可访问，文件体量与本地一致。

## 一、上游 skill 的核心判断

- 女娲不是复制人，是提炼思维框架
- 最强人物 skill 是一套可运行的认知操作系统
- 重点不是人物“说过什么”，而是人物“怎么思考”
- 人物 skill 必须写诚实边界：做不到什么，比能做到什么更重要

## 二、六维调研框架

上游蒸馏人物时，默认会覆盖六个维度：

| 维度 | 内容 | 网文可吸收方式 |
|------|------|----------------|
| 著作 | 作品里的选择、判断、行事逻辑 | 提炼主角决策顺序 |
| 对话 | 访谈、演讲、回复、交流风格 | 提炼表达 DNA |
| 表达 | 句式、口头禅、情绪表达方式 | 写入人物卡 |
| 外部评价 | 别人怎么看他、他的盲区 | 写成人物镜像关系 |
| 决策 | 重大选择、资源分配、风险取舍 | 写成心智模型 |
| 时间线 | 转折事件、成长节点、身份变化 | 写成人物弧线骨架 |

网文使用时注意：
- 人物是虚构的，不能原样照搬真实人物调研
- 只借“思维框架”，不借具体身世
- 冷门人物、信息极少的人物，优先做主题 skill，不要硬凑人物 skill

## 三、人物 skill 的五层产物

### 1. 心智模型
- 他看世界的基本镜片是什么
- 他判断优先级时先看什么
- 他在什么情况下会切换判断方式

### 2. 决策启发式
- 遇到冲突时先保什么
- 遇到利益时先算什么
- 遇到真相时先判断什么
- 遇到风险时先砍什么

### 3. 表达 DNA
- 句长偏好
- 直接还是绕
- 会不会主动解释
- 会不会自嘲
- 遇到压力时先怼、先跑、先藏、先算

### 4. 价值观与反模式
- 绝对会保的东西
- 绝对不破的规则
- 失控场景
- 绝对不会做的行为

### 5. 诚实边界
- 哪些事他根本看不懂
- 哪些事他做不到
- 哪些领域他不该硬撑专家感

## 四、人物 skill 的诚实边界写法

上游要求每个 skill 都写清楚：

- 擅长领域
- 不适配领域
- 常见误用
- 失效条件

网文吸收为：
- 主角擅长什么判断
- 主角在什么场景会失手
- 主角面对哪类信息最容易误判
- 主角在什么压力下会打破自己的规则

## 五、人物 skill 的构建纪律

- 新建或更新人物 skill 前，先确认用途：思维顾问 / 决策参考 / 角色扮演
- 快速档：3 个维度，每维度 5 个来源
- 标准档：6 个维度完整调研
- 深度档：加一手素材全量下载
- 默认标准档，除非用户明确要求轻量或精品

## 六、人物 skill 的测试要求

### 已知测试
- 这个人物是不是还能被认出
- 核心判断是不是前后一致
- 表达 DNA 是不是稳定

### 边缘测试
- 高压场景、利益冲突、身份暴露、关系破裂时，人物是否还能自洽

### 风格测试
- 换个问题类型，人物是否仍用同一套思维框架回答
- 会不会突然变成通用 AI 腔

### 通过标准
- 人物可运行
- 人物有盲区
- 人物不万能
- 人物不变成标签
