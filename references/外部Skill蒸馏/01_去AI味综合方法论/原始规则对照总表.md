# 01_去AI味综合方法论（原始规则对照总表）

> 用途：把 stop-slop、Humanizer、Humanizer-zh、shuorenhua、ai-flavor-remover 的去 AI 味规则做成一版可对照总表；不是文学理论，是网文改稿时可直接勾选的铁律。
> 来源说明：这些 skill 最初多为英文通用写作或中文通用写作；本表已将通用规则重写为“网文专用检查项”，并保留最原始的问题族和触发信号。

## 一、问题族总表

| 问题族 | 触发信号 | 原始 skill | 网文化改造 |
|--------|----------|------------|------------|
| 开场套话 | 值得注意的是、毫无疑问、综上所述、毫无疑问 | stop-slop / shuorenhua | 正文第一屏必须直接进事件或人物动作，不能先给读者上价值 |
| 总结收尾 | 归根结底、本质上、最终来看、毫无疑问 | stop-slop / Humanizer-zh | 章节结尾只收状态或新问题，不做全章升华 |
| 表演性动宾 | 推动了、促进了、彰显了、实现了、见证了、标志着 | Humanizer / Humanizer-zh | 改成人物动作和可见后果 |
| 虚假主语 | 市场改变了、文化转移了、决策浮现了 | stop-slop / shuorenhua | 必须写出是谁做成了这件事 |
| 无源权威 | 研究表明、数据显示、专家认为、业内指出 | shuorenhua / Humanizer | 保留事实，删掉无证据权威铺垫 |
| 夸大意义 | 关键转折点、不可磨灭的印记、深远影响 | Humanizer / Humanizer-zh | 改成具体变化、具体后果、具体人物反应 |
| 宣传腔 | 令人叹为观止、坐落于、充满活力的、开创性的 | Humanizer / Humanizer-zh | 改成事实陈述，不要给场景贴广告标签 |
| 三段式排比 | 速度、质量、成本——只能选两个 | stop-slop / Humanizer-zh | 改两项或四项，不硬凑三项 |
| 否定式排比 | 这不仅仅……而是…… | stop-slop / Humanizer-zh | 直接说结论 |
| 虚假范围 | 从大爆炸到宇宙网、从恒星到暗物质 | Humanizer-zh | 只列真实覆盖范围 |
| 空泛判断 | 方向是对的、意义重大、真正理解了 | shuorenhua / stop-slop | 删除或改成可验证判断 |
| 协作口癖 | 希望这有帮助、当然、一定、您说得对 | Humanizer-zh / ai-flavor-remover | 删除，正文里不需要客服腔 |
| 破折号滥用 | 一个段落里多个破折号、制造所谓有力收尾 | Humanizer / stop-slop | 一自然段最多一处，且只用于真实语气转折 |
| 机械节奏 | 连续三句长度一致、结构雷同 | stop-slop / Humanizer | 打断句长，换段落落点 |
| 元信息泄露 | 第X章、前文、后文、伏笔、细纲、读者 | 本地网文工程规则 | 改成角色能感知的场景内表达 |
| 金句收尾 | 每段都以简短有力的一句话收尾 | stop-slop | 变换结尾，不要写得像 pull-quote |
| 过度限定 | 潜在地可能被认为也许 | Humanizer-zh / shuorenhua | 直接说判断，不要层层套壳 |
| 通用积极结论 | 未来光明、激动人心的时代、迈向正确方向 | stop-slop / Humanizer-zh | 改成具体计划、具体数字、具体后果 |

## 三、网文场景分级建议

### 轻改
- 只删开场套话、总结收尾、工程词
- 不改剧情、不改人物反应、不改章节定位
- 适用于：初稿基本顺，只有局部 AI 味

### 中改
- 删整句空话、合并重复句、压缩套话段落
- 不改细纲、不新增角色、不新增主线
- 适用于：有明显 AI 腔，但骨架仍然成立

### 重改
- 回修细纲后重写章节
- 适用于：核心情绪交付失败、主角代理权失败、字数结构失稳、契约破坏

## 四、快速自检顺序

```
1. 开场是否直接进事件或人物动作
2. 是否有套话、总结腔、表演腔
3. 是否还有无源权威或无意义强调
4. 是否每句都有具体人物或可见后果
5. 是否有机械节奏、三段式、破折号滥用
6. 是否有工程词泄露到正文
7. 配角反应是否差异化
8. 字数是否在合理区间
```

## 五、来源与继承说明

- 本总表继承自 5 个外部 skill 的核心问题族，不做逐句翻译，只做“网文可执行化”改造
- 若外部 skill 更新，优先更新本总表，再反哺《最强去AI味铁律.md》
- 本地规则优先：只要本地细纲、文风、题材卡已经定义清楚，外部 skill 只负责清理味，不推翻本地创作决策
