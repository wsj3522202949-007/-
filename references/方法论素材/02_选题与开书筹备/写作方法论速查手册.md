# 网文写作方法论速查手册

> 整理来源：《萌新网文邪修速成攻略》
> 适用对象：新人作者 / 框架型写作 / 保底向创作
> 核心原则：先吃饱饭，再谈爆款

---

## 一、大纲与框架法

### 核心原则
不要写详细大纲。新人写10万字大纲被拒稿的情况很常见。免费网站题材热度周期短，要抢时间。

### 大框架（防崩盘）
框死主角升级线，保证主角不会提前突破极限导致后期无事可写。

| 示例（亮剑同人） | 卷次 | 核心升级线 |
|---|---|---|
| 跟随李云龙战斗 | 第1卷 | 从小兵成长为团长 |
| 独立带队作战 | 第2卷 | 成为晋西北英雄团长 |
| 抗日→抗美援朝 | 第3卷 | 成长为高级将领 |

> 每卷50万字，三卷150万字，升级线被框死，不会崩盘。

### 小框架（循环发动机）
一个可无限循环的四段结构：

```
发现目标 → 发生冲突 → 击败对手 → 震惊旁观者
```

- 本质上是"套娃"，但能保证持续产出
- 西游记就是用了81个同样的结构（大师兄！师父被抓走了！）
- 七猫很多书也是这个框架，用感情线/暧昧调剂循环疲劳

### 框架公式总结
- 大框架：限制整体节奏和升级天花板
- 小框架：提供可无限循环的剧情发动机
- 要素越少越可控，新人一个框架循环即可

## 二、人物塑造"贴标签"法

### 核心原则
人物塑造对新人很难，用"贴标签"法可以最低成本维持人设。

### 标签三件套

| 标签类型 | 作用 | 示例 |
|---|---|---|
| 口头禅 | 一开口读者就知道是谁 | 李云龙："他奶奶的" |
| 习惯性动作 | 反复出现，强化记忆点 | 张虎："瞪大一双虎眼"、"一拳打树上，树叶哗啦啦落" |
| 固定服饰/特征 | 视觉锚点 | 不换的服饰、标志性外貌 |

### 使用要点
- 抓住一个特质，反复重复（一次不够就两次，两次不够就三次）
- 动作每次出现可以换场景（打树、打墙、打桌子），但动作本身不变
- 名字设计也要贴标签（张虎→虎眼→虎性→虎式行为）

### 女角色：美羊羊大法

**核心结构：**
- 主角 = 喜羊羊（女主角的心之所向）
- 女主 = 美羊羊（只认可主角）
- 反派/配角 = 沸羊羊（送100万法拉利，女主不屑一顾）

**对比爽点公式：**
> 沸羊羊豪掷千金 → 女主冷漠拒绝 → 喜羊羊骑共享单车 → 女主开心上车 → 趴后座喂棉花糖

- 优点：无脑但有效，不会毒点
- 缺点：单薄，只能保底

## 三、开篇吸睛技巧

### 现在的开篇标准
> 黄金书名 + 黄金简介 + 黄金第一页

短视频冲击下，读者耐心极低。开篇要像短篇导语一样，三句话抓住注意力。

### 导语式开篇结构

```
【导语钩子】3句话内制造强冲突/悬念
    ↓
【信息交代】用最短篇幅交代：主角是谁、什么世界、什么金手指、要做什么
    ↓
【进入剧情】直接推进主线，不废话
```

**示例：**
> "三个小时后，A15号列车通往南城，恐怖分子袭击，我爸妈都死了。我现在已经在火车上了。兜里揣着一把手枪。"

### 节奏把控要点
- 节奏快 ≠ 没有铺垫
- 必须让读者知道：你是谁、你在哪、你要干嘛
- 最多翻两页没有看点，读者就划走了
- 不要大段风景描写

## 四、关于"擦边"开局的判断标准

### 核心原则：四个字——短小精悍

### 为什么必须短小精悍
从第1章第1个字开始，你就在筛选读者。
- 擦边太多 → 留下的是"老色批"读者 → 后面不擦了光速流失
- 正经读者被筛选走了
- 结果：两头不讨好

### 合格擦边的两个特征

| 特征 | 说明 | 示例 |
|---|---|---|
| **① 短小精悍** | 几十字到一两百字，绝不长篇大段 | 点到即止，不让读者产生"这书就是搞这个的"预期 |
| **② 带来矛盾冲突** | 擦边事件本身推动剧情 | 封疆汉族：青梅竹马被逼嫁给地主儿子，把清白给主角 → 主角必须保护她 |

### 不合格擦边
- 纯为擦边而擦边，没有后续矛盾
- 大量篇幅强化擦边描写
- 不能带来主角行动目标的擦边

**结论：** 不具备矛盾冲突的擦边，不如不写，直接进剧情更好。

## 五、题材选择与转型路径

### 转型原则：找共通点
两个完全不搭边的题材转型非常困难。要从简单题材入手，往原创过渡。

| 同人/简单题材 | 可转向 | 共通点 |
|---|---|---|
| 抗战同人 | 架空边军历史 | 军事战斗、家国情怀 |
| 四合院同人 | 年代文 | 时代背景、人情世故 |

### 操作建议
1. 先确定要写什么大类
2. 从难度最低的同人或跟风题材入手
3. 在写作过程中往原创方向迁移
4. 不要来回横跳，专注一个赛道打透

## 六、写作心态

### 现实预期
- 靠一篇攻略或提点不能马上提高水平
- 有人告诉你"这样做是对的"，你可能也做不到
- 需要写很久，某天突然领悟

### 入门标准
> **一百万字能入门，就是幸事。**
> 这里的"入门"指：靠这个饿不死。不是发财。

### 天赋不够怎么办
- 堆阅读量
- 堆写作量
- 强行把基本功拉上去

## 附录：快速自检清单

### 开书前确认
- [ ] 主角是谁？什么身份？什么金手指？
- [ ] 主角前期目标是什么？（100万字内的核心驱动力）
- [ ] 大框架是什么？（升级上限在哪里？）
- [ ] 小框架是什么？（循环结构是什么？）
- [ ] 书名+简介的钩子够强吗？

### 每章自查
- [ ] 有冲突/悬念/爽点吗？
- [ ] 推进了主线吗？
- [ ] 信息交代清楚了吗？（读者知道发生了什么吗？）
- [ ] 有"贴标签"的动作或台词吗？

### 人物塑造自查
- [ ] 每个重要角色有口头禅吗？
- [ ] 每个重要角色有习惯性动作吗？
- [ ] 主角的行动是否符合人设标签？
- [ ] 女角色是否遵循"美羊羊"对比结构？（如有感情线）
