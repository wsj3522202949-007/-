# 网文写作全流程实战指南

> 整理来源：《新手作者全流程实战指南（十四年老扑街の屠狗术）》
> 适用对象：新手作者 / 七猫平台 / 长篇连载
> 核心架构：战略 → 战术 → 执行 → 反馈
> 核心理念：方向 > 努力，结构 > 文笔，情绪 > 逻辑，坚持 > 灵感

---

## 一、战略准备：谋定而后动

### 1.1 平台与市场认知

网文是商品，必须符合市场需求。**选择大于努力。**

| 榜单类型 | 学习目的 |
|---------|---------|
| 畅销榜 / 大热榜 | 学习成熟套路 |
| 新书榜 | 把握最新风向 |

**行动：** 精读5-10本同类型热书前50章，拆解开篇、节奏、人设、钩子。

### 1.2 题材选择：兴趣与市场的交集

不要二选一，找最大公约数。

**新手安全赛道：**
- 重生逆袭、追妻火葬场、团宠、读心术、快穿
- 赘婿战神、年代文、玄幻升级

**微创新策略（旧瓶装新酒）：**

| 创新维度 | 示例 |
|---------|------|
| 职业创新 | 总裁→法医/机长/宠物心理医生 |
| 关系错位 | 男主是女主"前男友的小叔叔" |
| 背景迁移 | "姐妹换亲"从古代搬到星际 |
| 热梗叠加 | 心声+团宠+全员恶人（有主次） |

> 核心心法：让读者觉得"有新意且好看"，而非小众猎奇。

### 1.3 动笔前三个必答问题

1. 我的故事讲什么？（一句话主线）
2. 这本书写给谁看？（目标读者画像）
3. 市场上有类似成功作品吗？（对标作品）

**决策工具——三多法则：**
- 多输入：复盘自己最爱看的类型
- 多输出：试写2万字短篇测试手感
- 多请教：分析榜单爆款规律

## 二、作品包装：决定点击率

### 2.1 书名：一秒吸量的广告牌

| 错误 | 正确 |
|------|------|
| 文艺含蓄无信息量《星辰之下》 | 带情绪、有看点、有关键词 |

**公式：** 核心冲突 + 情绪词 + 身份标签

| 示例 | 拆解 |
|------|------|
| 《重生后，高冷女同桌才是我的白月光》 | 重生 + 高冷 + 女同桌 + 白月光 |
| 《出狱归来：被父母赶出门后，我继承了万亿家产》 | 出狱 + 被赶 + 万亿家产 |

> 技巧：收集热门关键词组合，避免生僻字。

### 2.2 简介：说服读者点进来的推销词

**三要素结构：**

| 要素 | 作用 | 示例 |
|------|------|------|
| 背景 | 主角身份 + 核心处境 | 她是21世纪神医，却穿越成不受宠的弃妃 |
| 冲突 | 核心矛盾 + 情绪爆发 | 冷面王爷纳妾恶心她？行！一针让他见阎王！ |
| 悬念 | 埋钩子，留期待 | "我已经向皇上请旨和离，还给孩子找了个好爹。" |

> 排版要点：段落要短，手机阅读优先。

### 2.3 封面设计

#### 必备要素

| 要素 | 要求 |
|------|------|
| 书名清晰突出 | 书名字体一般大于作者名，方便读者一目了然 |
| 信息完整 | 完整体现作品名、作者姓名等重点信息 |
| 排版整齐 | 书名长度适中时适当排版；书名较长时可用不同颜色、大小突出重要文字，避免过度拥挤 |

#### 风格与配色

根据作品分类确定封面风格：

| 分类 | 风格倾向 | 元素建议 |
|------|---------|---------|
| 男频（历史、玄幻等） | 偏深、偏冷色调 | 厚重感、力量感、史诗感 |
| 女频（现言、古言等） | 暖色调、偏可爱风 | 柔和感、甜宠感、唯美感 |

**设计原则：**
- 字体样式及配色要突出作品特色
- 在整体美观度基础上增加作品关联元素
- 用设计感吸引读者开启阅读

#### 上传要求

- PC端番茄小说网 / 番茄作家助手APP：【创建作品】→【选择封面】→ 本地上传
- 需符合番茄小说具体封面尺寸要求
- 可上传自制封面或由第三方专业人士制作
- 审核通过后即可拥有个人书封

## 三、实战核心：写出抓人的内容

### 3.1 开篇定生死：黄金第一章

**读者耐心极短，第一章必须完成"吸引→代入→期待"闭环。**

**开篇三大利器：**

| 利器 | 要点 | 适用场景 |
|------|------|---------|
| **冲突切入法** | 直接扔冲突：争吵、追杀、背叛、困境 | 最推荐，瞬间抓住注意力 |
| **悬念钩子法** | 抛出一个让读者必须知道答案的问题 | 悬疑、探案类 |
| **人设展示法** | 用主角的一个极具个性的行动开场 | 强人设驱动型 |

**开篇自检清单：**
- [ ] 主角是否在第一章登场？
- [ ] 是否快速建立人设（年龄/身份/性格）？
- [ ] 是否明确主角目标（复仇/逆袭/生存）？
- [ ] 是否设置强烈冲突或悬念？
- [ ] 是否避免背景堆砌、人物过多、视角混乱？

> 口诀：亮冲突、快节奏、定基调。

### 3.2 人物塑造：让读者追更的唯一理由

**人设四要素：**

| 要素 | 说明 | 示例 |
|------|------|------|
| 基础设定 | 年龄、外貌、身份、性格 | 18岁，穷小子，重生者，表面温和内里狠辣 |
| 个性化标签 | 口头禅、小习惯 | "我算过"；摩挲右手老茧 |
| 反差萌 | 外表与内在的反差 | 高冷霸总私下怕打雷；杀神爱哭 |
| 人物弧光 | 成长变化轨迹 | 从懦弱到强大，从冷漠到深情 |

**人设稳定法则：**
- 行为必须符合初始设定
- 变化需有合理铺垫（不能突然降智）
- 配角也要有动机，避免纯工具人

**逆推法：** 先确定行为，再思考"为什么他会这么做？"
> 例：刚正不阿→出身将门，从小被教育"不可辱没家风"。

### 3.3 情节设计：万能叙事框架

**小剧情单元：**
```
目标 → 行动 → 阻碍 → 反转
```
> 例：主角想参加宴会扬眉吐气 → 精心准备礼服 → 礼服被毁无人相助 → 神秘人送来限量高定，竟是暗恋她的大佬

**大剧情链条：**
```
起因 → 发展 → 转折 → 高潮 → 结局
```
> 适用于整本书或重要篇章。

**期待感营造五法：**
1. 设置悬念（身世之谜）
2. 制造冲突（误会、仇恨）
3. 控制信息释放（像剥洋葱）
4. 安排高潮节奏（三章一小爆，十章一大爆）
5. 建立情感连接（让读者心疼主角）

### 3.4 节奏把控：告别拖沓

| 技巧 | 操作 |
|------|------|
| 背景拆散 | 不整段介绍，拆成碎片融入剧情 |
| 不重复叙述 | 同一事件只说一次 |
| 章末留钩 | 每章结尾制造悬念（"老公没死，在我床上"） |
| 动作代心理 | "指甲掐进掌心"代替"她很愤怒" |
| 删除无意义描写 | 砍掉纯装饰性的外貌/环境描写 |
| 对话有信息 | 每句对话都要推进剧情或塑造人物 |
| 主线清晰 | 支线必须服务主线 |
| 逻辑时间线 | 提前设计事件发展步骤，防卡文 |

### 3.5 伏笔与铺垫

**伏笔 = 前文暗示，后文揭晓时"原来如此"。**

**操作要点：**
- 有伏必应（埋了必须回收）
- 记录在案（建文档追踪）
- 自然融入，不刻意

## 四、宏观架构：搭建故事骨架

### 4.1 大纲六大件（防崩文导航图）

| 组件 | 内容 |
|------|------|
| 1. 世界背景 | 年代、社会规则、主要场景 |
| 2. 类型与元素 | 古言重生 / 追妻火葬场 / 读心术 |
| 3. 人物设定 | 主角+配角小传 + 关系图 |
| 4. 故事亮点 | 3-5个核心高潮爆点 |
| 5. 故事线索 | 主线 + 支线 + 暗线 |
| 6. 阶段梗概 | 每10万字一个阶段，标明高潮点 |

> 公式思维：套用经典框架（赘婿逆袭、战神归来），再做微创新。

### 4.2 经济体系设计（玄幻/末世适用）

| 维度 | 要点 |
|------|------|
| 货币单位 | 金/银/铜 或 灵石/上品灵石 |
| 购买力锚定 | 1铜币=馒头，1金币=普通人年收入 |
| 获取难度 | 稀有货币不能轻易获得 |
| 防膨胀 | 不要过早定义"1万紫金币=神器" |

## 五、避坑指南：编辑拒稿的六大雷区

| 雷区 | 表现 | 解决 |
|------|------|------|
| 1. 开篇拖沓 | 大量背景介绍、风景描写、回忆 | 直接进冲突 |
| 2. 人设崩塌 | 主角行为前后矛盾、突然降智 | 写人设卡，严格对照 |
| 3. 节奏失控 | 同一事件反复写、支线喧宾夺主 | 每章只推进一件事 |
| 4. 逻辑硬伤 | 主角突然获得不合理能力 | 能力获取必须有铺垫 |
| 5. 毒点踩雷 | 绿帽、虐主过度、三观不正 | 避开红线题材 |
| 6. 文笔幼稚 | 大量口语、标点错误、分段混乱 | 多修改，减少感叹号 |

**绝对红线：** 涉政、涉军、抄袭、导向不正、乱码投稿。

## 六、数据优化：根据信号调整

| 数据指标 | 信号含义 | 优化方向 |
|---------|---------|---------|
| 读完率下降 | 某章让读者流失 | 检查该章是否有拖沓/毒点/无冲突 |
| 追读率低 | 读者看完一章不想看下一章 | 加强章末钩子，提升爽点密度 |
| 差评集中 | 特定情节引发反感 | 分析差评点，规避类似写法 |
| 评论反馈 | 读者直接表达喜好 | 提炼读者真正想看的方向 |

> 核心心态：数据是优化工具，不是否定标准。

## 七、长期成长：从签约到爆款

### 7.1 正确看待拒稿

拒稿是常态，原因通常是：
1. 故事本身不好看
2. 平台不对路（无线文投起点）
3. 讲述方式不对（基本功需练）

**应对：** 收到拒稿 → 分析原因 → 学习干货 → 修改重投

### 7.2 与编辑沟通

| 错误 | 正确 |
|------|------|
| "在吗？" "怎么改？" | "编辑您好，我是《XXX》作者，附上修改后的大纲和开头，请您指教。" |

> 主动跟进，工作时间礼貌询问。

### 7.3 稳定更新是生命线

- 断更 = 弃书
- 稳定更新 = 培养读者追读习惯
- 建议：每日固定时间、固定字数（如4000字）

## 八、终极心法：锚定"类型契约"

写作前必须明确你的文属于哪种"契约"，全力满足该类型读者的核心期待。

| 类型 | 读者核心期待 |
|------|------------|
| 爽文 | 一路碾压，打脸反派，绝不憋屈 |
| 虐文 | 哭得痛快，情感浓烈，结局HE或BE要极致 |
| 甜文 | 糖度够，互动甜，少误会 |
| 悬疑 | 谜题够硬，反转够狠，解释够圆 |
| 升级流 | 升级爽，宝物多，地图换得及时 |

### 写作时灵魂三问

1. 主角终极目标是什么？
2. 驱动TA的核心动机是什么？
3. 这本书最独特的卖点是什么？

## 附录：你的行动清单

### 阶段一：定方向
- [ ] 扫榜（畅销榜+新书榜，各精读5-10本前50章）
- [ ] 选平台（确认投稿目标平台风格）
- [ ] 定题材（找兴趣与市场的交集）
- [ ] 做微创新（旧瓶装新酒，差异化定位）

### 阶段二：搭框架
- [ ] 写一句话梗概
- [ ] 做大纲六件套（背景/类型/人设/亮点/线索/阶段梗概）
- [ ] 设计人设卡（主角+核心配角，含标签和弧光）
- [ ] 确定书名+简介+封面方向

### 阶段三：写开篇
- [ ] 用"冲突切入法"写3000字
- [ ] 过开篇自检清单
- [ ] 修改打磨

### 阶段四：投出去
- [ ] 规范格式投稿
- [ ] 主动与编辑沟通
- [ ] 收反馈 → 再优化

### 阶段五：持之恒
- [ ] 稳定更新（固定时间+固定字数）
- [ ] 关注数据信号
- [ ] 持续学习
- [ ] 不轻言放弃
