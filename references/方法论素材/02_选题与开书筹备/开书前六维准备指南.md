# 开书前六维准备指南

> 整理来源：王自律（番茄科幻分类作者，七百万字创作经验，代表作《我的右眼是神级计算机》《我降临在矩阵宇宙》，百万在读）
> 适用对象：所有品类
> 核心定位：开书前的六维准备工作，重点是不内耗的实操方法
> 核心理念：用市场化眼光看待写作，先拿到读者认可再追求文学梦

---

## 一、市场调研（选题方向）

### 1.1 逆向选题法

**核心思路：** 先做市场调研，再确定题材。把正常流程逆转。

> 很多新人扑街的原因是先想故事再找市场，但成功的路径往往是**先看市场需要什么，再构思能满足需求的故事**。

**操作步骤：**
1. 总结最近什么题材会火、什么题材有可能火
2. 确定市场热门方向后，思考自己能不能写类似题材
3. 收到反馈（评论、成绩）→ 更容易坚持下去 → 在坚持中锻炼写作技巧

**关于"跟风"的认知：**
> 这不是跟风，是根据市场决定的。写网文应当以非常商业化的目光看待自己要做的事，这不是亵渎创作，而是先拿到广大读者的认可。

### 1.2 题材改造法

**问题：** 反向确定题材，会不会浪费脑海中那个特别棒的故事？

**答案：** 不一定。只需稍微改造：
- 改造**动机或矛盾**
- 改造**背景时代**
- 故事仍可用，但套上市场热门分类，火的概率更高

**题材已确定时的操作：拆书**

至少拆解3-5本同类型头部作品：
- 情节架构、人设、亮点、节奏把控、爽点设计
- 不是抄袭，是学习创作思路

**降低内耗：**
> 不要想象成堆积如山的任务。新人只需要达到一个目的：**熟悉这个题材的基本套路，掌握读者喜好，掌握堵点，合理避雷。**

**微创新方法：**
- 有趣的人设、不一样的技能名 → 这不叫微创新
- 在过程中加入**不同的碰撞** → 这才是真微创新

**经典示例：** 把修仙文放到现代都市里 → 修仙的玄妙过程+技能放在都市中 → 产生极具现实、极具代入感的不一样爽点 → 老题材焕发新魅力

## 二、大纲制定（不内耗版）

### 2.1 关于大纲的两种作者

| 类型 | 特点 |
|------|------|
| **必备大纲型** | 开工前做细致准备，逻辑性条理性好，效率高 |
| **不喜欢大纲型** | 没有大纲捆绑，灵光一闪制造特别棒的高潮和剧情 |

**关键洞察：**
> 很多大神作者最兴奋、灵感最充沛的时候就是开书前做准备的时候。如果花两个月打磨大纲，激情澎湃的状态会丢失，对故事失去新鲜感。

> **莫不如先把当时那股激情使用出来，哪怕创造一个开头也好。**

### 2.2 简易大纲三要素（不内耗版）

**每条只有两三行字，后期逐步完善。**

**以《十日终焉》为例：**

| 要素 | 内容 | 作用 |
|------|------|------|
| **大主线** | 齐夏身处终焉之地，"十二生肖"设计死亡游戏，十天内收集三千六百颗"道"才能离开。不断轮回，有人觉醒"回响"，探寻终焉之地秘密，试图逃离。 | 让你清晰认识自己的故事，准确描述世界观和氛围感 |
| **大动机** | 齐夏想逃出终焉之地找到消失的妻子余念安；楚天秋想成为主宰；"天堂口"想攻破所有游戏带领众人逃脱。 | 确保人物动机合理性，**规避毒点** |
| **大矛盾** | 参与者vs"十二生肖"及规则（生存+收集任务）；参与者之间各有目的，楚天秋与齐夏既合作又竞争，各方势力交织冲突。 | 大矛盾拆解成小矛盾，**小矛盾创造剧情片段，增加读者粘性** |

**没有靶心的箭，剧情就会散，读者就会弃书。**

### 2.3 升级体系

**核心认知：**
> 能够把网文支撑200万、300万甚至千万字的，有一个很重要的指标——**升级体系**。

> 升级体系就像一个个坐标点，主角沿着坐标点向前走，每一个点是一个脚印，每一个点都有一个成长。

**毒点预警：**
- 战力崩塌
- 输赢不合理
- 主角行动目标和阶段性目标不明确

**不内耗标准：**
1. 把**级别列全**（一重境界、二重境界……有对应的霸气名字即可）
2. **升级前置条件**一定要列好 → 这是主角小阶段的目标
3. 避免战力崩塌的最低要求：**一级打不过二级，二级打不过三级**

**前置条件示例：**
> 凑齐几个神器碎片 → 合成天书 → 从三境升到四境。这是大动机拆解出来的，也是读者不弃书的重要原因。

## 三、素材收集

**建立文件夹或收藏夹，把可能用到的素材和设定全部扔进去，多多益善。**

**灵感枯竭时，这些就是粮食。**

### 3.1 推荐途径：短视频

短视频里有很多：
- 其他书的碎片化解读
- 速读
- 沙雕动画的情节

**优势：** 简短而信息量巨大，碎片化时间就能满足。

**平台推荐机制加成：**
> 经常收集某一类型的视频并点赞收藏，推荐机制会不断推荐类似内容 → 获得没有指向性的、非常广大的素材收集渠道。

### 3.2 收集范围

- 古代/现代背景
- 专业名词、专业工种、专业武器
- 符合主线的脑洞
- 跟想象中类似的图片

## 四、基础准备（书名、封面、简介）

### 4.1 封面设计：形成视觉锚点

**核心：** 封皮是身材，人本身有天生的审美机制。

> 扫过茫茫人海，第一个视觉锚点给你形成的感觉是**形状、曲线和色彩**。

**要求：**
- 颜色足够跳跃、足够吸睛
- 有**纵深感**，能让人产生联想

**纵深感示例：**
> 书名《我与恶魔战斗》，封面是一个巨大的恶魔占据90%背景，下方只站着一个一厘米高的小人影。
> → 读者下意识构建故事："弱小的主角该如何战胜那么强大的恶魔？"

### 4.2 书名：看点提炼

> **书名配合封皮产生联想。** 现在书名已变成**看点提炼**的作用。

**读者习惯：** 封皮吸引 → 下一个聚焦书名 → 书名精准提炼爽点 → 大概率点击

**禁忌：**
> 书名云里雾里、饱含深意、用生僻字 → 这是在跟市场作对。
> **市场要的是迅速知道你满不满足我的口味。**

### 4.3 简介：极度精准的看点提炼

> 简介是加强阅读欲望的工具，是书名和封皮的**进一步诠释**。

**要求：**
- 足够清晰
- 迅速交织成一个矛盾
- 包含：人物、金手指、背景、爽点、冲突

**示例：**
> 我是一个捡垃圾的少年，但我有一件金手指，可以把所有的废物垃圾合成全新的，于是我将两双旱冰鞋合成了一双喷气飞鞋，在这个科技消亡的世界中，成为了第一个飞上天空的人。

## 五、打磨开篇

### 5.1 多版本开篇测试法（核心技巧）

**黄金三章：** 开篇不能墨迹，要有冲突、反差、钩子。

**痛点：** 写完开篇不知道自己写的东西行不行。

**解决方案：**
> **把同一个故事用不同的切入点和事件写3个以上的开篇。**

**为什么：**
- 开篇写不好 → 读者很快弃书 → 后面10万、20万字白费
- 浪费的不仅是3个章节，而是整本书

**测试方法：**
1. 拿3个开篇版本找朋友/编辑看（要有一定网文基础）
2. **让他们只回答一个问题：你想不想继续看？哪个让你有翻页冲动？**
3. 找不同的人，因为不同人直观感受不同

**额外好处：**
- 反复咀嚼三遍后，对故事产生新的感悟
- 把三个版本中精华的部分融合成全新的三章

### 5.2 多版本切入示例（AI叛变故事）

| 版本 | 切入方式 | 要点 |
|------|---------|------|
| **开篇一** | 商场被困+程序员对抗AI | 直接冲突切入，节奏快 |
| **开篇二** | 穷孩子为贴补家用发现AI | 情感代入切入，建立共情 |

**核心操作：** 更换**切入点**和**视角**，同一个故事可以产生完全不同的开篇效果。

## 六、心态调整（最重要的维度）

> **心态才是关键，是最重要的！**

**从全文贯穿的心法中提炼：**

| 心态要点 | 具体表现 |
|---------|---------|
| **不内耗** | 简易大纲、简化拆书、降低准备门槛 |
| **先拿到反馈** | 市场化选题 → 快速获得读者认可 → 更容易坚持 |
| **激情优先** | 先把开头的激情用出来，别花两个月打磨大纲磨灭灵感 |
| **商业化思维** | 用市场眼光看待写作，先满足读者口味再追求文学梦 |
| **开篇反复打磨** | 3个版本不嫌烦，开篇不好后面全白费 |
| **不怕扑街** | 多次扑街后总结逆向选题法，从失败中找到方法论 |

## 七、六维总览表

| 维度 | 核心动作 | 不内耗标准 |
|------|---------|-----------|
| **市场调研** | 逆向选题 + 题材改造 + 拆3-5本头部 | 熟悉套路即可，不读几千万字 |
| **大纲制定** | 大主线+大动机+大矛盾 + 升级体系 | 每条2-3行字，级别列全+前置条件列好 |
| **素材收集** | 建文件夹/收藏夹，短视频推荐 | 碎片化时间，多多益善 |
| **基础准备** | 封面（纵深感）+ 书名（看点提炼）+ 简介（精准矛盾） | 一句话概括：爽点清晰不文青 |
| **打磨开篇** | 同一故事写3个版本，找人测试翻页冲动 | 不嫌烦、不侥幸、融合精华 |
| **心态调整** | 不内耗、激情优先、商业化思维、不怕扑街 | 最重要 |
