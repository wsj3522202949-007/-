# 改文自检与逻辑统一指南

> 整理来源：周大白（代表作《主母日常》《末世重生：大佬从百万囤货开始》）+ 煮熟的来福鸽（千万字经验，代表作《灵墟，剑棺，瞎剑客》）
> 适用对象：所有品类
> 核心定位：通文改稿流程、自检方法、避免越改越乱的策略
> 核心理念：改文不是凭感觉瞎改，改前要有能力驾驭后续，改时要确保逻辑统一、风格一致

---

## 一、通文改稿步骤

### 1.1 周大白：改文决策流程

**核心流程：** `先看反馈 → 自我思考 → 自我总结 → 结论`

**具体执行：**

| 步骤 | 操作 | 说明 |
|------|------|------|
| **看反馈** | 关注每日追更、完读、读者评论 | 大范围点评某个点且跟核心走向不太相关的，就改掉 |
| **自我思考** | 深度思考需不需要改 | 不改会怎么样，改的话需要大改还是小改 |
| **自我总结** | 写完后哪里觉得差点意思 | 三五天内可随时修改 |
| **结论** | 决定改或不改 | 三五天后无很大影响剧情走向和读者体验的，不用动 |

> **自我思考非常重要**，不管是数据还是读者评论都只是一个展示面，一定要自我深度思考需不需要改。

### 1.2 来福鸽：通读 + 朗读 + 检查完整性

**步骤一：通读一遍，总结问题**

问自己四个问题：
- 故事剧情本身不精彩？
- 自己写的有问题？
- 人设没立住，还是人设崩塌？
- 人设与人物行为思考逻辑是否有不符合的地方？

**步骤二：确定修改范围**

| 问题规模 | 处理方式 |
|----------|----------|
| 单章问题 | 单独单章修改 |
| 三五章问题 | 整段故事剧情修改 |
| 十章以上问题 | 大范围修改，需提前总结核心信息 |

> 如果修改章节过多，一定要保证这些章节的核心信息、抛出来的设定类信息提前总结好在一旁。书写新剧情时，把这些贯穿全文的信息点加入进去。

**步骤三：朗读修改**

- 嘴巴读出来
- 读的时候卡顿的地方 → 要么语句太长，要么形容词不合适
- 适当修改，读到自然流畅为止

**步骤四：检查每章完整性**

> 如果把这章作为独立的内容来看，有没有看点？有没有继续阅读下去的欲望？

## 二、自检方法：自己看不出问题时怎么办

### 2.1 周大白：数据 + 横向对比 + 拆书

**方法一：看后台数据**
- 每日追更、完读、读者评论

**方法二：找外部反馈**
- 找朋友、编辑看看
- 找读者聊天，问哪里观感不好、哪些人物不喜欢

**方法三：横向对比（最推荐）**

> 多看同类书！横向对比同类型火书，人家在跟你同字数段上写的都是什么内容：主线还是支线，主角还是配角，剧情推进快还是慢。

**具体操作：**
- 列一个简单的表格或小章纲
- 提炼差不多字数段的内容
- 对比对方推进多少东西，自己推进多少东西
- 看火书在哪里热度爆棚、讨论爆点
- 看自己是否在这个字数段故事内容上平淡没看点

> 自己拆自己的书，自己比对进度，一章对一章的看，能很清楚看到自己章节的差距。

### 2.2 来福鸽：角色换名法 + 读者三问法

**方法一：角色换名法**

> 把章节内的主角名换一个陌生的名字，再去读一遍。问问自己：这如果不是你写的，你觉得好看吗？

**方法二：读者三问法**

把章节内容发给没看过你书的朋友或读者，问三个问题：

| 问题 | 检验目的 |
|------|----------|
| **主角叫什么？** | 人物是否清晰、有记忆点 |
| **他想干什么？** | 目标是否明确、动机是否合理 |
| **他在做什么？** | 行为是否具体、有看点 |

## 三、如何避免越改越乱

### 3.1 周大白：改文的前提——有能力驾驭后续

> **如果把握不了后续剧情了，就不要改了。**

**改文决策矩阵：**

| 问题规模 | 处理方式 | 前提条件 |
|----------|----------|----------|
| **小毒点/小剧情** | 直接删改 | 随时可改 |
| **几章到十几章严重问题** | 慎重 | 必须能驾驭后续剧情衔接 |
| **大改（推倒重写）** | 全部删掉，重写全新剧情 | 明确大纲骨架，保证后续不偏离 |

**大改核心原则：**
- 把整个大剧情全部推倒、全部删掉
- 重新写一个全新的剧情上去
- **紧贴着大纲走向**，把每章落点方向都落在大纲骨架上
- 一点一点修正剧情，同时保证后面的剧情也不要偏离大纲

**大纲骨架不可偏：**

| 类型 | 骨架核心 |
|------|----------|
| 言情文 | 男女主感情线（虐恋就是虐恋，甜恋就是甜恋） |
| 男频升级 | 升级打怪 |
| 都市日常 | 日常主线 |

> 千万不要把大纲骨架走偏，一遍一遍强化故事的核心，才能把故事走向重新拉回核心剧情上。
>
> 大改是一个大工程，一定要明确核心走向，在改动之前心里面要梳理清晰明确才能动手。虽苦，但也很磨砺能力。

### 3.2 来福鸽：逻辑统一 + 风格一致

**逻辑统一：**

> 改文本就是重构故事剧情的过程，难度非常大。不能让小说的前后逻辑因为这一段改文而失效。

**操作步骤：**
1. 确定要修改的所有章节区间（例如修改10章，是从什么讲到什么）
2. 把重要信息、伏笔、抛出来的信息单独记录在一个地方
3. 重新构思故事剧情时，将这些信息再次填充回去
4. 避免前后故事逻辑割裂，让新读者也能连上故事剧情

> 毕竟改文都是为了新涌入进来的读者考虑。

**风格一致：**

> 最简单的问题就是**人设一致性**。

**常见陷阱：**
- 写到后期想改文开篇部分
- 容易把后期主角的人设、行为方式、说话逻辑代入到开篇
- 造成人设前后不一致

**保证方法：**
- 提取当前阶段主角配角的人设心理
- 确保角色的人设、说话方式、思考方式都符合当前故事剧情前后的设定

## 四、两位作者核心观点对比

| 维度 | 周大白 | 来福鸽 |
|------|--------|--------|
| **改文前提** | 有能力驾驭后续剧情才改 | 改文是重构，难度大，需提前规划 |
| **自检方法** | 数据+横向对比火书+拆书 | 角色换名法+读者三问法 |
| **改文流程** | 看反馈→自我思考→总结→结论 | 通读→总结问题→确定范围→朗读→检查完整性 |
| **避免越改越乱** | 明确大纲骨架，强化核心走向 | 提炼信息单独记录，重新填充；保持人设一致性 |
| **小修改** | 三五天内随时改 | 语句卡顿就改，读到自然流畅 |
| **大修改** | 能衔接后续才大改，否则当练笔 | 修改过多时，确保核心信息贯穿新剧情 |

## 五、改文实操 checklist

- [ ] 检查后台数据（追更、完读、评论），定位问题章节
- [ ] 自我深度思考：不改会怎样？改的话大改还是小改？
- [ ] 评估自己是否有能力驾驭后续剧情衔接 → 不能则当练笔继续写
- [ ] 确定修改范围：单章 / 三五章 / 十章以上
- [ ] 如需大范围修改，单独记录核心信息、伏笔、设定
- [ ] 重新构思时确保这些信息填充回去，避免前后逻辑割裂
- [ ] 朗读修改后的章节，语句卡顿处改到自然流畅
- [ ] 检查每章独立性：作为独立内容是否有看点？有阅读欲望？
- [ ] 角色换名法：换成陌生名字再读，判断是否好看
- [ ] 读者三问测试：主角叫什么？他想干什么？他在做什么？
- [ ] 检查人设一致性：说话方式、思考方式是否符合当前阶段设定
- [ ] 确认大纲骨架未走偏：核心走向是否被强化
