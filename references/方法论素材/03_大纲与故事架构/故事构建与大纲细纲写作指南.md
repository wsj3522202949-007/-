# 故事构建与大纲细纲写作指南

> 整理来源：京祺（番茄金番作者，10年经验，代表作《野玫瑰》《我于深渊时见你》）
> 适用对象：所有品类新手
> 核心定位：从0到1的系统创作方法论
> 核心理念：写故事就是盖房子，根基稳才能屹立不倒

---

## 一、如何写出好故事

### 1.1 选择故事题材

**最简单切入点：**
1. 设定一个大致题材
2. 在这个题材里构造一个故事场景
3. 由场景展开小说内容

**示例（重生题材）：**
> 主角正在被恶毒女配折磨 → 女配一把火烧死主角 → 主角重生回到过去 → 故事继续

### 1.2 寻找故事灵感

**方法一：社会热点新闻（抖音）**
- 从新闻事件中吸取灵感
- 提取故事基调、案例原型
- 抓取大人物或小人物，无限扩大构思

**方法二：小人物/小事件四两拨千斤**
- 不一定从大事件展开
- 通过小人物或小事件牵扯出大事件和大背景
- 让读者越看越上头

### 1.3 主角的身份与特点

**核心原则：** 主角必须有让读者第一时间觉得"值得关注、值得追随"的东西。

**反向思考（天崩开局）：**

| 常规思路 | 反向思路（更适合新手） |
|---------|----------------------|
| 主角有超能力 | 主角有几个亿的负债 |
| 主角天赋异禀 | 主角只剩三个月寿命 |
| 主角出身显赫 | 主角有被灭门的凄惨身世 |
| 主角一帆风顺 | 主角有命案在身（被迫反击型） |

> 读者最爱看小垃圾小屌丝的逆风翻盘。天崩开局不仅好写，而且戏剧性强。

### 1.4 确定主角目标（活的目标）

**错误示范（死目标）：**
> 主角只剩三个月寿命 → 努力治病 / 完成遗憾 / 孝敬父母 / 表白

**正确示范（活目标）：**
> 主角只剩三个月寿命 → 胡作非为 / 花光积蓄 / 揍领导 / 去澳门梭哈 → 30万变3000万 → 钱花不完不想死了 → 目标改变

**关键：** 目标不是死的，要随剧情发展而演变，这样才更有吸引力。

### 1.5 冲突与对抗（最核心的吸引力）

**题材和噱头是外衣，人物之间的冲突与对抗才是内核。**

**示例（悬疑开篇）：**
> 主角意外目睹凶杀案 → 本想报警 → 发现被杀的是虐待自己的继父 → 选择旁观 → 继父临死拿钥匙交换求救 → 主角犹豫收下 → 警察赶到，主角被认定为嫌疑人 → 真凶在暗处观察，主角落入圈套

**要点：**
- 不要单线思维，要反转、要出其不意
- 设定好人物关系、微妙关联、对抗
- 藏在暗处的关系网让读者猜了又猜

### 1.6 写作风格与标签

**核心原则：** 拥有独属于自己的写作风格，不被市场淘汰。

| 错误 | 正确 |
|------|------|
| 盲目大量阅读，写成别人的故事 | 练习出属于自己的风格 |
| 盲目追榜单追热点 | 做创新的那个人，创造热点 |
| 读一百本流水网文 | 一本经典读十遍 |

**经典作品的价值：**
- 故事框架、背景、人设、高潮起伏、台词都经过千锤百炼
- 一部好经典可以从一个点延伸出无数个面
- 一百本流水网文可能只总结出一条经验

**天赋的本质：**
> 天赋就是灵性。十个人炒同一道西红柿炒鸡蛋，味道各不相同。学不来的东西才是精华：你的灵性、阅历、对不同角度的看法。

**新手目标：** 坚持写完第一本30万字小说。
- 30万字 = 刚好能把故事写好写详细，不冗长
- 第一本30万 → 第二本50万 → 第三本100万
- 锻炼对整个故事框架的建造能力和把控能力

## 二、三种核心能力训练

### 2.1 脑中的画面感

**原则：** 写作一定是先有画面，才有文字。

**训练方法：**
- 看经典影视作品，把最精彩的几幕戏用文字书写出来
- 还原画面还不够，要还原画面所要表达的感情与氛围
- 追求"氛围感"和"代入感"

**五感描写示例（战场）：**
> 满地狼藉，硝烟滚滚，被烧毁一半的旗帜迎风挥舞，空气中弥散着血腥的味道，战友纷纷倒地，你因重伤忍着剧痛强撑而起，两耳嗡鸣，满目疮痍。

### 2.2 灵感练习

**方法：每天想十个开头（或五个），每个用一百字概括。**

**示例：**
- 女主长期经受家暴，不小心杀死丈夫，何去何从？
- 女主家道中落，被仇人收养养大，后面如何发展？
- 女主魂穿成小说里的恶毒女配，如何自救？

**操作：**
- 每天积累，一周后手握几十个开头
- 挨个筛选：哪些精彩？哪些乏味？哪些能支撑到十万字/三十万字？
- 日复一日，总能找到最好的开头和故事

### 2.3 对故事的建造能力

**三张纸排列组合法：**

| 纸张 | 内容 |
|------|------|
| 第一张 | 脑海里的零散有趣情节 |
| 第二张 | 各类人设及性格特点 |
| 第三张 | 故事背景、时代背景、必备场景 |

**操作：** 打散后做不同排列组合，让奇怪的人设出现在不同场景里，搭配不同情节，碰撞出新火花。

## 三、小说大纲怎么写

### 3.1 大纲的本质

**大纲 = 粗树干**
- 树干之下盘根错节
- 树干之上枝繁叶茂
- 故事是否站得住脚，看树干是否粗壮、枝叶是否繁盛

### 3.2 大纲核心要素

**主线 = 起承转合：**
```
困境 → 目标 → 阻碍 → 努力过程 → 中途意外 → 意外后的转折 → 最终结局
```

**示例（甄嬛传）：**
> 女主一路升级打怪，最后连皇帝都被拿下。从儿女情长到大家大国，一路披荆斩棘。

### 3.3 大纲必备内容

| 组件 | 说明 |
|------|------|
| 主角困境 | 开局身陷什么绝境 |
| 主角目标 | 要达成什么 |
| 阻碍 | 什么挡在前面 |
| 努力过程 | 如何一步步推进 |
| 中途意外 | 什么打乱了计划 |
| 转折 | 意外后如何翻盘 |
| 结局 | 最终走向 |
| 辅线 | 配角的目标、困境、转折、结局 |
| 人物关系 | 配角如何推动事件，带来机遇或挑战 |
| 爽点与反转 | 受困后的小逆袭 + 意想不到的反转，反复循环 |

### 3.4 人物小传

**必备要素：**
- 身份、年龄、职业、性格
- 人物的欲望
- 人物的目标
- 人物惧怕的是什么

**人设丰满的关键——反差感：**

| 反差类型 | 示例 |
|---------|------|
| 外在强势 vs 内在脆弱 | 极度自恋，但在女主面前极度自卑 |
| 白天 vs 黑夜 | 白天救死扶伤的好医生，晚上黑衣夜行的杀人狂魔 |
| 表象 vs 真相 | 好丈夫好领导好父亲，背地里家暴出轨酗酒赌博 |

**人设深度思考：**
- 人物追求的目标是什么？
- 为目标付出怎样的行动？
- 是否被逼入绝境？
- 过往做过哪些不为人知的事？
- 这些事与其他配角有什么牵扯？

> 好的人设占了一大半，务必重视。

### 3.5 大纲不是死的

- 给自己留下想象空间
- 很多灵感在书写过程中逐渐产生
- 一边写，一边修改大纲

## 四、小说细纲怎么写

### 4.1 细纲的本质

- 大纲 = 确定故事风格、走向、梳理大框架
- 细纲 = 开枝散叶，督促紧紧围绕主题，不把故事写跑偏

### 4.2 细纲写法

**以每天4000字更新为例：**
- 4000字 ≈ 两个小情节
- 每个小情节约2000字

**示例（女主被推下山崖）：**

```
情节一（2000字）：
  女主被女配推下山崖 → 写坠崖过程 → 坠落底部奄奄一息
  → 戛然而止（悬念：女主是死是活？）

情节二（2000字）：
  切画面到女配 → 女配认定女主必死 → 伪造自杀现场
  → 欺骗女主家人 → 幻想取代女主的地位

情节三（悬念回收）：
  切画面回女主 → 女主没死 → 自救或被男主拯救
```

> 4000字写不完就写7000字，内容可以扩充很多。

### 4.3 细纲的作用

- 简单写出后面情节的大致内容
- 保证故事不脱离主题
- 在紧紧围绕细纲的前提下扩充内容，让章节丰满
- 字数越写越多时，防止忘记前面剧情
- 不存稿的人，每天更新后花三五分钟捋顺第二天的细纲，隔天提笔就能写，几乎不卡文

## 五、小说开头怎么写

### 5.1 开篇核心

**直接从狗血开始。**

> 自古套路得人心。天龙八部、神雕侠侣、欧美拯救世界，都是同样的套路，百吃不厌。

### 5.2 开篇五要素

| 要素 | 说明 |
|------|------|
| **噱头** | 是否有吸引人的点 |
| **代入感** | 读者能否代入主角 |
| **氛围感** | 情绪是否烘托到位 |
| **冲突** | 是否由冲突展开 |
| **期待值** | 读者是否想继续看 |

### 5.3 代入感示例

> 女主在丈夫手机里发现丈夫和小三的聊天记录。善良的女主多年操持家中，一路扶持丈夫，换来的却是背叛与偷情。

- 身边真实事件比小说更狗血
- 真实感是最容易代入的

### 5.4 不要大篇幅交代背景

- 没有读者有耐心看无聊的背景介绍
- 由冲突展开剧情，或由极具画面感的剧情展开故事
- 背景在后续情节中简单带过，通过事件或对话介绍

### 5.5 期待值的拉扯（弹簧原理）

**错误：** 开头直接爆缸拉满，后面没有期待值。

**正确：** 像弹簧一样反复拉扯读者的期待神经，越拉越满，在适当的时候一击必杀。

**示例（女主发现丈夫出轨）：**
- 不是直接大闹离婚
- 而是暗中隐忍，伺机报复
- 联合闺蜜设陷阱
- 在小三不知情的情况下报复
- 牵扯出闺蜜、小三、婆婆
- 故事被无限拉长

### 5.6 反差感拉期待

| 套路 | 效果 |
|------|------|
| 真假千金 | 身份反差 |
| 身份互换 | 命运反差 |
| 互换重生 | 视角反差 |
| 善良女主穿成恶毒女配 | 人设反差 |
| 穷养男主实为首富之子（《抓娃娃》） | 认知反差 |

### 5.7 开头必须明确的四问

1. 主角的动机是什么？
2. 什么阻挡了主角前进？
3. 主角和反派的目的分别是什么？
4. 他们制定了怎样的计划？

### 5.8 开篇写作原则

> **希区柯克：好的故事就像人生，只是少了所有无聊的部分。**

- 每一个字都要有意义
- 每一句话、每一个用词，都要对后续情节有推动作用
- 否则就是废话
- 精简、打磨、再打磨
- 删除所有无聊和无意义的部分
