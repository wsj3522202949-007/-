# 核心纲与强设定大纲法

> 整理来源：煮熟的来福鸽（八百万字创作经验，代表作《灵墟》《剑棺》《瞎剑客》，擅长玄幻题材，文风热血，设定严谨）
> 适用对象：偏男频，女频可参考
> 核心定位：大纲制作三部曲——核心纲、设定集、OKR大纲法
> 核心理念：大纲相当于开车的导航，即便略有偏差也能带你达到目的地

---

## 一、合格大纲的定义

### 1.1 什么是大纲

> 大纲通常是**500-2000字左右的一段话**，就是你这部小说从头至尾的故事线精炼内容。

**示例（都市悬疑，168字）：**
> 张三被陷害之后，从之前的国企领导一下子变成了通缉犯，他失去了所有，甚至不能回家看看孩子就开始逃命，他开始着手调查到底是谁杀了自己的妻子，又是谁想要将自己置于死地，谜团重重，调查深入之后他才发现，自己妻子作为银行经理，生前竟然牵扯了许多大额交易等等，有人则是一直在暗中阻拦着他，威胁、恐吓、求饶、最终张三经历了重重困难终于将真相公之于众。

**检验标准：**
- 开篇、过程、结束，**主线清晰明了**
- 读者一开始就能感受到主角的目标是什么
- 驱动力是什么

> 简略版本的核心大纲内容，就是**"你整本书是讲述的一个什么样的故事"**。

### 1.2 大纲的比喻

> **小说的大纲就像旅游攻略一样。**

| 旅游攻略 | 对应小说 |
|---------|---------|
| 去哪里，什么时候出发 | 故事的开头 |
| 坐火车还是坐飞机 | 剧情的推进方式 |
| 布达拉宫→纳木错→珠峰大本营 | 故事剧情的关键节点、高潮剧情 |
| 预防高反的药、掉落没拿的手电筒 | 故事的伏笔 |
| 预计去旅游几天 | 故事的长度篇幅 |
| 沿途的风景、抵达后的感慨 | 故事的过程和结束 |

## 二、大纲制作三部曲

### 第一部：核心纲（分表层+里层）

#### 表层：骨架框架

> 表，是我们整部小说的**骨架框架**。沿着框架写，行文在框架内，它是约束剧情走向不跑偏的关键点。

**示例：** 张三不甘心被陷害，调查妻子被杀害的真相。

#### 里层：核心卖点

> 里层更像是我们小说的**核心卖点**。也像是命题作文的要求。

**示例：** 我想写一部剧情反转、情节紧张刺激的悬疑小说，一部能够让所有人看完之后惊呼"哇塞"的悬疑小说。

**判断标准：**
> 日后读者在给别人安利的时候会怎么介绍你这部小说？

> "兄弟，我昨天看了一个贼好看的玄幻小说，一点不俗套，杀伐果断，行文流畅，剧情写的贼好，嘎嘎热血，还有兄弟情。"

**三层递进：**
> **你想写什么题材 → 你想写一个什么样的故事 → 读者会怎么总结你的小说。**

**给自己打的标签：**
- 玄幻小说表层是主角的冒险故事
- 里层是：**这是一部热血、兄弟情、宗门护犊子的小说**

---

### 第二部：设定集

**最重要的一个设定不是境界设定，而是大的故事世界背景（世界观设定）。**

> 这是一个什么样的世界，以及时代背景。

**示例：**
- 灭世大战之后，整个仙界由四大仙帝所统治
- 红月降临，异世界怪物入侵蓝星，许多人觉醒异能对抗怪物

**设定范围：**
世界观、境界、法器、货币、修炼方式……

**核心原则：**
> **所有设定都是作者主观设定的，后期不可自我反驳。**
> 作者主观的强设定——在这部小说里，XX就是这样！直接告诉读者。

### 第三部：OKR大纲法（核心技巧）

#### 3.1 概念

- **O (Objective)** = 目标
- **KR (Key Results)** = 完成目标的途径、方法

**KR的三个条件：**
1. **可见性** —— 能不能看到进度
2. **可实现** —— 能不能完成
3. **一定是可以完成目标O的必要途径**

> **关键：如果你按照设定的KR1/KR2/KR3……去做，那么最后一定可以完成目标O。**

#### 3.2 方法演示

**O：** 张三为父母报仇雪恨，并且成为苍玄界最强之人。

| KR | 内容 | 作用 |
|:--:|------|------|
| **KR1** | 张三重新修炼，重塑丹田 | 获得实力 |
| **KR2** | 游历大陆增强实力，寻找仇敌踪迹 | 提升实力+追踪 |
| **KR3** | 和帝族圣女结婚，获得资源提升实力 | 资源获取 |
| **KR4** | 找到仇人，开始复仇计划，大仇得报 | 完成复仇 |
| **KR5** | 探索禁地，打败六大至强者，成为至强者 | 终极目标 |

> 按照所有KR顺序去做，是不是可以完成目标O？**没有任何一条KR是无效的。**

#### 3.3 逐级拆解

> 第一步剧情刚开篇的时候，只需要将**KR1当做一个新的目标O**，继续拆分KR。

**KR1 "张三重新修炼，重塑丹田" → 变成新的O：**

| 新KR | 内容 |
|:----:|------|
| KR1 | 寻找修复丹田的灵物（可继续细分：如何找到？） |
| KR2 | 通过玄天宗弟子考核，进入涅槃秘境，修复神魂 |
| KR3 | 觉醒金手指，虚无丹田 |

> **所有的KR必须是完成目标O的途径和手段。**

#### 3.4 实际应用

- **100W字作为一个阶段性节点**，设定一个目标O
- 接下来这一百万字的内容，都根据目标O来细分更多的KR
- **推荐工具：** 思维导图（如幕布）

#### 3.5 剧情倒推法（填充法）

> 脑子里灵光一闪，想到了一个非常好的故事剧情。先把高潮结局记录下来，然后开始**倒推铺垫和爆发的高潮情节**。

> 一般构思出来的高潮故事剧情，都可以提前预设好之后进行剧情倒推。你已经把一个故事情节的结束构思好了，只需要填充之前是如何发生这个故事的，怎么发展的，慢慢写出来就可以了。

## 三、坚持：静默期的心态

### 3.1 作者真实经历

| 时间节点 | 事件 |
|---------|------|
| 2021年1月 | 开始写第一部玄幻小说，兼职写作 |
| 2021年2月 | 第三次签约申请才过（投遍诸多平台） |
| 2021年3月 | 第一笔稿费：127.1元 |
| 2月-8月 | 半年多，风雨无阻不断更，每天抽空码字 |
| 6个月累计稿费 | 800多块 |
| 签约第6个月 | 终于来量，收入一直在增加 |

### 3.2 坚持的理由

> **就算没有成绩也要好好写到完结。**
> 那时候不知道为什么，就是天天写，也不断更。
> 可能是为了**当初那十几个经常留言的读者**吧，心里憋着一口气。

> **如果没有当初的坚持，就不会有现在的自己了。**

## 四、三部曲总览表

| 部分 | 内容 | 核心要求 |
|------|------|---------|
| **核心纲-表层** | 故事骨架（开头→过程→结尾，主角目标、驱动力） | 主线清晰，500-2000字 |
| **核心纲-里层** | 核心卖点/标签（读者会如何安利你的书） | 题材→故事→读者总结 |
| **设定集** | 世界观、境界、法器、货币等 | 主观强设定，后期不可自我反驳 |
| **OKR大纲法** | O=目标，KR=完成途径，逐级拆解 | 所有KR必须能完成O，100万字一个节点 |
| **剧情倒推法** | 先构思高潮结局，再倒推铺垫过程 | 灵光一闪时记录，填充前因 |
