# 副本设计与剧情架构指南

> 整理来源：一月九十秋（代表作《诸神愚戏》，多次登上番茄巅峰榜，单部百万在读，评分9.8）
> 适用对象：所有品类
> 核心定位：副本结构设计、设计流程与方法、各阶段写作技巧
> 核心理念：副本不是支线，而是对主线有推动作用的完整事件

---

## 一、核心概念与基础框架

### 1.1 副本的定义

> **副本其实就是小段的故事。** 小说整体是一个大的故事，里面嵌套了许多小故事，对主线有推动作用且篇幅不太短的情节就是所谓的副本，不是支线，而是单纯的一个完整的事件。

**示例：**
> 小说A分第1、2、3卷，第一卷里有两到三个大的篇章（A11-A12-A13），这三个事件就是副本。

**核心原则：**
> 无论是副本还是剧情，**都是为角色人设服务的**。想要将故事写得有趣，本质上还是在写人——人的成长、变化以及跟其他人的交互串联起来成了一篇好故事。

### 1.2 基础三段式

| 阶段 | 定义 | 作用 |
|------|------|------|
| **起因** | 铺垫和期待 | 事件预告，丢出饵，让读者模糊知道之后会发生什么 |
| **经过** | 剧情和代入 | 故事主干，埋爽点，推动高潮 |
| **结果** | 收获和成长 | 高潮爽点的延续，主角得到什么 |

**爽点节奏对应：**
> **爽点预热 → 爽点爆发 → 爽点回味**

**核心认知：**
> **爽才是网文的关键，但这个爽不是让作者写的爽，而是读者读着爽。**

### 1.3 爽点设计

**设计前必须想出一个爽点，这个爽点本质上就是大纲。**

**操作：** 扩写爽点，让大纲从一点火花变成一副骨架。

**个人倾向：**
> 爽点可以不是非常炸，但一定要有**记忆点**。

**爽点类型（不同文不同侧重）：**
- 日常文：重收获
- 无敌横推：重碾压打脸
- 长篇玄幻：重成长
- 悬疑文：揭秘或反转
- 恋爱：拉扯修罗场

**本质：** 反哺主角，让读者看到主角在这段剧情里与其他人不一样的地方、出彩的地方。

**个人套路：**
> 把自己代入主角视角，去想一种**"另辟蹊径"的破局方法**，达到**意料之外情理之中**的点睛效果。

## 二、设计流程与方法

### 2.1 先设计剧情骨架

**写的时候先设计小剧情的大纲。**

**目的：**
1. 防止剧情中段过度卡文（知道结局就有目的性和动机）
2. 带有目标性的写作更容易**伏笔埋线**，让故事更有趣

### 2.2 倒推法

**常用方法：把爽点当成剧情高潮，锚定高潮位置后，把整个故事倒推出来。**

**示例（《愚戏》第三个副本）：**
> 先预定结局：敢于死亡才是副本通关的关键。前面剧情已立起"试炼中死亡后果很严重"的认知，揭晓死亡是答案时就有反转效果。然后锚定这个结局去推之前的剧情——想试炼中的角色如何合理地死亡。

**优势：**
- 结局固定，人物线是收束关系，更容易揣测角色动机
- 结合角色性格时有方向感，不迷茫
- **可以在前文大胆塞伏笔**

### 2.3 大纲的灵活性

#### 填坑准则

> **挖坑一时爽，填坑火葬场。** 挖坑就是拉期待，没留一个坑就相当于用钩子拉了一条线勾在读者身上。

**锚定结局的好处：**
- 伏笔指向同一个结局，即使结局没那么精彩，前文伏笔同一时间引爆也会起到加成作用
- 读者读到结局回想起先前的种种暗示，会觉得故事更加合理有趣
- **避免先射箭再画靶的问题**

**平衡点：**
- 有的人设计细纲不卡文，详细到每章主角做什么、其他人有什么反应
- 有的人只有结局锚定，中间自我放飞，灵感到哪写到哪
- **写文没有任何标准范式，找到最适合自己的方式**

**总结公式：**
```
设计爽点（高潮、结局）→ 反推故事，填充枝节 → 开写
```

## 三、各阶段写作要点与技巧

### 3.1 起因（铺垫和期待）

#### 提前埋线

> **在某个事件之前就开始早早拉期待，提前铺垫。** 不要事到临头突然来个事件。

**期待的本质：** 知而未见
> 读者预见了一件即将发生的事，想要看到落地，但你没有让它落地，中间线索却总提起或指向这件事。

**这个"事"：** 其实就是**人物的碰撞和角色变化**。

#### 锁链式结构（核心手法）

> **写事件推动不能简单使用串联模式（A-B-C-D排队），而要像锁链一样，一个环扣的开头已经在上一个环扣的中间了。**

**分段结构：**
- 每个事件分成三段：A1-A2-A3，B1-B2-B3
- 拉长铺垫：A1-A2-B1-A3-B2-C1-B3……
- **把下一个事件的开头嵌入到前面一个事件的过程中**

**示例：**
> 玄幻调查探案，主角找到线索指向一个跟此次事件无关的门派。下一个副本要写这个门派，但没想好具体写什么，那就**侧写其他配角的神态反应小动作**，让人一看就知道这个牵扯里有鬼。不明说是什么事情本就符合人物的隐瞒心态，不算出戏。

#### 伏笔类型

**世界观的展开也是伏笔的一种：**
- 收获的新消息、新情报
- 遇到的新人物
- 传言、八卦
- 发现的神秘东西

**伏笔深浅：**
- **深伏笔**：引爆时有爽感，但前期需忍受平淡期（太深可能被忘记）
- **浅伏笔**：短线直接引爆，短平快

**进阶：多剧情嵌套**
> A故事中段引出B故事，A故事末尾捎带提一嘴C故事，B故事开始C故事造势，B故事完结D故事又跟上——期待感就不会断。

**注意：** 嵌套不是越多越好，过于花里胡哨会引起阅读疲惫，要**平衡故事和技巧**。

### 3.2 经过（剧情和代入）

#### 核心手法

**代入感：** 坚守角色人设不漂移。

**写情节人物对碰时：**
- 代入每个角色视角去写
- 改文时代入每个角色看说的是否合理
- 保住人设、发挥人设特点，阅读时就有对应的代入感

#### 节奏和合理性

> **适度合理，逻辑自洽即可。** 完全合理很少存在，追求极度合理会缺失爽感。

**示例：**
> 打脸爽文里路人点评主角不行，地位越高的反驳事后爽感越强烈。但其实地位越高的人物行为举止上不会有这种反应——可如果都写成老妖怪不作声，爽点就没了。

**核心：**
> **只要逻辑没大问题，能够自洽，适度放弃合理性是可行的。**

#### 高潮把控

- **高潮部分篇幅不必太长**，集中爆发比过于冗长的紧张节奏效果更好
- **高潮幅度也可以不用太大**，不断写小的起伏
- 大高潮过后，很多人阅读体验满足就会失去追读动力——**所以要提前拉期待，留好钩子**

#### 主角闪光点

> **着重描写主角的闪光点（破局之策）。**

**爽点立体化示例（玄幻）：**
- 明明能正面打赢，但**合纵连横不出力让其他人为己所用**碾压敌人 → 凸显主角的智
- 打赢了干掉敌人，但**把一切与敌人有关的反扑提前镇压** → 凸显主角果断

**核心：**
> 塑造人设魅力，让事件反哺到人设身上去。

#### 读者反馈

> 有的时候写文自嗨，觉得自己写得不错但反响不一定好。**读者一定知道是什么在吸引他们看下去**，所以他们的反馈能让作者找到新的支线。

**操作：**
- 抄书评是很好的手段
- 众筹写书能增加读者粘性
- **不能完全跟着读者走，也不能跟读者反馈背着走**

### 3.3 结果（收获和成长）

#### 获得感

> **高潮之后舒缓节奏，给读者按摩。** 这部分也是很多读者喜欢看的——人物成长的本质是**获得感**。

**收获类型：**
- 财富
- 道具
- 能力
- 情报线索
- 新建立的人物关系

#### 钩子衔接

> 收获最好可以成为下一个事件或后续剧情的钩子，就算不能，也需要跟后续剧情有连接作用。

**日常穿插：**
> 写日常其实挺难，因为写日常是在写人设。日常的对话和琐碎事件中，最好要展现出某角色对某件事的态度，以此强化人设。

**注意：**
> **一定不能写无意义的水文。** 如果不擅长写日常，放弃略过也行，硬写不仅水字数，还有消耗人设的风险。

## 四、核心心法总结

| 模块 | 核心要点 |
|------|---------|
| **副本定义** | 对主线有推动作用的完整事件，不是支线 |
| **三段式** | 起因（铺垫期待）→ 经过（剧情代入）→ 结果（收获成长） |
| **爽点节奏** | 预热 → 爆发 → 回味 |
| **设计方法** | 倒推法：锚定结局 → 反推剧情 |
| **填坑原则** | 锚定结局后大胆塞伏笔，指向同一结局 |
| **锁链结构** | 下一个事件的开头嵌入前一个事件的过程中 |
| **伏笔类型** | 深伏笔（长线爽感）+ 浅伏笔（短平快） |
| **高潮把控** | 篇幅不必太长，幅度不必太大，持续小起伏 |
| **主角闪光点** | 破局之策立体化，事件反哺人设 |
| **日常写作** | 强化人设，不写无意义水文 |
