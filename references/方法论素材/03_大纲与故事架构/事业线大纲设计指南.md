# 事业线大纲设计指南

> 整理来源：任欢游（番茄金番作家，代表作《缚春情》《无情调》）
> 适用对象：偏女频向，男频可参考
> 核心定位：事业线大纲的系统构建方法
> 核心理念：事业线核心只有四个字——从无到有

---

## 一、事业线的核心

### 1.1 本质

事业线的重点只有一个：**功成名就。**

| 题材 | 事业线终点 |
|------|-----------|
| 种田文 | 成为富豪 |
| 宫斗文 | 成为皇后/太后 |
| 言情文 | 行业翘楚 |
| 脑洞/男频 | 能力/等级升级 |
| 末日文 | 建立最牛基地，成为老大 |

> 无论结局是隐居乡村还是登顶巅峰，剧情推进的方式方法是相同的。

### 1.2 核心公式

```
事业线 = 从无到有
```

如果还摸不清事业线，就记住两个字：**升级。**

| 题材 | 升级维度 | 示例 |
|------|---------|------|
| 种田文 | 财力升级 | 白手起家 → 钱权皆在手 |
| 宅斗文 | 身份升级 | 低等丫鬟 → 贴身丫鬟 → 姨娘 → 正妻 → 主母 → 掌管中馈 |
| 宫斗文 | 身份升级 | 秀女 → 嫔妃 → 娘娘 → 皇后 |
| 修仙文 | 能力升级 | 练气 → 筑基 → 金丹 → 元婴 |
| 现代言情 | 身份升级 | 实习生 → 部门主管 → 总裁 |
| 艺术行业 | 声望升级 | 画手 → 知名画手 → 行业标杆 |

## 二、事业线大纲构建：种田文示例

### 2.1 大剧情点走向

```
一穷二白 → 赚到第一桶金 → 赚到第二桶金 → 引入冲突 → 冲突升级
→ 亮出底牌 → 出风头 + 获得补偿 → 继续升级
```

### 2.2 详细案例演示

**背景：** 种田文女主醒来发现家里一穷二白，无米下锅。

#### 第一阶段：向上（赚到第一桶金）

| 剧情 | 说明 |
|------|------|
| 目标 | 赚取第一桶金 |
| 方式 | 去山上采集木耳 |
| 行动 | 做凉拌木耳大卖 |
| 结果 | 赚钱给家里人改善生活 |

> 此时剧情向上，需要加入冲突来调整节奏。

#### 第二阶段：冲突引入

| 剧情 | 说明 |
|------|------|
| 冲突 | 邻居大娘眼红，带18个儿子霸占山头，不让女主采木耳 |
| 升级 | 女主家老弱病残，打不过，被迫让出木耳市场 |
| 再升级 | 大娘不依不饶，逼女主嫁给48岁傻儿子，答应每天给二两木耳 |

#### 第三阶段：铺设期待感

**核心技巧：女主手中有底牌。**

- 底牌女主知道，读者知道，反派不知道
- 读者期待：女主什么时候亮出底牌，给反派致命打击

**示例底牌：**
> 山中木耳有十种，只有一种能吃，其余全有毒——只有女主知道，大娘不知道。

#### 第四阶段：爽感爆发

**爽感双要素：**

| 爽感类型 | 示例 |
|---------|------|
| **出风头** | 大娘卖出毒木耳，吃坏乡亲，女主用知识解毒救人 |
| **获得补偿** | 救的是村长一脉单传的儿子/官夫人，村长/官府把大娘家产充公给女主 |

**延伸爽感：**
> 女主得到邻居房子后，发现后院有满满一院子的木耳。

## 三、事业线通用套路总结

### 3.1 核心规律

所有的区别，就是：
- 赚到手的这一桶金，**金额大小**
- 受到的冲突，就是**主角受挫的大小**
- 后面的情绪补偿/物质补偿，就是**爽感的大小**

### 3.2 事业线公式

```
起点（一无所有）
  ↓
发现商机 → 赚到第一桶金
  ↓
继续发展 → 赚到第二桶金
  ↓
引入冲突（反派眼红/打压）
  ↓
冲突升级（主角受挫/被迫退让）
  ↓
暗埋底牌（女主知道，读者知道，反派不知道）
  ↓
亮出底牌（反击）
  ↓
出风头 + 获得补偿（物质/身份/声望）
  ↓
进入下一阶段（升级后的新起点）
```

---

## 四、冲突设计要点

### 4.1 为什么必须加入冲突

- 没有冲突的文章和没有挫折的主角，显得单一寡淡
- 冲突是拉动读者情绪的关键
- 冲突是体现人设、加重人物弧光和魅力的必须条件
- 一味写爽点，会让人物性格和剧情显得浮夸、漂浮

### 4.2 冲突的节奏位置

在完成一个相对大的剧情点后，加入冲突来调整整体节奏。

**冲突后的剧情走向：**
```
事业受到打击 → 主人公反抗 → 反抗中插入期待感和爽点
```

## 五、不同题材事业线的异同

### 5.1 本质完全相同

无论种田、宫斗、宅斗、修仙、现代言情，事业线核心完全一致：

| 升级类型 | 代表题材 |
|---------|---------|
| 财力升级 | 种田、商战 |
| 身份升级 | 宅斗、宫斗、职场 |
| 能力升级 | 修仙、玄幻、异能 |

### 5.2 套用时只需换皮

把种田文的"木耳"换成：
- 宅斗文的"管家权/嫁妆"
- 宫斗文的"恩宠/位分"
- 修仙文的"灵石/法宝"
- 现代言情的"项目/客户"

套路骨架不变，只换外在元素。

## 六、感情线与事业线的交叉融合

### 6.1 融合原则

| 原则 | 说明 |
|------|------|
| 双线并行 | 感情线和事业线同时推进 |
| 互相服务 | 事业事件催化感情变化，感情事件推动事业发展 |
| 不单独抽离 | 不在事业低谷时大段单独写感情，反之亦然 |

### 6.2 融合示例

| 事业节点 | 感情变化 |
|---------|---------|
| 女主创业缺钱找投资人 | 投资人正是男主，初识触发 |
| 女主店铺被竞争对手打压 | 男主暗中相助，感情升温 |
| 女主事业遭遇重大危机 | 男主并肩作战，确定关系 |
| 女主事业达到新高度 | 感情也进入新阶段（成婚/共同经营） |

## 七、操作步骤总结

### 步骤一：确定事业线核心
- 明确你的题材对应哪种"升级"（财力/身份/能力）
- 明确终点是什么（富豪/皇后/行业标杆/巅峰强者）

### 步骤二：画出事业线公交站地图
- 起点：一无所有
- 站点：第一桶金 → 第二桶金 → 冲突 → 冲突升级 → 亮底牌 → 出风头+补偿
- 终点：功成名就

### 步骤三：设计冲突与升级
- 每个大剧情点后加入冲突
- 冲突必须升级，不能原地踏步
- 冲突是体现人设和弧光的必须条件

### 步骤四：暗埋底牌，铺设期待感
- 底牌：女主知道，读者知道，反派不知道
- 期待感：读者等待女主何时亮牌反击

### 步骤五：爽感爆发
- 出风头（女主展现实力/智慧/能力）
- 获得补偿（物质/身份/声望/情感）

### 步骤六：将事业线与感情线交叉
- 事业节点嵌入感情变化
- 感情推进关联事业进展
- 确保双线不分离、不抢戏

---

> 事业线有了这个走向后，定制后续剧情就变得非常简单。
>
> 所有的区别，就是金额大小、受挫大小、补偿大小的分别。
>
> 用这样的框架，新人就可以写出很成熟的事业线大纲。
