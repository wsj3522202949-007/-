# 卡文突破与持续写作指南

> 整理来源：京祺（番茄金番作家，10年经验，代表作《野玫瑰》《我于深渊时见你》）
> 适用对象：偏女频向，男频可参考
> 核心定位：卡文应对、保证不断更、突破十万字大关、提升签约率
> 核心理念：流水不争先，争的是滔滔不绝；坚持才是成神的致胜法宝

---

## 一、卡文怎么办

卡文有三种情况，分别对应不同的解决办法。

### 1.1 情节卡顿（已做充分准备的前提下）

如果故事题材、大纲、主线、支线、人物设定、人物关系、起承转合都已准备好，甚至写出了几十章细纲，卡文几乎不存在。

但如果还是卡了，四个解决办法：

| 方法 | 操作 | 核心 |
|------|------|------|
| **复盘大纲细纲** | 拉出小说大纲，从头到尾复读一遍 | 查漏补缺，捋顺后续情节 |
| **从配角入手** | 打开细纲，寻找还没解决的配角故事线，拆开预埋的包袱 | 让配角登场，丰满剧情 |
| **加快剧情进度** | 精简卡文阶段的情节，主动跳出卡文区域 | 千万别水文、别写流水账 |
| **换地图换支线** | 给主角制造更大矛盾，让主角身陷困境、逃亡、再翻身 | 复仇结束 → 惹到不该惹的人 → 逃亡 → 再复仇 |

> **友情提示：** 卡文时千万千万别水文，千万别写流水账。很多新手不知道写什么就写无关痛痒的东西凑字数——这是大忌！很多读者就是在这个过程中流失掉的。

### 1.2 因没有框架卡文（最普遍）

> 很多人不写大纲，也不写细纲，提笔就写，酷酷一顿写，写到中间写不下去，卡住了。

**解决办法：** 回头整理细纲，你会发现有一堆没填完的坑，随手拿过来一个就能继续写。

**根本办法：** 下一本好好写大纲和细纲，不然受苦受难的只会是自己。

### 1.3 因个人原因卡文

情绪原因、身体原因、灵感问题、素材问题。

**解决办法：**

| 原因 | 对策 |
|------|------|
| 情绪不好 | 休息，不用非逼着自己写 |
| 身体累了 | 好好休息一两天，看电影、看书、听音乐、逛公园、吃好的、睡个好觉 |
| 灵感枯竭 | 平日里很妙的灵感都是在身体愉悦和放松的情况下才会出现 |
| 素材不足 | 翻之前随手记录的素材（每天积累十个素材/十个开头的习惯） |

> 记不记得我在第1节课教过大家：养成每天积累素材和写开头的习惯，每天写十个开头，或每天随手积累十个素材。等到卡文那天，把之前记录的素材拿出来翻一翻，很容易就能找到精彩的点子。

**终极保险：** 有存稿的好习惯，卡文只是时间问题，都会迎刃而解。

## 二、如何保证不断更

### 2.1 核心：坚持

> 这个问题主观性太强，是个人意志力的问题。你能坚持住每天更新，自然就不会断更。

**京祺的个人经历：**
- 大二开始写短篇小说
- 大四毕业正式开始写长篇小说
- 一写就是十年整，几乎天天写、夜夜写
- 写了两千多万字，十几本小说
- **最长更新记录：连着更新365天，没断更过，每天4000字打底**

**两个核心方法：**
1. 把坚持更新的概念刻进骨子里
2. 不停地给自己正向洗脑，相信自己可以

> 写小说最后拼的就是耐力。基础知识学完以后，拼的就是持久力、理解能力，以及一点点的天赋。

> 很多人学了一肚子写作知识，但是他不写啊，迟迟不动笔——这跟没学有什么区别？

> **写网文想成神，没有捷径。最基础的要求就是尽量别断更，坚持写，日日写，在写作过程中总结经验，一本接一本地往下写。只有"坚持"二字，才是成神的致胜法宝。**

> 再笨也能靠着"努力码字"踏出一片天地。努力的主动权牢牢掌握在我们手中，所以光是冲着这一点，我们就不能断更。

### 2.2 辅助办法

| 办法 | 说明 |
|------|------|
| **完善准备** | 大纲、人设、主线支线准备完善，想断更想卡文都很困难 |
| **组队码字** | 在番茄里组队，找小伙伴一起比拼码字，断更就惩罚自己 |
| **主动存稿** | 新手开书建议主动存稿，存3-5天稿子，留有修改余地和思考时间 |

### 2.3 新手码字建议

- 不一定非得日更4000字，每天写2000字也可以，卡文时每天1000字也可以
- 别让自己手生了，时间长了不写，灵感也会枯竭
- 手速不是天生的，是练习出来的
- 新手前三本书大概率是练手用的，可能没什么成绩，但一定是一本比一本好
- 初期速度不用求快，一小时几百字都可以，慢慢形成习惯，思路捋顺了，手速自然就上来了

> **新人还是那句话：基础知识学完以后，就动笔闷头写，一口气写个三万字，再回头去改，不要写写停停。初期的连贯性是很重要的。就算是卡文，也要硬着头皮写。**

> 说一千道一万，想要不断更，就要把基础功打好，把课程学明白学扎实，然后去实操训练自己，保证日更，不要偷懒！

> **一万小时定律亲测有效。当初二百人的作者群，最后可能就只剩下七、八个人还在写。**

> 写作是个长跑马拉松，坚持到最后的人才是赢家。把写作练习成肌肉记忆，让身体习惯码字这件事。你要把码字当成终身事业，你才会赢。

> **流水不争先，争的是滔滔不绝。**

## 三、如何突破十万字大关

### 3.1 根本问题：故事不够大、不够丰满

> 很多人写不到十万字就放弃，主要就是因为不会写，脑袋里没有系统的方法论；或者会写了，但没有足够多的素材积累。

**突破十万字的关键：** 系统性学习，把前面的基础都打好了，想不突破都困难。

**写不到十万字的根本原因：** 故事不够大，不够丰满，人物关联不够精彩，故事框架从一开始就没有搭建好。

### 3.2 开新书前要想好的四个问题

| 问题 | 说明 |
|------|------|
| **开篇是否精彩？** | 开篇的包袱是否给出来了？给了包袱不要当即拆开，要留着吊读者胃口 |
| **故事框架够庞大吗？** | 主角的困境、目标、反转都想好了吗？足够支撑三十万字或五十万字吗？ |
| **人物关系够耐人寻味吗？** | 是否爱了不该爱的人？家庭背景如何？正派与反派的关联有没有给主线加分？有没有让人又爱又恨的角色？ |
| **明线暗线多线如何发展？** | 主线发展到哪个阶段需要牵出更精彩的支线？多线并行如何安排？ |

> 这些问题不用一次性想清楚，搭建好故事大纲后可以慢慢添加。想清楚了，别说十万字，五十万字都不够你发挥。

### 3.3 如何把故事写庞大

**示例：电视剧《我的兄弟姐妹》**
> 弟弟妹妹被送到不同家庭抚养长大，有了不同的成长路径。四个兄弟姐妹成年后互相寻亲，再次相遇时，同样出身的人却有了各自不同的人生轨迹。

> 很小的故事，但可以书写的内容非常之多。同样出身的四个人物，走向四条不同的人生旅途，经历四种截然不同的人生转折，成长成四种不同的人物性格。

**核心认知：**
> 突破十万字大关，**考验的是对故事创作的综合能力**。只有多练多学习，才能把故事越写越长，越写越丰满。

## 四、如何提升作品的签约率

番茄小说平台投稿签约相对容易，包容性强。以下是编辑建议：

### 4.1 基本要求

| 要求 | 说明 |
|------|------|
| **三观正** | 符合社会主流价值观，不违反国家法律法规政策 |
| **不抄袭** | 不能高仿，更不能抄袭 |
| **阅读观感好** | 没有错别字，语句流畅，排版简洁清晰 |

### 4.2 题材方面

- 网文小说要和平台相适应，作品题材要适合番茄小说平台
- 平时研究番茄平台榜单，看看有没有自己想写的类型
- 研究同类型的大体数据和流量
- **文好可破一切限制**

### 4.3 内容方面

| 维度 | 说明 |
|------|------|
| **创新** | 创新一定是最重要的 |
| **切入点** | 作品的切入点是否新颖 |
| **出场人物** | 人物设定、人物关系 |
| **事件安排** | 故事线索是否合理 |
| **独创性** | 好的想象力 + 合理的逻辑安排 |
| **避免毒点** | 人设不讨喜、故事逻辑不流畅 |

### 4.4 故事形式和技巧方面

- 故事是否有足够的**期待感**
- 故事节奏**详略得当，不拖沓**
- 故事情节**清晰简洁**
- 爽点和高潮的处理**一定要精彩**

> **一个符合市场需求的原创故事，远胜于同质化的故事。故事本身决定了作品是否可以签约，而形式技巧方面则提升了签约概率。番茄平台鼓励大家多多创新！**
