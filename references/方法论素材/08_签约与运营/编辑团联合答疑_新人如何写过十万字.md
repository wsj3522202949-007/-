## 一、核心诊断：为什么写不到十万字？

| 根因 | 典型表现 | 编辑共识 |
|------|----------|----------|
| **动力缺失** | 无读者反馈、无数据正向激励、孤独感强 | **找 1-2 个“专属读者”**（朋友/互阅作者）即刻建立反馈闭环 |
| **技力不足** | 越写越差、情节推不进、人设崩、逻辑断 | **先看长文学架构、再补技巧、再动笔**；十万字剧情极少，写不下去说明基础未备 |
| **心态失衡** | 迷信“一书成神”、预期过高、急功近利、抗挫力弱 | **降预期、设阶段奖励、接受“首书扑街是常态”**；大神首秀多为小号/多平台积累 |

> **七星（男频资深编辑）金句**  
> “轻易不要断更，断更一日惰性生，惰性发酵文必短。”

> **古帆（男频资深编辑）金句**  
> “没激情的写作只是砖瓦堆砌字数，不如不写。”

## 二、七大实战破局法（任选组合）

| 编辑 | 核心方法论 | 适用场景 | 关键动作清单 |
|------|------------|----------|--------------|
| **七星**（男频） | **外部反馈驱动+阶段奖励** | 孤独/无动力型 | 1️⃣ 章节即发给友/互阅群 2️⃣ 设“日更4k=美食/皮肤”奖励 3️⃣ 严禁断更 |
| **古帆**（男频） | **心态重塑+技力补课** | 技术卡文/心态崩型 | 1️⃣ 问自己：愉悦自己or求共鸣？ 2️⃣ 缺梗→刷剧/游戏/长文积素材 3️⃣ 不会写→拆解长文架构 4️⃣ 写不顺→查人设是否立稳 |
| **北竹**（女频主编） | **拆分合并法（长目标→短循环）** | 宏观失控/不知从何写起型 | 1️⃣ 定十万字终点：主角达何高度/剧情进何处 2️⃣ 拆 10×1 万字小剧情（各自铺垫/发展/高潮/影响） 3️⃣ 合并成长线 4️⃣ **细节卡文即删、先推剧情、后补细节** |
| **烟烟**（女频） | **极简前置自问+算法信仰** | 焦虑/数据恐慌/渣更倾向型 | 1️⃣ 自问：为何写？为收入目标付出足够耐心？ 2️⃣ 认清赛程：2万=入场券、10万=热身完进赛场、10万后=算法个人赛 3️⃣ **心态六不：不骄/不躁/不急/不恼/不悲/不馁** 4️⃣ 闷头稳更、其余交给算法与时间 5️⃣ 10万前无读者≠无质量、勿渣更/弃坑 |
| **堆堆**（女频） | **世界观框架“双避”+核心脑洞优先** | 宏大空泛/梗太小写不长型 | **避坑①** 世界观太大→无血肉填地基 **避坑②** 世界观太小/单一梗→几万字写完无发散<br>**正解**：核心脑洞立住→设人设/小传→填主线→再补境界/门派/势力等“可套用设定”<br>**梗测试三问**：能绕梗造 3+ 完整大情节？层层递进/有反转？前后连成画风一致/逻辑清晰主线？ |
| **咕咕**（男频） | **三件套：大纲/细纲+人物小传+体系设定** | 无章法/写着写着断片型 | 1️⃣ 大纲/细纲=稳定框架 2️⃣ 人物小传=梳理构思+行动推剧情 3️⃣ 体系设定（境界/法宝/功法/势力/派别）=支撑长度的骨架，玄幻至少10+境界 |
| **仙人球**（男频） | 同咕咕，强调**体系设定决定上限** | 长篇/高幻/系统流 | 境界少→写不长；法宝/功法/势力/派别体系越完备，阅读期待越久 |

## 三、综合执行清单（新人版）

### Phase 0：开书前（1 天）
- [ ] 定核心脑洞（能否支撑 3+ 大情节、有反转、能连成主线）
- [ ] 写人物小传（主角+重要配角：性格/目标/反差/金手指/口头禅/标签）
- [ ] 列体系设定表（境界/货币/法宝/功法/势力/地理/官职——按题材取舍）
- [ ] 拟 10 万字终点目标 & 拆 10 个 1 万字小剧情块

### Phase 1：起步期（0–2 万字）
- [ ] 找 1–2 个“专属读者”建立即时反馈
- [ ] 设“日更 4k=奖励”微习惯
- [ ] **顺叙+少量插叙**写开头；切忌：人物>4、描写>100 字连续、世界观倾倒、视角跳跃、打哑谜、触雷点
- [ ] 卡细节即删、先推主线

### Phase 2：冲刺期（2–10 万字）
- [ ] 按小剧情块逐个攻克（铺垫→发展→高潮→影响）
- [ ] 保持“心态六不”，遇卡文→看爱书/影/听歌 30 分钟再战
- [ ] 每 1 万字复盘一次：主线是否偏移？人设是否 OOC？伏笔是否埋好？

### Phase 3：算法期（10 万字后）
- [ ] 稳更、质量稳定、其余交给算法
- [ ] 持续收集读者长评/弹幕/追读数据，微调节奏/爽点密度

## 四、避坑速查卡（贴显示器）

```
【三大死因】无反馈 → 找专属读者
          技力弱 → 先拆长文再写
          心态崩 → 降预期+设奖励+禁断更

【七大法】七星：友读+奖励+禁断更
          古帆：问初心+积素材+拆架构+查人设
          北竹：拆10块+合长线+细节卡即删
          烟烟：自问初心+认清赛程+六不心态+信算法
          堆堆：核心脑洞优先+人设小传+主线→再补设定+梗三问
          咕咕/仙人球：大纲+小传+体系设定（境界≥10）

【开头六忌】人物>4 描写连续>100字 世界观倾倒 视角跳跃 打哑谜 触雷点
【卡文急救】删细节→推主线→看长评→改微调→继续写
```

## 五、编辑团心声精选（评论区高赞）

> “14 岁作者天天累死，问有无出路” → **出路在坚持与复盘，不在年龄**  
> “8 万字试推 216 读者/16 书架/8 追更，心态崩” → **10 万前数据无参考值，信算法**  
> “字能写到没人看，想写 BE 文” → **共情是剧情给的，不是文风给的**  
> “990 字真没人评论” → **新书期单机是常态，找互阅组/发书友群**  
> “坚持坚持再坚持，发现一百万了” → **抱团取暖，互相催更，熬过单机期**  
> “六千字五人在看，嘻嘻开心” → **每一个读者都是里程碑，珍惜**
