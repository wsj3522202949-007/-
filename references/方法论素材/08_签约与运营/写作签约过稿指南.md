# 写作签约过稿指南

> 整理来源：《签约真的不难，但你得找到方法》
> 适用对象：纵横 / 七猫 男频投稿
> 核心目标：一万字内投过稿
> 核心理念：开篇定生死，矛盾是引擎

---

## 一、开篇铁律：前100字聚焦主角

**必须在100字以内让主角登场。**

读者第一时间要知道故事围绕谁展开。聚光灯先照亮主角，再展开世界。

| 错误 | 正确 |
|------|------|
| 先写世界观、背景、历史 | 先写主角在做什么、面临什么 |
| "这是一个灵气复苏的时代……" | "宁宸睁开眼，发现自己被捆在柴房里。" |

---

## 二、世界观融入法：别一上来铺陈

### 核心原则
投稿的一万字里，**不要急于铺陈庞大世界观**。大段背景介绍会让读者枯燥、编辑直接拒稿。

### 正确做法
**通过主角的视角，一点点带读者进入世界。**

| 方式 | 示例 |
|------|------|
| 主角看到了什么奇特的建筑 | "那塔高得离谱，塔尖插进云里，像根刺穿天空的针。" |
| 主角遇到了什么怪异的人 | "那人走路没声，影子却是两个人的。" |
| 主角的所见所闻所思所感 | "宁宸摸了摸腰间的玉佩——这是宁家嫡子才有的东西，而他，只是个庶子。" |

> 世界观要从"主角眼睛里长出来"，而不是作者直接倒给读者。

---

## 三、矛盾节奏：2000字内引爆

### 开头两千字：必须引出核心矛盾

矛盾是故事的引擎。没有矛盾就没有冲突，读者就没有阅读动力。

**矛盾类型：**

| 类型 | 示例 |
|------|------|
| 主角 vs 他人 | 被欺负、被误解、被陷害、被追杀 |
| 主角 vs 环境 | 身负重伤、被迫逃亡、陷入绝境 |
| 主角 vs 自身 | 身中奇毒、记忆丧失、能力被封 |

### 后面八千字：围绕主线解决矛盾

开头的矛盾就是主线的起点。接下来必须沿着"如何解决这个矛盾"推进。

| 解决方式 | 示例 |
|---------|------|
| 智慧化解 | 主角设局反制对手 |
| 武力突破 | 主角获得能力/突破境界后反杀 |
| 外力相助 | 关键人物介入解围（但要留悬念） |

> **底线：不能跑偏。** 支线可以存在，但不能喧宾夺主。

---

## 四、爽点营造：欲扬先抑

### 核心公式

```
被欺负（抑）→ 读者代入情绪 → 出人意料反击（扬）→ 爽感拉满
```

### 关键：爽不能无脑

**必须让读者明白：**
1. 主角为什么被欺负？
2. 对方的动机是什么？
3. 主角反击的合理性在哪？

> 例：《逍遥四公子》宁宸被哥哥欺负——读者知道他是庶子、被继母打压、父亲不管——所以当宁宸反击时，读者才会觉得大快人心。

### 支线必须服务主线

诗词、才华展示、装逼打脸等元素**只是锦上添花**，不能写太多。

| 正确 | 错误 |
|------|------|
| 诗词震惊众人后，立刻回到"如何逃出去"的主线 | 连写三章诗词比赛，主线停滞 |
| "蓝星"名动王朝后，引出新的矛盾（继母压榨） | 纯为装逼而装逼，无后续推进 |

---

## 五、反派塑造：要有脑子

**失败的反派：** 无脑、纯坏、脸谱化。

**成功的反派：**
- 有心机和手段
- 有合理的动机（利益、权力、仇恨）
- 让读者觉得"这人是真难缠"而不是"这人是个傻子"

> 例：《逍遥四公子》的继母——不是无脑欺压，而是有手段地压榨、布局，这样的冲突才有看点。

---

## 六、男频毒点清单（必须规避）

| 毒点 | 说明 | 处理方式 |
|------|------|---------|
| **优柔寡断** | 主角不杀伐、没主见 | 必须坚持主见，由内而外的强势 |
| **舔狗** | 无原则地讨好女性角色 | 这个时代不能写纯舔狗。如必须"舔"，要有明确目的（获取好处），且要写出"暗爽"感，而非卑微感 |

> 男频核心气质：**嚣张、果断、有主见。**

---

## 七、投稿准备

### 投稿格式
- 一万字正文 + 大纲
- 内投编辑QQ（作家助手可查询）

### 扫榜学习法

**不是抄袭，是借鉴结构和方法。**

| 研究维度 | 看什么 |
|---------|--------|
| 开篇 | 怎么抓人？主角怎么登场？矛盾怎么引？ |
| 结构 | 情节怎么推进？爽点怎么分布？ |
| 人设 | 主角怎么立住的？反派怎么写的？ |
| 爽点 | 抑扬节奏怎么把控？装逼怎么装得不尴尬？ |

**操作：** 精读目标平台5-10本同类型热书前50章，拆解后融会贯通，加自己的创意。

## 八、一万字投稿结构自查表

| 字数节点 | 必须完成的事项 | 自检 |
|---------|---------------|------|
| 0-100字 | 主角登场，聚光灯照亮 | [ ] |
| 100-500字 | 主角身份/处境快速交代 | [ ] |
| 500-2000字 | 核心矛盾引爆，读者知道主角面临什么难题 | [ ] |
| 2000-5000字 | 矛盾升级，主线方向明确 | [ ] |
| 5000-8000字 | 主角开始行动（智慧/武力/外力） | [ ] |
| 8000-10000字 | 矛盾初步缓解或转向新冲突，留下钩子 | [ ] |
| 全篇 | 世界观通过主角视角自然融入，无大段铺陈 | [ ] |
| 全篇 | 支线服务主线，无喧宾夺主 | [ ] |
| 全篇 | 反派有脑子、有动机、有手段 | [ ] |
| 全篇 | 主角不优柔寡断、不当舔狗 | [ ] |
| 全篇 | 爽点有铺垫（欲扬先抑），反击大快人心 | [ ] |

---

> 签约的关键：把握好开篇节奏，塑造鲜明的矛盾和主线，合理营造爽点，不断学习和借鉴优秀作品。
