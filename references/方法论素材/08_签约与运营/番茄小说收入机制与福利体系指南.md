# 番茄小说·收入机制与福利体系指南

> **来源**：番茄小说网·签约编辑——阿宏
> **原文链接**：https://fanqienovel.com/writer/zone/article/7480089164512247832
> **适用对象**：所有品类作品
> **预计学习时长**：5分钟
> **核心定位**：收入机制、福利体系、签约流程、新人常见问题

---

## 一、收入机制

### 1.1 全勤奖

| 阶段 | 要求 | 最低月更新量 |
|------|------|-------------|
| **开书前3个月** | 每天更新 ≥ 4000字 | ≥ 12万字/月 |
| **开书3个月后** | 每天更新 ≥ 6000字 | ≥ 18万字/月 |

- 全勤奖金额根据不同时期和活动有所不同，具体以后台公告为准
- ⚠️ 全勤奖需要 **签约后** 才能获得

### 1.2 分成收入

| 收入类型 | 说明 |
|----------|------|
| **广告分成** | 读者阅读过程中产生的广告收入，按比例分给作者 |
| **付费阅读** | 读者付费解锁章节后，作者获得相应分成 |
| **打赏收入** | 读者对作品的打赏，作者直接获得 |

### 1.3 其他收入

| 收入类型 | 说明 |
|----------|------|
| **活动奖金** | 平台不定期举办各种创作活动，参与即可获得奖金 |
| **版权收入** | 作品被改编为影视、动漫、有声书等，作者获得版权分成 |
| **推荐位奖励** | 作品获得推荐位后，阅读量增加带来的收入提升 |

### 1.4 收入提现

| 项目 | 说明 |
|------|------|
| **提现门槛** | 账户余额 ≥ 50元即可提现 |
| **提现方式** | 银行卡转账 |
| **提现时间** | 每月15日统一处理上月提现申请 |

## 二、福利体系

### 2.1 签约福利

| 福利类型 | 内容 | 条件 |
|----------|------|------|
| **签约奖金** | 签约时一次性发放的奖金 | 成功签约即可 |
| **全勤奖** | 每月按时完成更新任务即可获得 | 每月达到字数要求 |
| **完本奖** | 作品完结后一次性发放的奖励 | 作品正常完结 |
| **推荐位** | 作品获得平台推荐位 | 达到一定标准后由编辑分配 |

### 2.2 作者等级体系

| 等级 | 条件 | 权益 |
|------|------|------|
| **LV1** | 新注册作者 | 基础创作工具 |
| **LV2** | 发布第一部作品 | 基础工具 + 数据看板 |
| **LV3** | 签约成功 | 签约工具 + 编辑对接 |
| **LV4** | 作品阅读量达到一定标准 | 更多推荐机会 |
| **LV5** | 多部作品表现优异 | 专属编辑 + 更多福利和资源 |

### 2.3 活动与培训

- **创作营**：平台定期举办线上创作营，邀请资深作者和编辑分享经验
- **征文比赛**：不定期举办各类主题征文比赛，奖金丰厚
- **作者交流会**：定期组织线上/线下作者交流会

## 三、签约流程

### 3.1 投稿阶段

1. 在番茄小说网注册账号
2. 创建作品，上传开篇内容（建议 1-2万字）
3. 等待编辑审核
4. 编辑审核通过后，会主动联系作者

### 3.2 签约阶段

- 签约是独家签约，签约后不可同时在其他平台发布
- 签约后享受全勤奖、分成收入等各项福利
- 作品正常完结后可申请完本奖

## 四、新人作者常见问题

| 问题 | 解答 |
|------|------|
| **没有写作经验可以签约吗？** | 可以，只要作品质量达标即可 |
| **签约后可以断更吗？** | 不建议，断更会影响全勤奖和推荐 |
| **签约后可以同时发其他平台吗？** | 不可以，番茄签约是独家签约 |
| **完本奖怎么领取？** | 作品正常完结后，在后台申请即可 |
| **收入多久结算一次？** | 每月结算一次，次月15日提现 |

## 五、编辑寄语

> 新人作者最重要的是 **坚持**。不要因为一时的数据不好就放弃，坚持写完一部作品，你会发现自己成长了很多。欢迎加入番茄小说的大家庭！
