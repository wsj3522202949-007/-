# 主角设定与人物小传指南

> 整理来源：番茄小说网官方课程
> 适用对象：所有品类
> 核心定位：从主角入手，设计有血有肉、冲突自然的小说人物体系
> 核心理念：先定"人物在故事里要干什么"，再补"他为什么会这样"

---

## 一、人物小传的作用

人物小传 = 精简的角色资料清单

记录身世、性格、喜好、软肋等关键信息。

**作用：**
- 提前理清角色的言行逻辑
- 避免后期人设崩塌、剧情跑偏
- 方便高效推进故事

> 人物小传不一定出现在正文里，但它是写作的底层支撑。

---

## 二、撰写核心思路

```
先定 "人物在故事里要干什么"
  ↓
再补 "他为什么会这样"
```

---

## 三、撰写步骤

### 步骤一：明确角色在故事中的职责

设计角色时，首先要想清楚这个人在故事里**"是干什么用的"**。

| 职责类型 | 示例 |
|---------|------|
| 推动主线发展 | 主角为复仇而变强，驱动整个故事 |
| 制造矛盾冲突 | 反派为争夺资源与主角对抗 |
| 辅助主角成长 | 导师型角色提供关键指引 |
| 衬托主角特质 | 配角优柔寡断，反衬主角果断 |

> 职责想清楚了，人物就不容易写偏。

### 步骤二：用一句话概括人物

给角色贴一个**"标签"**，后面所有设定围绕它展开。

**示例：**
> "外表冷淡、内心极度渴望被认可的天才少女"

> "表面嚣张跋扈，实则极度自卑的落魄贵族"

> "玩世不恭，但重情重义的江湖浪子"

### 步骤三：补充关键经历

**原则：** 不要什么都写，只挑能**解释性格和行为**的关键事件。

| 关键经历 | 对性格的影响 |
|---------|------------|
| 小时候被忽视 | 特别在意他人评价 |
| 家族被灭门 | 性格变得冷酷多疑，不轻易信任他人 |
| 曾被挚友背叛 | 对亲密关系有防御心理 |
| 童年贫困挨饿 | 对金钱极度敏感，有囤积癖 |

### 步骤四：明确欲望与弱点

| 维度 | 作用 | 示例 |
|------|------|------|
| **欲望** | 他/她想要什么 → 人物才会行动 | 想要被认可、想要复仇、想要守护家人 |
| **弱点** | 他/她因为什么会犯错 → 人物才会真实 | 缺爱所以容易被甜言蜜语欺骗、自负所以轻敌、心软所以放过敌人 |

> 欲望驱动行动，弱点制造真实感。

### 步骤五：设计人物变化/成长

**核心公式：**
```
一个人开始是什么样 → 经历了什么 → 最后变成了什么样
```

**五步设计法：**

| 步骤 | 内容 | 关键问题 |
|------|------|---------|
| ① 定起点 | 人物最初的状态 | 他一开始是什么样的人？ |
| ② 找内在问题 | 导致起点状态的根本原因 | 他为什么会变成这样？ |
| ③ 设置改变事件 | 逼他必须改变的外部触发 | 什么事件让他不得不变？ |
| ④ 给变化节点 | 从行为→能力→内心的渐进转变 | 他在哪些关键节点发生了哪些变化？ |
| ⑤ 用行动证明 | 最终状态与起点的鲜明对比 | 他现在和最初相比，哪里不一样了？ |

## 四、完整示例

**人物：** 苏青，将军府大小姐，恋爱脑

### 第一步：定起点

女主上辈子是个超级恋爱脑。

为了扶持假装深情的渣男二皇子，她偷亲爹（大将军）的布防图，最后被渣男一碗毒药送走，临死还被告知"你不过是颗垫脚石"。

### 第二步：找内在问题

女主恋爱脑的根源：**从小母亲早逝，父亲常年打仗，她极度缺爱。**

渣男稍微递杯热水、说句甜言蜜语，她就觉得是全世界。

### 第三步：设置改变事件

重生睁眼，正好回到她要偷布防图的那天。她想起前世的悲惨遭遇，彻底清醒了：**如果不改，全家还得死。**

### 第四步：给变化节点

| 节点 | 内容 | 变化层面 |
|------|------|---------|
| 节点一 | 渣男又来送定情木簪，以前当宝贝，这次当场掰折扔进水里，冷笑："就这？" | **行为上的初次反抗** |
| 节点二 | 利用重生的预知帮亲爹避开朝堂陷阱，保护了家人 | **能力上开始成长** |
| 节点三 | 发现不靠男人垂青，自己搞事业也能光芒万丈 | **内心病根开始愈合** |

### 第五步：用行动证明变化

| 维度 | 前世 | 重生后 |
|------|------|--------|
| 对渣男 | 为了他害得全家惨死 | 摆脱渣男，清醒独立 |
| 对自己 | 恋爱脑，缺爱自卑 | 成为清醒独立的大女主 |
| 对家人 | 背叛偷布防图 | 帮父亲避陷阱，保护全家 |

> **读者一看就明白：她真的变了。**

## 五、主角设定自查清单

### 基础层
- [ ] 角色在故事中的职责是什么？（推动主线/制造冲突/辅助成长/衬托主角）
- [ ] 用一句话概括这个人物（标签）

### 动机层
- [ ] 他的欲望是什么？（想要什么）
- [ ] 他的弱点是什么？（会因为什么犯错）
- [ ] 他的关键经历有哪些？（解释性格和行为的根因）

### 成长层
- [ ] 起点：他最初是什么样？
- [ ] 内在问题：为什么会这样？
- [ ] 改变事件：什么逼他必须改变？
- [ ] 变化节点：从行为→能力→内心的渐进转变有哪些？
- [ ] 终点：他现在和最初相比，哪里不一样了？

### 一致性层
- [ ] 他的行为是否符合标签和经历？
- [ ] 他的欲望是否贯穿始终？
- [ ] 他的弱点是否在关键时刻制造了真实冲突？
- [ ] 他的成长是否有清晰的证据（行动证明）？
