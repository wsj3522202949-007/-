# 零基础写作入门指南

> 整理来源：京祺（番茄金番作者，10年经验，代表作《野玫瑰》《我于深渊时见你》）
> 适用对象：所有品类
> 核心定位：新手0-1入门网文写作的五大模块
> 核心理念：热点会过时，但好的内容永远不会过时

---

## 一、新手入门：如何写出好故事

### 1.1 选择故事题材

先设定一个大致题材，再构造故事场景，由场景展开内容。

**示例：** 重生题材 → 主角被恶毒女配烧死 → 重生回到过去 → 故事继续。

### 1.2 寻找故事灵感

**灵感来源：**
- 抖音社会热点新闻，提取故事基调或案例原型
- 抓取案例中的大人物或小人物，无限扩大构思

**关键认知：**
> 不一定从大事件展开，完全可以通过**小人物或小事件牵扯出大事件和大背景**，四两拨千斤，让读者越看越上头。

### 1.3 主角的身份与特点

主角身份要让读者第一时间觉得"值得关注、值得追随"。

**反向思考（天崩开局）：**
| 常规思路 | 反向思路 |
|---------|---------|
| 超能力、透视眼 | 几个亿的负债 |
| 完美身世 | 只剩三个月寿命 |
| 无敌金手指 | 被灭门的凄惨身世 |

> 读者最爱看的是**小垃圾小屌丝的逆风翻盘**，天崩开局对新手更友好。

### 1.4 确定主角目标

**案例（只剩三个月寿命）：**

| 阶段 | 目标变化 |
|------|---------|
| 初始 | 痛快花钱，不留遗憾 |
| 发展 | 胡作非为，梭哈变3000万 |
| 转折 | 钱花不完，不想死了 |
| 后续 | 目标活过来，剧情展开 |

> **目标不是死的，是活的。** 随着剧情戏剧化发展，主角改变目标，故事才有吸引力。

### 1.5 冲突与对抗

**核心认知：** 题材和噱头是一方面，最能吸引读者的是**主角的社会身份、主角和配角之间的关系冲突与对抗**（人物之间的拉扯）。

**悬疑示例（局中局）：**
> 主角目睹凶杀案，本想报警，却发现被杀的是虐待他的继父。他选择见死不救，收了继父的钥匙，却被警察认定为嫌疑人。更离奇的是，杀人凶手故意叫来的警察——主角落入了圈套。

**要点：**
- 反转才精彩，不要单线思维
- 设定好人物关系、微妙关联、对抗、暗处关系网
- 让读者意犹未尽，猜了又猜

### 1.6 拥有独立的写作风格和标签

**关键建议：**
- **不要盲目追榜单、追热点**，热点会过时
- 练习独属于自己的写作风格，做**创造热点**的作者
- 经典作品读十遍的效果，远超读一百本流水网文

**天赋认知：**
> 一百本网文流水作品，可能只能总结出一条有用的经验；一部好的经典作品，可以从一个点延伸出无数个面。

**写作灵性：**
> 学不来的东西才是精华——你的灵性、过往阅历、对很多事的不同角度的不同看法，这才是你能超越别人的东西。

**第一本目标：**
> **坚持写完一本30万字的小说。** 30万字刚刚好能把故事写好写详细，锻炼对整个小说框架的建造能力和对故事的把控能力。

## 二、新手最需要锻炼的三种能力

### 2.1 脑中的画面感

**定义：** 把脑中演绎的剧情，用文字精准展现，让读者幻想出你打造的小说世界。

**练习方法：**
- 看经典影视作品，思考如何用文字还原画面
- 还原画面的同时，还原画面所要表达的**感情与氛围**（氛围感、代入感）

**五感运用：**
> 视觉、听觉、嗅觉、触觉，都是你可以表达和书写的内容。

### 2.2 灵感练习

**方法：** 每天想十个开头或十个小故事（一百字概括即可）。

**示例：**
- 女主长期经受家暴，结果不小心杀死了丈夫，后面何去何从？
- 女主魂穿成了小说里的恶毒女配，她要如何自救？

**操作：**
- 等待一周，手里就有几十个开头
- 挨个查看哪些精彩、哪些乏味
- 哪些能支撑十万字甚至三十万字
- 日复一日，总能找到最好的开头

### 2.3 对故事的建造能力

**三张纸排列组合法（创新情节）：**

| 纸张 | 内容 |
|------|------|
| 第一张 | 脑海里零散的情节（你认为有趣的） |
| 第二张 | 各类人设、性格、特点 |
| 第三张 | 故事背景、时代背景、必备场景 |

**操作：** 打散，做不同排列组合，让奇怪的人设出现在不同场景里，搭配不同情节，碰撞出新火花。

## 三、小说大纲怎么写

### 3.1 大纲的本质

> 大纲就是一条非常粗的树干，扎根在泥土地之上，树干之下盘根错节，树干之上枝繁叶茂。

**核心：** 故事是否站得住脚、是否精彩，看两点：
1. 树干是否粗壮
2. 树干开出的枝叶是否繁盛翠绿

### 3.2 大纲的内容

讲清楚故事的**起承转合**：
- 主角的困境
- 目标
- 阻碍
- 努力的过程
- 中途的意外
- 意外后的转折
- 最终的结局

**示例（《甄嬛传》）：**
> 女主一路升级打怪，最后连皇帝都被彻底拿下，从儿女情长到大家大国，一路披荆斩棘。

### 3.3 写大纲的核心原则

**名人名言：**
> "唯恐天下不乱，乃作家职责所系，责无旁贷。" ——雷蒙德·钱德勒
>
> "一旦人物摊上了事，摊上了大事，那么其摆脱困境的千方百计则可美其名曰'编排情节'。" ——巴纳比·康拉德
>
> "我从来不写那些没到穷途末路的人物。" ——斯坦利·埃尔金

**核心：**
- 写极度精彩、起伏波澜的故事
- 平庸的故事没人爱看
- 把老故事写出新意来
- 给主角一个**绝地求生的开篇**（屌丝逆袭）

## 四、核心心法总结

| 模块 | 核心要点 |
|------|---------|
| **题材选择** | 先定大致方向，再构造场景 |
| **灵感获取** | 小人物牵出大事件，四两拨千斤 |
| **主角设定** | 天崩开局比完美开局更吸睛 |
| **目标设计** | 目标是活的，随剧情变化 |
| **冲突对抗** | 人物关系拉扯 > 单一事件 |
| **风格培养** | 不追热点，练独属于自己的风格 |
| **三本定律** | 前三本练手，坚持写完30万字 |
| **三种能力** | 画面感、灵感、建造能力 |
| **大纲写法** | 起承转合，起起伏伏 |

---

> 写故事就是盖房子，根基稳，才能屹立不倒。
>
> 热点题材转瞬即逝，但抗打的题材和故事，能养活你三年、五年，甚至十年。
