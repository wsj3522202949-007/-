# 新手写作破局三步法

> 整理来源：丛月（番茄金番作家，九年写作经验，代表作《我在修仙界搞内卷》《首辅家的锦鲤妻》）
> 适用对象：所有品类
> 核心定位：写作第一步、题材选择、情节环环相扣
> 核心理念：好故事胜过好文笔，因果关系是小说最底层逻辑

---

## 一、写作最重要的是什么？

> **当然是写啊！** 别人都在观望，你已经动笔，你始终领先朋友一步。写了不一定赚钱，但不写一定不赚。

### 1.1 好故事胜过好文笔

**核心认知：** 小说本质上就是讲故事，**故事性要强，事件要跌宕起伏。**

**误区：** 新人容易陷入强调文笔的误区，用大量华丽辞藻堆描写。

**比喻：**
> 把一本小说比作盖房子，**故事性就是房子的框架，文笔就是外观。**
> 如果说房子只是一个茅草屋，你非要给它贴瓷片，房子能承受住吗？

**读者行为：** 看第一章看了半天还没进入正题，会很快弃文。

> 好的文笔无疑是锦上添花，但**小说的故事性才是一篇小说的基础。**

### 1.2 新人突破口：构思新鲜的故事

**每天发书的人没有一千也有八百，要从这么多书中杀出去——**
> **其实就是看谁的书故事性更强、更新鲜，也就是大家说的噱头。**

**新人优势：** 思维还没有被圈子里的条条框框限制，将自己天马行空的想法写出来或许更容易出成绩。

### 1.3 行动与坚持是成功的起点

> 写小说最重要的事情就是先写，先走进来。文笔、节奏、情节过渡等等，写得多看得多也就明白了。

## 二、如何选择合适的题材？

### 2.1 选对题材：兴趣和性格是关键

**核心原则：**
> **淡人写不了情绪文。** 比如本身性格怕跟人起冲突、不敢表达自己，这种性格来写情绪文根本驾驭不了。

**判断方法：**
> 看到后悔流、追妻火葬场，想不通"人都死了，后悔有什么用"——说明这种类型的文不适合自己，没必要一味迎合。掌握不到爽点，写出来的东西节奏和读者不同频，很容易扑街。

### 2.2 从读到写：你的阅读史就是最佳指南

> **时间花在哪里，收获就在哪里。** 以自己的兴趣为中心，再向外拓展。

**优势：**
- 喜欢看的类型，大量阅读就是创作的根基
- 能更好把握爽点和读者的情绪点
- 写起来更加顺手（日常对话、动作场面、心理描写）
- 保证基本产出效率

### 2.3 纠结题材：试写开篇来定夺

**方法：** 喜欢看的类型很多，不知道开哪个——先在脑子里想象每个题材的核心画面，哪个更震撼、更让你热血沸腾、迫不及待，就先开哪个。

**如果想象不来：**
> 每个类型写一千字，感受一下自己写的时候是否是文思如泉涌。如果连高光情节都写起来很难受，那这个类型你可能不太能驾驭，就先放一放。

## 三、情节如何环环相扣吸引读者？

### 3.1 小说的底层逻辑：构建因果关系

**核心：** 底层逻辑就是因果关系。

**对比：**

| "然后"关系（流水账） | "因果"关系（好故事） |
|---------------------|---------------------|
| 我打开门取了快递，然后又下楼扔垃圾 | 我打开门取快递，看到有人拿刀站在隔壁门口 → 慌忙关上门 → 门口响起敲门声 |
| 两个事件之间没有联系 | 每个情节都是前因导致的必然结果 |

**操作：**
> 写一个故事情节的时候，多问问自己为什么——我为什么要这么写？这个故事写出来对文章情节有什么推进作用？它会引起一个怎样的悬念，或者可以填掉什么时候挖的坑？

> **因果关系是一篇小说最底层的逻辑链，小说也是由无数逻辑链组成的。**

### 3.2 用人物欲望推进情节

**核心：** 在因果关系的基础上，用人物欲望来驱动情节。

**公式：**
> 每个场景中，人物行动都应有 **"我想要怎样，所以必须怎样"** 的内在逻辑。

| 欲望 | 行动 |
|------|------|
| 为全家复仇 | 在仇人家忍辱负重 |
| 因为爱情 | 火灾时冲进家里救妻子 |

### 3.3 埋设伏笔与回收

**操作：** 在整体逻辑链的基础上，加上小巧思（伏笔）。

**示例：**
> 主角前期救过一个小孩，后期遇上麻烦时，这个小孩带着家族大佬强势来救。

### 3.4 所有逻辑链服务主线

**常见误区：** 结构太过涣散，被某一个逻辑链拉偏，脱离主线。

**示例：**
> 女主重生复仇是主线 → 习武是为了复仇 → 却跑去做生意几十章 → 破案几十章 → 读者连女主一开始要干什么都忘了。

**解决：**
> **所有的逻辑链最终都要汇聚在一起。** 去破案，那每一个案子都要发现一点跟复仇相关的因素，最终案子聚焦在仇人身上。

> **情节环环相扣就好像一个钩子勾着读者，让读者好奇接下来到底会发生什么。**

## 四、核心心法总结

| 模块 | 核心要点 |
|------|---------|
| **写作第一步** | 写，先写出来，永远不可能完全准备好 |
| **故事vs文笔** | 故事性是框架，文笔是外观，好故事 > 好文笔 |
| **题材选择** | 淡人写不了情绪文，兴趣和性格是关键 |
| **阅读史** | 喜欢什么写什么，大量阅读就是创作根基 |
| **底层逻辑** | 因果关系，每个情节都是前因导致的必然结果 |
| **人物驱动** | 用人物欲望推进情节，"我想要→所以必须" |
| **伏笔回收** | 伏笔必须回收，所有逻辑链服务主线 |

---

> 好故事胜过好文笔，因果关系是小说最底层的逻辑链。
>
> 写了不一定赚钱，但不写一定不赚。
