# 《十日终焉》创作揭秘与写作心法

> 整理来源：杀虫队队员（番茄金番作家，代表作《十日终焉》《传说管理局》）
> 适用对象：所有品类
> 核心定位：《十日终焉》创作历程回顾、数据观、读者反馈驱动、选题策略、高压写作法
> 核心理念：写书可以输给没人看、输给剧情差、输给所有人骂，但不能输给自己没能坚持下去

---

## 一、创作历程回顾

### 1.1 两部作品数据

| 作品 | 时间 | 字数 | 状态 |
|------|------|------|------|
| 《传说管理局》 | 2021.12-2022.08（260天） | 139.2万字 | 已完结 |
| 《十日终焉》 | 2022.12-2024.10（698天） | 293.4万字 | 已完结 |

**关键事实：**
- 两次开书都是在某一个夜里打开番茄后台忽然上传的
- 《十日终焉》到一百万字、一百多万人在读的时候，才第一次有了编辑的联系方式
- 三十多岁才入行，之前创过业、上过班、摆过地摊、出过苦力
- 入行前一共只看过大约五六部网文（诛仙、斗破苍穹这种火出圈的）

> **我的起跑线和你们一样，甚至还不如你们。因为在落笔的时候，我连网文的读者都不算。**

### 1.2 关于存稿

> **一般情况下没有存稿。**

原因：
- 在没有读者反馈的情况下，盲目前进容易"抓瞎"
- 会陷入**"作者的自我满足"**：在自己的逻辑大圆满里自己感动自己，但跳出环境让局外人看，会有很明显的漏洞
- 一旦没发现漏洞并在上面继续建造高楼，后续要处理的问题会更多，修改愈发困难

**例外：** 一开始有部分存稿（二三十章），后来发现没有读者反馈的情况下，存稿反而会阻碍调整。

## 二、核心心法

### 2.1 数据到底是不是一切？

> **与其像盯着股市一样盯着后台数据，不如把所有时间都放在打磨自己的故事上。**

**为什么数据不重要？**
- 第一部书写了八九个月，前半年没有任何收益
- 前六个月的收益放在任何作者群里，都不会有人劝继续写下去，一定会推荐切书
- 很庆幸当时不认识任何作者，能一个人单机坚持下来

**核心心态：**
> **写书这件事，可以输给没有人看，可以输给剧情很差，也可以输给所有人都在骂，但不能输给自己没能坚持下去。**

> 否则很多年后总是会留下一个念头："当时我坚持下去是不是就成了？"

### 2.2 你写书的目的是什么？

**三种目标：**

| 目标 | 建议 |
|------|------|
| **实现梦想/写着玩** | 记住一定要坚持下去，给自己一个交代 |
| **赚钱** | 接下来的内容需要留意 |
| **既要又要** | 不建议，两手抓容易都抓不住 |

### 2.3 读者反馈是最重要的

> **我认为是"读者反馈"。** 当然，建立在书已有少量读者评论的情况下。

**没有评论时：**
> 反复阅读自己前面的内容，并且多次修改。我从来不认为好作品能够一次成型。

**我的番茄账号阅读时间790个小时——其中至少780个小时是在一遍一遍重读自己的书。**
> 我不是资深网文读者，我是资深游戏迷。790个小时不是在看别人的书，而是在改自己的书。

**每一部作品都经过海量修改，直到按下"完结"键才停止修改。**

### 2.4 读者的评论就是教程

**操作：**
- 《传说管理局》到完结之前，**每一条评论都看了，大约十万条左右**
- 《十日终焉》每天发表完章节后的半小时、两小时和一天之后，回去查看最新两章的所有段评
- 从段评获取：读者对某个角色的好恶程度、对剧情的期待感有多高、有没有什么待解决的疑问

**核心认知：**
> 我不是读者，不能提前知晓读者的反应。读者比我看的书多，他们的每一条评论对我来说都算作教程。

**有效评论 vs 无效评论：**
- 如果同一条问题被多人提出 → 修改有问题的章节，或在以后剧情中尽量避免
- 抽象人的评论 → 自己分辨

**面对错误的处理：**
> 曾经写错了一个设定，正方辩友说这是伏笔，反方辩友说不符合前面设定。我在抖音看到争吵后，留言说"抱歉，其实是我写错了"。
> 正反双方的辩友只是让我别刷抖音了，赶紧去改。

> **有人愿意在你的作品里留言或提建议，是因为他们希望这部作品变好，而不是带着百分百的敌意来攻击你。**

### 2.5 关于"没火是因为不给量"

> 有人在有这个念头的时候可以想想我：单机了一百万字，稿费才终于突破九块钱。

> **想要在这个市场上站稳脚跟，肯定得付出一些别人付出不了、或者不愿意付出的东西。**

## 三、高压写作法（零存稿模式）

### 3.1 核心方法：切断所有退路

> 我一旦这么写了（主角信誓旦旦说我知道怎么破解了），我就会想到了。

**具象化比喻：**
> 抽了很多年烟的长辈忽然戒烟了，大夫说："你现在的身体状态自己选吧——这是烟，这是命，你要哪个。"

**写作方法具象化：**
> 这面是你想到谜题的解法，这面是你全面崩塌——包括口碑、荣誉、金钱，可能饭也吃不上了。你怎么选？
>
> **我没得选，我只能去这样做。**

### 3.2 高压下的状态

> 几乎就是一种要么写，要么噶的状态。

在这种巨大高压之下，大脑会一整天飞速旋转，甚至有的时候怕得都会发抖。

**核心逻辑：**
> 想要杀进网文市场，写作经验不如前辈、写作水平不如前辈、码字速度也不如前辈——如果再不能坚持、不能吃苦、不能让自己承受巨大压力的话，我们凭什么能站在这个市场上？

> **如果写作像喝水一样简单，我有个大纲，每天只需要抽时间填一点字上去，指望这种付出能换来可观的回报——我认为不合理。**

## 四、选题策略

### 4.1 为什么选择悬疑（《十日终焉》）

**不是因为悬疑水平很好，也不是因为更热爱——而是因为同类网文相对较少。**

**推理过程：**

| 赛道 | 现状 | 新人能否进入 |
|------|------|------------|
| 玄幻修仙 | 耕耘十年，有完整规则和约定俗成的体系 | 读者会自动对比已知世界观，新人想象力受限 |
| 都市高武 | 同上 | 同上 |
| 规则怪谈（悬疑） | 开书时清一色规则怪谈 | 不算正统悬疑，不算竞品 |
| **正统悬疑** | **同类作品较少** | **可以找到自己的赛道** |

### 4.2 学会"藏拙"

> 我的《传说管理局》题材涵盖非常多，并不是因为我擅长的东西多，而是**我不擅长的东西多**，所以要尽可能地尝试所有题材。

**发现自己的强项：**
> 《传说管理局》写到后来发现自己更擅长的是**大结局的反转和大局的统筹**，前面的亲情、友情、爱情不是强项。

**最终选择：**
> 只能选择分类相对小众、同类作品较少的赛道。

### 4.3 不要追当下热点

> **尽量不要以当下正在流行的元素为主题进行创作。**
> 尤其是当下火热的网络热点，搜一搜就能发现有很多类似的作品。

## 五、读者反馈驱动改稿模型

### 5.1 核心流程

```
写一章 → 发布 → 半小时/两小时/一天后查看段评 → 获取反馈 → 调整后续剧情
```

### 5.2 反馈驱动调整类型

| 反馈类型 | 调整方式 |
|---------|---------|
| 读者对某个角色的好恶 | 增减该角色戏份 |
| 读者对剧情的期待感 | 加快或放缓节奏 |
| 读者的疑问 | 在后续剧情中解答 |
| 多人提出的问题 | 修改有问题的章节 |
| 毒点/尬点 | 能改则改 |

### 5.3 大方向不变，小方向灵活

> 我会跟着读者的反馈做适时调整，但前提是**大方向不变**。比如把某个人的戏份增多，把某段小剧情反转。

## 六、核心心法总结

| 模块 | 核心要点 |
|------|---------|
| **写作第一步** | 先动笔写出来，再考虑其他 |
| **灵感来源** | 翻读者评论，尤其是长评 |
| **数据观** | 数据不是一切，关注故事打磨而非后台数字 |
| **核心** | 读者反馈是最重要的，十万条评论都是教程 |
| **存稿** | 一般没有，避免自我满足和盲目前进 |
| **高压法** | 切断所有退路，要么写出来要么全面崩塌 |
| **选题** | 选择竞争小的赛道，学会藏拙 |
| **改稿** | 每章发布后查看段评，大方向不变小方向调整 |
| **坚持** | 可以输给一切，但不能输给自己没能坚持 |

---

> 我把自己比作生产商，读者是消费者。
>
> 餐馆想要生意好，菜品不应该只符合老板的口味，而应该符合客人的口味。
>
> **读者就是市场。**
