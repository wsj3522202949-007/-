# 模板库 · 三套可套用落地表单

> 用法：复制对应小节到 `你的书名/` 目录，按提示填空。填完用 `../tools/scripts/writing/chapter_selfcheck.py 你的正文目录` 跑一遍自检（字数 2600–3400 / AI味 / 章末钩子）。

---

## 一、男频·重生逆袭（对齐《重生千禧：从高中毕业开始造芯片》）

**一句话卖点**：给爽文读者的"信息差碾压爽"，靠"重生+金手指"，在"技术封锁/商战/家庭"中兑现。
**平台首选**：番茄（前300字出事）/ 起点（概念感书名）。详见 platforms/番茄.md、genres/重生.md。

### 1.1 框架填空

```markdown
# 《书名》全书框架（男频·科技重生爽文）
> 平台目标：____（番茄保底 / 起点签约 / 征文）
> 体量：约 ____ 万字，____ 卷｜更新 ____ 字/天

## 一、一句话立意
重生回 ____，用 ____（金手指）在 ____（赛道）逆袭。

## 二、核心爽点公式
主角____ + 金手指____ + 反派____ = 读者爽____

## 三、金手指（前三章必须上线）
____（重生记忆 / 系统 / 未来信息）→ 首次用在具体事件：____

## 四、分卷（每卷一个爽点承诺闭环）
卷1 ____：承诺____/兑现(章__) / 新状态____
卷2 ____：承诺____/兑现(章__) / 新状态____
卷3 ____：承诺____/兑现(章__) / 新状态____

## 五、反派/系统阻力
明线反派____ / 暗线势力____ / 系统支线____

## 六、重生文避坑（自查）
□ 开篇即时危机（非发呆回忆）
□ 金手指前三章用在具体事件
□ 危机落到具体代价（丢单/断资/被请喝茶）
□ 无"重生后发呆"慢热
```

### 1.2 人物卡填空

```markdown
主角：____（标签：落魄____×信息差金手指）
  Want（错的药）：证明前世憋屈  / Need（解药）：学会信任伙伴  / 最怕：重蹈孤独
金手指锚点：____（如"2004.4.17 真实节点"）｜每次使用须"被兑现"
头号反派：____（同行/掮客/看不起主角的长辈）｜最得意时刻：____
关键配角：____（带主角突围的伙伴，如王虎/周叔）｜反应分层：巴结/观望/嫉妒/恐惧
```

### 1.3 章纲填空（每章一张，对齐章法与钩子学·章纲模板）

```markdown
【第__章】唯一核心任务：____
章首承接：接上章____后果，用____式开头（动作/对话/疑问/张力/神秘/后果/时间）
爽点循环：铺垫(信息差/嘲讽__次)→反转(还有一手)→碾压(物理+精神+围观+收获)→余波(埋新危机)
伏笔：轻埋____，计划第____章回收（记进伏笔账本）
章尾钩子（五类选1）：____式 —— ____（禁用"下章预告"括号/主题升华）
```

### 1.4 钩子范式（章尾八成以上用这三类）

- **信息炸弹**：抛颠覆认知的产业真相/时间节点。例："上面要清掉一批低端产线，名单第一个就是你刚接手的厂。"
- **危机降临**：可量化危机。例："距首轮流片还有11天，良率还卡在3%。"
- **打脸预示**：反派最得意时主角暗蓄。例：对方酒桌笑"高中生懂什么晶圆"，镜头切主角兜里刚签的产线协议。
- **三章小上升（事业线）**：N章危机露头→N+1暗蓄→N+2小突破+更大对手浮出。

## 二、女频·青梅竹马少年夫妻（对齐《难得夫妻是少年》）

**一句话卖点**：给言情读者的"青梅回甘"，靠"少年夫妻×成年重逢反差"，在"误会×掉马"中兑现。
**平台首选**：晋江（人设/关系锚）/ 番茄女频 / 盐言（悬疑向）。详见 genres/甜宠.md、platforms/晋江.md。

### 2.1 框架填空

```markdown
# 《书名》全书框架（女频·都市言情·青梅竹马）
> 平台目标：____（晋江申签 / 番茄女频 / 盐言）
> 体量：约 ____ 万字，____ 卷

## 一、一句话立意
____（青梅）与____（竹马）从____到____，中间隔着____（误会/当年真相）。

## 二、核心爽点（情绪向）
"差点得到又差点失去"的关系拉扯 × ____（少年期物件/约定回收）

## 三、关系变量清单（每卷推进一个）
误会____ / 旧物____ / 掉马____ / 同居____ / 和解____

## 四、分卷（每卷一个关系变量闭环）
卷1 ____：立住____关系 → 卷末____突变
卷2 ____：____把人推开 → 小和解+更大考验
卷3 ____：掉马/真相 → 新状态____

## 五、女频避坑（自查）
□ 不开篇写"梧桐又黄了"环境慢热，直接写尴尬瞬间/当众翻脸
□ 关系钩子扎根两人具体事件，不写空泛"有了隔阂"
□ 甜章后必接酸章（慢张），不纯糖灌
```

### 2.2 人物卡填空

```markdown
女主：____（嘴硬心软青梅）｜Want：岁月静好 / Need：直面当年逃离的真相 / 最怕：被看穿脆弱
男主：____（看似淡漠竹马）｜反差：____（其实一直记着____）
关系锚点：____（少年期物件/约定，占全书1/3篇幅亮点）｜回收章：____
关键配角：____（制造误会/助攻）｜掉马节点：____
```

### 2.3 章纲填空

```markdown
【第__章】唯一核心任务（关系向）：____
章首承接：接上章____情绪后果，用____式开头
情绪曲线：起点(替主角憋屈/甜)→终点(期待/心痒)｜波动≥1次
爽点（关系）：差点得到____又差点失去____（非强行误会）
伏笔：轻埋少年期____（计划第____章回收）
章尾钩子（女频优选）：关系破裂式 / 认知反转式 / 决策时刻式 —— ____（停在不可逆动作上，不写结论）
```

### 2.4 钩子范式

- **关系破裂式**：停在关系不可逆变化。例："婚纱我退了。"她拉开门，没回头。门合上的声音比任何承诺都清楚。
- **认知反转式**：读者发现之前理解错了。例：她一直以为在调查别人，这刻才发现自己才是被盯上的那个。
- **决策时刻式**：重要选择已做后果未知。例：他抓起文件袋冲出门，师兄喊"你去做什么"，他没回头。
- **三章小上升（感情线）**：N章暧昧升温→N+1误会把人推开→N+2小和解+更大考验。

## 三、短篇·盐言风（强情节 / 悬疑 / 情感，1–3 万字）

**一句话卖点**：给短篇读者的"高密度反转"，靠"一个钩子撑全场"，在"悬疑/情感爆破"中兑现。
**平台首选**：盐言（悬疑35%·现实情感28% 完读率红线）。详见 platforms/盐言.md、genres/悬疑.md。

### 3.1 框架填空

```markdown
# 《短篇名》（盐言风·____类）
> 平台：盐言（投稿 / 分成）｜目标字数：____（建议 8k–30k）
> 完读率红线：悬疑≥35% / 现实情感≥28%（低于则限流）

## 一、核心钩子（一句话，开篇即抛）
____（谜团/反常细节/倒计时）

## 二、三幕极简
建置(0–20%)：____（抛钩+立人物）
对抗(20–80%)：____（反转×2+碾压式真相）
结局(80–100%)：____（余波/身份暴露）

## 三、反转设计（至少 2 个）
反转1：读者以为____ → 实际____
反转2：____ → ____

## 四、短篇避坑
□ 无注水过渡（短篇容错极低）
□ 章末（=段落末）必留钩子
□ 完读率优先于铺陈
```

### 3.2 人物卡填空（短篇从简）

```markdown
主角：____（困在____处境）｜秘密：____
对手/真相源：____（直到____才揭）
关键物件/细节：____（开篇反常，结尾回收）
```

### 3.3 章纲填空（短篇可合并为"段落纲"）

```markdown
【段__】任务：____｜钩子：____（信息炸弹/危机/倒计时/认知反转）
【段__】任务：____｜反转：____｜钩子：____
【结尾段】身份暴露/真相爆破：____（落在具体动作，不写"终于明白"）
```

### 3.4 钩子范式（短篇高密度）

- **信息炸弹 / 认知反转**：悬疑通用，开篇抛反常细节，结尾回收。
- **倒计时**：明确时间压力（例：距____还有____）。
- **抵达临界**：到重要场所/见关键人，门内未知。
- **盐言铁律**：完读率即生命，前 3 屏必须出钩；中段每屏小反转；结尾爆破不升华。

## 四、写完必跑自检

```bash
python ../tools/scripts/writing/chapter_selfcheck.py 你的书名/正文/
```

检查三项：① 字数 2600–3400（短篇按平台另计）；② AI味 干净/轻度（重度必修）；③ 章末钩子 命中五类之一（非"下章预告"空钩）。
