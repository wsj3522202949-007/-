# 实战模板包 · 从示范项目沉淀出的可克隆写作武器库

> 本包不是新理论，是把 `../` 已有的**空白表单**、**单页卡**、和 **已填示范**（前5章+全骨架+已填卡，端到端证明系统能产出可投正文）三合一，让你"照着填就能写出签约级稿"。
> 核心对症你被拒的四痛点：**切入点不足 / 爽点不够 / 看点不足 / AI味**。

## 一、四层结构（从低启动成本到高）
| 层 | 内容 | 位置 | 何时用 |
|----|----|----|----|
| **① 单页实战层** | 15 张独立可克隆卡（00 开写 → 14 改稿） | `../模板/` | 每次坐下来要写 |
| **② 通用表单层** | 框架/人物/伏笔/分卷/逐章/自检/投稿… | `../模板库.md` §0–§14 | 开新书建结构 |
| **③ 题材落地层** | 男频重生/女频少年夫妻/短篇盐言 三套填空 | `../模板库_三套可套用表单.md` | 按题材开书 |
| **④ 已填示范层** | 每文件的"填好的样子" | [已填示范索引.md](已填示范索引.md) | 不会填时照抄结构 |

## 二、标准开书工作流（照着走）
1. **启动**：复制 `../项目骨架模板/` 改名后放进 `projects/`，或复制某个示范项目换题材。
2. **骨架**：用 `模板库.md §1–§5` 填 框架/人物卡/伏笔表/分卷细纲（不会填 → 查 [已填示范索引](已填示范索引.md) 看已填示范怎么填）。
3. **逐章写**：每章开写前跑 `templates/01_单章作战卡`（→ `00` 启动器）→ 写完跑 `自检清单_升级版`。
4. **前 3 章签约体检**：写完前3章跑 `templates/02_前3章签约体检表`（实测 59/60）。
5. **投稿**：跑 `templates/12_投稿信与编辑沟通模板` + `模板库.md §9`。
6. **连载**：签约后跑 `templates/13_追读数据监控表` + `templates/14_改稿优先级批次表`。

## 三、三痛点 × 武器对照（一图记住）
| 你的痛点 | 用的武器 |

| 切入点不足（章首慢热） | `01_` §1 + `最强去AI味` §九 |
| 爽点不够 / 看点不足 | `02_` 维度二 + `平台差异手册` 爽点公式 |
| AI味 | `04_` + `最强去AI味铁律` §九~十三 |
| 钩子弱 | `03_` + `平台差异手册` 章末钩子速查(13式) |

## 四、克隆说明
- 单页卡 `templates/00–14`：直接复制进任何项目改名即用，相对链接互引。
- 通用表单 `模板库.md`：复制 § 内代码块进 `你的书名/`。
- 项目骨架模板：整体复制改名换题材，保留结构即保留"签约级质量基线"。
- 本包所有链接锚定真实规则文件，不另起一套；导航纪律见 `../../../schema/维护标准.md`。
