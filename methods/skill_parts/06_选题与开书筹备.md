# 六、选题与开书筹备

> 适用：开新书时。男频女频均覆盖。

## 6.1 选题三大原则

| 原则 | 说明 |
|------|------|
| **兴趣性格定题材** | 淡人写不了情绪文；掌握不到爽点、和读者不同频就扑街 |
| **阅读史即指南** | 喜欢什么写什么，大量阅读是创作根基 |
| **试写开篇定夺** | 每个类型写一千字，哪个文思泉涌先开哪个 |

> **简介最忌讳文不对题。** 仙侠配言情简介、悬疑配甜宠内容 → 目标读者望而却步。跨品类混搭要找"主类型"做基底。

## 6.2 开书前六维准备（王自律）

| 维度 | 要做什么 |
|------|---------|
| **市场调研** | 扫榜单，找同类火书，分析数据 |
| **简易大纲** | 主线、主角目标、核心冲突 |
| **升级体系** | 等级、晋升条件、战力换算（详见 §七）|
| **人设** | 主角+核心配角+反派（详见 §八）|
| **多版本开篇** | 写 3-5 个不同切入点的开头，对比选最好的 |
| **心态调整** | 接受前几本可能是练手 |

## 6.3 开书六大硬核筹备（徐二家的猫，男频向）

> 这是男频开书最系统的基建流程。六步走完，节奏很难崩盘。

**第一步：主线——一句话说清整本书讲什么。** 玄幻="少年成长拯救世界"；重生="大佬重生归来复仇"。一句话能说清，太复杂太发散就崩了。

**第二步：世界观——先正派后反派。** 先设定正派势力和体系，再完善反派体系、地图、科技树。三个必答：①世界基底是什么 ②最大势力是谁 ③"最大势力之下其他势力为何还能存活"找合理理由。

**第三步：体系设定——开书前最关键的一环。**

> 体系设定出现漏洞，会导致整本书崩盘。

必须严格制定三个前提：①达到什么要求才能晋级下一体系 ②节奏是否合理 ③每个等级分别提升了什么待遇。

**战力换算技巧：** 用具体战斗场景把差距描写出来。

| 等级 | 战力对比 |
|------|---------|
| 武者 | 打 2 个普通士兵 |
| 武士 | 打 10 个普通士兵 |
| 武师 | 打 50 个普通士兵 |
| 宗师 | 万军丛中过 |

**第四步：金手指——辅助主角，不能替代主角。**
> 金手指不要盖过主角风头，不要让主角成为可有可无的人。不要给读者"主角就是废物，这金手指我上我也行"的感觉。

**第五步：人设——不完美才真实。** 主角根据主线定性格基调，尽量不要完美人设；配角补充主角性格缺陷，形成互补；**反派越强越冷静越理智，越能证明主角成功的含金量**。

新手特别提醒：第一本书不要尝试群像；不要填充过多个人三观、立意；主线精简、人物精简。

**第六步：卷纲（最重要）。**

> **卷纲意义大过大纲。** 大纲周期长、不确定因素多；卷纲更灵活、节奏更稳。

大纲只做精炼的主线（基本不改），每卷单独做卷纲。体系化后：节奏很难崩盘、故事流畅、不卡文。

## 6.4 不断更的四大手段（鹿时七）

| 手段 | 说明 |
|------|------|
| **开书五准备** | 大纲、人设、体系、爽点表、伏笔表备齐 |
| **大纲破题/目标五分法** | 把大纲拆成 5 个目标段，逐个攻克 |
| **开头快准狠** | 前三章必须抓人 |
| **日更 4k 四大手段** | 组队码字、主动存稿、固定时间、正向洗脑 |

## 6.5 封面与简介设计（番茄官方）

**封面要求：** 清晰、要素突出（书名>作者名）、字号分级、配色（男频偏深冷；女频暖萌）。

**简介黄金五结构：**

| 结构 | 操作 |
|------|------|
| **开篇定调** | 首行点明故事核心梗 |
| **高能开场** | 反套路金句/核心冲突/灵魂拷问 |
| **核心梗概** | 300 字内讲明主线和人设亮点 |
| **钩子收尾** | 开放式提问/高能预告/视觉意象 |
| **加分技巧** | 小剧场式对话/亮点剧情 |

**简介三大雷点：** 文艺病（堆砌辞藻）→ 人设标签+动词+目标；流水账（剧透全文）→ 已知危机×未知变数；自嗨式（忽略代入感）→ 痛点共情×解决方案。

## 6.6 选题开书速查

```
【选题】兴趣+性格 > 追热点；题材内容不错位
【开书六步】主线→世界观→体系→金手指→人设→卷纲
【体系】等级+换算+前置条件，漏洞会崩盘
【金手指】辅助主角，不替代主角
【卷纲】卷纲 > 大纲，灵活防卡文
【封面】清晰、突出、分级；男频深冷女频暖萌
【简介】定调→高能→梗概→钩子→加分
【不断更】五准备 + 快准狠开头 + 日更 4k 四手段
```
