# 七、大纲与故事架构

> 适用：写大纲时。覆盖故事构建、核心纲、事业线、感情线、副本设计、升级体系。

## 7.1 合格大纲的定义

> 大纲通常是 500-2000 字的一段话，从头至尾的故事线精炼。

**检验标准：** 开篇-过程-结束主线清晰；读者一开始就能感受到主角目标是什么、驱动力是什么。

## 7.2 核心纲与强设定大纲法（来福鸽，男频长篇最适用）

**核心纲：表层 + 里层**

| 层次 | 内容 | 示例 |
|------|------|------|
| **表层（骨架）** | 故事框架，约束剧情不跑偏 | 张三不甘心被陷害，调查妻子被杀真相 |
| **里层（卖点）** | 核心卖点/标签——读者会怎么安利 | 一部剧情反转、紧张刺激、让人惊呼"哇萨"的悬疑小说 |

**三层递进判断：** 你想写什么题材 → 想写什么样的故事 → 读者会怎么总结你的小说。

**设定集核心原则：** 所有设定都是作者主观设定的，后期不可自我反驳。

## 7.3 OKR 大纲法（核心技巧）

- **O (Objective)** = 目标
- **KR (Key Results)** = 完成目标的途径

**KR 三个条件：** ①可见性（能看到进度）②可实现（能完成）③必须是完成 O 的必要途径。

**演示：**

| O：张三为父母报仇，成为苍玄界最强 | |
|:--|:--|
| KR1 | 重新修炼，重塑丹田（获得实力）|
| KR2 | 游历大陆，寻找仇敌踪迹（提升+追踪）|
| KR3 | 和帝族圣女结婚，获取资源 |
| KR4 | 找到仇人，复仇计划，大仇得报 |
| KR5 | 探索禁地，打败六大至强者，成为至强者 |

> 按 KR 顺序做，一定能完成 O。没有任何一条 KR 是无效的。

**逐级拆解：** 把每个 KR 当成新的 O，继续拆分更细的 KR。推荐工具：思维导图（幕布）。

**剧情倒推法：** 脑子里灵光一闪想到一个好剧情——先记录高潮结局，再倒推铺垫和爆发。

## 7.4 事业线大纲（任欢游）

**核心：从无到有 = 升级。**

| 题材 | 升级维度 | 终点 |
|------|---------|------|
| 种田 | 财力升级 | 富豪 |
| 宅斗 | 身份升级 | 主母 |
| 修仙 | 能力升级 | 巅峰强者 |

**事业线通用公式：**

```
起点（一无所有）→ 发现商机→第一桶金 → 第二桶金
→ 引入冲突（反派眼红/打压）→ 冲突升级（主角受挫）
→ 暗埋底牌（主角知道，读者知道，反派不知道）
→ 亮出底牌（反击）→ 出风头+获得补偿 → 进入下一阶段
```

> 所有的区别，就是金额大小、受挫大小、补偿大小的分别。套路骨架不变，只换外在元素。

## 7.5 感情线大纲（任欢游）

**公交站地图法：** 第一站（开头）→ 中间站点（重要剧情点）→ 终点（大结局）。

**感情线四大骨架：** 初识（不打不相识）→ 接触（了解）→ 升温（深化）→ 确定关系（收束）。

**情感状态库（可无限套入的节点）：** 单恋→奔赴→误会→分手→复合→相爱→背叛→暧昧→追妻火葬场→破镜重圆→死心→再次心动……

**暧昧阶段是重点：** 拉扯感大多在暧昧不明的阶段。用一个误会引发另一个误会，依次叠加，作为吊着读者的胡萝卜。

**误会叠加法：**
| 层级 | 剧情 |
|------|------|
| 第一层 | 朋友其实也喜欢男主/嫉妒女主 |
| 第二层 | 朋友给错误信息："男主是喜欢我" |
| 第三层 | 女主拉开距离，男主找朋友询问，女主看见误会加深 |

> 两个人只需解开最初的误会就能恢复关系，不要反复用新剧情造新误会。

**感情线 + 事业线缠绕：** 双线并行、互相服务、不单独抽离。每个事业节点嵌入感情变化。

## 7.6 副本设计（一月九十秋）

**副本三段式：** 进入副本（建立目标/规则）→ 副本推进（冲突/反转/成长）→ 副本结束（收获/伏笔/钩子）。

**锁链式结构：** 一个副本的结束 = 下一个副本的开始。副本之间用钩子串联。

**伏笔深浅：** 浅伏笔（几章内回收）、中伏笔（一卷内）、深伏笔（跨卷）。

## 7.7 升级体系设计（番茄官方）

**六步设计法：**
1. **先定底层能源：** 1 个主因 + 1 个次因（不要叠加太多）
2. **控制阶梯数量：** 大阶 4-7 个，每大阶 3 小阶段
3. **定每阶质变内容：** 不能只数值变高，必须有质变（身体积累→技巧成形→法则领域）
4. **与世界结构绑定：** 高阶资源谁掌握？普通人升到哪步？升级后社会地位变吗？
5. **提前设计例外机制：** 主角可以特殊，但必须写清来源、优势、代价、边界
6. **补全输入-过程-输出：** 输入（资源+功法+战斗）→ 过程（压缩/冲击/稳定）→ 输出（技能+寿命+感知）

**六大常见崩盘点：**

| 问题 | 解决 |
|------|------|
| 资源前后不一 | 用稀缺度+获取渠道+使用门槛锁死 |
| 只有等级没机制 | 加身体/精神承载限制 |
| 例外太多 | 每个特殊设定回答：来源/代价/能否复制 |
| 金手指太万能 | 先定核心方向，主动保留短板 |
| 越阶战常态化 | 越阶战只能偶发，条件苛刻+提前铺垫 |
| 能力没副作用 | 附带体力/精神/寿命/冷却/反噬成本 |

## 7.8 大纲架构速查

```
【大纲本质】导航，不是剧本；略有偏差也能到目的地
【核心纲】表层（骨架）+ 里层（卖点/读者怎么安利）
【OKR】O=目标，KR=途径，逐级拆解，所有KR必须能完成O
【事业线】从无到有 = 升级（财力/身份/能力）
【感情线】公交站地图：初识→接触→升温→确定
【误会叠加】用一个误会引发另一个，解最初的就能恢复
【副本】三段式（进入→推进→结束）+ 锁链串联
【升级体系】为什么能升/不能乱升/升了有代价
【崩盘点】资源不一/没机制/例外多/金手指万能/越阶常态/没副作用
```
