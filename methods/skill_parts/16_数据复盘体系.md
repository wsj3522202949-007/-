# 十六、数据复盘体系

> 适用：已开书、有后台数据后。连载期最该读的章节。别凭感觉改，让数据指路。
> 深拆可执行复盘手册（指标字典 / 诊断树 / 用数据反推创作 / 周复盘 / 平台差异 / 两本书数据关注点）见 `craft/数据化复盘.md`。

## 16.1 核心指标

| 指标 | 看什么 | 预警信号 |
|------|--------|---------|
| 完读率 | 一章从头读到尾的比例 | 某章骤降→从上一章开始改 |
| 追读率 | 看这章的人里多少看下一章 | 持续下滑→节奏/钩子出问题 |
| 章末跳出 | 读到章末就走、不点下一章 | 章末钩子弱 |
| 收藏/推荐票 | 长期价值认同 | 涨不动→人设/主线吸引力不足 |
| 段评情感 | 读者原话（最真实） | 高频"尬/毒/水"→定位毒点 |

## 16.2 诊断流程

```
看曲线：哪章明显下滑？
  → 从上一章看起（毒点常在前一章埋下）
  → 定位病因：
      节奏太慢（十几章一个小剧情且非主线）→ 加钩子/砍剧情
      节奏太快（读者总结要十几句话）→ 加情绪/撑开
      毒点（人设崩/逻辑硬伤/虐无必要）→ 删或圆
      钩子弱（章末无悬念）→ 重写入尾
  → 改完多等一周再看，不刚改一天就下结论（§10.10）
```

## 16.3 用数据决策（对应 §10.4 调控心法）

| 数据现象 | 动作 |
|---------|------|
| 完读率掉、章末跳出高 | 章末加悬念/反转/期待 |
| 追读率掉但完读稳 | 节奏太快，插心理/环境/生理反应撑开 |
| 收藏不涨 | 人设记忆点/主线钩子不够，回炉 §8/§9 |
| 段评集中吐槽某角色 | 减戏份或改人设（§13.1 反馈驱动） |

## 16.4 A/B 与实验

- **多版开头**：前 3 章写 2–3 个切入点，小范围测完读率，留胜者。
- **读者反馈闭环**：每章发 1–2 个专属读者，收集"主角叫啥/想干啥/在干啥"三问（§11.7）。
- **实验记录**：在 `写作进度.md` 或周表记"本次测试→结论"。
