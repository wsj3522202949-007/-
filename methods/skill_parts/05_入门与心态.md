# 五、入门与心态

> 适用对象：所有品类，尤其零基础新手。焦虑时、写不动时读这一章。

## 5.1 写之前必须想通的事

**好故事 vs 好文笔：** 把小说比作盖房子——故事性是框架，文笔是外观。茅草屋贴瓷片会塌。第一章看了半天没进正题 → 直接弃文。

**新人突破口：** 构思新鲜的故事。每天发书的人没有一千也有八百，杀出去靠的是故事性更强、更新鲜（噱头）。

## 5.2 新手六大高频雷点（自查清单）

写完前三章务必逐条对照：

- [ ] **开篇拖沓**：前三章没建立"困境→金手指→第一次爽点"闭环
- [ ] **世界观模糊**：设定堆砌、读者抓不住"这是个什么世界"
- [ ] **人设矛盾**：前后言行不一致
- [ ] **视角杂乱**：多视角来回切，读者晕
- [ ] **剧情平淡**：流水账，"然后…然后…"，没有因果与冲突
- [ ] **文笔无效**：华丽辞藻堆砌，却推动不了剧情

### 五大雷针（京祺版）

| 雷针 | 症状 | 解法 |
|------|------|------|
| 视角混乱 | 多视角来回切 | 一章一个主视角，转换要有过渡 |
| 流水账 | "然后"接"然后" | 改成因果关系，每个情节有推进作用 |
| 开头太慢 | 大段背景/景物描写 | 从冲突切入，动态代替静态 |
| 人设崩 | 为了剧情牺牲人设 | 人设是红线，宁可改剧情 |
| 炫文笔 | 堆砌华丽词藻 | 故事性优先，文笔服务于故事 |

## 5.3 新手写作破局三步法（丛月）

**第一步：先写，别等准备好。** 别人都在观望，你已经动笔，你始终领先一步。

**第二步：选题材——兴趣和性格是关键。**
- 看到后悔流、追妻火葬场，想不通"人都死了后悔有什么用" → 这类文不适合你
- 喜欢什么写什么，大量阅读就是创作根基
- 纠结时试写开篇：每个类型写一千字，哪个文思泉涌先开哪个

**第三步：情节如何环环相扣——因果关系。**

| "然后"关系（流水账） | "因果"关系（好故事） |
|---------------------|---------------------|
| 我开门取快递，然后下楼扔垃圾 | 我开门取快递，看到有人拿刀站隔壁门口 → 慌忙关门 → 门口响起敲门声 |

**用人物欲望推进：** 每个场景里，人物行动都有"我想要…所以必须…"的内在逻辑。

**伏笔必须回收：** 主角前期救的小孩，后期麻烦时带着家族大佬来救。

**所有逻辑链服务主线：** 女主重生复仇是主线 → 却跑去做生意几十章破案几十章 → 读者忘了最初目标。解法：所有逻辑链汇聚主线。

## 5.4 写作心态（焦虑时读）

- **过度准备压制灵感：** 觉得要全写完设定才能动笔 → 永远动不了笔。**故事先于大纲。**
- **人物扁平怎么办：** 不是描写不够，而是故事性不足。给人物加故事性：复杂背景、情感联系、双重身份、性格矛盾点。
- **坚持哲学：** 一万小时定律亲测有效。当初二百人的作者群，最后只剩七八个还在写。把码字当终身事业才会赢。

## 5.5 突破十万字大关

**根本原因：** 故事不够大、不够丰满、人物关联不够精彩、框架没搭好。

**开新书前想清楚四个问题：**

| 问题 | 说明 |
|------|------|
| 开篇精彩吗？ | 包袱给出来了？给了别当即拆开 |
| 故事框架够庞大吗？ | 能支撑 30-50 万字吗？ |
| 人物关系耐人寻味吗？ | 正反派关联给主线加分？有让人又爱又恨的角色？ |
| 明暗多线如何发展？ | 主线到哪阶段牵出更精彩的支线？ |

## 5.6 入门心法速查

```
【第一性】先写 > 准备；好故事 > 好文笔
【题材】兴趣+性格定题材，喜欢什么写什么
【底层逻辑】因果关系，不是"然后"接"然后"
【人物驱动】"我想要→所以必须"
【伏笔】埋了必须回收，所有逻辑链服务主线
【雷点】前三章自查六大雷点
【十万字】故事够大、框架够庞、人物关联够精彩
【坚持】流水不争先，争的是滔滔不绝
```
