# 十三、作者心法

> 适用：想放弃/焦虑时读。

## 13.1 杀虫队队员的创作心法（《十日终焉》作者）

**创作数据：**

| 作品 | 字数 | 耗时 | 备注 |
|------|------|------|------|
| 《传说管理局》 | 139.2 万字 | 260 天 | 前半年没有任何收益 |
| 《十日终焉》 | 293.4 万字 | 698 天 | 到 100 万字时稿费才突破九块钱 |

> **三十多岁入行，之前只看过五六部网文。我的起跑线和你们一样，甚至还不如你们。**

**存稿观：** 一般情况下没有存稿。原因：没读者反馈时盲目前进容易"抓瞎"；陷入"作者自我满足"——在自己逻辑大圆满里自己感动自己。

**读者反馈驱动模型：**

```
写一章 → 发布 → 半小时/两小时/一天后查看段评 → 获取反馈 → 调整后续剧情
```

| 反馈类型 | 调整方式 |
|---------|---------|
| 读者对角色好恶 | 增减该角色戏份 |
| 读者对剧情期待感 | 加快或放缓节奏 |
| 读者疑问 | 后续剧情解答 |
| 多人提出同一问题 | 修改有问题章节 |
| 毒点/尬点 | 能改则改 |

**大方向不变，小方向灵活。**

**高压写作法（零存稿模式）：**
> 写书这件事：要么写出来，要么全面崩塌——我没得选，只能去这样做。
> **如果写作像喝水一样简单，指望这种付出换来可观的回报——我认为不合理。**

## 13.2 选题策略

**核心：选竞争小的赛道，学会"藏拙"。**

| 赛道 | 分析 |
|------|------|
| 玄幻修仙 | 耕耘十年，有完整规则，新人想象力受限 |
| 都市高武 | 同上 |
| 规则怪谈 | 清一色规则怪谈，不算正统竞品 |
| **正统悬疑** | **同类较少 → 能找到自己的赛道** |

> 尽量不要以当下正在流行的元素为主题。当下火热 → 搜一搜已经很多类似作品。

**藏拙：** 涵盖多题材不是因为擅长多，而是**不擅长的多**→尽量尝试所有题材→发现自己擅长大结局反转和大局统筹→选择竞争小的赛道。

## 13.3 关于数据

> 与其像盯股市一样盯后台数据，不如把所有时间放在打磨自己的故事上。

- 第一部书写了八九个月，前半年没收益
- 前六个月收益放任何作者群都不建议继续写
- 庆幸当时不认识任何作者，能一个人单机坚持

> **有人愿意在你作品里留言或提建议，是因为他们希望作品变好，不是带着敌意来攻击你。**

## 13.4 写作通关地图（板面王仔）

| 难关 | 破局法 |
|------|--------|
| 更新关 | 养成日更习惯，哪怕每天 1000 字 |
| 留言关 | 重视读者反馈，互动保追读 |
| 套路关 | 学套路但不被套路困住 |
| 爆点关 | 爽点密集、多样、有反馈 |
| 人物关 | 人设立住才有记忆点 |
| 荒诞感 | 适度反常规、反套路制造新鲜感 |

## 13.5 持续写作的四个支柱

| 支柱 | 说明 |
|------|------|
| **日更习惯** | 哪怕 1000 字也不要断，手不能生 |
| **读者反馈闭环** | 找 1-2 个专属读者，每章发给他们看 |
| **素材积累** | 每天积累十个素材/十个开头，卡文时翻出来 |
| **正向洗脑** | 不断告诉自己"我可以"，把坚持刻进骨子里 |

## 13.6 作者心法速查

```
【坚持】可以输给一切，但不能输给自己没能坚持
【反馈】读者评论就是教程，十万条评论十万教程
【数据】与其盯数据不如打磨故事，单机100万字稿费9块——坚持
【选题】选竞争小的赛道，不追当下热点
【高压法】要么写出来要么崩塌，没得选只能写
【藏拙】不擅长的多→尝试→发现强项→选小赛道
【读者观】读者是市场，菜品应符合客人而非老板口味
【六步破局】更新→留言→套路→爆点→人物→荒诞感
【坚持支柱】日更习惯+反馈闭环+素材积累+正向洗脑
【新手观】前三本大概率练手，一本比一本好，一万小时定律有效
```
