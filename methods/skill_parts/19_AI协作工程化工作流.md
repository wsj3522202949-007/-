# 十九、AI 协作工程化工作流

> 本章把前面所有方法论变成"AI 助手能直接执行的流程"。当你说"继续写下一章""帮我推进项目"，助手应按本章循环作业，而不是凭记忆乱写。

## 19.1 总原则

- **文件即记忆**：所有决策写进项目文件（框架/人物卡/伏笔表/进度），不依赖对话记忆（§二 Step 工作流铁律）。
- **先读后写**：每次动笔前，必读 `写作进度.md` + `框架.md` + 相关 `人物设定卡.md` + `伏笔管理表.md`。
- **写完即登记**：章末更新伏笔表、进度日志，闭环。
- **人审定稿**：AI 出初稿 + 自检，最终金句/情绪浓度/方向由你拍板（§15.1）。

## 19.2 标准项目文件结构

严格使用《模板库.md》第 0 节结构：`框架.md / 写作进度.md / 人物设定卡.md / 伏笔管理表.md / 分卷细纲.md / 设定集.md(选) / 正文/`。新项目直接从模板库复制。

## 19.3 Agent 主循环（逐章推进）

```
┌─ 1. 读状态：读 写作进度.md 找到"下一步"
├─ 2. 读上下文：框架.md + 该角色人物卡 + 本章逐章细纲 + 伏笔管理表(待收)
├─ 3. 写初稿：按细纲写第N章，遵守 去AI味铁律(§3.1) + 禁词表(§15.5)
├─ 4. 自检：跑《模板库》第6节「每章自检清单」逐项改
├─ 5. 登记：本章埋/收伏笔 → 更新 伏笔管理表.md
├─ 6. 记进度：在 写作进度.md 追加"第N步/第N章 完成"
└─ 7. 交付：输出正文 + 一句话本章钩子，交你审阅定稿
```

> 每章只推一个核心事件（§11.8 叙事层），章末必留钩子（§9.6）。

## 19.4 断点续写协议（Resume）

- 靠 `写作进度.md` 的"状态/下一步"字段定位。
- 续写前额外读最新 2–3 章正文，保持语气/人设/伏笔连续。
- 若进度日志缺失，先重建：扫描 `正文/` 目录与现有框架，补一份进度摘要再继续。
- **绝不凭空编造前文设定**：前文人设/伏笔以文件为准。

## 19.5 每章交付清单（助手自检用）

- [ ] 五要素齐：核心事件 / 出场人物 / 拉扯或爽点 / 人味细节 / 章末钩子
- [ ] 去 AI 味达标（五感≥3 / 动作代形容词 / 口语对话 / 生活碎片 / 情绪有起伏）
- [ ] 人设未 OOC（对照人物卡）
- [ ] 伏笔已登记（埋则登 伏笔管理表，收则标记）
- [ ] 段落≤3 行，字数达标
- [ ] 禁词扫描通过（§15.5）

## 19.6 伏笔追踪自动化

- 写前：从 `伏笔管理表.md` 取"待收"列表，本章必须呼应或推进至少 1 条。
- 写时：每埋一个新伏笔，立即在表里加一行（编号/内容/埋设章/状态=已埋）。
- 写后：把"已埋→回收中/已回收"的变更写回表格。
- 开新卷前：跑一次"待收未收"扫描，避免烂尾（§14.5）。

## 19.7 跨卷一致性检查（开新卷/卷末必跑）

- [ ] 主角年龄/外貌一致
- [ ] 科技树/力量体系边界一致（§7.7 / §14.3）
- [ ] 资产/规模增长合理
- [ ] 伏笔无遗漏
- [ ] 反派动机自洽（§8.4）
- [ ] 感情线/事业线连贯
- 输出一份"一致性报告"给你，标红冲突点。

## 19.8 启动与继续（对接本技能）

- **启动新项目**：调研同类 → 写 `框架.md`（套模板库 §1）→ 展示摘要等你确认 → 写黄金三章 → 逐章推进。
- **继续已有项目**：读 `写作进度.md` 定位 → 读上下文 → 按 §19.3 主循环续写。
- **解决具体问题**：卡文→§十；改稿→§十一；投稿→§十二；心态→§十三；数据→§十六；平台→§十七；IP→§十八；世界观→§十四；AI用法→§十五。

> 助手应在每次会话开始时主动读 `写作进度.md`，而不是等你提醒"接着写"。
