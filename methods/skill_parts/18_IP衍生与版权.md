# 十八、IP 衍生与版权

> 适用：书有起色后、签合约前必读。很多作者扑在"全版权买断"上，本章帮你避坑。

## 18.1 版权基础（签之前搞懂）

| 权利 | 是什么 | 常见归属坑 |
|------|--------|-----------|
| 信息网络传播权 | 网络连载 | 通常授平台，保留其他 |
| 改编权 | 影视/动漫/游戏/有声 | 最值钱，慎全授 |
| 署名权 | 你是作者 | 一般不剥夺 |
| 翻译/海外 | 出海收益 | 常被忽略 |

> 关键区分：**净收益分成** vs **全版权买断**。买断一次拿钱但后续 IP 红利与你无关；分成能跟着 IP 长大但前期少。

## 18.2 签约陷阱清单

- [ ] 是否"全版权"（含影视游戏有声漫画）一次性授权？→ 尽量只授"信息网络传播权+有声"，改编权另谈。
- [ ] 改编收益分成比例与到账周期？
- [ ] 同人/二创授权归谁？
- [ ] 独家期多长？解约条件？
- [ ] 数据/流水是否透明可查？

## 18.3 IP 开发路径

```
小说（立人设/立情节）
  → 有声书（最快变现，验证剧情吸引力）
  → 漫画（视觉化人设，扩圈）
  → 动画/影视（IP 峰值，重改编权）
  → 游戏/周边（长尾）
```
每级跃迁靠"可改编性"：强情节、强人设、强视觉道具、清晰世界观。

## 18.4 为 IP 蓄力（写作时就做）

- **人设记忆点**：一眼能画出来的特征（§8.6）。
- **视觉化道具**：银镯、疤、特定武器——漫画家最爱。
- **可改编结构**：主线清晰、高潮节点明确（方便影视拆集）。
- **世界观干净**：改编时美术好落地（见 §十四）。

## 18.5 维权基础

- 保留创作时间戳（平台后台即证据）。
- 盗版/抄袭：平台举报通道 + 存证。
- 合同纠纷：签约前让懂行的人看条款，别只看稿费数字。
