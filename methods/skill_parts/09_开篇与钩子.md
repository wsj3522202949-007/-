# 九、开篇与钩子

> 前 3000 字决定生死，前三章决定追读。

## 9.1 开篇三步公式（丛月）

```
突发事件制造混乱 → 人物反应暴露性格 → 插入记忆碎片暗示过往 → 抛出钩子引出主线
```

**骨架 + 血肉：**
```
【骨架】突发事件 → 人物反应 → 记忆碎片 → 抛出钩子
  + 【血肉】天气烘托 + 动作微表情 + 道具线索
  = 【效果】画面感 + 代入感 + 氛围感 + 钩子
```

**渲染原则：** 小说中的雨不能白下，天不能白晴。任何场景都要为剧情服务。写她惨就要惨到极致，半惨不惨不叫惨。

## 9.2 两种主流开篇方式（徐二家的猫）

| 方式 | 特点 | 适用 |
|------|------|------|
| **剧情切入** | 对话/简单情况→主角遭遇危机→思考破局/金手指降临 | 大多数爽文、悬疑文。**新人首选** |
| **场景切入** | 不涉剧情，偏重环境渲染 | 需较强笔力 |

> **铁律：千万不要第一时间抛大量世界观、体系设定！** 先通过冲突吸引读者，在主角解决危机的过程中一点一点带出设定。

## 9.3 主动引爆法（徐二家的猫，男频向）

> 作为作者，我们要做的就是把这段剧情主动引爆！核心：一步一步来，让冲突性升级再升级。

**引爆链示例（悬疑向）：**

| 步骤 | 剧情 | 效果 |
|:----:|------|------|
| ① 小事件 | 小偷回家，发现门锁被撬过 | 引发好奇 |
| ② 升级 | 猫眼一片漆黑，像被堵住 | 好奇升级 |
| ③ 再升级 | 那抹黑……**动了！** | 震撼 |
| ④ 引爆 | 房间内有人通过猫眼偷窥他！ | 冲突引爆 |
| ⑤ 高潮 | 男主转身要跑，血淋淋的手拽住他拖进房间，砰—— | 完整引爆 |

**类比：** 摆摊说免费洗衣 → 来了又说抽奖 → 大家被吸引 → 宣布：今天送法拉利，免费！

**反差锚点：** 正常人遇怪物躲远，男主却拎电钻上去，比怪物还怪物 → 强烈反差第一时间让读者喜欢。

## 9.4 七大高能开篇梗（未小兮，女频向）

| 梗类型 | 核心操作 | 示例 |
|--------|---------|------|
| **悬疑钩** | 抛令人费解的悬疑事件 | 小镇符号出现在谁身上三天内必死，今早主角肩上出现了 |
| **反差梗** | 主角前后反差 | 杀敌无数的硬汉大将军睁眼，五个奶娃围着他 |
| **金手指** | 开局抛金手指 | 穿成炮灰宫女，暴君要杀她时她听到了他的心声 |
| **强冲突** | 强烈冲突开局 | 一睁眼极品亲戚上门闹事抢地 |
| **先抑后扬** | 压抑主角引反转期待 | 废材在大师收徒时大放异彩 |
| **先扬后抑** | 极大落差感 | 世家天才意外变残废，虎落平阳 |
| **复仇报恩** | 血海深仇/救命之恩 | 上辈子满门抄斩，一睁眼回到定亲那天 |

## 9.5 切入方式与五大原则

**切入方式：**
- **对话切入（最简单）：** 直接呈现有意思的对话，让读者好奇说话人是谁。搞不定开头就试这个。
- **场景切入：** 细腻描绘独特场景。**忌冗长**。
- **悬念叙事：** 抛出引人深思的悬念。如"葬礼上棺材里传出三声敲击——死者昨天火化的。"

**五大原则：** ①简洁明了（尽快切入关键）②展现核心元素（人物特点+故事类型）③建立情感连接（共鸣+期待感）④留下引子（第一件事写完要留引子，**可以解决但不能完全解决干净**）⑤行文风格贯穿始终。

## 9.6 钩子设计（京祺 + 徐二家的猫）

**钩子 = 噱头 + 悬念 + 包袱 + 期待感。** 吸引读者一直往下读的东西。

| 位置 | 作用 |
|------|------|
| 书名/简介 | 一本书最大的噱头 |
| 小说开头 | 一见钟情 |
| 小说中间 | 持续吸引的胡萝卜 |
| 章节末尾 | 吸引点开下一章的小悬念 |

**① 剧情反转类钩子：** 剧情发展出乎意料。正常往东走，你偏往西走。

> 钩子本质是末端被掰弯的金属——**你不能按套路出牌，要会拐弯。**

连续拐弯示例：
> 第一弯：女主下班发现丈夫和小三在床。
> 第二弯：小三是她的女老板。
> 第三弯：女老板说"让给我给你一百万"，女主疯狂点头"我下午就去离婚"。

> 钩子不是单一悬念，是**山路十八弯的九连环**，一个弯接一个弯，持续吊胃口。

**② 情绪向钩子：** 主打把读者情绪拉满。可以没反转，但开头要把情绪拉到位。天崩开局示例：妻子跑了、孩子被卖、公司被骗、腰子被嘎、父母被害、小三也跑了——那叫一个惨。

**③ 融合写法（最无敌）：** 情绪钩子 + 反转钩子融合。
- 第一阶段：情绪到位（天崩开局）
- 第二阶段：第一次反转给甜头
- 第三阶段：第二次反转更惨

**钩子的大小之分：**

| 类型 | 说明 | 位置 |
|------|------|------|
| **大钩子** | 故事主干线，主角要完成的目标 | 开篇抛出，可能结尾才拆 |
| **小钩子** | 小剧情或 1-3 章结尾悬念 | 持续穿插 |

> 钩子的核心作用：除了吸引阅读，**更重要的是引出下一个钩子**。

**拆弹升级示例（把普通钩子变精彩）：**

**普通钩子：** 女主要拆炸弹，能不能成功？——她拆不拆跟读者没关系。

**升级三步：**
1. 加人物关系+情绪冲突：炸弹挂在女主**前夫**身上，前夫劈腿八次骗光她钱
2. 加人设深度+两难：女主是**恶女人设**，对谁都坏只对前夫好，她完全可以"剪错线"送他下地狱
3. 给读者意外：女主邪魅一笑"今天老娘炸了你"

> 当读者面临两难选择时，往往是故事最有趣的时候。

## 9.7 前三章节奏（徐二家的猫）

| 章节 | 内容要点 | 核心功能 |
|:----:|---------|---------|
| **第一章** | 主角处境 + 钩子 | 钩子→叙事剧情线→章末钩子 |
| **第二章** | 伏笔 + 情绪矛盾 | 眼熟想不起（伏笔）→ 制造情绪矛盾 → 翻到照片发现 30 年没变老（钩子）|
| **第3-4章** | 复仇 + 爽感 + 高潮 + 新钩子 | 准备→潜伏→高潮→房门再开→新钩子 |

**读者理想心理路程：**
```
咦，主角有麻烦了 → 嘶，不好处理 → 嗯？还能这样？
→ 这主角不错 → 这伏笔怎么回事 → 刚圆又挖坑，继续看
```

**避坑：** 前三章不要一条主线+五条支线+三个设定！读者会感觉漫无目的、繁杂、看不懂。

## 9.8 新手开篇禁忌

### 禁忌一：少用静态，用动态代替

| 静态（差） | 动态（好） |
|-----------|-----------|
| 夕阳下的咖啡厅，女主静静看着窗外 | 高跟鞋卡进排水盖，她撞进带着雪松香的怀抱——抬头正是分手五年的前任 |

### 禁忌二：避免三个以上人物同时出场

人物越多越没主次。第一章 2000 字写五个人，每个人分到的笔墨有限，人设立不起来。

### 禁忌三：避免大篇幅无推动性文字

开篇字数有限，任何对剧情无推动的文字都别写，哪怕一句。> **在读者没爱上你的人设时，没有耐心看大篇幅非剧情文字。**

### 禁忌四：忌完美人设

躁郁症男主、绿茶女主，三观没问题的情况下缺点反而是亮点。

## 9.9 记忆点设计（让读者记住你的书）

| 手法 | 示例 |
|------|------|
| **运用数字** | 离婚冷静期还剩 30 天；原剧本女主 8 年后会死；每天 12 点交房租 |
| **特殊道具** | 银镯子（线索道具）、胎记（身份识别）、扑克牌（标志性作案）、泪痣 |

## 9.10 钩子自查清单

- [ ] 开头有没有让读者"意想不到"的反转？
- [ ] 剧情有没有连续拐弯（至少 2-3 个弯）？
- [ ] 情绪有没有在开头就拉到位？
- [ ] 钩子有没有形成闭环（不是无意义反转）？
- [ ] 章节末尾有没有留小悬念？
- [ ] 书名/简介有没有一句话概括最大噱头？
- [ ] 前三章有没有建立"困境→金手指→第一次爽点"闭环？
- [ ] 前五章出现的每个人都有意义吗？

## 9.11 开篇钩子速查

```
【开篇公式】突发事件→人物反应→记忆碎片→抛出钩子
【切入】新人选剧情切入，禁第一时间抛设定
【引爆】冲突升级再升级，一步步引爆
【七大梗】悬疑/反差/金手指/强冲突/先抑后扬/先扬后抑/复仇报恩
【钩子本质】九连环，一个弯接一个弯
【钩子类型】剧情反转类 + 情绪向，融合最强
【钩子大小】大钩子（主线）+ 小钩子（章末），作用是引出下一个钩子
【前三章】处境+钩子→伏笔+情绪→复仇+爽感+新钩子
【禁忌】动态代静态/≤3人出场/无推动文字不写/忌完美人设
【记忆点】数字 + 特殊道具
```
