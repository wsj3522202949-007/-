# 八、人物设定

> 适用：设计人物时。主角、配角、反派全覆盖。

## 8.1 人物功能选定

| 角色类型 | 核心原则 | 说明 |
|----------|----------|------|
| **主角** | 功能性大于完美性 | 不完美才引出更多故事线 |
| **配角** | 记忆点大于完整性 | 抓一个最独特的记忆点即可 |
| **反派** | 破坏力大于邪恶值 | 必须实际给主角带来压力 |

**主角功能性示例：** 过度自信 → 因过度自信错过线索，做出错误判断 → 引出剧情。

**配角记忆点示例：** 女频古言设计"嗜甜如命的暗卫"或"结巴的毒医"——一提就能精准定位。

**反派破坏力示例：** 仙侠反派设定为修为高超但被心魔控制的大能——放出来破坏力惊人，悬在主角头顶的利剑。

## 8.2 三维人物模型

**基础设定：** 姓名（简洁有记忆点）、年龄（涵盖成长）、身份（双面设定）、外貌（**动态描写代替静态**）、记忆锚点（关键伏笔/标签）。

**动态描写示例（王熙凤出场）：** 从后院笑声 → 门口说话声 → 黛玉反应 → 走进屋子被簇拥 → 容貌描写。比静态罗列更令人印象深刻。

**背景设定 = 故事性：** 家庭背景（性格的根本）+ 情感联系（亲情友情爱情）+ 双重身份（有隐藏身份就有期待值，读者期待掉马）。

> 复杂背景、丰富情感联系、双重身份，都是人物身上的故事性。只有有故事性的人物，才能拉动后续剧情。

**性格立体化——核心矛盾点：**

| 矛盾类型 | 说明 | 示例 |
|----------|------|------|
| 价值观冲突 | 新旧身份观念冲突 | 现代医学生穿越成用毒世家继承人，旧身份救人，新身份杀人 |
| 行为模式冲突 | 身份与行为反差 | 极度社恐被迫成为团队领袖 |
| 认知冲突 | 内心信念与现实的矛盾 | 救赎文男主坚信自己不值得被爱 |

**特定行为反应（三层）：** 本能反应（被背叛立即拔剑）→ 理性反应（强压怒火分析利弊）→ 隐藏反应（指尖掐入掌心渗血）。

## 8.3 主角设定五步成长法（番茄官方）

**核心思路：** 先定"人物在故事里要干什么"，再补"他为什么会这样"。

| 步骤 | 关键问题 |
|------|---------|
| ① 定职责 | 推动主线/制造冲突/辅助成长/衬托主角？ |
| ② 一句话标签 | "外表冷淡、内心渴望被认可的天才少女" |
| ③ 补关键经历 | 只挑能解释性格行为的（被忽视→在意评价；灭门→冷酷多疑）|
| ④ 定欲望与弱点 | 欲望驱动行动，弱点制造真实感 |
| ⑤ 设计成长弧线 | 起点 → 内在问题 → 改变事件 → 变化节点 → 终点 |

**变化节点要分层：** 行为上的初次反抗 → 能力上开始成长 → 内心病根开始愈合。

## 8.4 拒绝无脑反派（番茄官方）

**反派必须有自洽逻辑：** 想实现什么？为什么觉得自己对？经历了什么形成这套逻辑？

> 让读者感觉："我不认同他，但我理解他为什么会变成这样。"

**不是反对主角，而是坚持自己：** 他不是故意针对主角，而是主角刚好挡了他的路。

**给反派一个"退不了"的理由：**
- 一旦真相曝光他会失去一切
- 一旦停手过去做的一切都白费（沉没成本）
- 一旦心软他珍视的人会死（被胁迫的恶）

**让反派有局部正确性：** 最具张力的冲突是双方各执一词的"局部正确"——主角追求真相，反派维护秩序，各自有理。

## 8.5 拒绝工具人配角

| 工具人特征 | 正确写法 |
|-----------|---------|
| 存在只为帮/害主角 | 有自己的生活目标和行动逻辑 |
| 没有独立动机 | 每个行为源于自身诉求 |
| 依附主角主线 | 有自己的支线和生活 |

**人物冲突关系网四问：** ①核心诉求——他想要什么？②底层动因——他为什么非要？③矛盾落点——他和主角在哪一点冲突？④多边关系——制衡/结盟/反目/误会。

**关键：** 要有不经过主角也能自行运转的独立关系线，让局面复杂好看。

## 8.6 成长规划与记忆点

**成长可视化：** 修为实质化（灵气雾状→金丹凝实体）、物品升级（二手电动车→定制超跑）、服装变化。

**黑化/觉醒触发点：** 亲友背叛 / 力量反噬 / 信仰崩塌。隐藏开关：童年记忆封印、血脉诅咒。

**记忆点强化：** 语言特征（每次被围困说某句话）、动作标签（紧张就啃衣角）、时间标签（每逢月圆夜功力尽失）、视觉反差（娇小女生武器是大铁锤）、行为反差（高冷人设看到蘑菇就想笑）。

## 8.7 人物设定速查

```
【主角】功能性 > 完美性；不完美才引出故事
【配角】记忆点 > 完整性；抓一个独特标签
【反派】破坏力 > 邪恶值；必须给主角压力
【背景】家庭+情感+双重身份 = 故事性
【性格】价值观/行为/认知 三重冲突
【成长】可视化升级 + 触发点 + 隐藏开关
【反派逻辑】不是反对主角，是坚持自己；给"退不了"的理由
【关系网】每个人为自己目标行动；多边拉扯
【禁忌】配角独立、忌堆砌、忌完美
```
