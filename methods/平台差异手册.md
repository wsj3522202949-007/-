# 平台差异手册 · 同一内容如何切换平台表达

> 用途：你写好的故事内核不变，但**字数节奏、简介写法、更新要求、读者预期、开篇偏好**因平台而异。投稿/分发前翻这份，避免「用错平台的腔调」。

## 先定平台，再定题材
不同平台的「爽点密度」「信息差落差」「感情戏占比」预期完全不同。开书前先锁定主投平台，再反向设计前 3 章。

| 维度 | 番茄小说 | 起点 | 晋江 | 知乎盐选（盐言） | 七猫 | 豆瓣（小众） | 小程序/知乎短篇 |
|---|---|---|---|---|---|---|---|
| 商业模式 | 免费+广告分账 | 付费订阅 | 付费订阅+版权 | 会员/单篇 | 免费+广告 | 出版向 | 短篇买断/分账 |
| 开篇偏好 | 强冲突、快节奏、前 3 章必出爽点 | 金手指/世界观铺陈可稍缓 | 人设/感情/文笔优先 | 一个极抓人的「钩子问题」 | 类似番茄，更下沉 | 文学性/真实感 | 前 100 字定生死 |
| 字数节奏 | 2000–4000/章，日更 | 2000–4000/章 | 2000–3000/章 | 单篇 1–3 万或连载 | 2000–4000/章 | 不限 | 3000–8000 短篇 |
| 更新要求 | 日更、稳定 > 爆发 | 日更/隔日更 | 稳定更新 | 一次性或短更 | 日更 | 低 | 短平快 |
| 读者预期 | 「停不下来」爽感 | 「成长+装逼+体系」 | 「嗑到了」情感满足 | 「原来如此」认知反转 | 爽+通俗 | 「被理解」共鸣 | 「看完即走」的爽点 |

## 分平台写法要点

### 番茄小说（免费流·爽文主战场）
- **简介**：前 2 句抛「身份落差+核心爽点」，不给结局；用「当 X 时，所有人都以为…直到…」句式。
- **前 3 章**：必须出现第一个小爽点/打脸/信息差；禁止慢热回忆、禁止重生后发呆。
- **章末钩子**：用「危机降临 / 打脸预示 / 信息炸弹」五类强钩子之一，禁「下章预告」括号。
- **雷区**：AI 味重、钩子弱、爽点密度不足（你《重生千禧》被拒的真实反馈）。
- **题材腔调**：番茄不是"一种写法"，而是按题材切腔调——锁定题材后抄该卡「开场抓手/冲突发动机/章尾钩子/禁止漂移」四栏进细纲。→ 见下方「番茄题材腔调速查」。

### 起点（付费订阅·男频体系流）
- **简介**：世界观+金手指+主线目标，强调「升级体系」与「格局」。
- **前 3 章**：可稍铺陈，但第 1 章需立住主角处境与金手指雏形。
- **读者预期**：长期追读靠「升级曲线+装逼打脸节奏」，副本要有清晰收益。

### 晋江（女频·情感向）
- **简介**：人设反差+关系张力（如「落魄穷小子 × 体面大小姐」），重情绪钩子。
- **前 3 章**：人设与关系登场 > 事件密度；文笔与「拉扯感」优先。
- **读者预期**：嗑 CP、感情线的细腻与反转，事业线作辅助。

### 知乎盐选 / 盐言（盐选故事）
- **开篇**：一个极抓人的「钩子问题」或反转设定（如「我重生前…」）。
- **结构**：单篇 1–3 万或短连载；认知反转 > 长期铺垫。
- **待吸收**：oh-story 的知乎盐选/小程序投稿层。

### 七猫（免费下沉）
- 类似番茄但更通俗直给，爽点更密集、解释更少。

### 豆瓣 / 出版向
- 文学性与真实感优先，重人物内心与时代细节，慢热可接受。

### 小程序 / 知乎短篇
- 前 100 字定生死，单篇闭环，无冗长铺垫。

## 番茄题材腔调速查（回流自 oh-story 32 张题材卡）

> 来源：`archive/99_原始来源包_小说sill_20260718/oh-story-claudecode-main/oh-story-claudecode-main/skills/story-setup/references/agent-references/genre-prose-cards/`（32 卡完整索引）。下方为 6 张高置信卡精炼，直接对应你两本小说的题材 + 番茄两大品类。
> **用法**：开书前锁定主题材 → 把该卡「开场抓手 / 冲突发动机 / 章尾钩子 / 禁止漂移」四栏抄进细纲；跨题材时主题材取 1 张完整卡，辅题材只摘 1–2 条「常见场面/禁止漂移」。

### 都市脑洞（你《重生千禧》主题材：科技流重生 + 系统）
- **开场抓手**：欠钱 / 退队 / 被嘲 / 求职失败 / 亲戚压力 / 手机消息等低门槛困境切入；金手指先给一次能被现实验证的小结果，不先念说明书。
- **冲突发动机**：现实身份被看轻 + 新规则介入 + 旁人误判；围绕「谁不信 / 谁阻拦 / 谁付账 / 谁被公开打脸」，别让主角一个人看面板自嗨。
- **爽点**：小爽=现实收益到账（钱/形象/技能/关系位）；中爽=围观态度反转；大爽=旧秩序被新规则改写。奖励到账必须有外部反馈。
- **章尾钩子**：新任务 / 新奖励到账 / 手机热搜 / 陌生来电 / 检测结果 / 下一位误判者登场。
- **禁止漂移**：不写纯系统说明书；不连续贴面板；不罗列奖励；不让主角没有主动选择；不为去 AI 硬删「的/了/地/得」致中文别扭。
- **场景颗粒**：手机通知 / 账单 / 合同 / 体检表 / 监控 / 门禁 / 直播间 / 公司群 / 亲戚饭桌。

### 年代（你《重生千禧》副题材：千禧重生）
- **开场抓手**：分家 / 下乡返城 / 随军 / 票据粮食 / 工作名额 / 亲戚欺负 / 旧伤委屈切入；第一场让读者知道主角缺什么（钱/名声/住处/婚姻自主/工作）。
- **冲突发动机**：时代规则 + 家庭人情账 + 主角改命意志；压迫可慢半拍，但每章推一个现实账或关系账。
- **爽点**：当场还回去 / 名声扭转 / 资源到手 / 长辈态度变 / 家庭位置变。爽点符合时代流程，别像现代网暴打脸。
- **章尾钩子**：亲戚上门 / 干部通知 / 婚约变化 / 工作名额 / 票据物证 / 旧人重逢。
- **禁止漂移**：不用现代网感冲掉年代感；不堆物件清单；不让金手指替主角做人情账；不只写极品吵架不推进现实收益。
- **场景颗粒**：粮票 / 布票 / 介绍信 / 搪瓷缸 / 供销社 / 筒子楼 / 家属院 / 缝纫机 / 工作名额 / 亲戚饭桌。

### 青春甜宠（你《难得夫妻》主题材：青梅竹马少年夫妻）
- **开场抓手**：换座位 / 考试排名 / 同学起哄 / 家长电话 / 社团 / 雨天接送 / 校园误会 / 小伤小险切入。
- **冲突发动机**：青春身份限制 + 同龄人围观 + 不敢说破的好感；冲突轻中有钩，甜点短而密。
- **爽点**：公开维护 / 称呼变化 / 消息置顶 / 帮忙补课 / 一起担惩罚 / 误会后低头；关系前进一步就够，不必每章大告白。
- **章尾钩子**：新座位 / 新分组 / 下次考试比赛 / 家长发现 / 同学误会升级 / 未发出的消息。
- **禁止漂移**：不只写脸红心跳；不连续撒糖无外部压力；不成人化油腻；不让校园规则消失。
- **场景颗粒**：课桌距离 / 草稿纸 / 校服外套 / 便利店 / 成绩单 / 班群消息 / 操场 / 社团道具 / 家长电话。

### 都市日常（你《难得夫妻》副题材：婚后日常）
- **开场抓手**：手机消息 / 吃饭接送 / 账单 / 工作班级 / 邻里亲友误会 / 家庭小争执切入；开场可低压，但必须有具体麻烦或期待。
- **冲突发动机**：小问题 + 熟人关系 + 现实成本；每段日常都要产生结果（一顿饭改善关系 / 一笔小钱决定下一步）。
- **爽点**：可见改善（一顿饭吃踏实 / 一笔钱解决 / 一个人愿开口 / 关系缓和 / 机会到手）。释放要细，不靠作者总结「生活真好」。
- **章尾钩子**：一条新消息 / 一个上门的人 / 一个未说出口的请求 / 下次饭约。
- **禁止漂移**：不写吃饭睡觉流水账；不让普通人天天出入顶级场所；不连续几十章无目标变化；不突然变仙侠高武；不用温馨总结代替细节。
- **场景颗粒**：早餐 / 公交地铁 / 外卖 / 账单 / 群聊 / 钥匙 / 菜市场 / 办公室小物 / 店门铃 / 老物件 / 邻里招呼。

### 豪门总裁（番茄女频第一品类）
- **开场抓手**：家庭逼迫 / 婚约契约 / 酒店医院 / 相亲宴会 / 手机热搜 / 公司公开场切入；第一场要有关系压力，别先写豪门陈设。
- **冲突发动机**：亲密需求 + 身份资源不对等 + 信息差；误会要有面子/家族/舆论/合同/旧伤作阻力，不能靠一句解释消失。
- **爽点**：当众维护 / 分寸确认 / 恶意者失算 / 资源转向女主 / 男主从冷到偏爱；写动作和场内反应，少用「安全感拉满」总结。
- **章尾钩子**：身份暴露 / 旧人出现 / 热搜爆料 / 家族电话 / 契约反噬 / 男主公开站队。
- **禁止漂移**：不只堆品牌豪宅；不让霸总成命令机器；不靠「听我解释」消矛盾；不写没女主主动性；不用成人油腻台词替拉扯。
- **场景颗粒**：合同 / 戒指 / 病历 / 热搜 / 家族电话 / 董事会 / 酒店门卡 / 车内空间 / 公开座位 / 转账记录。

### 都市高武（番茄男频大品类）
- **开场抓手**：异常事故 / 天赋检测 / 校园训练场压力 / 家庭负担 / 官方通报 / 职业考试切入；先给危险或等级压迫，再给破局。
- **冲突发动机**：现实身份被看轻 + 超凡等级秩序 + 异常危险；旁人按等级天赋履历误判，主角用能力/信息差/胆识打破。
- **爽点**：能力展示要有见证者/代价/后果（检测记录改写 / 老师官方注意 / 家人处境改善 / 敌人重估）。战斗写策略不只数值碾压。
- **章尾钩子**：新异常预警 / 天赋复测 / 官方征召 / 榜单变化 / 敌方盯上 / 系统检测结果异常。
- **禁止漂移**：不连篇解释力量体系；不写古典宗门玄幻；不只数值提升无现实反馈；不让战斗无空间规则代价。
- **场景颗粒**：检测仪 / 训练馆 / 校服 / 城市警报 / 伤检报告 / 职业证 / 积分榜 / 官方通报 / 家中账单。

**钩子纪律**：① 章首前 100 字必须有钩子（非风景/天气开头）；② 章尾约 100 字显著提升完读率；③ 连续两章不用同一种钩子；④ 日常章不必强钩子，但要有「继续看」的理由；⑤ 禁「下章预告」括号。

### 爽点核心公式（装逼打脸节奏）
- **爽点 = 两个逻辑的冲突点**：大众逻辑（对手不可战胜→恐惧/绝望） × 主角逻辑（正好手痒/轻描淡写），落差越大越爽。
- **看点 = 吊起期待；爽点 = 满足期待**，一一对应：前面铺垫多少，后面爽点就有多少。
- **三要素**：吃瓜群众用议论吹高对手逼格→震惊完成打脸；对手嚣张到让读者恨→被打脸才爽；主角铺垫时低调→释放时干脆。
- **装逼打脸节奏（公众期 5 章循环）**：人设 1 章 → 铺垫 2 章 → 打脸 1 章 → 善后 1 章。前置小无敌（打脸前备好道具/实力），铺垫比打脸重要——铺垫到位主角站着不说话都能装逼。

## 一书多平台策略（摘自 SKILL §17.3）
- 注意独家限制：签约平台常要求独家，错峰分发需「形态改造」而非原样搬运。
- 改造维度：章节奏、简介、开篇前 300 字、是否保留「下章预告」式钩子。
- 先定平台再定题材，比「写完再投」成功率高。
