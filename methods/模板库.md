# 模板库 · 网文创作可直接套用表单

> 配合《小说创作助手》SKILL.md 使用。
> 用法：开新书时，把下面任一模板复制进 `你的书名/` 目录，按提示填空即可。
> 所有模板结构均已对齐标准项目结构，保证一致、可直接续写。你之前两本在写小说《难得夫妻是少年》《重生千禧》已于 2026-07-19 删除，结构可从 git 历史 `437837a^` 取回。

## 0. 标准项目文件结构（先建这个）

```
你的书名/
├── 框架.md              # 全书核心纲：立意/设定/人设/感情线或事业线/分卷/钩子
├── 写作进度.md           # 进度日志（每完成一步更新，AI 断点续写靠它）
├── 人物设定卡.md         # 主角+核心配角+反派的完整卡
├── 伏笔管理表.md         # 长线/中线/短线伏笔的埋设与回收追踪
├── 分卷细纲.md           # 各卷分幕与关键章蓝图（可拆成 第一卷细纲.md…）
├── 设定集.md             # 选填：世界观/势力/科技树/历法/货币等（玄幻科幻系统文必备）
├── 模板库.md             # 本文件，留作参考（也可不放进项目）
└── 正文/
    ├── 第001章_xxx.md
    ├── 第002章_xxx.md
    └── ...
```

> 女频/男频通用；体量小的书可把「分卷细纲」合并进「框架.md」的第六节。

## 6. 每章自检清单（去 AI 味 + 五要素）

写完一章，逐项过：

- [ ] **推进**：本章有推进剧情吗？（不是铺垫没爆发）
- [ ] **钩子**：章末有钩子吗？（引出下一章）
- [ ] **主角能动**：主角主动行动，不是被剧情推着走？
- [ ] **人设稳**：人物行为符合设定卡？没 OOC？
- [ ] **视角集中**：一章一个主视角，没乱切？
- [ ] **去 AI 味·五感**：每个场景≥3 处五感（视/听/触/嗅/味）？
- [ ] **去 AI 味·动作**：用"他攥紧拳头"代替"他很愤怒"？
- [ ] **去 AI 味·对话**：角色一张口知道是谁？无"综上所述/值得一提的是"？
- [ ] **去 AI 味·生活碎片**：有吃饭/发呆/吐槽等非主线细节落地？
- [ ] **去 AI 味·情绪**：人物有起伏，不是设定执行机器？
- [ ] **段落**：每段≤3 行？
- [ ] **禁词扫描**：无"不禁让人""仿佛""似乎在诉说""一股……之感"等套话？（见 §十五 禁词清单）
