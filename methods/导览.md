# 导览 · 通用小说创作流程（方法论子地图）

> ↩ **回总地图**：[🗺️ 知识库总地图](../README.md)（本页是子地图，统一从前门进入）

> **这是「小说创作方法论」区的结构总入口。** 这套方法论库是一套从 50 份作家方法论 + 外部写作 Skill + 在线资料，**蒸馏成你自己可直接照做**的网文创作系统，服务于你用这套方法论写小说——具体书放在 `../projects/` 下。
> 本文件是**结构清晰总入口**：先在这建立全局认知 → 再用 `INDEX.md`（精确检索表）找文件 → 卡住时翻 `QUICK_START.md`（症状→武器）。

## 三、怎么用：两条主线 + 一张速查表

### A. 按写作流程走（开书→投稿标准动作）

| 环节 | 打开这些 | 工具 |
|---|---|---|
| ① 开书筹备 | `网文写作最强SOP.md` + `模板库.md` | — |
| ② 大纲 | `../knowledge/craft/大纲工程.md` + `../knowledge/craft/结构学.md` | 模板库·细纲表 |
| ③ 写稿 | `../knowledge/craft/章法与钩子学.md` + `爽点与情绪曲线.md` + `描写与对话学.md` + `人物学.md` | 模板库·章纲表 |
| ④ 改稿 | `../knowledge/craft/改稿与拆文工序.md` + `最强去AI味铁律.md` + `改稿润色指令库.md` | — |
| ⑤ 投稿前 | `平台差异手册.md` + `模板库.md §9 多平台投稿自查` + 对应 `../knowledge/platforms/` 篇 | — |
| ⑥ 卡文急救 / 副线散 / 人物没弧光 / 数据掉了 | `../knowledge/craft/卡文急救.md` · `副线设计.md` · `人物弧光.md` · `数据化复盘.md`（4 个独立速查包） | — |
| ⑦ 每章质检 | `../tools/scripts/writing/chapter_selfcheck.py` + `自检清单_升级版.md` | 字数/AI味/钩子扫描 |

### B. 按你的具体书走（projects/ 项目区）

具体书放在 `../projects/` 下，每本用统一合规骨架（README/STATUS/framework/outline + chapters/ + entities/）。
- 当前无活跃项目。
- 写某本书时，从这里挑题材/平台武器，再进 `../projects/你的书/` 落正文。

### C. 按场景速查（更多症状见 `QUICK_START.md`）

| 你现在的症状 | 直接打开 |
|---|---|
| 前 3 章没钩子 / 编辑说"切入点不足" | `平台差异手册.md`·章末钩子13式 + `../knowledge/craft/章法与钩子学.md` |
| 正文有 AI 腔 / 被拒因"AI味" | `最强去AI味铁律.md` → `改稿润色指令库.md` |
| 爽点不够 / 节奏平 | `../knowledge/craft/爽点与情绪曲线.md` |
| 人物扁平 / 台词没性格 | `人物思维蒸馏法.md` + `模板库.md` 人物卡 |
| 卡文 / 不知断点在哪 | `../knowledge/craft/大纲工程.md` 卡文急救 |
| 投某平台拿不准红线 | `../knowledge/platforms/` 对应篇 + `平台差异手册.md` |
