# 自检清单_升级版（最强版）

> 定位：每次写完一章、每批补纲前、进入日更前、大修前都可复用；按“先硬性、再情绪、再AI味、再项目纪律”的顺序检查。

## 一、细纲与章节结构检查

- [ ] 本章有细纲文件，且细纲字段完整；缺字段先补字段，再写正文
- [ ] 本章阶段位置明确：开篇期 / 发展期 / 高潮期 / 收尾期
- [ ] 本章在阶段内承担的功能明确：高压推进 / 关系回收 / 信息整理 / 低压过场
- [ ] 章节定位和爽点密度匹配，高压章不写成过场，过场章不硬塞爽点
- [ ] 章首钩子存在，且不是从天气/风景/解释世界规则开始
- [ ] 章尾有往下看的理由：新问题、新压力、新期待、新后果，四者至少占其一
- [ ] 本章没有提前释放后卷真相、终局底牌、未解锁关系结论、终局矛盾
- [ ] 相邻章情绪不趋同；连续两章都是高压时，中间至少有压强变化

## 二、主角与契约检查

- [ ] 本章主角目标明确，且读者能看出他想要什么
- [ ] 本章主角作出至少一个关键选择或关键判断
- [ ] 主角拥有因果权：事件怎么进入、怎么转向，由主角决定，或由主角获取关键信息后决定
- [ ] 主角拥有结算权：核心收益、认可、权力、真相回到主角或给出可见交换
- [ ] 没有让配角、机构、偶然性无声拿走已经承诺给主角的高光或收益
- [ ] 打脸/揭露/装逼章写了在场配角的差异化反应

## 三、情绪与爽点检查

- [ ] 本章目标情绪具体，不是“热血/悲伤/爽”这种标签
- [ ] 爽点出手前有可指认的铺垫段落：危机、期待、信息差、憋屈感至少存在其一
- [ ] 低压/过场章也给了读者一个继续看的理由，而不是“什么都没发生”
- [ ] 情绪切换自然，不会连续三段都是同一种激烈情绪
- [ ] 如果本章是情绪高点，结尾没有立刻泄掉；如果是低压章，结尾没有硬拔高
- [ ] 对白推进剧情、暴露判断、改变关系，没有为了凑字数而存在的聊天

## 四、去 AI 味检查

- [ ] 没有“综上所述、值得注意的是、毫无疑问、归根结底、诚然”
- [ ] 没有“这不仅仅……而是……”这类二元对比骨架
- [ ] 没有无源权威铺垫，或已知来源已补全
- [ ] 没有表演性动宾堆砌：“实现了、推动了、促进了、彰显了”
- [ ] 没有空泛结论句：“方向是对的、意义重大、核心价值在于”
- [ ] 没有机械三段式排比；若必须列举，优先两项或四项
- [ ] 没有破折号滥用；一个自然段内破折号不超过 1 处
- [ ] 没有连续三句长度、结构几乎一致
- [ ] 正文不出现“第X章、上章、前文、后文、伏笔、细纲、读者”
- [ ] 具体字数表达只在统计明确、核对无误、故事必须时使用

## 五、人物与细节检查

- [ ] 高压场景不会突然让搞笑担当负责解说核心信息
- [ ] 情绪型角色没有突然变成冷静分析型角色
- [ ] 配角不会连续三次用同一句口头禅或同一类反应
- [ ] 关键事件有可见代价：时间、金钱、关系、身份、秘密暴露、后续追责
- [ ] 人物反应符合他当前的决策顺序和表达风格
- [ ] 人物档案、伏笔、时间线、角色状态与本章结果一致

## 六、字数与结构检查

- [ ] 高速推进章 ≥ 2000 字；正常节奏 / 舒缓铺垫 / 高潮爆发 ≥ 3000 字；细纲另有要求时以细纲为准
- [ ] 字数低于目标 90% 时，先补细纲内容，不自造新主线、新角色、新反转
- [ ] 字数高于目标 110% 时，先压过场、合并疏点，不删主线爽点
- [ ] 章节预算合计落在目标区间，疏点和密点比例合理
- [ ] 本章文件已写入正文目录，且文件大小正常

## 七、日更 / 批量写作检查

- [ ] 日更时只读取本批必需材料，不把全部设定都塞进本轮上下文
- [ ] 同一批次内，章节号连续，细纲存在，伏笔状态已更新
- [ ] 每 3 章做一次进度快照：最近 3 章文件已写入，上下文索引已更新
- [ ] 单轮最多 3 章，用户未给数量时默认只写 1 章

## 八、大修检查

- [ ] 先判断是改纲还是改章；契约破坏、期待债错误、爽点结构失准时，优先改纲
- [ ] 回炉章不新增未经用户确认的支线、金手指上限、新关系结论
- [ ] 修完后重新做全章自检，不能只修前半段
