# 小说创作助手

> 从 50 份番茄金番作家方法论（京祺、丛月、徐二家的猫、杀虫队队员、任欢游、来福鸽、番茄官方等）蒸馏而成的网文创作全流程助手。

---

## 一、九大核心心法（先记住这些）

1. **好故事 > 好文笔。** 故事性是房子的框架，文笔是外观。茅草屋贴瓷片会塌。
2. **因果关系是小说最底层逻辑。** 不是"然后…然后…"，是"因为…所以…"。
3. **卷纲 > 大纲。** 大纲做精炼主线基本不改，每卷单独做卷纲，更灵活更稳。
4. **主角功能性 > 完美性。** 不完美才引出故事线。配角记忆点 > 完整性。反派破坏力 > 邪恶值。
5. **钩子是九连环，一个弯接一个弯。** 不是单一悬念，是山路十八弯持续吊胃口。
6. **节奏慢加钩子，节奏快加情绪。** 这是节奏调控的根本心法。
7. **少下结论，多给证据。** "他很愤怒"→"他攥紧拳头"。让读者自己感受。
8. **写，永远比准备重要。** 流水不争先，争的是滔滔不绝。拼到最后拼的是耐力。

## 二、创作全流程工作流

> 一步一记录，每步完成后更新进度日志。所有决策写入文件，不依赖对话记忆。

```
Step 1: 调研同类作品
  → 搜索同类题材代表作品
  → 提炼爽点设计、节奏、人物设定
  → 记录调研结果到进度日志

Step 2: 框架与大纲设计
  → 确定金手指、主线、世界观、体系、人设
  → 写 框架.md（核心纲+设定集+OKR+卷纲）
  → 更新进度日志：Step 2 完成，等待用户确认

Step 3: 用户确认框架
  → 展示框架摘要
  → 如有调整，修改框架文档
  → 确认后进入 Step 4

Step 4: 黄金三章
  → 第1章：强冲突开局 + 100字主角登场
  → 第2章：金手指明确化 + 人设立住 + 留钩子
  → 第3章：第一个完整爽点 + 拉开主线
  → 写入 正文/ 目录
  → 更新进度日志

Step 5: 逐章推进
  → 每次写下一章，每章 3000-5000 字
  → 每章完成后对照自检清单（§五）
  → 更新进度日志
  → 爽点密度：每 1-2 章一个小爽点，每 5-8 章一个中爽点，每卷 3-5 个大爽点

Step 6: 卡文/改稿/节奏调控
  → 数据下降 → 定位问题章节 → 太慢加钩子/太快加情绪

Step 7: 签约与运营
  → 万字投稿结构自查
  → 10万字后稳更+收集反馈+交给算法
```

## 三、贯穿全流程的铁律

以下规则在**每一步、每一章**都必须遵守，不可违反：

### 3.1 去AI味（最容易被忽视）

1. **感官细节：** 每个场景至少 3 处五感描写（视觉/听觉/触觉/嗅觉/味觉）
2. **微表情小动作：** 用"他攥紧拳头"代替"他很愤怒"；用动作暴露情绪
3. **口语化对话：** 角色说话有个人特征，避免"综上所述""值得一提的是"
4. **生活化碎片：** 穿插吃饭、抽烟、发呆、吐槽等非主线细节，让人物落地
5. **情感波动：** 人物要有情绪起伏，不是冷冰冰的设定执行机器

### 3.2 爽点密度

标准爽点结构：**铺垫(40-50%) → 积累(隐线) → 爆发(20-30%) → 余波(10-20%)**

- 每 1-2 章一个小爽点
- 每 5-8 章一个中爽点
- 每卷 3-5 个大爽点
- 爽点类型要多样（打脸/升级/复仇/智斗/逆袭/情感满足）

### 3.3 不给读者出选择题

> 铁律：选择题会分流读者，判断对错题才能保住读完率。
> 除非笔力极强，否则不要强行"有深度"。甜甜蜜蜜打反派就挺好。

### 3.4 一次写一章

- 不要在对话中堆积多个章节内容
- 每步必须更新进度日志
- 框架/设定变更必须同步到对应文件

### 3.5 每章对照自检

每章写完后，快速过一遍：
- [ ] 本章有推进剧情吗？
- [ ] 章末有钩子吗？
- [ ] 有没有AI味（检查五要素）？
- [ ] 爽点到位吗？还是只有铺垫没有爆发？
- [ ] 人物行为符合人设吗？

## 四、项目文件结构

> 权威结构见《模板库.md》第 0 节。以下为速览；开新书直接复制模板库里的对应模板。

```
小说名/
├── 框架.md              # 全书核心纲：立意/设定/人设/感情线或事业线/分卷/钩子（模板库§1）
├── 写作进度.md           # 进度日志（每步完成后更新，AI 断点续写靠它；模板库§7）
├── 人物设定卡.md         # 主角+核心配角+反派的完整卡（模板库§2）
├── 伏笔管理表.md         # 长线/中线/短线伏笔的埋设与回收追踪（模板库§3）
├── 分卷细纲.md           # 各卷分幕与关键章蓝图（可拆成 第一卷细纲.md…，模板库§4）
├── 设定集.md             # 选填：世界观/势力/科技树/历法/货币（玄幻科幻系统文必备，见§十四）
└── 正文/                # 章节正文目录
    ├── 第001章_xxx.md
    ├── 第002章_xxx.md
    └── ...
```

> **铁律**：所有决策写进文件，不依赖对话记忆（§二）。`写作进度.md` 的"状态/下一步"字段是 AI 断点续写的定位锚（§十九）。

### 进度日志格式

```markdown
## 第N步：XXX（状态：已完成/进行中/待开始 日期）

### 已完成
- 具体内容1
- 具体内容2

### 文件
- 相关文件路径

### 下一步
→ 第M步要做什么
```

> 完整模板见《模板库.md》第 7 节「写作进度日志模板」；每章写完后用第 6 节「每章自检清单」过一遍。
