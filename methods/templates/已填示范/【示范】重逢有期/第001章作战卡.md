# 单章作战卡 · 第 001 章《汇报会上的新甲方》（状态：☑ 已过自检）

## 1. 章首 300 字强冲突（禁慢热）
- 开头方式：☑ 动作　☑ 对话（顾延舟推门进场 + "沈设计师，开始吧"）

- 出场人物：沈念 / 顾延舟 / 老周 / 林薇（4 人，首章 ≤ 4 ✓）
- 阶段位置：☑ 开篇期

## 7. 去 AI 味四查
- [x] **五感**：视觉（银表带/牙印/白得晃眼的日头）/ 听觉（钢笔磕桌面/皮鞋声）/ 触觉（指尖发凉/卷边掐指缝）/ 嗅觉（橙花味—第002章）—— 4 处
- [x] **动作代形容词**："指节抵了一下下巴""把图抽回来，卷边掐在指缝里"——无"带着一丝"
- [x] **口语对话**："顾总记性真好""旧相识"——无"综上所述/值得一提的是"
- [x] **生活碎片**：出租车/屏保是中标方案/通讯录存"甲方顾总"——有落地
- [x] **视角**：锁死沈念限知，不跳顾延舟内心
- [x] **禁词扫描**：0 命中（无"不是A而是B/仿佛/眼中闪过一丝/命运棋局"）
