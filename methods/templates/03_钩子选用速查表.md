# 章末钩子速查（13 式 + 五类强钩 + 纪律）

## 一、13 式钩子（对症"爽点 / 看点不足"）
| # | 类型 | 公式 | 适配题材 |
|----|------|------|---------|
| 1 | 突然揭示 | 抛出改变全局的信息 | 全题材 |
| 2 | 紧急危机 | 下章必须回应的紧迫威胁 | 脑洞 / 高武 / 悬疑 |
| 3 | 未完成动作 | 动作被新变量打断 | 全题材 |
| 4 | 身份反转 | 身份真相偏离预期 | 总裁 / 悬疑 |
| 5 | 两难抉择 | 被迫在两个坏选项选一 | 总裁 / 日常 |
| 6 | 神秘物品 | 重要但含义未知的物件 | 脑洞 / 高武 |
| 7 | 倒计时 | 时间不够用 | 高武 / 脑洞 |
| 8 | 承诺 / 威胁 | 有人宣布行动意图 | 总裁 / 脑洞 |
| 9 | 离奇消失 | 不可能的消失 | 悬疑 / 灵异 |
| 10 | 隐藏含义 | 表面正常暗藏信息 | 甜宠 / 日常 |
| 11 | 意象钩子 | 反复意象发生变化 | 日常 / 甜宠 |
| 12 | 回声钩子 | 章尾呼应开头、关键细节变了 | 情感向 |
| 13 | 留白钩子 | 只展示反应，不揭示发生了什么 | 全题材（最稳） |

> **五类强钩（八成以上章节用这三类）**：危机降临 / 打脸预示 / 信息炸弹。男频多用信息炸弹 + 危机降临；女频多用关系破裂 / 认知反转 / 决策时刻（见 [../模板库\_三套可套用表单.md](../模板库_三套可套用表单.md) 钩子范式）。

## 二、钩子纪律（五条）
1. 章首前 100 字必须有钩子（非风景 / 天气开头）。
2. 章尾约 100 字显著提升完读率——收在**具体事件 / 动作 / 不可逆后果**上。
3. 连续两章不用同一种钩子（轮换 13 式编号）。
4. 日常章不必强钩子，但要有"继续看"的理由（小悬念 / 小期待）。
5. **禁"下章预告"括号**：不写"他不知道的是…""下章将…"——用具体钩子物件 / 事件收束。
