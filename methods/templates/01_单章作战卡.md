## 3. 爽点闭环（期待 → 满足，前 3 章必须有 ≥ 1 个）

> **爽点公式**：爽点 = 两个逻辑的冲突点——大众逻辑（对手不可战胜 → 恐惧 / 绝望）× 主角逻辑（正好手痒 / 轻描淡写），落差越大越爽。看点 = 吊期待，爽点 = 满足期待——前面铺垫多少，后面爽多少。三要素：吃瓜群众吹高对手逼格 → 震惊完成打脸；对手嚣张到让读者恨 → 被打脸才爽；主角铺垫时低调 → 释放时干脆。

## 7. 去 AI 味四查（每章必过）
- [ ] **五感**：本章每个场景 ≥ 3 处（视 / 听 / 触 / 嗅 / 味）____ 处
- [ ] **动作代形容词**："他攥紧拳头"代替"他很愤怒"；无"带着一丝…""眼中闪过一丝…"
- [ ] **口语对话**：角色一张口知是谁；无"综上所述 / 值得一提的是 / 毋庸置疑"
- [ ] **生活碎片**：有吃饭 / 发呆 / 吐槽等非主线落地细节
- [ ] **视角**：锁死深度限知，作者不跳出来解释 / 剧透 / 定性（模式 8 解释腔，最难查）
- [ ] **禁词扫描**：无"不是 A 而是 B""仿佛""似乎在诉说""一股…之感""命运…棋局"（见 [04\_去AI味改写练习表.md](04_去AI味改写练习表.md) 最毒句式表）
