# 连载专项体检卡 ·《____》（单页克隆卡）

> 原则：**别凭感觉改，让数据指路**。看曲线下滑→从上一章看起（毒点常在前一章埋下）→改完多等一周再看，不刚改一天下结论。

## 一、什么时候用本卡
- □ 已有 ≥ 1 万字后台数据　□ 完读率/追读率出现异常下滑　□ 段评集中吐槽某角色/某章
- □ 准备大修前定位"改哪章"　□ 每周例行复盘

## 二、节奏体检（追读/完读定位）
| 数据现象 | 病因判断 | 处置（对齐 §10.4） |
|----------|----------|----------------related:
  - methods/模板库.md
  - methods/网文写作最强SOP.md
---|
| 完读率掉、章末跳出高 | 章末钩子弱 | 重写入尾（信息炸弹/危机/反转） |
| 追读率掉但完读稳 | 节奏太快 | 插心理/环境/生理反应撑开 |
| 某章完读骤降 | 该章太慢/水/毒点 | 从上一章看起，加钩子/砍剧情/删毒点 |
| 十几章一个小剧情且非主线 | 节奏太慢 | 加钩子 + 砍无关男女主剧情 |

量化判断：快=一章一个剧情；慢(问题)=十几章写一个小剧情且非主线。

## 三、毒点扫描（段评高频词→定位）
- 高频词映射：
  - "尬/毒/水/喂玻璃渣" → 定位该章，能改则改，明显毒点直接删
  - "人设崩/OOC" → 查人物卡，回 ð 人设一致性（见 [05\_人设行为对照卡.md](05_人设行为对照卡.md)）
  - "虐无逻辑/BE 无预警" → 女频情感线核查（补铺垫）
  - "降智/无敌无对手" → 男频反派/金手指核查（加阻力）
- 多人提出同一问题 → 必须修改有问题章节；孤例可观察。

## 四、追读体检（收藏/推荐票/章末跳出）
- [ ] 收藏/推荐票涨不动 → 人设记忆点/主线钩子不足，回炉 §8/§9
- [ ] 章末跳出高 → 章尾非强钩（重写入尾，禁"下章预告"）
- [ ] 追读率持续下滑 → 节奏/钩子结构出问题，跑 §二定位

## 五、改稿优先级决策
1. **先看反馈 → 自我思考 → 自我总结 → 结论**（不盲从数据）
2. 改稿范围：单章 / 三五章 / 十章以上（通读总结：故事不精彩？写得有问题？人设没立住？）
3. 朗读修改：卡顿处要么语句太长、要么形容词不合适
4. 避免越改越乱：大改紧贴大纲骨架，把每章落点落在骨架上；逻辑统一（改前提炼核心信息/伏笔/设定，改后填回）
5. **驾驭不了后续就别改**

## 六、周复盘联动
填 [../模板库.md](../模板库.md) §8「数据复盘周表」：
- 指标快照（完读/追读/章末跳出/收藏/段评）
- 下滑章节定位表（章节→病因→处置）
- 读者反馈闭环（好评点/毒点/下周调整）
- A/B 与实验记录（多版开头/专属读者测试→结论）
