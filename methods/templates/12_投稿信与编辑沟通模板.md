# 投稿信与编辑沟通模板 ·《____》

> 铁律：**一稿一投**（同一平台不同编辑可并行；不同平台/大赛不可一稿多投）；投稿前先跑 `02_前3章签约体检表`，任一否决项命中先改再投。

## 1. 投稿信黄金结构（5 段，编辑 30 秒看完）
| 段 | 写什么 | 反面（别写） |
|----|----|----|
| ① 一句话卖点 | 类型 + 核心梗 + 爽点落点，如"男频鉴宝·神瞳打脸专家 + 捡漏暴富" | "这是一部关于……的深刻小说" |
| ② 数据亮点 | 已写 __ 字 / 前3章体检 __ 分 / 完读率 __（有就写，没就空） | 编造数据 |
| ③ 题材契合 | 点名平台 + 征文，如"番茄·都市脑洞，对齐平台腔调手册" | 投错赛道还说"都行" |
| ④ 正文进度 | 已更 __ 章 / __ 字，存稿 __，日更 __ | 只给大纲不给正文 |
| ⑤ 编辑钩子 | 抛一个前3章最强钩子/反差，引编辑点开 | "望垂阅""恳请指正"套话 |

## 2. 分平台投稿信差异
- **番茄**：首投 1–2 万字，重"开篇切入点 + 爽点密度"，投稿信突出"前 300 字出事 + 即时打脸"。
- **起点**：重"概念感书名 + 长线格局"，投稿信突出"金手指设定 + 分卷爽点承诺闭环"。
- **晋江**：重"人设 / 关系锚"，投稿信突出"CP 变量 + 情绪引擎"。
- **盐言 / 小程序**：重"完读率"，投稿信突出"前 3 屏钩子 + 反转密度"。
