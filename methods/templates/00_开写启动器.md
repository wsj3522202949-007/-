# 🚀 开写启动器（每次写作前 5–10 分钟）

## A. 今日目标（先定，再写）

- [ ] 本次写 \_\_\_\_ 章（章号：第 \_\_\_\_ 章《\_\_\_\_》）
- [ ] 任务类型：□ 开新章　□ 续写　□ 补细纲　□ 大修
- [ ] 目标字数：\_\_\_\_（建议 2600–3400；短篇按平台另计）
- [ ] 今天 \_\_\_\_ 前完成

## B. 取卡填空（30 秒）

- [ ] 已复制 [01\_单章作战卡.md](01_单章作战卡.md) 到本章，填了：章首冲突 / 爽点闭环 / 章末钩子 / 去 AI 味四查
- [ ] 若写**前 3 章**：额外跑 [02\_前3章签约体检表.md](02_前3章签约体检表.md)

## C. 三不写（开始前自检，命中任一条先补，别硬写）

- [ ] 章首 300 字内**有强冲突 / 动作 / 对话**？（非风景 / 天气 / 重生发呆 / 大段回忆慢热）
- [ ] 本章**有一个"期待 → 满足"爽点闭环**？（男频 = 信息差降维打脸 + 变现；女频 = 感情拉扯入场）
- [ ] 章末**有强钩子（五类之一）**，没写"下章预告"括号？

## D. 写中纪律（贴屏幕）

1. 段落 ≤ 3 行（手机阅读）；番茄高分样本段落中位约 **23.5 字**。
2. 每个场景 ≥ 3 处五感；用动作代形容词；台词一张口知是谁。
3. 锁死**深度限知视角**——镜头钉在主角身体里，作者不跳出来讲（最难查的 AI 味 = 解释腔 / 上帝视角 / 安排感）。
4. 破折号 / 省略号节制；不凑三连排比；不为去 AI 而删光"地 / 得 / 很 / 像 / 省略号"（番茄样本这些大量存在，删光反成另一种模板）。

## E. 交稿前（写完跑）

- [ ] 过 [../自检清单\_升级版.md](../自检清单_升级版.md) 一遍
- [ ] 跑 `python ../../tools/scripts/writing/chapter_selfcheck.py 你的书名/正文/` → 字数 2600–3400 / AI 味 干净或轻度 / 章末钩子命中
- [ ] 伏笔状态更新（埋 / 收同步进伏笔管理表）
- [ ] 写作进度.md 记一笔（AI 断点续写靠它）

> 新人最省事路径：**A 定章 → B 取卡 → C 三不写 → 写 → E 自检**。卡住回 [../QUICK\_START.md](../QUICK_START.md)。
