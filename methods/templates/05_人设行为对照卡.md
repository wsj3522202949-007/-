# 人设行为对照卡（防 OOC）

> 用法：每本新书建一张总表（下栏），再给每个关键角色填一张角色卡。写每章前看一眼"OOC 红线"，写完在 §3 打勾。

## 一、角色卡模板（每人一张，复制填写）
### 【角色】____（主角 / 配角 / 反派）
- 核心欲望（他要什么）：____
- 深层错信 Lie（故事要拆穿的歪理）：____
- 口头禅 / 说话特征：____（一张口知是谁）
- 习惯动作 / 微表情：____
- 底线（绝不跨）/ 软肋：____
- 决策顺序（遇事先保谁 / 先算什么）：____
- **OOC 红线**（写了就崩的 3 条）：
  1. ____（如：绝不主动解释动机）
  2. ____（如：对长辈永远嘴硬心软）
  3. ____（如：不轻易信人，被骗一次记三年）

## 三、每章行为自检（写后勾）
- [ ] 主角本章程行为未跨 OOC 红线？　□ 是　□ 否（哪条：____）
- [ ] 配角没连续三次用同一口头禅 / 同一类反应？　□ 是　□ 否
- [ ] 高压场景没让搞笑担当负责解说核心信息？　□ 是　□ 否
- [ ] 情绪型角色没突然变冷静分析型？　□ 是　□ 否
- [ ] 人物反应符合其当前决策顺序与表达风格？　□ 是　□ 否
- [ ] 关键事件有可见代价（时间 / 金钱 / 关系 / 身份 / 秘密）？　□ 是　□ 否

> 反派自洽：他为自己活，不是为帮 / 害主角；写清"为什么觉得自己对"。退不了的理由（沉没成本 / 被胁迫 / 失去一切）要给足，否则反派像工具人。
