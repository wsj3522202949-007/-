# 去 AI 味改写练习表（原句 → 改后）

## 一、最毒句式速查（命中即修，最高优先级）
| 毒级 | 句式 | 错误例 |
|------|------|--------|
| ★★★★★ | "不是 A，（而）是 B" / "不是 A，不是 B，（而）是 C" | "他不是冷漠，而是绝望" |
| ★★★★ | "，带着……" 万能状语 | "他笑了一下，带着一丝不易察觉的嘲讽" |
| ★★★★ | 无情绪声线："声音不大，却带着……" / "语气毫无波澜" | "她声音不大，却带着不容置疑的力量" |
| ★★★★ | "他 / 她知道……" | "他知道这一切都来不及了" |
| ★★★ | "仿佛 / 犹如 / 宛若……一般" | "仿佛能穿透一切一般" |
| ★★★ | "眼中闪过一丝……" / "嘴角勾起一抹……" | "眼中闪过一丝悲伤" |
| ★★★ | "心中涌起一股……" / "心头一震" | "心中涌起一股暖流" |
| ★★★ | 抽象命运 / 开端收束："命运…棋局 / 獠牙" / "这一刻终于明白" / "反击才刚刚开始" | "命运终于露出獠牙；属于他的反击才刚刚开始" |
| ★★ | 章末预告"他不知道的是……" | "他不知道的是，更大的风暴即将来临" |

> ★★★★★ 命中一处 = 重度 AI 味强证据；★★★★ 命中 ≥ 2 处 = 触发中度复扫。

## 三、最难查的 AI 味（模式 8·解释腔 / 上帝视角 / 安排感）
每句问——这是"角色在经历"，还是"作者在讲解 / 安排"？凡作者跳出来讲，删或改回角色视角内呈现：
- 解释因果「之所以…是因为」「这意味着」→ 删，因果只从动作 / 对话 / 反应让读者自己拼。
- 上帝视角剧透「她不知道的是」「殊不知」「多年以后」「冥冥之中」→ 删，只写角色此刻知道的。
- 替读者定性「演得真好」「他就是这样薄情的人」→ 删，把证据摆出来，定性留给读者。
- 升华式收尾「命运终于露出獠牙」→ 用一个动作或一句留白收住。

> **反投机边界**：不要为去 AI 而删光"地 / 得 / 很 / 像 / 好像 / 仿佛 / 如同 / 省略号 / 顿号"——番茄高分样本（305 章）里这些全都大量存在。根治 = 锁死深度限知视角，镜头钉在角色身体里。
