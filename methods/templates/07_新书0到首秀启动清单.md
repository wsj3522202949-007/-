> **适用场景**：决定开一本新书到拿出可投前 3 章，按本清单顺序填空，约 30 分钟出可写框架。本文件不重复各模板内容，只告诉你"先填哪个、填完干嘛"。
> **关联文件**：[../模板库.md](../模板库.md)（§0–§12 通用表单）· [../模板库\_三套可套用表单.md](../模板库_三套可套用表单.md)（按题材落地骨架）· [00\_开写启动器.md](00_开写启动器.md) · [02\_前3章签约体检表.md](02_前3章签约体检表.md)

# 新书 0 → 首秀启动清单（顺序填空，约 30 分钟）

## 阶段 0：定盘（5 分钟）
- [ ] 类型 / 平台目标：____（番茄保底 / 起点签约 / 晋江申签 / 盐言…）
- [ ] 一句话立意：____（能安利给朋友的一句话）
- [ ] 选落地骨架：□ 男频重生 → 填 [../模板库\_三套可套用表单.md](../模板库_三套可套用表单.md) 一套；□ 女频少年夫妻 → 二套；□ 短篇盐言 → 三套；□ 其他 → 用 [../模板库.md](../模板库.md) §1 框架通用模板

## 阶段 1：建框架（8 分钟）
- [ ] 复制 [../模板库.md](../模板库.md) §1《框架.md》到 `你的书名/`，填：立意 / 核心设定 / 人物一览 / 主线地图 / 分卷 / 钩子表 / 开篇设计
- [ ] 平台对齐：填 [../模板库.md](../模板库.md) §9 多平台投稿自查的"平台适配检查"表

## 阶段 2：立人设（7 分钟）
- [ ] 复制 [../模板库.md](../模板库.md) §2 人物卡，主角 + 头号反派 + 1 关键配角先填
- [ ] 同步提炼 [05\_人设行为对照卡.md](05_人设行为对照卡.md) 的 OOC 红线（防后面崩）

## 阶段 3：埋伏笔 + 分卷（5 分钟）
- [ ] 复制 [../模板库.md](../模板库.md) §3 伏笔管理表，先登记 3 条长线 + 本卷中线
- [ ] 复制 [../模板库.md](../模板库.md) §4 分卷细纲，填第一卷分幕 + 关键节点

## 阶段 4：写前 3 章细纲（5 分钟）
- [ ] 对第 001–003 章，各复制一张 [01\_单章作战卡.md](01_单章作战卡.md)，填：章首冲突 / 爽点闭环 / 章末钩子 / 去 AI 味四查
- [ ] 钩子选型参考 [03\_钩子选用速查表.md](03_钩子选用速查表.md)，相邻章不重复

## 阶段 5：开写 + 体检（循环）
- [ ] 每章写完跑 [00\_开写启动器.md](00_开写启动器.md) 的 E 交稿前清单
- [ ] 前 3 章全写完，跑 [02\_前3章签约体检表.md](02_前3章签约体检表.md) → 无否决项再投
- [ ] 投稿前：填 [../模板库.md](../模板库.md) §9 投稿材料勾选 + 简介（§10 黄金五结构）

> 之后每章日常循环：开写前 [00\_开写启动器.md](00_开写启动器.md) → 写 → 自检。日更多章用 [06\_日更批次推进卡.md](06_日更批次推进卡.md)。
