## 与 SKILL.md 的关系
- **`SKILL.md`** = 核心心法与铁律（心法/工作流/铁律/项目结构）。遇到「为什么这么做」去查它。
- **本文件 / `INDEX.md`** = 导航层。遇到「我现在该用哪份文件」来查这里。

## 日常最小循环
1. 开写前：`templates/00_开写启动器.md`（5–10 分钟定章取卡）→ 需要建结构再翻 `模板库.md` / `模板库_三套可套用表单.md`。
2. 写章中：卡住就回上表；每章完跑 `自检清单_升级版.md` + `最强去AI味铁律.md`。
3. 前3章完：跑 `templates/02_前3章签约体检表.md`（实测 59/60）。
4. 投稿前：`模板库.md §9 多平台投稿自查` + `templates/12_投稿信与编辑沟通模板.md`。
5. 签约后：`templates/13_追读数据监控表.md` + `templates/14_改稿优先级批次表.md`。
