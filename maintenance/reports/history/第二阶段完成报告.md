**解决方案**：
- 宪法规定：确认9目录结构

**解决方案**：
- 宪法规定：明确三目录职责
- knowledge/ → 理论知识库
- methods/ → 方法论武器库
- ai/ → AI协作系统

## 五、宪法核心内容摘要

### 5.1 项目结构标准
```
projects/作品名/
├── README.md                 # 项目门面
├── STATUS.md                 # 进度跟踪
├── framework.md              # 核心设定
├── outline.md                # 大纲细纲
├── chapters/                 # 正文（英文）
│   ├── README.md
│   └── 第NNN章-标题.md
└── entities/                 # 知识实体（英文）
    ├── characters/
    ├── settings/
    ├── locations/
    └── items/
```

### 5.2 九目录职责
1. `schema/` - 规范与契约（6份核心规范）
2. `projects/` - 所有项目
3. `knowledge/` - 结构化知识实体
4. `drafts/` - 写作中草稿
5. `archive/` - 归档资料
6. `references/` - 参考资料与外部素材
7. `methods/` - 可复用方法论
8. `tools/` - 工具说明与脚本
9. `goals/` - 目标级联系统

### 5.3 六份核心规范
1. 目录规范（schema/目录规范.md）
2. 项目结构规范（schema/项目结构规范.md）
3. frontmatter规范（schema/frontmatter规范.md）
4. 链接规范（schema/链接规范.md）
5. AI协作规范（schema/AI协作规范.md）
6. 维护门禁说明（schema/维护门禁说明.md）
