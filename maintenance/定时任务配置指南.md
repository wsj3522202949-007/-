# Windows 定时任务配置指南

> 本指南说明如何配置 Windows 定时任务，自动运行维护脚本。
> 需要管理员权限。

---

## 📋 定时任务清单

| 任务名称 | 脚本 | 执行时间 | 说明 |
|---|---|---|---|
| KnowledgeBase_DailyBackup | `daily-backup.ps1` | 每日 23:30 | 校验、提交、推送 |
| KnowledgeBase_WeeklyHealth | `weekly-health.ps1` | 每周日 21:00 | 生成健康报告 |
| KnowledgeBase_MonthlyCleanup | `monthly-cleanup.ps1` | 每月第一个周日 20:00 | 清理检查 |

---

## 🚀 配置步骤

### 前置条件

- [ ] 已安装 Git 并添加到 PATH
- [ ] 已安装 Python 并添加到 PATH
- [ ] 已配置 Git 用户信息
- [ ] 已配置 Git 远程仓库（异地备份）
- [ ] 以管理员身份运行 PowerShell

---

### 任务 1：每日自动备份

**脚本路径**：`e:\个人知识库\maintenance\scripts\daily-backup.ps1`

**执行时间**：每日 23:30

**配置命令**：

```powershell
schtasks /create /tn "KnowledgeBase_DailyBackup" /tr "powershell -ExecutionPolicy Bypass -File `"e:\个人知识库\maintenance\scripts\daily-backup.ps1`"" /sc daily /st 23:30 /f
```

**验证命令**：

```powershell
schtasks /query /tn "KnowledgeBase_DailyBackup"
```

**删除命令**：

```powershell
schtasks /delete /tn "KnowledgeBase_DailyBackup" /f
```

---

### 任务 2：每周健康报告

**脚本路径**：`e:\个人知识库\maintenance\scripts\weekly-health.ps1`

**执行时间**：每周日 21:00

**配置命令**：

```powershell
schtasks /create /tn "KnowledgeBase_WeeklyHealth" /tr "powershell -ExecutionPolicy Bypass -File `"e:\个人知识库\maintenance\scripts\weekly-health.ps1`"" /sc weekly /d SUN /st 21:00 /f
```

**验证命令**：

```powershell
schtasks /query /tn "KnowledgeBase_WeeklyHealth"
```

**删除命令**：

```powershell
schtasks /delete /tn "KnowledgeBase_WeeklyHealth" /f
```

---

### 任务 3：每月清理检查

**脚本路径**：`e:\个人知识库\maintenance\scripts\monthly-cleanup.ps1`

**执行时间**：每月第一个周日 20:00

**注意**：Windows 任务计划不支持"每月第一个周日"这样的复杂表达式。替代方案：
1. 每月 1 日运行
2. 或手动运行

**配置命令（每月 1 日）**：

```powershell
schtasks /create /tn "KnowledgeBase_MonthlyCleanup" /tr "powershell -ExecutionPolicy Bypass -File `"e:\个人知识库\maintenance\scripts\monthly-cleanup.ps1`"" /sc monthly /d 1 /st 20:00 /f
```

**验证命令**：

```powershell
schtasks /query /tn "KnowledgeBase_MonthlyCleanup"
```

**删除命令**：

```powershell
schtasks /delete /tn "KnowledgeBase_MonthlyCleanup" /f
```

**预期输出**：

```powershell

schtasks /run /tn "KnowledgeBase_WeeklyHealth"

# 运行每月清理检查
schtasks /run /tn "KnowledgeBase_MonthlyCleanup"
```

## 📝 手动配置方法

如果 schtasks 命令失败，可以手动配置：

### 方法 1：任务计划程序（图形界面）

1. 按 `Win + R`，输入 `taskschd.msc`，回车
2. 点击右侧"创建任务"
3. 填写任务信息：
   - 名称：`KnowledgeBase_DailyBackup`
   - 描述：`每日自动备份知识库`
4. 触发器：新建 -> 每天 -> 23:30
5. 操作：新建 -> 启动程序
   - 程序：`powershell.exe`
   - 参数：`-ExecutionPolicy Bypass -File "e:\个人知识库\maintenance\scripts\daily-backup.ps1"`
6. 条件：取消勾选"只有在计算机使用交流电源时才启动此任务"
7. 设置：勾选"如果任务失败，按以下频率重新启动"
8. 确定保存

### 方法 2：注册表导入

导出任务配置到 .xml 文件，然后导入：

```powershell
# 导出现有任务（如果有）
schtasks /query /tn "KnowledgeBase_DailyBackup" /xml > daily-backup.xml

# 导入任务
schtasks /create /tn "KnowledgeBase_DailyBackup" /xml daily-backup.xml /f
```

## 🔧 常见问题

### Q1：schtasks 命令失败

**问题**：`Access is denied` 或 `The specified account already exists`

**解决**：
1. 以管理员身份运行 PowerShell
2. 或使用任务计划程序图形界面配置

### Q2：任务不执行

**问题**：定时任务到了时间不执行

**解决**：
1. 检查任务计划程序历史记录
2. 检查脚本路径是否正确
3. 手动运行脚本测试

### Q3：Git 命令不可用

**问题**：`git: command not found`

**解决**：
1. 安装 Git 并添加到 PATH
2. 重启 PowerShell
3. 在脚本中使用 Git 完整路径

### Q4：Python 命令不可用

**问题**：`python: command not found`

**解决**：
1. 安装 Python 并添加到 PATH
2. 在脚本中使用 Python 完整路径
