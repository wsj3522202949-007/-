# Git 安装与 GitHub 备份配置指南

> 当前状态：Git 未安装，需要先完成安装才能继续配置 GitHub 异地备份。

---

## 第一步：安装 Git

### 方式一：官网下载安装（推荐）

1. 访问 [Git 官网下载页面](https://git-scm.com/downloads)
2. 下载 Windows 版本（64-bit Git for Windows Setup）
3. 运行安装程序，**全部使用默认设置**即可
4. 安装完成后，**重启终端/ PowerShell** 使 `git` 命令生效

### 方式二：使用包管理器

如果你已安装 Chocolatey 或 Scoop：

```powershell
# Chocolatey
choco install git

# Scoop
scoop install git
```

---

## 第二步：验证安装

安装完成后，打开新的 PowerShell 窗口，运行：

```powershell
git --version
```

如果显示类似 `git version 2.xx.x`，说明安装成功。

## 第三步：配置 Git 用户信息

```powershell
# 设置用户名（使用你的名字或昵称）
git config --global user.name "你的名字"

# 设置邮箱（使用你的 GitHub 邮箱）
git config --global user.email "your.email@example.com"
```

## 常见问题

### Q: 推送时提示需要认证？

**A**: GitHub 现在要求使用个人访问令牌（PAT）代替密码认证。

1. 访问 [GitHub Settings -> Developer settings -> Personal access tokens](https://github.com/settings/tokens)
2. 生成新令牌，勾选 `repo` 权限
3. 推送时，用户名输入你的 GitHub 用户名，密码输入生成的令牌

### Q: 推送速度慢或失败？

**A**: 可以配置 Gitee 作为备选远程仓库：

```powershell
# 添加 Gitee 远程仓库
git remote add gitee https://gitee.com/yourname/private-knowledge-base.git

# 推送到 Gitee
git push -u gitee main
```

### Q: 如何设置自动每日推送？

**A**: 参考 `maintenance/定时任务配置指南.md`，创建 Windows 计划任务：

```powershell
schtasks /create /tn "KnowledgeBase_DailyBackup" /tr "powershell -ExecutionPolicy Bypass -File `"e:\个人知识库\maintenance\scripts\daily-backup.ps1`"" /sc daily /st 23:30 /f
```
