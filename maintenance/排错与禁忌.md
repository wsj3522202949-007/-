# 🧯 排错速查与禁忌

> 本文件从原《维护标准》拆出，汇集已知例外、禁忌清单与排错速查表。不变量契约定义见 [维护标准.md](../schema/维护标准.md)。

---

## 四、已知例外（诚实记录，不视为 ERROR）

- **37 个历史遗留 `owner-repo.md`（无编号）已删除**：工作树 `../tools/enriched/readmes/` 现已 0 残留（git status D，待提交）；删除后校验脚本 WARN 由 37 → 0。若日后重跑 `_enrich_readmes.py` 可防止再生成；**勿手动补回**。
- **22 个重复工具卡组 / 27 张冗余卡（待清理）**：同 `owner__repo` 双编号（低编号来自原始 50 源富集、高编号 04798–04810 来自扩容批次），内容重复。校验脚本不检跨文件重复，故不报 ERROR；建议保留低编号、删高编号副本（删除前 `grep` 全库引用避免断链）。
- **`pitfalls` 在绝大多数非特殊仓库为空**：仅部分特殊协议/API 风险仓库填避坑，其余空是基线设计，非缺失。

## 五、禁忌（别这样做）

| ❌ 禁忌 | ✅ 改为 |
|---|---|
| 手改工具卡 `tags/tier` | 重跑 `_enrich_readmes.py`（改脚本常量后 `--force`） |
| 笔记写裸标签 `tags: [模板]` | `tags: [type/template, area/方法]` |
| 在工具卡 `tags` 写 `area/库` | 工具卡不用命名空间，标签只取受控/技术 |
| 领域当标签 `tags: [长篇AI写作]` | 留 `category:` 字段 |
| 删 `.obsidian/` 或 `小说工作台.css` | 它们是工作台配置，已版本化 |
| 提交前不跑校验 | 提交前必跑，ERROR=0 再提 |
| 正文文件不叫 `第NNN章-标题.md`（如 `chap1.md` / `第一张.md`） | 改名为 `第001章-标题.md`（见 [维护标准.md](../schema/维护标准.md) §1.5 ①） |
| 知识单页沉到 vault 根（`人物/沈念.md`） | 移到 `projects/书名/人物/沈念.md`（见 [维护标准.md](../schema/维护标准.md) §1.5 ②） |
| 把 `platform/genre/pov/chapter` 塞进 `tags` | 改为独立 YAML 键：`platform: 番茄` `pov: 林晚星`（见 [维护标准.md](../schema/维护标准.md) §1.5 ③ / §1.2） |
| 用 `[[wikilink]]` 作为唯一引用方式 | 标准 markdown 链接 `[文本](路径.md)` + `related`/`see_also` 字段（见 [链接规范](../schema/链接规范.md)） |
| 新笔记只写 `tags: [type/xxx]` 命名空间标签 | 改为平键 `type: xxx` + `area: xxx` + `status: xxx`（见 [frontmatter规范](../schema/frontmatter规范.md)） |

## 六、排错速查

| 现象 | 原因 | 处理 |
|---|---|---|
| ERROR: tier 非法 | 手改了 tier 或脚本 bug | 重跑富集；或核对值 ∈ {S,A,B,C} |
| ERROR: 非受控中文标签 | 领域泄漏进 tags | 移出 tags，放回 `category` |
| ERROR: 笔记标签未命名空间化 | 新增笔记忘打 `type/area/` | 补 `type/<v>` `area/<v>` |
| ERROR: 链接失效 `../tools/enriched/readmes/...` | 文件改名/删除 | 修正指南/仪表盘的链接或恢复文件 |
| WARN: 37 个命名不规范 | 历史遗留（见 §四） | 忽略，或日后随富集规范化 |
| 仪表盘空白 | Dataview 插件未装/未启用 | Obsidian 设置→社区插件→装 Dataview |
