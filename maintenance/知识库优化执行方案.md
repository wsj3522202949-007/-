#### 3.2.3 Dataview动态视图创建（2-3小时）
创建3个核心视图：

**视图A：工具选型矩阵**
```dataview
TABLE tier AS "评级", category AS "类别", use_case AS "用途"
FROM "tools/cards"
WHERE tier = "S" OR tier = "A"
SORT tier ASC, stars DESC
```

**视图B：按任务快速找工具**
```dataview
TABLE title AS "工具", tier AS "评级", use_case AS "用途"
FROM "tools/cards"
WHERE contains(tags, "task/去AI味")
SORT stars DESC
LIMIT 10
```

**视图C：方法论速查**
```dataview
TABLE title AS "文档", summary AS "摘要"
FROM "methods"
WHERE type = "guide"
SORT title ASC
```

**验收标准**：
- ✅ Dataview查询成功返回结果
- ✅ 标签体系覆盖90%以上工具卡
- ✅ 动态视图可正常筛选和排序
