## 🛠️ 常用操作

### 1. 运行校验

**校验脚本**：[tools/scripts/validation/校验脚本.py](tools/scripts/validation/校验脚本.py)

```bash
# 检查所有区域
python tools/scripts/validation/校验脚本.py

# 检查特定区域
python tools/scripts/validation/校验脚本.py --zone core
python tools/scripts/validation/校验脚本.py --zone production
python tools/scripts/validation/校验脚本.py --zone template

# JSON 输出
python tools/scripts/validation/校验脚本.py --json
```

**检查项**：
- A. Frontmatter 合法性
- B. 中文命名空间与枚举值
- C. 描述自洽性
- D. 标题/摘要/内容相关性
- E. 生命周期/归档合规性
- F. 文档清单
- G. 通用字段缺失

### 2. 修复链接

**链接检查器**：[tools/scripts/validation/_run_link_fixed.py](tools/scripts/validation/_run_link_fixed.py)

```bash
# 检查链接
python tools/scripts/validation/_run_link_fixed.py

# 检查特定区域
python tools/scripts/validation/_run_link_fixed.py --zone core
python tools/scripts/validation/_run_link_fixed.py --zone production

# 自动修复
python tools/scripts/validation/_run_link_fixed.py --fix

# JSON 输出
python tools/scripts/validation/_run_link_fixed.py --json
```

**检查项**：
- 1. 链接文本未转义 `_`
- 2. 无效 wiki / markdown 链接
- 3. 中文 tag / 命名空间规范

### 3. 批量检查

**统一入口**：[tools/scripts/validation/run_all.py](tools/scripts/validation/run_all.py)

```bash
# 检查所有区域
python tools/scripts/validation/run_all.py

# 检查特定区域
python tools/scripts/validation/run_all.py --zone core
python tools/scripts/validation/run_all.py --zone production

# JSON 输出
python tools/scripts/validation/run_all.py --json
```

**输出示例**：

## 📋 维护任务

### 每日维护

**时间**：每日晚上

**任务**：
1. **收件箱处理** - 整理未分类内容
   - 检查 `drafts/inbox/`
   - 分类、归档或删除
   - 更新相关链接

2. **日记整理** - 整理日记
   - 检查 `drafts/journal/`
   - 完善 frontmatter
   - 建立关联

### 每周维护

**时间**：每周六上午

**任务**：
1. **笔记整理** - 整理笔记、修复链接
   - 运行 [链接体检与修复](tools/scripts/validation/_run_link_fixed.py)
   - 修复断链
   - 优化标签

2. **周回顾** - 回顾本周成果
   - 运行 [每周回顾](/weekly)
   - 总结本周成果
   - 规划下周目标

### 每月维护

**时间**：每月最后一天

**任务**：
1. **月回顾** - 回顾本月成果
   - 运行 [每月回顾](/monthly)
   - 总结本月成果
   - 规划下月目标

2. **目标对齐** - 检查目标对齐
   - 运行 [目标对齐](ai/agents/goal-aligner.md)
   - 检查目标完成情况
   - 调整目标

3. **清理重复** - 清理重复文件
   - 检查重复内容
   - 合并或删除重复
   - 更新索引

## 🔧 高级操作

### 1. 清理重复文件

**工具**：[tools/scripts/validation/run_all.py](tools/scripts/validation/run_all.py)

```bash
# 检查重复文件
python tools/scripts/validation/run_all.py --zone core
```

**手动清理**：
1. 检查 `drafts/inbox/` 中的重复内容
2. 合并或删除重复文件
3. 更新相关链接

### 2. 优化性能

**工具**：[Git 仓库整理项目完成通知.md](Git仓库整理项目完成通知.md)

```bash
# 运行清理脚本
python tools/scripts/生成首页统计.py --update-readme
```

**优化内容**：
- 清理 `.tools/` 目录
- 删除重复文件
- 压缩大文件
- 更新索引

### 3. 备份与恢复

**备份策略**：
1. **本地备份**：定期复制到外部硬盘
2. **云备份**：使用 Git 推送远程仓库
3. **快照**：使用 Git 标签记录重要版本

**恢复步骤**：
1. 从 Git 仓库克隆
2. 运行 [校验脚本](tools/scripts/validation/校验脚本.py) 检查完整性
3. 修复链接（如有需要）
