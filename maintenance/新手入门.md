# 新手入门

> 欢迎来到知识库！本指南将帮助你从零开始，快速上手。

---

## 第一步：了解知识库

### 知识库是什么？

这是一个专为网文写作设计的知识管理系统，帮助你：
- 📚 **组织知识**：结构化存储写作方法论、工具、参考资料
- 🎯 **追踪进度**：管理多个项目，追踪写作进度
- 🔧 **提升效率**：使用 AI 辅助写作，提高创作效率
- 📈 **持续改进**：通过目标管理，持续提升写作能力

### 目录结构概览

知识库采用 **9 目录结构**（已冻结）：

| 目录 | 职责 | 内容 |
|---|---|---|
| `schema/` | 规范与契约 | 规范文件 |
| `projects/` | 所有项目 | 小说项目 |
| `knowledge/` | 结构化知识 | 写作技艺、题材、平台 |
| `drafts/` | 写作中草稿 | 未完成内容 |
| `archive/` | 归档 | 历史内容 |
| `references/` | 参考资料 | 外部资料 |
| `methods/` | 方法论 | 可复用的写作方法 |
| `tools/` | 工具说明 | AI 写作工具情报网 |
| `goals/` | 目标管理 | 从愿景到日任务 |

## 第三步：学习基本概念

### 项目结构

每个项目遵循统一的结构：

```
projects/作品名/
├── README.md                 # 项目门面
├── STATUS.md                 # 进度数字
├── framework.md              # 核心设定
├── outline.md                # 总纲/分卷细纲
├── chapters/                 # 正文（英文目录名）
│   ├── README.md             # 章节索引
│   ├── 第001章-标题.md
│   └── 第002章-标题.md
└── entities/                 # 知识实体（英文目录名）
    ├── characters/           # 人物
    ├── settings/             # 设定
    ├── locations/            # 地点
    └── items/                # 道具
```

### Frontmatter 规范

所有笔记层文件都有 frontmatter：

```yaml
---
id: unique-id
type: index|guide|ref|dashboard|template|moc|demo|project
area: 库|方法|项目|资料|日记|索引
status: active|demo|wip|done|draft|archived
tags: [标签1, 标签2]
title: 标题
summary: 摘要
source: 来源
created: 2026-08-04
updated: 2026-08-04
---
```

### 链接规范

使用标准 markdown 链接：

```markdown
[链接文本](路径)
[项目说明](../projects/项目名/README.md)
```

使用 `related` 和 `see_also` 字段建立关联：

```yaml
related:
  - 相关文档1
  - 相关文档2
see_also:
  - 参见文档1
  - 参见文档2
```

## 常见问题

### Q1：我该如何开始写第一本书？

**A**：
1. 阅读 [网文写作最强SOP](../methods/网文写作最强SOP.md)
2. 使用 [项目骨架模板](../methods/项目骨架模板/README.md) 创建项目
3. 从 `[选题分析](../methods/选题与开书筹备.md)`（待创建）开始
4. 参考 [开篇写作指南](../methods/开篇写作指南.md)

### Q2：我卡文了怎么办？

**A**：
1. 查看 [QUICK_START](../methods/QUICK_START.md) 按症状查找解决方案
2. 使用 [卡文急救](../knowledge/craft/卡文急救.md)
3. 参考 [节奏与留白](../knowledge/craft/节奏与留白.md)

### Q3：如何选择合适的 AI 工具？

**A**：
1. 阅读 [工具选型指南](../tools/工具选型指南.md)
2. 使用 [任务选型速查](../tools/任务选型速查.md) 快速筛选
3. 查看 [工具情报网](../tools/README.md) 了解详细信息

### Q4：如何维护知识库？

**A**：
1. 阅读 [维护入口](入口.md)
2. 运行 [校验脚本](../tools/scripts/validation/校验脚本.py)
3. 使用 [链接体检与修复](../tools/scripts/validation/_run_link_fixed.py)
4. 定期运行 [批量清理](../tools/scripts/validation/run_all.py)
