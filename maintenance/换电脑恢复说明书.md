## 🚀 步骤 1：安装基础软件

### 1.1 安装 Git

1. 下载 Git：[https://git-scm.com/downloads](https://git-scm.com/downloads)
2. 运行安装程序
3. 安装选项：
   - ✅ Use Git from the Windows Command Prompt
   - ✅ Checkout as-is, commit as-is
   - ✅ Use Windows' default console window
4. 完成安装

**验证安装**：
```powershell
# 打开 PowerShell，运行
git --version

# 预期输出：git version 2.xx.x
```

### 1.2 安装 Python

1. 下载 Python：[https://www.python.org/downloads/](https://www.python.org/downloads/)
2. 运行安装程序
3. **重要**：勾选 "Add Python to PATH"
4. 选择 "Install Now"
5. 完成安装

**验证安装**：
```powershell
python --version
pip --version

# 预期输出：
# Python 3.x.x
# pip x.x.x
```

### 1.3 安装 VS Code（可选）

1. 下载 VS Code：[https://code.visualstudio.com/](https://code.visualstudio.com/)
2. 运行安装程序
3. 完成安装

**推荐扩展**：
- Markdown All in One
- GitLens
- Python
- YAML

## 📥 步骤 2：克隆知识库

### 2.1 创建目标目录

```powershell
# 创建知识库目录
mkdir e:\个人知识库
cd e:\个人知识库
```

### 2.2 克隆仓库

**方式 1：SSH（推荐）**

```powershell
# 使用 SSH 克隆
git clone git@github.com:yourname/private-knowledge-base.git .

# 注意：最后的点表示克隆到当前目录
```

**方式 2：HTTPS**

```powershell
# 使用 HTTPS 克隆
git clone https://github.com/yourname/private-knowledge-base.git .
```

## ⚙️ 步骤 3：配置环境

### 3.1 配置 Git 用户信息

```powershell
# 进入知识库目录
cd e:\个人知识库

# 配置用户名
git config user.name "Your Name"

# 配置邮箱
git config user.email "your.email@example.com"

# 验证配置
git config --list

# 确认输出包含：
# user.name=Your Name
# user.email=your.email@example.com
```

### 3.2 配置远程仓库

```powershell
# 设置远程仓库地址
git remote set-url origin git@github.com:yourname/private-knowledge-base.git

# 验证远程仓库
git remote -v

# 预期输出：
# origin  git@github.com:yourname/private-knowledge-base.git (fetch)
# origin  git@github.com:yourname/private-knowledge-base.git (push)
```

### 3.3 安装 Python 依赖（可选）

```powershell
# 进入工具目录
cd e:\个人知识库\tools

# 安装依赖（如有 requirements.txt）
pip install -r requirements.txt

# 返回根目录
cd e:\个人知识库
```

### 3.4 配置自动备份（可选）

```powershell
# 创建每日自动推送任务
schtasks /create /tn "GitAutoPush" /tr "cd e:\个人知识库 && git add -A && git commit -m 'auto: daily backup' && git push" /sc daily /st 23:00 /f

# 验证任务
schtasks /query /tn "GitAutoPush"
```

## ❓ 常见问题

### Q1：克隆速度慢怎么办？

**问题**：克隆大仓库速度很慢

**解决方案**：
```powershell
# 1. 使用浅克隆（只克隆最新版本）
git clone --depth 1 git@github.com:yourname/private-knowledge-base.git .

# 2. 或使用 HTTPS 并配置代理
git config --global http.proxy http://127.0.0.1:7890
git clone https://github.com/yourname/private-knowledge-base.git .
```

### Q2：SSH 连接失败怎么办？

**问题**：`Permission denied (publickey)`

**解决方案**：
1. 检查 SSH 密钥：
   ```powershell
   ssh-keygen -l -f ~/.ssh/id_ed25519
   ```
2. 添加 SSH 密钥到 GitHub/Gitee
3. 测试连接：
   ```powershell
   ssh -T git@github.com
   ```

### Q3：Python 脚本运行失败怎么办？

**问题**：`ModuleNotFoundError`

**解决方案**：
```powershell
# 安装依赖
pip install -r tools/requirements.txt

# 或安装单个包
pip install pyyaml
```

### Q4：文件编码问题怎么办？

**问题**：中文文件名显示乱码

**解决方案**：
```powershell
# 配置 Git 支持中文文件名
git config --global core.quotePath false

# 或使用 PowerShell 命令
chcp 65001
```

### Q5：大文件克隆失败怎么办？

**问题**：`fatal: Out of memory`

**解决方案**：
```powershell
# 增加 Git 内存限制
git config --global pack.windowMemory 100m
git config --global pack.packSizeLimit 100m

# 或使用浅克隆
git clone --depth 1 git@github.com:yourname/private-knowledge-base.git .
```
