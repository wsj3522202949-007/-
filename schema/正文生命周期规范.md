# 正文生命周期规范

> 正文内容按成熟度分三层存放。**写在哪一层 = 内容处于什么阶段**。层与层之间有明确的流转规则，不可越层存放。

---

## 一、三层定义

```
drafts/                    ← 写作中：正在写、未校验、可能冲突
  ↓（通过自检 + 校验后）
projects/*/chapters/       ← 生产中：已校验、可进入生产
  ↓（不再迭代后）
archive/                   ← 归档：不再迭代、只保留不删除
```

### drafts/ — 写作中

| 维度 | 规则 |
|---|---|
| 定位 | 正在写、未校验、可能冲突的内容 |
| 内容 | 未定稿章节、临时草稿、收件箱待整理项、每日笔记、实验性片段 |
| 状态标记 | frontmatter `status: draft` |
| 命名 | 无强制命名规范（草稿可随意命名，如 `陆远初遇林傲-草稿.md`） |
| 校验 | **不参与 frontmatter ERROR 级机检**（草稿可以缺字段、可以脏） |
| 链接 | 允许死链（目标可能尚未创建） |
| 谁能改 | 任何人随时改，不需走流程 |

### projects/*/chapters/ — 已校验生产

| 维度 | 规则 |
|---|---|
| 定位 | 已校验、可进入生产的最终稿 |
| 内容 | 定稿章节（`第NNN章-标题.md`），且 frontmatter 完整、已过自检 |
| 状态标记 | frontmatter `status: published` 或 `status: final` |
| 命名 | **强制**：`第NNN章-标题.md`（NNN 三位零填充） |
| 校验 | **参与全部 ERROR 级机检**：缺 frontmatter / 缺必填键 / type 不符 = ERROR 阻断 |
| 链接 | **死链 = 0**，提交前必跑链接体检 |
| 谁能改 | 改动需走流程：从 chapters/ 取出 → 放回 drafts/ 修改 → 重新校验 → 回 chapters/ |

### archive/ — 归档保留

| 维度 | 规则 |
|---|---|
| 定位 | 不再迭代、只保留不删除 |
| 内容 | 废弃的旧稿、被替换的章节版本、过期的方案、已完结书的存档 |
| 状态标记 | frontmatter `status: archived` 或 `status: deprecated` |
| 命名 | 保留归档时的原始文件名，不重命名 |
| 校验 | **豁免全部机检**（归档内容不要求 frontmatter 合规） |
| 链接 | 允许死链（引用方应已更新指向新版本） |
| 谁能改 | **只读**：归档后不再修改内容，除非有明确纠错理由 |

## 二、流转规则

### 2.1 drafts/ → chapters/（定稿流转）

```
drafts/某章草稿.md
  → 跑自检（自检清单_升级版.md + 最强去AI味铁律.md）
  → 跑链接体检（链接体检与修复.py --fix）
  → 补全 frontmatter（chapter 类型，所有必填字段）
  → 重命名为 第NNN章-标题.md
  → 移入 projects/作品名/chapters/
  → 更新 STATUS.md 章节推进表
```

**准入条件（全部满足才能进 chapters/）：**
- [ ] frontmatter 完整（type: chapter，含 chapter/pov/location/characters/word_count）
- [ ] 字数在 2300–2700 范围内
- [ ] 已过 AI 味黑名单检查（0 命中）
- [ ] 章末钩子属于 5 种强钩子之一（非下章预告）
- [ ] 链接体检死链 = 0
- [ ] 人名/设定/金手指与前文一致（查 entities/ + outline.md 伏笔表）

### 2.2 chapters/ → archive/（归档流转）

```
projects/作品名/chapters/第NNN章-旧标题.md
  → 确认不再迭代（如：重写后旧版需保留 / 完结存档）
  → 移入 archive/projects/作品名/chapters/第NNN章-旧标题.md
  → frontmatter status 改为 archived
  → 更新 chapters/README.md 章节列表
```

**归档条件（满足其一即可）：**
- 章节被完整重写，旧版有参考价值需保留
- 整本书完结，正文转入存档
- 章节被废弃（如剧情线删除），但不删除文件

### 2.3 drafts/ → archive/（直接归档）

```
drafts/实验性片段.md
  → 确认不再使用且有保留价值
  → 移入 archive/drafts/实验性片段.md
  → 可不补 frontmatter（archive 豁免机检）
```

**适用场景：**
- 实验性写法片段，不打算用但想留作参考
- 被否决的大纲方案
- 已吸收进正文但原文有溯源价值的外部素材

## 三、禁止行为

| 禁止 | 原因 |
|---|---|
| 把草稿直接放 chapters/ | 未校验内容进入生产 = 污染最终稿 |
| 在 drafts/ 里放已定稿章节 | drafts 允许脏数据，定稿可能被误改 |
| 在 chapters/ 里同时存多个版本 | chapters/ 每章只有一个文件 = 当前生产版 |
| 删除 archive/ 中的文件 | 归档 = 只保留不删除 |
| 修改 archive/ 中的正文 | 归档 = 只读，改了就失去溯源意义 |
| 在 chapters/ 里放非章节文件 | chapters/ 只放 `第NNN章-标题.md`，索引在 chapters/README.md |
| 跳过自检直接进 chapters/ | 违反准入条件 = 未校验内容进入生产 |

## 四、目录结构映射

### 4.1 在 vault 顶层结构中的位置

```
vault/
├── drafts/                          # 全局草稿区（跨项目）
│   ├── inbox/                       # 收件箱（临时待整理）
│   ├── journal/                     # 每日笔记
│   ├── scratch/                     # 临时草稿
│   └── projects/                    # 项目草稿（按项目隔离）
│       └── <你的书名>/
│           ├── 第001章-初稿.md       # 正在写的章节
│           └── 顾羽初遇唐晚-草稿.md   # 实验性片段
│
├── projects/                        # 生产区
│   └── <你的书名>/
│       └── chapters/                # 已校验最终稿
│           ├── README.md
│           ├── 第001章-标题.md       # ← 只有定稿
│           └── 第002章-标题.md
│
└── archive/                         # 归档区（只保留不删除）
    ├── projects/                    # 项目归档
    │   └── <你的书名>/
    │       └── chapters/
    │           └── 第001章-旧版.md   # 被替换的旧版
    └── drafts/                      # 草稿归档
        └── 实验性片段.md
```

### 4.2 与项目结构规范的关系

项目内（`projects/作品名/`）只有 `chapters/`，**不含 drafts 和 archive**：
- 草稿在 vault 级 `drafts/projects/作品名/` 下（项目隔离但位于 drafts 区）
- 归档在 vault 级 `archive/projects/作品名/` 下

> 这样做的原因：drafts 和 archive 是跨项目共用的生命周期阶段，不应下沉到每个项目内部。

## 五、状态标记与机检策略

| 层 | frontmatter status | 机检级别 | 死链处理 |
|---|---|---|---|
| `drafts/` | `draft` | **豁免**（不阻断提交） | 允许 |
| `projects/*/chapters/` | `final` / `published` | **全部 ERROR 级**（阻断提交） | =0（阻断） |
| `archive/` | `archived` / `deprecated` | **豁免**（不阻断提交） | 允许 |

### 校验脚本更新要求

`校验脚本.py` 需按目录区分机检级别：

```python
# 伪代码
if file_path.startswith("drafts/"):
    # 豁免 ERROR，仅 WARN
    pass
elif file_path.startswith("projects/") and "/chapters/" in file_path:
    # 全部 ERROR 级检查
    run_all_checks(file_path)
elif file_path.startswith("archive/"):
    # 完全豁免
    pass
```

## 六、日常操作速查

| 我现在想… | 放在哪 | 怎么做 |
|---|---|---|
| 写一章新内容 | `drafts/projects/书名/` | 随意命名，开始写 |
| 实验一段写法 | `drafts/scratch/` | 随意命名，不进项目 |
| 章节写完想定稿 | `drafts/` → `chapters/` | 跑自检 → 补 frontmatter → 重命名 → 移入 |
| 改已定稿的章节 | `chapters/` → `drafts/` | 取出到 drafts 改 → 重新校验 → 回 chapters |
| 旧版章节想保留 | `chapters/` → `archive/` | 移入 archive，status 改 archived |
| 完结存档 | `chapters/` → `archive/` | 整个 chapters/ 移入 archive/projects/书名/ |
| 丢弃实验片段但留底 | `drafts/` → `archive/drafts/` | 移入 archive，可不补 frontmatter |
