- `立即选型`：看 [任务选型速查](任务选型速查.md)，按写作任务直接找 S/A 候选和禁忌
- `按场景查`：看 [工具选型指南](工具选型指南.md)，按需求反查适合工具

- `按分类逛`：按下方 21 个分类 MOC 进入（见「分类导航」）
- `全量索引`：看 [最终索引](最终索引.md)，按 Stars 排序浏览

## 使用路径

- `选工具`：[任务选型速查](任务选型速查.md) 或 [工具选型指南](工具选型指南.md) 跳到 `cards/`
- `写 SOP`：[通用小说创作流程](../methods/导览.md) 里继续接流程、模板、平台分发
- `存灵感`：先把素材丢到 `archive/`，成熟后再升到主库或 `projects/`
- `做决策`：看 `tier` 和 `tags`，不用先读完每个 README

## 数据定义

- `cards/*.md`：单工具情报卡，frontmatter 带 `tier/tags/use_case/pitfalls/category/stars/url/repo`
- `分类导航/*.md`：分类 MOC，已挂 `type: moc` 和 `area: 库`
- `./工具选型指南.md`：按任务组织的高优先级候选表
- `./标签规范.md` / `./标签体系说明.md`：工具卡标签规则
- `仪表盘.md`：Dataview 实时工作台，数字从 `cards/` 自动统计
