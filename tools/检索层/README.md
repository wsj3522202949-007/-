## 📋 工具卡说明

### 工具卡格式
每张工具卡包含以下信息：
- **tier**：S/A/B/C 评级
- **title**：工具名称
- **summary**：工具简介
- **tags**：分类标签
- **platform**：支持平台
- **cost**：成本类型
- **url**：工具链接
- **features**：功能特点
- **pros/cons**：优缺点

### 评级标准
- **S级**：强烈推荐，综合最佳
- **A级**：推荐，性能良好
- **B级**：可用，有明显不足
- **C级**：谨慎选择，存在严重问题
