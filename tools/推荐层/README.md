### 按任务查找
1. 确定你的任务类型（写作辅助、改稿润色、研究调研等）

3. 查看推荐方案：

## 📋 推荐原则

### S 级工具标准
- 综合性能优秀
- 稳定性高
- 社区活跃
- 长期维护承诺

### A 级工具标准
- 性能良好
- 稳定性较好
- 有明确使用场景
- 持续维护中

### B/C 级工具处理
- 移至 [检索层](../检索层/README.md)
- 保留检索价值
- 不主动推荐
- 仅在有特殊需求时查阅

## 📖 使用指南

### 如何选择工具
1. **确定任务类型**：写作辅助、改稿润色、研究调研等
2. **查看推荐方案**：首选 → 本地方案 → 免费方案 → 中文友好
3. **考虑约束条件**：成本、平台、隐私、中文支持
4. **查看不推荐列表**：避免踩坑

### 如何贡献
1. 发现更好的工具？更新对应分类
2. 工具失效？标记为失效并说明原因
3. 工具降级？调整 tier 等级
4. 新增工具？先评估再添加到推荐层
