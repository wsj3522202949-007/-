# 📋 库·落地建议（怎么把情报网变成你的写作武器）

> 本库有 3572 张工具卡，但**对你真正有用的只有 S/A 级 258 张**。本文件专治「卡在 255 张里不知道选哪个」——按你的**约束**（要不要买 API、能不能商用、看不看得懂英文）直接给清单和组合。**实时数据看 `[仪表盘](../仪表盘.md)` 的「实用查询层」；标签规矩见 [标签规范](标签规范.md)。**

---

## 一、先问自己三个问题（决策树）

```
你要做什么？
├─ 投稿前给正文降 AI 味（你的拒签痛点）→ 去AI味
├─ 写正文 / 续写 / 大纲规划          → 大纲规划 / 多Agent
├─ 长篇人物设定一致性（RAG 记忆）     → RAG
├─ 小说转语音 / 有声化                → TTS
├─ 错别字 / 语法 / 风格校对           → 校对
└─ 互动叙事 / 聊天 Bot 写故事         → 互动叙事

然后套约束（三者取交集，越严越省心）：
① 不想买/配 API Key？            → 只要「本地优先」
② 要商用 / 闭源分发？             → 只要「协议宽松」（避开 协议传染/协议未明）
③ 英文吃力？                      → 只要「中文友好」
```

> 预算敏感 + 想商用 + 中文 → 直接看第四节「零门槛可商用 ∩ 中文友好」的 29 张甜区。

## 四、怎么读一张工具卡

每张卡 frontmatter 就这么几个字段，30 秒判断要不要点进去：

- `use_case` —— 自动抽取的用途摘要（**模板套话居多，仅供参考**，别全信）
- `pitfalls` —— 避坑（**95% 是空的**，真坑得靠 [维护说明](维护说明.md) 和社区口碑补）
- `License` —— 商用红线，见第二节「协议」三档
- `tags` —— 协议 / 部署 / 文档 / 能力 / 技术 五维；`本地优先` vs `需API密钥` 一眼定成本
- `stars` —— 人气，**不等于适合你**；噪声仓库也可能高星

---

## 五、三个避坑提醒

1. **星标 ≠ 适合你。** 本库约 1–2% 误分类（如把机器人 SDK、W3C 文档塞进「去 AI 味」）。先看 `tags` 和 `category` 是否真沾写作，再决定。
2. **商用前自己查 License。** `协议宽松` 是自动判的，AGPL/GPL 误判或作者改协议都可能；闭源分发前到仓库确认一眼。
3. **本地优先 ≠ 一定好用。** 有些本地优先项目文档稀、社区冷、装不上。先看 `中文友好` / `英文文档` 和最近提交时间，再下手。
