## 选型快捷检查

先问四件事：1）是否接受 API Key；2）是否需要联网；3）是否接受 GPL/AGPL；4）是否有中文需求。

- 全都要避开：找 `本地优先` + `协议宽松` + `中文友好`
- 商业敏感：避开 `协议传染`
- 先看样例再看 README：优先看 `tier`，次要看 Stars
