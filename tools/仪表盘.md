## 一、工具情报网 · 总览

### 分层分布（tier）

```dataview
TABLE WITHOUT ID
  choice(tier="S","🟦 S 主力",tier="A","🟩 A 备选",tier="B","🟨 B 长尾",tier="C","🟥 C 存疑") AS "分层",
  length(rows) AS "工具数"
FROM "tools/cards"
GROUP BY tier
SORT choice(tier="S",0,tier="A",1,tier="B",2,3)
```

### 按源分类计数（Top 12）

```dataview
TABLE WITHOUT ID category AS "源分类", length(rows) AS "工具数"
FROM "tools/cards"
GROUP BY category
SORT length(rows) DESC
LIMIT 12
```

## 二、实用查询层（约束速筛）

> 三个最常用的「按约束挑工具」查询：**本地优先**（不买/不配 API Key）、**商用避坑**（协议宽松、避开传染/未明）、**API 约束**（哪些必须自备 LLM Key、有 token 成本）。再加两个交集甜区：**零门槛可商用** = 本地优先 ∩ 协议宽松；**中文友好**。所有数字见 [静态快照版](仪表盘-静态版.md)（零依赖）。

**① 不想买/配 API Key（只看 `本地优先` 的 S/A，共 184 个）**
```dataview
TABLE stars AS "⭐", use_case AS "用途" FROM "tools/cards"
WHERE contains(tags,"本地优先") AND tier IN ("S","A")
SORT stars DESC
```

**② 要商用避坑（排除 `协议传染` 与 `协议未明` 的 `协议宽松` S/A，共 148 个）**
```dataview
TABLE stars AS "⭐", use_case AS "用途", tags AS "标签" FROM "tools/cards"
WHERE contains(tags,"协议宽松") AND tier IN ("S","A")
SORT stars DESC
```

**③ API 约束速览（需自备 LLM Key、有 token 成本与网络门槛的 S/A，共 71 个）**
```dataview
TABLE stars AS "⭐", use_case AS "用途", tags AS "标签" FROM "tools/cards"
WHERE contains(tags,"需API密钥") AND tier IN ("S","A")
SORT stars DESC
```

**④ 零门槛可商用（本地优先 ∩ 协议宽松，预算敏感作者的甜区，共 108 个）**
```dataview
TABLE stars AS "⭐", use_case AS "用途", tags AS "标签" FROM "tools/cards"
WHERE contains(tags,"本地优先") AND contains(tags,"协议宽松") AND tier IN ("S","A")
SORT stars DESC
```

**⑤ 中文友好（有中文资料 / README 的 S/A，共 87 个）**
```dataview
TABLE stars AS "⭐", use_case AS "用途", tags AS "标签" FROM "tools/cards"
WHERE contains(tags,"中文友好") AND tier IN ("S","A")
SORT stars DESC
```

> 想直接看结论与推荐组合，见 [库·落地建议](./落地建议.md)；标签含义见 [标签规范](./标签规范.md)。

## 七、怎么自己加查询

复制任意代码块，改两处即可：
1. `FROM "tools/cards"` 不变（工具都在这里）；
2. `contains(tags, "某标签")` 换成 [标签规范](./标签规范.md) 里的受控标签（如 `RAG` `TTS` `协议宽松`）。

> 例：查「能商用 + 不要 API Key + S 级」的校对工具
> ```dataview
> TABLE stars, use_case FROM "tools/cards"
> WHERE contains(tags,"校对") AND contains(tags,"协议宽松") AND contains(tags,"本地优先") AND tier="S"
> SORT stars DESC
> ```
