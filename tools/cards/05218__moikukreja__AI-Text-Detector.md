# AI Text Detector — BrightPress internal tool

Streamlit app for Case Study H (MAIB AI 115). Paste text, get a HUMAN /
AI-GENERATED verdict with a confidence score.

## How this version differs from the course notebook

The course notebook (`AI_Text_Detector.ipynb`) fine-tunes DistilBERT on
real IMDb reviews and real GPT-2 generations — the full assignment as
specified, and the one to submit as Deliverable 1.

**This repo is a lightweight, dependency-free version built to actually
deploy cleanly on Streamlit Community Cloud's free tier.** Instead of
DistilBERT (torch + transformers, ~250MB of weights, a build that can
time out or run out of memory on the free tier), it uses a TF-IDF +
Logistic Regression classifier trained on a small synthetic corpus
generated by `train_model.py`. The trained model is ~60KB and is
committed directly to this repo — no Hugging Face Hub, no secrets, no
external downloads at runtime. Same GAN-style attack/retrain loop
(Round 1 → attack → Round 2 → fresh attack), just a lighter model
underneath.

If you'd rather deploy the real DistilBERT model, you can retrain it
using the notebook and swap `app.py`'s model-loading logic for
`transformers` + a Hugging Face Hub repo — just be aware of the free-tier
resource limits mentioned above.

## Deploy steps

1. **Push this repo to GitHub:**
   ```bash
   git init
   git add .
   git commit -m "AI text detector app"
   git branch -M main
   git remote add origin https://github.com/moikukreja/AI-Text-Detector.git
   git push -u origin main
   ```
   If the GitHub repo already has commits (e.g. an auto-created README),
   `git clone` it first, copy these files in, then `git add . && git commit && git push`.

2. **Deploy on [share.streamlit.io](https://share.streamlit.io).**
   - New app → pick this repo → branch `main` → main file path `app.py`.
   - No Secrets needed — everything the app needs is in the repo.
   - Deploy. First load should be fast since the model is tiny and there
     are no heavy ML libraries to import.

## Retraining

```bash
pip install -r requirements.txt
python train_model.py
```

This regenerates `model/ai_text_detector.joblib` and `model/scoreboard.json`.
Commit and push the updated `model/` folder to update the deployed app.

## Local testing

```bash
pip install -r requirements.txt
streamlit run app.py
```
