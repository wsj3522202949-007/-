# AI Text Detector

This project detects whether a given text is written by a human or generated by AI using machine learning models. It focuses on comparing:
- **BERT CLS embeddings** with classifiers (Logistic Regression & SVM)
- *(Coming soon)* **TF-IDF** based classification

---

## 🔧 Features

- Uses [CLS] token from BERT (`bert-base-uncased`) for sentence-level representation
- Supports training and evaluation using:
  - Logistic Regression
  - SVM (Support Vector Machine)
- Outputs accuracy, precision, recall, and F1-score
- Modular and extendable design

---

## 📦 Installation (One-Time Setup)

Open **Command Prompt** and install dependencies:

```bash
pip install torch transformers scikit-learn pandas numpy joblib
```

(Optionally, for faster models: `pip install sentence-transformers`)

---

## 📁 Required Dataset

The main dataset (`reviews.csv`) is **not included in this repository** because it exceeds GitHub’s 100MB limit.

### 📥 To Get the Dataset:
Please contact the **project owner** to request `reviews.csv`, or prepare your own `.csv` file with:
- A column for **text**
- A column for **label** (0 = Human, 1 = AI)

Once obtained, place the file in:

```
FYP PROJECT/data/reviews.csv
```

---

## ▶️ How to Use (Step-by-Step)

### 1️⃣ Open Command Prompt and Navigate to Project Folder

```bash
cd "D:\FYP PROJECT"
```

> Tip: Replace the path if you saved it somewhere else.

---

### 2️⃣ Extract BERT CLS Embeddings

This reads each review, extracts the [CLS] token using BERT, and saves it as NumPy arrays.

```bash
python scripts/extract_bert_cls.py
```

It will create:
- `data/bert_cls_vectors_5k.npy`
- `data/labels_5k.npy`

---

### 3️⃣ Train the Classifiers

Once the `.npy` vectors are created, run:

```bash
python train_classifiers.py
```

It will train both:
- Logistic Regression
- SVM

And save the models in `models/` folder.

## 📝 Notes

- You can swap `bert-base-uncased` with lighter models like `distilbert-base-uncased` for better speed.
- Current results on 5,000 samples show **very high accuracy**, but should still be validated with more real-world samples and cross-validation.
- TF-IDF version will be added for method comparison.
