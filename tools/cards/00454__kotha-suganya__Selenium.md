# Selenium Basics Practice 🚀

This repository contains basic Selenium automation practice scripts designed for beginners who want to learn web automation using Selenium.

## 📌 Objective
The goal of this project is to understand:
- How Selenium works
- How to automate browser actions
- How to locate web elements
- How to perform basic user interactions

## 🛠️ Tools & Technologies
- **Programming Language:** Python 
- **Automation Tool:** Selenium WebDriver
- **Browser:** Google Chrome
- **IDE:** VS Code 
- **Driver:** ChromeDriver


## ✨ Topics Covered
- Installing Selenium
- Launching a browser
- Opening a website
- Locating elements using:
  - ID
  - Name
  - Class Name
  - XPath
  - CSS Selector
- Sending input to text fields
- Clicking buttons and links
- Browser navigation (back, forward, refresh)
- Closing and quitting the browser
