# AI Research Tools Workflow

This repository collects notes, prompts, and workflow ideas for using AI tools in research, writing, and technical content creation.

## Why this exists

AI tools are useful, but they are more effective when used as part of a clear workflow.

This repo focuses on practical use cases such as:

- researching technical topics
- comparing AI tools
- writing structured articles
- building knowledge workflows
- evaluating research assistants like ChatGPT, NotebookLM, Perplexity, and Claude

## Basic Workflow

1. Start with a specific research question
2. Expand the topic into comparison dimensions
3. Collect source material
4. Build an outline
5. Draft with AI assistance
6. Review manually
7. Publish
