# Student-Performance-EDA-Dashboard
This project is a data analytics dashboard built with Streamlit to explore student performance data. It uses Python libraries such as Pandas, Matplotlib, and Seaborn to perform exploratory data analysis . It visualizes how factors like gender, test preparation, parental education, and lunch type affect student scores in Math, Reading, and Writing.
