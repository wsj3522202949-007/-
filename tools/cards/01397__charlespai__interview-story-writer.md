# Interview Story Writer - 深度访谈文章生成器

> 🎯 **一次对话，五份产出**：通过 AI 深度访谈，自动生成长文、短文、访谈纪要、核心观点提取、社交媒体片段库

## 🔥 核心价值

### 解决的痛点

**痛点 1：写作困难症**
- ❌ 面对空白页不知道从哪里开始
- ❌ 想法很多但无法组织成文
- ✅ **解决方案**：通过对话式访谈，AI 引导你逐步展开思路

**痛点 2：思维混乱**
- ❌ 脑子里有很多想法，但东一下西一下，理不清逻辑
- ❌ 观点之间有矛盾，不知道如何处理
- ✅ **解决方案**：AI 自动识别、整理、构建逻辑框架，把散乱的想法变成清晰的文章

**痛点 3：内容复用率低**
- ❌ 辛苦写了一篇长文，只能发一次
- ❌ 想在社交媒体持续曝光，但没时间拆解内容
- ✅ **解决方案**：自动生成 12+ 个社交媒体片段，一次创作，持续分发 4 周（Dan Koe 工作流）

**痛点 4：文章缺乏深度**
- ❌ 写出来的文章很平，没有金句，没有记忆点
- ❌ 读者看完就忘，无法产生共鸣
- ✅ **解决方案**：AI 通过 Socratic 提问法深度挖掘，提炼 8-12 个可传播的金句

## ✨ 功能特性

### 🎭 双模式自动识别

**模式 1：故事提取模式**（STORY_EXTRACTION）
- 适用场景：你有一个清晰的故事或经历想分享
- 触发词：`"我想聊聊我的..."`, `"有个故事"`, `"发生了一件事"`
- 输出风格：叙事驱动，有故事弧线（冲突→转折→解决→感悟）

**模式 2：思维整理模式**（THOUGHT_ORGANIZER）
- 适用场景：你有很多散乱的想法，需要整理成文
- 触发词：`"想法有点乱"`, `"理不清"`, `"帮我理理思路"`, `"梳理一下对XX的看法"`
- 输出风格：逻辑清晰，有框架结构（论点→论据→综合）

### 🤖 零打扰工作流

- ✅ **全自动**：从对话到文章生成，无需任何确认
- ✅ **智能处理**：自动处理简短回答、矛盾观点、缺失信息
- ✅ **一键生成**：5 个文件自动保存到结构化文件夹

### 📦 五份产出物

每次访谈自动生成：

1. **长文版.md**（2000-3000字）
   - 完整逻辑框架 / 故事弧线
   - 8-12 个金句
   - 适合公众号深度文章

2. **短文版.md**（800-1200字）
   - 口语化、去 AI 感
   - 保留核心洞察
   - 适合朋友圈、知乎

3. **访谈纪要.md**
   - 完整对话记录
   - 逐轮分析
   - 可复盘学习

4. **核心观点提取.md**
   - 结构化洞察
   - 金句分类整理
   - 可延伸话题

5. **社交媒体片段库.md**（🆕 v3.1.0）
   - 12+ 个独立片段（100-300字）
   - 4 种类型：金句型、观点型、故事型、反思型
   - 4 周发布日历
   - Dan Koe 内容原子化策略

## 🚀 快速开始

### 安装步骤

1. **下载 Skill 文件**
   ```bash
   # 克隆或下载本仓库
   git clone https://github.com/charlespai/interview-story-writer.git
   ```

2. **放置到 Obsidian vault**
   ```
   你的 Obsidian vault/
   └── skills/
       └── interview-story-writer/
           ├── SKILL.md          # 核心 Skill 文件
           └── README.md         # 本文件
   ```

3. **（可选）准备风格参考**
   ```
   你的 Obsidian vault/
   └── style-references/         # 或 公众号风格/ 或 writing-style/
       ├── 范文1.md
       ├── 范文2.md
       └── ...
   ```
   - 放入 1-10 篇你喜欢的文章风格
   - AI 会自动学习标题、金句、节奏
   - 如果不提供，会使用内置爆款模板

### 使用方法

**触发 Skill**（任选一种方式）：

```
# 故事模式
"我想聊聊我的创业经历"
"有个故事想跟你说"
"发生了一件事，想写成文章"

# 思维整理模式
"我对远程工作有些想法，但有点乱，帮我理理"
"想梳理一下对财富自由的看法"
"脑子里东一下西一下，理不清逻辑"
```

**对话过程**（3-8 轮）：

- AI 会根据模式提问（故事模式挖掘细节，思维模式深度追问）
- 每轮 AI 会先总结你的观点，再提出挑战性问题
- 你只需要自然回答，不用担心逻辑或完整性

**自动生成**：

- 对话结束后，AI 自动生成 5 个文件
- 保存到 `YYYY-MM-DD-[主题关键词]/` 文件夹
- 无需任何确认，全程零打扰

## 📖 使用示例

### 示例 1：思维整理模式

**用户触发**：
```
我想聊聊对财富自由的看法，想法有点乱，帮我理理思路
```

**AI 自动识别**：THOUGHT_ORGANIZER 模式

**对话过程**（5轮）：
- Round 1：开放式邀请（"关于财富自由，你有什么想法？"）
- Round 2：总结 + 深度挑战（"我理解你的意思是...但为什么零边际成本一定是终极目标？"）
- Round 3：总结 + 对立面挑战（"你提到信用积累，但这个过程本身是不是巨大的成本？"）
- Round 4：总结 + 挖掘具体案例（"能举个客户问题驱动你研究的例子吗？"）
- Round 5：汇总 + 核心洞察提炼（"经过这轮思考，你对财富自由有没有新的定义？"）

**自动生成**：
```
📂 2026-01-14-财富自由的三重境界/
   ├── 长文版.md (2856字)
   ├── 短文版.md (1038字)
   ├── 访谈纪要.md (完整5轮对话)
   ├── 核心观点提取.md (12个核心观点 + 12条金句)
   └── 社交媒体片段库.md (12个片段，4周发布计划)
```

## 🎨 高级功能

### 风格学习

AI 会自动从你提供的范文中学习：
- **标题模板**：问句型？数字驱动？对比型？
- **金句特征**：长度、修辞手法、密度
- **段落节奏**：短句/长句比例、情感曲线
- **开篇策略**：悬念钩子？故事切入？冲突开场？

### 矛盾处理

当你表达矛盾观点时（如"远程工作很自由"vs"远程工作很孤独"），AI 会：
1. **找到更高层逻辑**："远程工作的两面性"
2. **呈现为复杂性**："增长与克制，并非非此即彼"
3. **时间/情境解析**："从兴奋到痛苦，认知的演变"

### Dan Koe 工作流

**内容原子化策略**：
- 一次深度创作（长文 2000-3000字）
- 拆解成 12+ 个内容原子（100-300字）
- 长文每月发 1-2 次
- 社交片段每周发 3-5 次
- 持续曝光 4 周，最大化内容 ROI

**片段类型**：
- **金句型**：开门见山，核心观点加粗
- **观点型**：常见误区 → 真相揭示 → 简要论证
- **故事型**：小故事 → 洞察 → 普遍应用
- **反思型**：个人转变 → 思维变化 → 邀请读者反思

## 🛠️ 技术细节

### 自动化逻辑

**边缘情况处理**（全部静默处理，无需用户干预）：
- 简短回答（<10字）→ 自动追问一次 → 继续
- "不知道/没有" → 跳过该问题，转向其他角度
- 风格参考缺失 → 使用内置爆款模板
- 信息不足 → 生成精简版（1200-1500字）
- 矛盾观点 → 自动找到更高层逻辑

### 质量保证

**文章质量检查**（内部自动执行）：
- 标题冲击力 ≥ 8/10
- 开篇 5 秒钩住读者
- 故事弧线完整 / 逻辑结构清晰
- 情感曲线有 2+ 个峰值
- 金句密度 ≥ 1 个/300字
- 结尾留有余味

## 💡 最佳实践

### 获得最佳效果的技巧

1. **准备风格参考**（可选但推荐）
   - 找 3-5 篇你最喜欢的文章风格
   - 放到 `style-references/` 文件夹
   - AI 会学习并模仿这些风格

2. **自然对话**
   - 不用担心逻辑是否清晰
   - 不用担心表达是否完整
   - 想到什么说什么，AI 会帮你整理

3. **接受挑战**
   - AI 会从对立面提问，这是为了激发深度思考
   - 不用防御，坦诚回答你的真实想法
   - 矛盾的观点也没关系，AI 会帮你找到更高层逻辑

4. **利用社交片段**
   - 长文发布后，按照建议的 4 周日历发布片段
   - 每个片段都是独立完整的，可以单独传播
   - 根据平台特点选择合适的片段类型
