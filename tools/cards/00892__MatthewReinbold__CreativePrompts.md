# CreativePrompts
A collection of tools to prompt creativity - be it drawing, writing, or AI generation.

Follows the format:

```
[adj1 50%], [adj2 25%], and [adj3 10%] [subject] [present-tense action] in/on/under [location], [style-of] [mood/flavor/aesthetic 20%]
```
