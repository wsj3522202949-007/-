🌟 AI Story Generator

A web-based AI-powered story creation tool built using Gemini API, HTML, CSS, and JavaScript. This project allows users to generate unique stories by selecting a genre (Fantasy, Sci-Fi, Mystery, Adventure, Fairy Tale) and story length (Short, Medium, Long). The generator produces creative, dynamic narratives based on the user’s prompt.

🚀 Features

✔️ Generates AI-driven stories using the Gemini API

✔️ Clean and interactive UI built with HTML, CSS, and JavaScript

✔️ User input validation for accurate genre and length selection

✔️ Real-time story display with smooth user interaction

✔️ Supports multiple genres and story lengths

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

AI Model: Gemini API

📌 How It Works

Choose a genre

Select a story length

Enter a custom prompt

The AI creates a story based on your choices

📄 Project Goal

To build a simple, accessible AI tool that helps users generate imaginative stories tailored to their preferences.
