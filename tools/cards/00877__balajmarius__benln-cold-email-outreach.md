# Benln Cold Email Outreach

This skill turns Ben Lang's cold email advice into a reusable writing prompt for AI tools. It helps draft short, thoughtful outreach emails that read like a real text, make a clear ask, and avoid the usual vague or AI-sounding patterns.

Inspired by this post from Ben Lang:

https://x.com/benln/status/2037441676591919155

<img width="640" height="auto" alt="@benln" src="https://github.com/user-attachments/assets/eee97829-b4c4-406b-b0bc-6dbb34379a47" />

## Install

```bash
npx skills add https://github.com/balajmarius/benln-cold-email-outreach
```

## What It Does

The skill writes cold emails with these constraints:

- 2-3 sentences
- read like a text
- have a clear ask
- no signature
- thoughtfully personalized
- punchy subject line
- avoid vague asks like "pick your brain"
- do not sound like AI wrote them
