# Prompt-Engineering-in-Gen-AI
# 🎨 AI Prompt Writing Collection

## 📌 Project Description

This repository contains a **PDF collection of carefully designed prompt writing keywords** for AI image generation.  
The goal of this project is to help beginners and creators write **clear, detailed, and effective prompts** for generating high-quality images using AI tools.

The prompts focus on important aspects such as lighting, camera angles, subjects, actions, and backgrounds to improve image realism and creativity.

---

## 📄 About the PDF

The PDF includes structured prompt components such as:

- Lighting styles (natural, soft, dramatic, studio, etc.)
- Camera settings (wide-angle, low-angle, close-up, motion blur, etc.)
- Subject descriptions
- Actions and emotions
- Background and environment details  
- Composition and framing tips  

These elements help in building **complete and powerful prompts** for AI image generation.

## ✍️ Prompt Writing Guidelines

While writing prompts for AI image generation, keep the following points in mind:

- Be clear and specific in your description  
- Describe the subject first, then details  
- Mention lighting and camera settings  
- Add emotions and actions for realism  
- Define the background clearly  
- Avoid vague or confusing words  

A well-structured prompt usually follows this order:

**Subject → Action → Emotion → Lighting → Camera → Background → Style**




--- 
## ⭐ Best Practices

- Use descriptive adjectives (soft, dramatic, warm, calm)  
- Combine technical and emotional details  
- Avoid repeating unnecessary words  
- Keep prompts structured and readable  
- Experiment with different combinations  
- Save successful prompts for reuse
