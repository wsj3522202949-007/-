# AI 长篇小说写作助手

支持长篇小说创作的 AI 写作工具，具备：

- **分章节管理**：创建、编辑、重组章节
- **角色管理**：角色设定、关系图谱、一致性检查
- **世界观设定**：背景、规则、时间线管理
- **智能上下文**：自动摘要、分块记忆、角色追踪
- **多种写作模式**：续写、润色、对话生成、情节建议

## 技术栈

- 前端：React + TypeScript + Tailwind CSS
- 后端：Node.js + Express
- AI：OpenAI API / 兼容接口
