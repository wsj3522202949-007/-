# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/1dd67f1b-7e28-4e92-9680-b04ccc35397e

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](https://github.com/SATYAMTIWARI001/S2-FLOW/blob/main/.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
