# AI-Powered Academic Writing Assistant

## Overview
The AI-Powered Academic Writing Assistant is designed to help users generate and summarize academic texts efficiently. Utilizing advanced AI models, this assistant can assist in various writing tasks, making it a valuable tool for students, researchers, and professionals.

## Features
- **Text Generation**: Generate coherent and contextually relevant text based on user prompts.
- **Text Summarization**: Summarize lengthy texts into concise summaries.
- **Customizable Configurations**: Load configurations for model parameters and API keys.

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/ai-writing-assistant.git
   ```
2. Navigate to the project directory:
   ```
   cd ai-writing-assistant
   ```
3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage
1. Run the main application:
   ```
   python src/main.py
   ```
2. Follow the prompts to generate or summarize text.
