# AI Spam Email Detector

A beginner Machine Learning project that classifies text messages as Spam or Not Spam using Natural Language Processing (TF-IDF) and the Multinomial Naive Bayes algorithm.

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Multinomial Naive Bayes

## Features
- Reads a dataset of spam and ham messages
- Converts text into numerical features
- Trains a machine learning model
- Predicts whether a new message is spam or not spam

## Project Structure
AI-Spam-Email-Detector/
│── spam_mail_detector.py
│── spam.csv
│── README.md
│── requirements.txt

## Sample Output

Enter your message:
You won a free lottery!

Prediction: Spam
