# SAT Writing Assistant

An AI-powered tool to help analyze and generate SAT-style analytical essays.

## Features

- Upload and analyze SAT articles (.txt or .docx format)
- Four-dimensional analysis (Reading/Analysis/Writing/Rhetorical)
- Generate analytical essays following SAT writing criteria
- Word count tracking
- Modern and user-friendly interface

## Installation

1. Clone the repository:
git clone https://github.com/yourusername/sat-writing-assistant.git
cd sat-writing-assistant

2. Install dependencies:

pip install -r requirements.txt


3. Make sure you have Ollama running locally on port 11434

## Usage

Run the application:

python sat_writing_assistant.py


The web interface will be available at `http://localhost:7860`

## Requirements

- Python 3.8+
- Gradio
- python-docx
- requests
- Ollama (running locally)
