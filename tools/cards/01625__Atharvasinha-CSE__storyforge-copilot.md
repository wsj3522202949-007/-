# ✍️ StoryForge Copilot

> AI-powered writing assistant that transforms rough ideas into polished, structured content — built for the Microsoft Agents League Hackathon.

---

## 🎯 Problem It Solves

Most people struggle to convert their ideas into well-structured written content. Whether it's a blog post, story, email, or essay — starting from scratch is hard and time-consuming.

**StoryForge Copilot** solves this by letting users:
- Type any rough idea or topic
- Select their desired tone (Professional, Casual, Persuasive, Creative)
- Choose content type (Blog Post, Short Story, Email, Essay)
- Get a fully structured, engaging piece of content instantly

---

## 🤖 How GitHub Copilot Was Used

GitHub Copilot was used throughout the entire development process:
- **Code generation** — Copilot suggested the fetch API structure, event listeners, and DOM manipulation code
- **Debugging** — Copilot Chat helped identify and fix API integration errors
- **CSS styling** — Copilot autocompleted the gradient styles and responsive layout
- **Refactoring** — Copilot helped clean up and optimize the JavaScript logic

Without GitHub Copilot, this project would have taken significantly longer to build, especially for a beginner developer.

---

## 🧠 Microsoft IQ Layer Used

### Foundry IQ
StoryForge Copilot integrates the **Foundry IQ** intelligence layer concept by:
- Using grounded AI generation to reduce hallucination in written content
- Structuring prompts to enforce cited, accurate, and coherent outputs
- Connecting AI reasoning to real user intent through tone and content-type selection

---

## ✨ Features

- 4 tone modes: Professional, Casual, Persuasive, Creative
- 4 content types: Blog Post, Short Story, Email, Essay
- One-click Copy to Clipboard
- Clean, responsive UI
- Powered by Groq's ultra-fast LLaMA 3.3 model

## 🚀 How to Run

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/storyforge-copilot.git
```

2. Open the project folder in VS Code

3. Get a free Groq API key from https://console.groq.com

4. In `script.js`, replace `YOUR_GROQ_API_KEY_HERE` with your actual key

5. Right click `index.html` → Open with Live Server

6. Start writing! ✍️
