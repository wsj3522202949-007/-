# AI vs Human Text Detection System 🤖📝

## 📌 Project Overview

This project is a Machine Learning and Natural Language Processing (NLP) based AI system built to distinguish between AI-generated and human-written text.
The system takes text input from users, processes it using text preprocessing and feature extraction techniques, and predicts whether the content was generated by an AI model or written by a human. It provides real-time classification results through an interactive web interface.

## 🚀 Features

🔍 Classifies text as AI-generated or human-written

🧠 Uses NLP techniques and Machine Learning algorithms for text analysis

⚡ Provides real-time predictions with confidence scores

🎤 Supports voice-to-text input for seamless user interaction

📊 Visualizes prediction results and model performance metrics

📂 Modular and scalable architecture

## 🛠️ Tech Stack

Python

Scikit-learn

Pandas

NumPy

TF-IDF Vectorization

Gradio

Speech Recognition

## 📊 Workflow

**Input:** User enters text manually or through voice input

**Text Preprocessing:** Clean and normalize the input text

**Feature Extraction:** Convert text into numerical vectors using TF-IDF

**Model Prediction:** Pass features to trained machine learning models

**Classification:** Determine whether the text is AI-generated or human-written

**Result Display:** Show prediction label and confidence score through the Gradio interface
