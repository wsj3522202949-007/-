# AI Content and Misinformation Detection

## Overview

This FastAPI-based application detects misinformation by analyzing text, images, and verifying facts. It integrates AI-powered models to detect AI-generated content and uses Tavily for fact-checking.

## Features

- **AI-Generated Text Detection**: Identifies whether the input text was generated by an AI model.
- **AI-Generated Image Detection**: Determines if an uploaded image is AI-generated.
- **Fact-Checking with Tavily**: Verifies the authenticity of statements using Tavily's API.
- **FastAPI Framework**: Provides a fast and efficient API backend.

## Technologies Used

- **FastAPI** (Backend API Framework)
- **Mistral AI** (Fact Checking agent)
- **Hugging Face Transformers** (AI-generated image detection)
- **Tavily API** (Fact-checking)
- **Python Libraries**: PIL, Transformers, Requests, Torch
- **Ollama** (For running the agent)
