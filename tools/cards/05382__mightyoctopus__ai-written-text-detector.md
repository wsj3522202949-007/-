## AI Written Text Detector 

This project is a lightweight web application that analyzes whether a given piece of text is likely written by a human or generated by an AI model.

### System Structure
![AI Text Detector System Diagram](https://github.com/mightyoctopus/ai-written-text-detector/blob/main/AI_Text_Detector_System.jpg)
### Overview

The app combines multiple technologies to deliver accurate and explainable results:

* RoBERTa-base (fine-tuned): used as a text classification model for AI-text detection. 
* GPT-5 Mini (LLM): powers the reasoning layer that interprets results and explains why the text is likely AI- or human-written, using an agentic architecture.
* Agentic Frameworks: LangChain, LangGraph 

By combining a robust detection model with an interpretive LLM agent, the system provides not only a probability score but also a natural-language explanation of the decision in a way that results in the most accurate analysis.
