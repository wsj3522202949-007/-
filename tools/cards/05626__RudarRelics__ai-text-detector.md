# AI Text Detector

A machine learning web app that detects whether a piece of text was written by a human or generated by AI.

## How it works
- Uses TF-IDF vectorization (unigrams + bigrams) to extract features from text
- Logistic Regression classifier trained on ~400,000 labeled samples
- Returns a prediction (Human / AI) with a confidence score

## Tech Stack
- Python, Flask, scikit-learn, pandas
- Frontend: HTML, CSS, JavaScript (single page)

## Run locally
pip install -r requirements.txt
python train.py
python app.py

## Project structure
- app.py — Flask web server and UI
- train.py — model training script
- predict.py — prediction logic
- features.py — TF-IDF vectorizer setup
- models/ — saved classifier and vectorizer
- data/ — dataset (not included, download from Kaggle)
