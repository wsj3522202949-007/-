# Universal-AI-PDF-Chatbot
A robust, aesthetic, and universal AI-powered Chatbot built with Streamlit and LangChain. Capable of analyzing any PDF document (novels, technical docs, study notes) using RAG (Retrieval-Augmented Generation). Features include sentiment analysis, dynamic conversational memory, and a custom aesthetic UI. Powered by Llama-3-70B via Groq API.
