# AI Detector

AI Detector is a tool designed to analyze text samples and determine whether they were generated by an AI language model or written by a human. It leverages local LLM capabilities through llama.cpp to perform sophisticated text forensics analysis.

## Features

- **AI Text Forensics Analysis**: Determines if a text sample was generated by an AI or written by a human
- **Structured Output**: Provides detailed analysis with probability scores, classifications, and key indicators
- **Local LLM Integration**: Uses llama.cpp for on-device inference without requiring internet connectivity
- **Cross-platform Support**: Works across multiple operating systems

## How It Works

The tool uses a specialized language model prompt to analyze text for several key indicators:
- Structural patterns (low burstiness, low perplexity)
- Generic transition words and phrasing
- Predictable sentence structures

Based on these indicators, it assigns an AI probability score and classifies the text as:
- **Human**: Low probability of AI generation (probability < 0.4)
- **Highly Suspect**: Mixed probability (0.4 ≤ probability ≤ 0.69)
- **AI**: High probability of AI generation (probability ≥ 0.7)

## Prerequisites

This project requires:
- **llama.cpp**: Local LLM inference engine
- **uv**: Modern Python package manager (used instead of pip)

## Installation

1. Install uv (if not already installed):
   ```bash
   # Install uv using the recommended method
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

2. Install project dependencies using uv:
   ```bash
   uv pip install openai
   ```

3. Ensure llama.cpp server is running on `http://127.0.0.1:8080`

## Usage

The tool can be run directly:
```bash
python main.py
```

This will analyze a sample text and output forensic analysis results including:
- AI probability score
- Classification result
- Confidence score
- Key indicators
- Forensic analysis

## Configuration

The tool is configured to work with a local llama.cpp instance. Make sure your llama.cpp server is running on port 8080 before executing the script.
