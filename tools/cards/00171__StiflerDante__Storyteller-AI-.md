# 📖 Storyteller AI  

## 🌟 Название проекта  
**Storyteller AI** – генератор интерактивных историй с картинками.  

---

## 💡 Основная идея, уникальность, целевая аудитория  
**Идея:** Пользователь делает запрос сказки/истории → модель пишет историю, обогащённую фактами с помощью инструмента wiki → Stable Diffusion генерирует иллюстрацию.  
На выходе получается история + обучающий факт + иллюстрация. 

**Уникальность:**  
- При генерации историй/сказок пишется не просто фантазия, а с фактами из википедии (например о космосе, животных, истории).
- Благодаря предыдущему пункту истории также являются обучающими. 
- Каждая история визуализируется нейросетью (Stable Diffusion).  
- Возможность выбора художественного стиля (аниме, комикс, акварель).  

**Целевая аудитория:**  
- Дети и родители (интерактивные сказки).  
- Учителя (визуализация уроков).  
- Контент-креаторы (истории, иллюстрации к постам).  

---

## ✨ Особенности реализации  
- **Stable Diffusion 3:** создание картинок  
- **Гибкость:** можно менять стиль иллюстраций.  
- **Вывод:** История на экране + картинка  

**Дальнейшие шаги для улучшения:**  
- Добавить озвучку историй (TTS).  
- Интерактивность: выбор направления сюжета (как визуальная новелла).
- Улучшить качество иллюстраций с помощью ControlNet / LoRA.
- "Оживлять" картинки с помощью видео (Wan 2.1)
- Возможность создания аналогии комиксов

---

## 📦 Необходимые библиотеки и ресурсы  
**Python-библиотеки:**  
- `groq` – генерация текста.  
- `python-dotenv` – хранение API-ключей.  
- diffusers + transformers + torch - генерация текста и картинок
-  `gradio` – веб-интерфейс.  
- wikipedia - для поиска и добавления фактов
- langchain - использование агентов и структуры, использование памяти

**Ресурсы:**  
- Groq API (используется модель llama-3.3-70b).  
- Flash Stable Diffusion 3 medium (локально, небольшая модель для демо).  
- Wikipedia (факты для историй).  

---

## ⚙️ Технические особенности  
- **Сбор данных:** открытые источники (Wikipedia).  
- **RAG-пайплайн:** запрос → поиск релевантных фактов → включение фактов в prompt.  
- **Промптинг Техники:**
  - Few shot prompting   
  - Автоматическая генерация промптов для Stable Diffusion.  
- **Хранилища:**  
  - БД на данный момент отсутствуют, используется только память агентов из Langchain

## 🚀 Деплой  
- **Где развернули:** Локально через Gradio interface (просто и бесплатно).  
- **Особенности взаимодействия:**  
  - Пользователь открывает веб-страницу.  
  - Вводит тему → получает историю + иллюстрацию.
## Минимальные требования (для теста / медленной генерации)
- GPU: хотя бы RTX 3060 (6–8 GB VRAM)
- CPU: i5/Ryzen 5 и выше
- RAM: 16 GB
- VRAM: 8 GB (это прям минимум, будет тормозить, лучше 12 GB+)

## Оптимальные требования (чтобы работало быстро)
- GPU: RTX 4070 / 4080 / 4090 (12–24 GB VRAM)
- RAM: 32 GB
- Хранилище: SSD, минимум 20 GB свободно 
- CUDA: версия должна совпадать с PyTorch
