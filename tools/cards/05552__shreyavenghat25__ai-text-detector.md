# AI Text Detector

Estimates whether a piece of text was written by a human or generated by a language model. Combines GPT-2 perplexity with stylometric features (burstiness, vocabulary diversity, function-word ratio, sentence-length variance) and returns an AI probability with a human-readable explanation.

Paste text or upload a `.txt`, `.docx`, or `.pdf` file.

## How it works

The final score is an ensemble of two signals:

- **Perplexity** (weight 0.6) — GPT-2 log-likelihood over the input. Lower perplexity means the text is more predictable to the language model, which leans AI.
- **Burstiness** (weight 0.4) — variance of sentence length. Humans tend to mix short and long sentences; AI output is more uniform.

A trained gradient-boosting classifier (`backend/detector/classifier.py`, trained via `backend/detector/train_classifier.py`) is also run and surfaced in the response for transparency, but it does not contribute to the final score — its output proved too compressed on the HC3-trained model to add signal beyond perplexity + burstiness.

Each verdict ships with a list of rule-based explanations from `backend/detector/explainer.py` (e.g. *"Very low burstiness (0.18) — sentence lengths are unusually uniform"*).

## Project layout

```
backend/
  main.py                 FastAPI app (endpoints: /health, /analyze, /upload)
  detector/
    features.py           Stylometry feature extraction
    perplexity.py         GPT-2 sliding-window perplexity scorer
    classifier.py         Trained stylometry classifier wrapper
    ensemble.py           Combines perplexity + burstiness into final score
    explainer.py          Rule-based natural-language explanations
    extractors.py         .txt / .docx / .pdf text extraction
    train_classifier.py   Trains the gradient-boosting classifier
  data/                   Training dataset (HC3-derived)
  models/classifier.pkl   Trained model artifact
frontend/                 Vite + React + Tailwind UI
```

## Running locally

### Backend

Requires Python 3.10+.

```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r ../requirements.txt

# First run downloads the GPT-2 weights (~500 MB)
uvicorn main:app --reload --port 8000
```

NLTK tokenizers need to be available the first time you run feature extraction:

```bash
python -c "import nltk; nltk.download('punkt'); nltk.download('punkt_tab')"
```

### Frontend

Requires Node 18+.

```bash
cd frontend
npm install
npm run dev
```

The UI expects the backend at `http://localhost:8000` (configured in `frontend/src/App.jsx`).

## API

### `POST /analyze`

```json
{ "text": "..." }
```

Returns `ai_probability`, `human_probability`, `confidence`, `perplexity`, the raw `features` object, the per-signal `components`, and an `explanation` list. Requires at least 20 words.

### `POST /upload`

`multipart/form-data` with a `file` field. Supports `.txt`, `.docx`, `.pdf` up to 5 MB. Same response shape as `/analyze`, plus `extracted_text` and `filename`.

### `GET /health`

Health check.

## Retraining the classifier

```bash
cd backend
python detector/train_classifier.py
```

Reads `backend/data/dataset.csv` (columns: `text`, `label` where 0 = human, 1 = AI) and writes `backend/models/classifier.pkl`.

## Caveats

- Perplexity scoring with GPT-2 is the slow path (~0.5-2 s per analysis on CPU, faster on Apple Silicon MPS).
- The detector is best-effort. No statistical detector is reliable on short text, paraphrased AI output, or text from models very different from GPT-2.
