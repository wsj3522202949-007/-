# CreatorFlow

CreatorFlow is an AI-powered Creator Operating System that unifies writing, content creation, collaboration, and workflow automation into a single intelligent workspace.

## Vision

To build the world’s most powerful AI-native operating system for creators, teams, and digital businesses.

## Status

Early-stage development (Phase 0: Foundation Setup)

## Core Philosophy

- AI-first design
- Modular architecture
- Scalable from solo creators to enterprises
- Single unified creative workspace

## Structure

- `docs/` → System documentation (PRD, architecture, design)
- `frontend/` → Web application (UI)
- `backend/` → API and services
- `database/` → Supabase schema and migrations
- `infra/` → Deployment and DevOps
- `prompts/` → AI agent prompts and workflows
- `assets/` → Images, diagrams, and design resources
