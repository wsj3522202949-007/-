# 🤖 AI Text Detector

A sleek, single-file AI text detection web app with a glassmorphism UI, dark/light theme toggle, and real-time analysis — powered by the BK9 AI Detection API.

> Built by **Jithula Bhasitha** for [Bit X Tools](https://bit-x-tools.vercel.app)

---

## ✨ Features

- 🔍 **AI Detection** — Analyze text to detect if it was written by a human or generated by AI
- 📊 **Confidence Score** — Get a detailed percentage breakdown of human vs AI content
- 🌙 / ☀️ **Dark & Light Theme** — Toggle with a beautiful animated switch; preference saved in `localStorage`
- 📋 **Clipboard Copy** — Copy the detection results to your clipboard with one click
- ⚡ **Single File** — Entire app lives in one `index.html` — no build tools, no dependencies to install
- 📱 **Fully Responsive** — Works great on desktop, tablet, and mobile

## 📁 Project Structure

Since the entire app is bundled into one file, the internal structure is:

```
index.html
├── <head>
│   ├── Font Awesome CDN
│   └── Google Fonts CDN
├── <style>
│   ├── CSS variables (dark/light themes)
│   ├── Glassmorphism component styles
│   └── Responsive breakpoints
├── <body>
│   ├── Navbar (logo + back button + theme toggle)
│   ├── Hero section (title + description)
│   ├── Detector card
│   │   ├── Input textarea (min 25 chars)
│   │   ├── Result display (score circle + status)
│   │   └── Action icons (clear, paste, copy)
│   ├── Features grid
│   └── Footer
└── <script>
    ├── Theme toggle + localStorage persistence
    ├── Input handling (char/word count)
    ├── BK9 API fetch + error handling
    └── Copy & paste handlers
```

---

## 🌐 API Reference

This project uses the [BK9 AI Detection API](https://api.bk9.dev/).

```
GET https://api.bk9.dev/tools/txtdetect?q={text}
```

The API returns a detailed analysis including human percentage, AI word count, and feedback messages.

## 🐛 Known Limitations

- Detection accuracy improves with longer text (minimum 25 characters recommended)
- AI detection is probabilistic and may occasionally produce false positives or negatives
- API availability depends on the BK9 service status
