# 📰 AI Fake News Detection System

An AI-powered web application that helps users identify whether a news article is **Real** or **Fake**. The system analyzes the text and provides a prediction along with a confidence score using Machine Learning and Natural Language Processing (NLP) concepts.

---

## 📌 Features

* 📰 Fake News Detection
* 🤖 AI-Based Text Analysis
* 📊 Confidence Score Display
* 🔍 News Content Verification
* 📱 Responsive Design
* 🎨 Modern User Interface

---

## 💡 How It Works

1. Enter or paste a news article.
2. Click the **Analyze News** button.
3. The system analyzes the text.
4. It predicts whether the news is Real or Fake.
5. A confidence score is displayed.
