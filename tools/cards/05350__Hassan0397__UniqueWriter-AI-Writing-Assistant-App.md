# UniqueWriter – AI Writing Assistant App (UI/UX Project)

**UniqueWriter** is a mobile UI/UX design project showcasing an AI-powered writing assistant. It helps users **paraphrase text, check grammar, detect AI-generated content, and improve writing quality** through smart tools and an integrated keyboard assistant.

This repository contains all screens exported from the design file.

---

## 📂 Screens Included (Based on PDF)

### 🏠 Home
- Main home screen (Paraphraser)  
- Paste text area  
- “Try Sample Text”  
- Tool mode options: Standard, Fluency, Academic, Humanize  
- Language selector  
- Tools navigation: Paraphraser / Grammar Checker / AI Detector  

### 📝 Paraphraser
- Paraphrase input screen  
- Paraphrased output screen  
- Sample text preview  
- “Next” step screen  

### 🧹 Grammar Checker
- Grammar check input  
- Grammar-correction result  
- “Fix all errors” screen  

### 🤖 AI Detector
- AI detection input screen  
- AI detection result interface  

### 🛠 Tools
- Tools dashboard  
- Tools quick selection  
- English (UK) / English (US) options  

### ⚙️ Settings
- Main settings page  
- Enable Assistant / Enable Keyboard  
- Language selection  
- “Access app anywhere you go”  
- Assistant overview page  
- Keyboard overview page  

### 👤 Account
- Login screen  
- User Profile  
- User ID  
- Change name, password, profile image  
- Premium plans  
- Accounts & Security (PIN / Fingerprint)  
- Help (FAQs, tutorials, live chat)  

### ⌨️ Keyboard Assistant
- UW keyboard interface  
- Grammar checking & Paraphrasing from keyboard  
- “Back to keyboard” screen  
- Writing prompt screen (“Early awaiting your words…”)
