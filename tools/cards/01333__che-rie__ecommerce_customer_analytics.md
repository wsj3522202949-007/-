# E-commerce Customer Analytics Dashboard

## 📌 Project Overview
This project analyzes customer behavior, segmentation, and revenue patterns using an e-commerce transactional dataset. The workflow covers data preparation, cleaning, analysis, and dashboard creation.

## 🔄 Project Workflow
1. Data was downloaded in Excel format
2. Initial cleaning was performed in Excel (removing formatting issues such as commas)
3. Data was imported into SQL Server
4. Data cleaning and transformation were performed in SQL
5. Analytical queries were executed to extract insights
6. Cleaned data was imported into Power BI
7. Data modeling and calculations were created in Power BI
8. Interactive dashboards were built for visualization

## 🛠️ Tools Used
- Excel (Initial raw data preparation)
- SQL Server (Data cleaning & analysis)
- Power BI (Data visualization & dashboard)
- PDF (Data explanation)

## 🔍 Key Analysis
- Customer Segmentation (VIP, High, Medium, Low)
- Repeat vs One-time Customers
- Customer Status (Active, At Risk, Churned)
- Monthly Revenue Trends

## 📈 Key Insights
- Repeat customers generate the majority of revenue
- Most customers fall into the low-value segment
- A significant number of customers are at risk or churned
- Revenue shows strong seasonal trends, peaking toward the end of the year

## 💡 Recommendations
- Focus on retaining repeat customers through loyalty programs
- Re-engage at-risk customers with targeted marketing campaigns
- Develop strategies to convert low-value customers into higher-value segments
- Align marketing efforts with peak revenue periods
