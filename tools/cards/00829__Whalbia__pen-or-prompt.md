# Pen or Prompt

A real-time multiplayer party game where players write answers to prompts and everyone votes on which responses were written by AI or by humans.

**Live:** [penorprompt.com](https://penorprompt.com)

## Tech Stack

- React, TypeScript
- Node.js, Express
- Socket.IO (WebSockets)
- Redis (state management)
- Zod (input validation)
