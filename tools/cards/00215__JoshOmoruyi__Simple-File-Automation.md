Simple File Automation

Automate and organize your files effortlessly using Python.

Overview

I created this project to clean up my computer, mainly school notes, images, and various music/audio files etc, and automatically sort them into their proper folders.
This lightweight Python script uses the shutil module to move and organize files quickly and reliably.

Features
	•	Automatically organizes files based on type or extension
	•	Simple and easy to customize
	•	Uses Python’s built-in shutil module
	•	Great for cleaning messy directories

Technologies Used
	•	Python 3
	•	shutil module

Learn more about shutil:
https://www.geeksforgeeks.org/shutil-module-in-python/

Video Reference

YouTube tutorial I used as inspiration:
https://www.youtube.com/watch?v=gs0FNQR0njI

Usage
	1.	Clone the repository
	2.	Adjust file paths in the script to match your directories
	3.	Run the script and watch your files organize themselves
