## Project Background

AI product roles require more than knowing AI tools. A strong candidate needs to translate user problems into product requirements, define a small MVP, evaluate competitors, and communicate clearly with technical and non-technical stakeholders.

## Problem I Solved

I wanted a reusable toolkit that helps me move from an idea to a structured product case study quickly while keeping assumptions visible and testable.

## Tools & Tech Stack

- ChatGPT / Claude / Gemini for research support and structured drafting.
- Markdown for PRD and case-study templates.
- Canva for visual product narratives.
- GitHub for versioned product documentation.

## Core Features

- PRD template.
- Competitor analysis template.
- User persona and user journey template.
- MVP prioritization matrix.
- Prompt workflow library.
- Product metric checklist.

## Project Highlights

- Designed for AI product internship interviews and portfolio cases.
- Keeps each AI-generated draft tied to a human decision checkpoint.
- Connects user needs, data signals, and product features.

## Data / AI / Product Thinking

- Data thinking: metric selection, success criteria, experiment design.
- AI thinking: prompt workflows for research, synthesis, and documentation.
- Product thinking: prioritization, user journey, MVP scope, risk framing.

## Outcome

This repository functions as a reusable product management workspace for building AI-related case studies and MVP proposals.
