🍕 Pizza Sales Analysis Project
Welcome to the Pizza Sales Analysis Project! This project provides detailed insights into pizza sales using tools like Excel, Power BI, and SQL. It covers everything from data cleaning to interactive dashboards — perfect for understanding customer preferences and business trends in the food industry.

📌 Project Overview
This project analyzes sales data from a fictional pizza restaurant. It includes:

📊 Sales trends by pizza type, size, and category

🕒 Time-based analysis (monthly, weekly, hourly)

🧀 Most & least popular pizzas

🎯 Insights to help improve sales and inventory decisions

🚀 Tools & Technologies Used
Microsoft Excel – Data cleaning & preliminary analysis

Power BI – Interactive dashboards & visual storytelling

SQL – Data queries and aggregations

📁 Files Included
Pizza_Sales_Dashboard.pbix – Power BI dashboard

Pizza_Sales_Cleaned.xlsx – Cleaned dataset

Pizza_Sales_Report.pdf – Project presentation/report

README.md – Project documentation
