# smart-tone

SmartTone is a smart writing assistant that helps users write better messages in just a few seconds. The goal is not to be a chatbot like ChatGPT, but rather a tool specialized in text transformation. The user pastes some text, chooses what they want to do, and SmartTone returns an improved version.
