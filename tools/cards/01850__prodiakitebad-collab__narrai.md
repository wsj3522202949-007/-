# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/3fba6df0-653a-49e9-8065-80d25b0aed65

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](https://github.com/prodiakitebad-collab/narrai/blob/main/.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
