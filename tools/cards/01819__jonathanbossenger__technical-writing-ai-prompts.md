# Technical Writing AI Prompts

A collection of AI prompts designed for creating technical educational content, including developer tutorials and instructional videos.

## Contents

This repository contains specialized prompts for generating high-quality technical content:

### 📝 [Senior Technical Writer Prompt](https://github.com/jonathanbossenger/technical-writing-ai-prompts/blob/main/senior-technical-writer-prompt.md)
A comprehensive prompt for generating developer-focused blog posts and written tutorials. Features:
- Step-by-step technical workflows
- Multi-platform instructions (macOS, Linux, Windows)
- Conversational, friendly tone
- Contextual explanations and best practices
- Security considerations and troubleshooting guidance

### 🎥 [Developer Educator Prompt](https://github.com/jonathanbossenger/technical-writing-ai-prompts/blob/main/developer-educator-prompt.md)
A specialized prompt for creating video tutorial scripts. Includes:
- Structured video script format
- Learning objectives and engagement strategies
- Platform-specific instructions
- User experience tips and troubleshooting
- Call-to-action and viewer engagement elements

## Usage

These prompts are designed to be used with AI language models to generate consistent, high-quality technical educational content. Simply:

1. Choose the appropriate prompt for your content type
2. Fill in the placeholders with your specific topic and requirements
3. Use with your preferred AI model to generate structured content

## Features

Both prompts emphasize:
- **Accessibility**: Content suitable for varying technical backgrounds
- **Completeness**: Comprehensive coverage with official documentation references
- **Clarity**: Well-structured, logical flow with clear explanations
- **Practicality**: Real-world examples and troubleshooting guidance
