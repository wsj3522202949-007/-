# 🤖 AI Text Detector

A web application that detects whether text is written by humans or generated by AI. Built with **RoBERTa**, **PyTorch**, and **Streamlit**.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Python](https://img.shields.io/badge/python-3.8+-green.svg)
![Streamlit](https://img.shields.io/badge/streamlit-1.28+-red.svg)

🔗 **Live Demo:** [https://ai-text-detector-vbhgwftvzeydeo6iffpq7m.streamlit.app](https://ai-text-detector-vbhgwftvzeydeo6iffpq7m.streamlit.app)

## 🚀 Quick Start

### **1. Clone Repository**
```bash
git clone https://github.com/TutulMajumder/ai-text-detector.git
cd ai-text-detector
```

### **2. Create Virtual Environment**

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**
```bash
python -m venv venv
source venv/bin/activate
```

### **3. Download Dataset**

Download from Kaggle: [Human vs AI Text Classification Dataset](https://www.kaggle.com/datasets/aknjit/human-vs-ai-text-classification-dataset)

Steps:
1. Go to the Kaggle link above
2. Download `your_dataset_5000.csv`
3. Create `DataSet/` folder in project root
4. Extract file into `DataSet/` folder
5. Rename to `Ai_vs_Human_generated_text.csv`

### **4. Install Dependencies**
```bash
pip install -r requirements.txt
```

### **5. Run the App**
```bash
streamlit run app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

## 🏗️ Architecture

```
Text Input
    ↓
Preprocessing (lowercase, remove punctuation)
    ↓
Tokenization (RoBERTa tokenizer)
    ↓
Model Inference (Fine-tuned RoBERTa)
    ↓
Classification (Human: 0, AI: 1)
    ↓
Display Results with Confidence Scores
```

## 📊 Model Details

| Aspect | Details |
|--------|---------|
| **Base Model** | RoBERTa (Robustly Optimized BERT) |
| **Task** | Binary Text Classification |
| **Classes** | Human-written (0), AI-generated (1) |
| **Max Length** | 512 tokens |
| **Accuracy** | ~95% on test set |
| **Framework** | PyTorch + Hugging Face Transformers |
| **Model Hub** | [SNEvernia/ai-text-detector](https://huggingface.co/SNEvernia/ai-text-detector) |

## 🐛 Troubleshooting

### **App won't start**
```bash
# Reinstall dependencies
pip install -r requirements.txt --force-reinstall
```

### **Model not found**
```bash
# Ensure roberta_finetuned_model folder exists in project root
ls roberta_finetuned_model/
```

### **Slow predictions**
- First prediction takes 30 seconds (model loading)
- Subsequent predictions are instant (caching)
- Use GPU for faster inference (if available)

### **Memory issues**
```bash
# Reduce batch processing
# Modify app.py to process shorter text chunks
```
