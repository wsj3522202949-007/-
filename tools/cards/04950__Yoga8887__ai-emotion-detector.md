# 🤖 AI Emotion Detector

## Overview

AI Emotion Detector is a web application built using Python, Flask, HTML, CSS, JavaScript, OpenCV, and DeepFace.

The application uses a webcam to capture a user's face and predicts the emotion shown in the image.

---

## Features

* Live webcam access
* Emotion detection using AI
* Modern user interface
* Real-time analysis
* Displays detected emotion

---

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
* OpenCV
* DeepFace

## How It Works

1. Open the application.
2. Allow webcam access.
3. Click the **Analyze Emotion** button.
4. The image is captured from the webcam.
5. DeepFace analyzes the facial expression.
6. The detected emotion is displayed on the screen.
