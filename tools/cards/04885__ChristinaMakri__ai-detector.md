# AI Text Detector

A web app that analyzes text and estimates whether it was written by a human or generated by an AI.

## How it works

The detector combines two signals:

**Heuristics (55% weight)**
- **Burstiness** — LLMs produce uniformly-lengthed sentences; humans vary more
- **Lexical diversity** — type-token ratio; LLMs tend to be slightly more repetitive
- **Cliché density** — detects common AI phrases like *"it's important to note"*, *"delve into"*, etc.
- **Structural uniformity** — LLMs produce suspiciously balanced paragraphs
- **Punctuation diversity** — humans use more varied punctuation (dashes, ellipses, semicolons)

**Perplexity (45% weight)**
- Runs the text through GPT-2 and measures how "surprising" it is
- LLM-generated text has low perplexity (predictable); human text scores higher

The final score is a weighted average. Scores ≥ 0.7 → *Likely AI-generated*, ≤ 0.45 → *Likely Human-written*, in between → *Uncertain*.

## Getting started

### Backend

```bash
cd backend
pip install -r requirements.txt
python -m spacy download en_core_web_sm
uvicorn main:app --reload
```

The API will be available at `http://localhost:8000`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.

## API

**POST** `/analyze`

Request body:
```json
{ "text": "Your text here (50–5000 characters)" }
```

Response:
```json
{
  "ai_probability": 0.82,
  "verdict": "Likely AI-generated",
  "confidence": "High",
  "perplexity": { "raw": 15.4, "ai_score": 1.0 },
  "heuristics": {
    "raw": { "burstiness": 0.12, "lexical_diversity": 0.48, ... },
    "ai_signals": { ... },
    "heuristic_ai_score": 0.67
  }
}
```
