# Deepak AI Writing Studio

Deepak AI Writing Studio is a personalized AI-powered writing assistant built with Next.js and the OpenAI API. It helps you transform a short idea into a fully fledged blog outline or draft in seconds.

## ✨ Features

- Tailored copywriting flow with a clean prompt-to-draft interface
- Serverless API route connected to OpenAI for content generation
- Responsive layout optimized for fast ideation sessions

## 🚀 Getting Started

### Prerequisites

- Node.js 16+
- An OpenAI API key

### Installation

```bash
npm install
```

Create an `.env.local` file in the project root and add your key:

```env
OPENAI_API_KEY=your-openai-key
```

Run the development server:

```bash
npm run dev
```

Visit `http://localhost:3000` to start creating drafts.

## 🛠️ Tech Stack

- Next.js 13
- React 18
- OpenAI API
