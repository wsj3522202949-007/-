# 🤖 AI Detector & Humanizer

> **Detect AI-generated content and make it sound more human!**

## 🎯 What This Project Does

This tool helps you:
- 🔍 **Detect** if text was written by AI (like ChatGPT, Claude, etc.)
- ✍️ **Humanize** AI text to make it sound more natural and human-like
- 📊 **Analyze** text patterns and provide feedback

## 🚀 Features

| Feature | Description |
|---------|-------------|
| **AI Detection** | Analyzes text patterns to identify AI-generated content |
| **Text Humanization** | Rewords AI text to sound more natural |
| **Confidence Score** | Shows how confident the detection is |
| **Simple Interface** | Easy to use with clear results |

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/ORANGE14-11/ai-detector-humanizer.git
cd ai-detector-humanizer
2. Create a virtual environment

bash
# On Mac/Linux
python3 -m venv venv
source venv/bin/activate

# On Windows
python -m venv venv
venv\Scripts\activate
3. Install dependencies

bash
pip install -r requirements.txt
4. Run the app

bash
python app.py
5. Open in browser

Go to: http://localhost:5000
