# 🧠 AI-Based Plagiarism Detector using NLP

A powerful **Streamlit web app** that detects plagiarism and text similarity using **Natural Language Processing (NLP)** and **Machine Learning techniques**.  
It analyzes uploaded documents, compares content similarity, and provides interactive visual results with **Plotly charts**.

---

## 🚀 Features

- 🔍 Detects plagiarism using **cosine similarity** between documents  
- 🌐 Can also search for content similarity via **Google Search API**  
- 📄 Supports `.txt`, `.pdf`, and `.docx` file formats  
- 📊 Interactive similarity visualization using **Plotly**  
- 🧩 Uses **NLTK**, **BeautifulSoup**, and **Scikit-learn** for text analysis  
- 🧠 Built with **Streamlit** for an intuitive web interface
