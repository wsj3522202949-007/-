# Smart Speech Assistant 🎤

一個智能致詞稿產生器，專為企業活動和協作場景設計。

![Smart Speech Assistant](https://img.shields.io/badge/version-v1.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 🌟 Live Demo

👉 **[立即使用 Smart Speech Assistant](https://sirenfychen.github.io/smart-speech-assistant)**

## ✨ 功能特色

- 📋 **智能引導**：三步驟完成致詞稿撰寫
- 🎯 **多種風格**：正式專業、溫馨親切、激勵人心、輕鬆幽默
- 💾 **草稿功能**：儲存進度，隨時繼續編輯
- 🔗 **協作分享**：一鍵產生分享連結，支援團隊協作
- 📱 **響應式設計**：電腦、平板、手機都能完美使用
- 📄 **Google整合**：直接匯出到Google文件

## 💡 專案背景

這個專案源於實際工作痛點：
- 主管經常需要在各種活動上致詞
- 活動負責人需要協助準備適合的內容
- 傳統方式效率低，容易出錯
- 缺乏有效的協作機制

因此開發了這個工具來優化整個工作流程。

## 🎯 適用場景

- 🏢 **企業內部會議**開場致詞
- 🚀 **產品發表會**主題演講
- 🏆 **頒獎典禮**致詞與感謝
- 🎉 **年終聚餐**溫馨致詞
- 📚 **教育訓練**開場引言
- 🤝 **客戶活動**歡迎致詞

## 🛠️ 技術架構

- **前端**：Pure HTML5 + CSS3 + Vanilla JavaScript
- **儲存**：LocalStorage + URL-based sharing
- **設計**：Mobile-first responsive design
- **部署**：GitHub Pages static hosting
- **協作**：URL參數傳遞草稿數據

### 核心技術亮點
- ✅ 無外部依賴，純原生技術
- ✅ 客戶端資料處理，保護隱私
- ✅ Base64編碼實現資料分享
- ✅ 動態表單生成與驗證

## 🚀 使用方式

### 活動負責人工作流程：
1. 填寫活動基本資訊
2. 設定重要來賓和亮點
3. 點擊「儲存草稿」
4. 點擊「分享草稿」產生連結
5. 將連結和自動生成的郵件範本發送給主管

### 主管使用流程：
1. 點擊分享連結，自動載入草稿
2. 調整致詞風格和內容
3. 在編輯區進行個人化修改
4. 複製使用或匯出到Google文件
