# Python-Driven-User-Interface-for-SQL-
A Python-Driven Streamlit UI integrated with MySQL, enabling non-technical users to manage inventory, sales, and operations without writing SQL. Combines advanced SQL (views, procedures, functions) with real-time dashboards, bridging backend logic and business insights through an interactive analytics tool.

# Python-Driven UI for Database Operations

## 📌 Project Vision
This project demonstrates how to build a **real-world inventory and supply chain management dashboard** by combining:
- **SQL (backend)**: advanced database operations with views, stored procedures, and functions  
- **Python (frontend)**: a Streamlit-powered interface for non-technical users  
- **Business relevance**: systems similar to those used in inventory, sales, and operations management  

The goal is to make complex database operations accessible to managers and team leads who don’t know SQL, while showcasing how backend and frontend layers work together in real-world applications.

---

## 🎯 Key Features
- **Basic Information Dashboard**: Displays key inventory metrics and detailed tables directly from the database.  
- **Operational Tasks**:  
  - Add new products with category, supplier, and stock details  
  - View product inventory history  
  - Place reorders with quantity tracking  
  - Mark reorders as received to update stock levels  
- **Streamlit UI**: Intuitive, interactive interface for non-technical users.  
- **SQL Integration**: Uses stored procedures, views, and functions for robust backend operations.  

---

## 🛠️ Skills Demonstrated
- Writing and using **advanced SQL** (procedures, views, functions)  
- Connecting **MySQL to Python** for seamless data flow  
- Building a **real-time Streamlit UI** for interactive dashboards  
- Creating apps that mimic **company-style tools** used in inventory and operations  
- Ensuring **backend and frontend integration** for smooth workflows  

---

## 📌 4 Strong Pointers
- **Designed and implemented advanced SQL operations** (views, stored procedures, functions) to manage inventory and supply chain workflows.  
- **Built a Streamlit-powered dashboard** that enables non-technical users to interact with MySQL databases without writing SQL queries.  
- **Developed multi-layered application workflows** (inventory, sales, operations) showcasing real-world business system design.  
- **Integrated backend SQL logic with Python frontend** to deliver a seamless, real-time analytics and management tool.
