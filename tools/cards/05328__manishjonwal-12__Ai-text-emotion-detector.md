# Text Emotion Detection using BERT

This project uses a pre-trained BERT model to detect emotions from text input. It provides a simple Streamlit web interface to test the emotion detection.

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Example

Input: `I am so happy today!`  
Output: `Predicted Emotion: joy`
