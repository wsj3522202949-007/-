# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/67c42918-6ada-4335-9f31-a2388206bda7

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](https://github.com/Royalbulls/rba-advisor-knowledge-hub/tree/main/.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
