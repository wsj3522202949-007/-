# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/6a161b20-c926-437b-b007-267dceaf126f

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](https://github.com/mondayadamu837-source/NovelIP-/blob/main/.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
