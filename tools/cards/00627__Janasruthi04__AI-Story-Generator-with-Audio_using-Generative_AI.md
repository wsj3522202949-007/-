# AI-Story-Generator-with-Audio_using-Generative_AI
Built a Streamlit app using Generative AI to create customizable themed stories,  convert them into narrated MP3s, and export as PDFs with sleek UI/UX. | Skills: HuggingFace, GPT-2, gTTS, PyTorch.
AI Story Generator with Audio

A Streamlit app that leverages Generative AI to create customizable themed stories, convert them into narrated MP3s, and export them as PDFs. The app features a sleek and user-friendly interface.

Features
Generate themed stories using AI (GPT-2 model)
Convert stories into audio narration using gTTS
Export stories as PDF files
Sleek and interactive Streamlit UI/UX
Fully customizable story themes and titles

Tech Stack / Skills
Python
Streamlit – for the web app interface
HuggingFace – GPT-2 model for story generation
PyTorch – backend for GPT-2
gTTS (Google Text-to-Speech) – for audio narration
PDF export – export generated stories
UI/UX design – clean, interactive interface

Installation
Clone the repository:
git clone https://github.com/your-username/AI-Story-Generator-with-Audio.git
cd AI-Story-Generator-with-Audio

Create a virtual environment (optional but recommended):
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

Install dependencies:
pip install -r requirements.txt
Usage
Run the Streamlit app:
streamlit run app.py

Open the app in your browser (usually at http://localhost:8501).
Steps in the app:

Choose a story theme
Provide a story title or keywords
Click Generate Story
Listen to the story via MP3 narration
Export the story as PDF
