## Project Overview
Six tasks demonstrating AI prompt engineering skills including email writing, resume improvement, SQL queries, report writing, data analysis, and fact-checking.

1. **Email Writing** - Professional extension request
2. **Resume Improvement** - Professional resume line enhancement
3. **SQL Query** - Sales analysis query
4. **Report Writing** - AI in education summary
5. **Data Analysis** - Budget analysis insights
6. **Fact Checking** - AI job replacement analysis

## Tools Used

- Clear prompts produce better AI responses
- AI-generated content needs verification
- Learned practical prompt engineering techniques
