AI Text and Human Text Detector

This project is a web-based application that detects whether a given piece of 
text is generated by artificial intelligence or written by a human. It uses a machine learning model 
trained on a labeled dataset and provides a prediction along with a confidence score.
The system is built using Python, Flask, and basic web technologies.

Project Overview

The application allows users to input any text through a web interface. Once submitted, 
the backend processes the text, applies preprocessing, converts it into numerical features 
using TF-IDF vectorization, and then feeds it into a trained Logistic Regression model. 
The output is displayed as either AI Generated Text or Human Written Text along with a 
percentage indicating confidence.

Files in the Project

app.py
This is the main Flask application file. It loads the trained machine learning model and 
vectorizer, handles user requests, processes input text, and returns predictions to the frontend.

index.html
This file contains the user interface of the application. It includes a text area for input, 
a button to trigger detection, and a section to display results. It also contains styling 
for a modern UI appearance.

train_model.py
This script is used to train the machine learning model. It reads the dataset, cleans the text, 
converts it into TF-IDF features, trains a Logistic Regression classifier, evaluates its performance, 
and saves the trained model and vectorizer as pickle files.

model.pkl
Serialized trained machine learning model used for prediction.

vectorizer.pkl
Serialized TF-IDF vectorizer used to transform input text into numerical features.

ai_human_dataset_10k.csv
Dataset used for training the model. It contains text samples labeled as AI-generated or human-written.

How the System Works

Step 1
User enters text into the web interface.

Step 2
The text is sent to the Flask backend via a POST request.

Step 3
The backend cleans the text by converting it to lowercase and removing non-alphabetic characters.

Step 4
The cleaned text is transformed into numerical format using the TF-IDF vectorizer.

Step 5
The trained Logistic Regression model predicts whether the text is AI-generated or human-written.

Step 6
The model also calculates probability scores, and the highest probability is used as the confidence level.

Step 7
The result is displayed on the web page.

Installation and Setup

Step 1
Install Python (version 3.7 or above recommended).

Step 2
Install required libraries using pip:

pip install flask scikit-learn pandas numpy

Step 3
Ensure all project files are in the same directory, including model.pkl and vectorizer.pkl.

Step 4
Run the Flask application:

python app.py

Step 5
Open a browser and go to:

http://127.0.0.1:5000/

Training the Model

To retrain the model or use a different dataset:

Step 1
Place your dataset file in the project directory.

Step 2
Ensure the dataset has at least two columns: text and label.

Step 3
Run the training script:

python train_model.py

Step 4
After training, new model.pkl and vectorizer.pkl files will be generated.

Model Details

Algorithm
Logistic Regression

Feature Extraction
TF-IDF Vectorizer with up to 5000 features and n-grams (unigrams and bigrams)

Text Preprocessing
Lowercasing and removal of special characters

Train-Test Split
75 percent training and 25 percent testing with stratification

Evaluation Metrics
Accuracy score and classification report including precision, recall, and F1-score

Key Features

Simple and user-friendly web interface
Real-time prediction
Confidence score display
Lightweight and fast model
Easy to retrain with new data

Limitations

Accuracy depends on the quality and size of the dataset
May not perform well on very short or highly complex text
Cannot guarantee 100 percent correctness
Sensitive to writing styles and patterns in training data

Future Improvements

Use advanced models like neural networks or transformers
Improve dataset diversity for better accuracy
Add support for multiple languages

Conclusion

This project demonstrates how machine learning can be applied to classify text as AI-generated 
or human-written. It combines natural language processing techniques with a simple web interface, 
making it easy to use and extend for further development.
