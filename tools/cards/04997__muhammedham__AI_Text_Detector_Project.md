# AI vs Human Text Classification Web Application 🤖✍️

## 📌 Project Overview
An end-to-end Machine Learning project developed by Software Engineering students to detect and classify text as either human-written or AI-generated using engineered linguistic features.

## 📂 Repository Structure & File Guide

- **`Project_Analysis_and_Graphs.ipynb`**: Comprehensive project report, model comparison metrics, and performance visualization charts.
- **`System_Interface_and_Database.ipynb`**: Core application runtime environments, cleaned database workflows, and primary system interface setup.
- **`01_Feature_Extraction.py`**: Dedicated script handling the core feature engineering and NLP linguistic metrics extraction.
- **`02_Model_Visualizations.py`**: Focused module containing statistical plots and data distribution graphs.
- **`03_Operational_Interface.py`**: The live operational application interface and execution codebase.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** scikit-learn, pandas, numpy, matplotlib, seaborn
- **Models Evaluated:** Logistic Regression, Random Forest, Decision Trees, SVM, Gradient Boosting.
