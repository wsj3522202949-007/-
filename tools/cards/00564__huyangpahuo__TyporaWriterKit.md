# TyporaWriterKit
This is a writing assistant tool designed for Typora. It helps you quickly change font colors and insert custom YAML front matter, reducing repetitive work and improving writing efficiency. It is especially useful for creators using static site generators such as Hexo and Astro.

Hello everyone! 👋

Some time ago, I created a tool called FontColorChange, which makes it very easy to change font colors in Typora. I’m not sure how many of you have used it, but while writing posts for my personal blog with Hexo and Astro, I often found myself repeatedly typing YAML front matter, which quickly became tedious and inefficient.

Because of this, I decided to make a major upgrade based on FontColorChange. This new version combines custom YAML front matter insertion with font color editing, and also comes with a redesigned and improved interface. The result is a tool that is both visually pleasing and much more comfortable to use. I truly hope you enjoy it!

P.S. This tool is the result of more than 10 iterations on top of the most stable and practical FontColorChange v5. With the help of Gemini 3 Pro, I was also able to fix several long-standing bugs along the way. 🎉

Since this tool was created purely for writing, feel free to let me know your needs or suggestions in the Issues section.

Happy writing! 😃🎉
