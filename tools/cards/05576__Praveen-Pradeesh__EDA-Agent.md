An intelligent, dataset‑agnostic Exploratory Data Analysis agent powered by LLM tool‑calling. The system automates the entire EDA workflow by invoking modular Python tools for profiling, statistics, null and outlier detection, date parsing and correlation analysis . It also generates a full suite of Plotly visualizations, including distributions, heatmaps, categorical summaries, trends, and segment analysis.

After collecting all tool outputs, the agent produces a structured, consultant‑grade EDA report with an executive summary, key insights, deeper hypotheses, a narrative data story, limitations, and actionable recommendations. Designed for reliability, modularity, and dataset‑agnostic operation, this project demonstrates practical LLM orchestration, clean tool design, and automated analytical reasoning.
