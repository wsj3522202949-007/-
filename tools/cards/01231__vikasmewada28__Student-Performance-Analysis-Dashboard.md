# Student-Performance-Analysis-Dashboard
An interactive Power BI dashboard for analyzing student academic performance using reading, writing, and math scores. Features insights by gender, ethnicity, parental education, and test preparation status with KPI cards and visual analytics to identify trends, compare groups, and support data-driven educational decisions.
