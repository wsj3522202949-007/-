# AI-Generated Phishing Detector with AI Text Awareness



## Overview



This project detects phishing emails using Machine Learning and Natural Language Processing (NLP).



The system uses:



- TF-IDF Vectorization

- Logistic Regression

- AI Text Awareness

- Risk Scoring

- Explainable Detection

- Streamlit Dashboard



## Features



- Phishing Email Detection

- AI Text Awareness

- Risk Scoring

- Security Recommendations

- Explainable Detection



## Technologies Used



- Python

- Scikit-learn

- Pandas

- NumPy

- Streamlit



## Model Performance



Accuracy: 97.1%



## Project Workflow



Email Input → TF-IDF → Logistic Regression → AI Text Awareness → Risk Scoring → Dashboard Output
