# 🎭 AI Story Generator



A beautiful, modern web application that generates creative stories using Google Gemini AI. Create engaging short stories with customizable genres, tones, and writing styles.



![AI Story Generator](https://img.shields.io/badge/AI-Story%20Generator-blue?style=for-the-badge&logo=openai)

## ✨ Features



- **🤖 AI-Powered Story Generation**: Uses Google Gemini AI for high-quality story creation

- **🎨 Beautiful Modern UI**: Responsive design with gradient backgrounds and smooth animations

- **📚 Genre Selection**: Choose from Fantasy, Sci-Fi, Mystery, Romance, Horror, and more

- **🎭 Tone Customization**: Select from Funny, Serious, Dark, Romantic, and other tones

- **✍️ Writing Style Options**: Descriptive, Dialogue-heavy, Action-packed, Poetic, and more

- **📏 Story Length Control**: Short (200-400 words), Medium (400-800 words), or Long (800-1200 words)

- **🔑 Keyword Integration**: Include specific keywords in your stories

- **💡 Inspiration Feature**: Get random story prompts for creative inspiration

- **📋 Copy to Clipboard**: Easily copy generated stories

- **💾 Download Stories**: Save stories as text files

- **🔒 Secure API Key Storage**: API keys stored locally in browser

- **📱 Fully Responsive**: Works perfectly on desktop, tablet, and mobile devices



## 🚀 Getting Started



### Prerequisites



1. **Google Gemini API Key**: Get your free API key from [Google AI Studio](https://makersuite.google.com/app/apikey)



### Installation



1. **Clone or Download** this repository

2. **Open `index.html`** in your web browser

3. **Enter your API key** when prompted (stored securely in your browser)

4. **Start creating stories!**



### No Server Required



This is a client-side application that runs entirely in your browser. No server setup or installation needed!



## 🎯 How to Use



1. **Enter a Story Prompt**: Describe your story idea, characters, or setting

2. **Select Genre**: Choose from 9 different genres (optional)

3. **Add Keywords**: Include specific words you want in the story (optional)

4. **Choose Tone**: Select the emotional tone (Funny, Serious, Dark, etc.)

5. **Pick Writing Style**: Choose how the story should be written

6. **Set Length**: Decide how long you want your story to be

7. **Generate**: Click the magic button and watch your story come to life!



### 💡 Pro Tips



- Use **Ctrl+Enter** in the prompt field to quickly generate a story

- Click **"Get Inspiration"** for random story prompts

- Try different combinations of genre, tone, and style for unique results

- Use specific keywords to guide the story in interesting directions

## 🐛 Troubleshooting



### Common Issues



**"API Key Required" modal keeps appearing**

- Make sure you entered a valid Google Gemini API key

- Check that your API key has the necessary permissions



**Stories not generating**

- Verify your internet connection

- Check that your API key is valid and active

- Try a different browser or clear your browser cache



**Blank or incomplete stories**

- Try adjusting the prompt to be more specific

- Experiment with different genre and tone combinations

- Check if you've reached any API rate limits
