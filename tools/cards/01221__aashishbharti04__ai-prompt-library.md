## ✍️ Writing & Content

### Blog post from a single idea
```
You are an expert content writer. Write a 1,000-word blog post about [TOPIC].
Audience: [WHO]. Tone: [friendly/professional/witty].
Structure: a hook intro, 4–5 H2 sections with practical examples, and a short
conclusion with a call to action. Use simple language and short paragraphs.
End with 3 SEO meta-description options under 155 characters.
```

### Rewrite for clarity
```
Rewrite the text below so a busy 12-year-old could understand it, without losing
any key information. Keep it under [N] words, use active voice, and cut filler.
Return the rewrite, then a one-line note on what you changed.

TEXT: """[PASTE]"""
```

### Email that gets a reply
```
Write a short, polite email to [PERSON/ROLE] about [GOAL].
Keep it under 120 words, lead with the ask, give one clear reason, and end with a
specific next step. Give me 2 subject-line options.
```

## 💻 Coding & Development

### Explain code like a senior dev
```
Explain the code below to me. Cover: (1) what it does in one sentence,
(2) a line-by-line walkthrough of the tricky parts, (3) any bugs or edge cases,
and (4) one idea to make it cleaner. Assume I know basic [LANGUAGE].

CODE: """[PASTE]"""
```

### Debug helper
```
Act as a debugging partner. Here is my error and my code.
First, list the 3 most likely causes ranked by probability.
Then give me the exact fix for the most likely one, and how to verify it worked.

ERROR: """[PASTE]"""
CODE: """[PASTE]"""
```

### Build a feature step by step
```
I want to add [FEATURE] to my [LANGUAGE/FRAMEWORK] app.
Give me a step-by-step plan first (no code), then wait for me to say "go".
Keep steps small and testable.
```

## 📈 Marketing & Business

### Landing page copy
```
Write landing-page copy for [PRODUCT], which helps [AUDIENCE] to [BENEFIT].
Include: a headline, a sub-headline, 3 benefit bullets, and one CTA button label.
Make it punchy and specific — no vague buzzwords.
```

### 30-day content calendar
```
Create a 30-day content calendar for [BRAND/NICHE] on [PLATFORM].
For each day give: a hook, the content type (reel/carousel/post), and a one-line caption.
Mix education, entertainment, and promotion in a 70/20/10 ratio.
Return it as a table.
```

### Competitor teardown
```
Act as a marketing strategist. Given the competitor [NAME/URL], give me:
their likely target audience, their main value proposition, 3 strengths,
2 gaps I could exploit, and one positioning angle for my brand [MY BRAND].
```

## 🎨 Image Generation
*For Midjourney, Stable Diffusion, DALL·E, etc.*

### Cinematic photo prompt
```
[subject], [action], [setting], cinematic lighting, shot on 85mm lens, shallow
depth of field, golden hour, ultra detailed, 8k, photorealistic --ar 16:9
```

### Clean product shot
```
[product] on a minimal [color] background, soft studio lighting, subtle shadow,
centered composition, high detail, commercial product photography --ar 1:1
```

### Logo / icon concept
```
Flat vector logo for [BRAND], representing [CONCEPT], simple geometric shapes,
2-color palette ([color] and [color]), white background, no text, crisp edges
```

## 🎬 Video & Social Media

### YouTube script outline
```
Write a YouTube script outline for a [LENGTH] video titled "[TITLE]".
Include: a 15-second hook, 4 main sections with talking points, a re-hook in the
middle to keep retention, and an outro with a subscribe CTA. Keep the tone [TONE].
```

### Viral short / reel hook ideas
```
Give me 10 scroll-stopping opening lines (first 3 seconds) for a short video about
[TOPIC] aimed at [AUDIENCE]. Each should create curiosity or tension. Number them.
```

### Repurpose one video into a week of posts
```
I have a video about [TOPIC]. Turn it into: 1 carousel (5 slides), 3 tweet ideas,
1 LinkedIn post, and 2 short-video hooks. Keep each platform's native style.
```

## 🧠 Learning & Productivity

### Learn anything fast (Feynman style)
```
Teach me [TOPIC] as if I'm a smart beginner. Use a simple analogy first,
then the real explanation, then a 3-question quiz to test me. Wait for my answers
before revealing the solutions.
```

### Turn a goal into a plan
```
My goal is [GOAL] by [DATE]. Break it into weekly milestones, list the 3 highest-
leverage actions for week 1, and warn me about the 2 most common ways people fail
at this.
```

### Daily standup for yourself
```
Ask me 3 questions: what I did yesterday, what I'll do today, and what's blocking me.
After my answers, summarize my day's top priority in one sentence.
```
