# Gaia-Detector
AI Content Authenticity Detector is a full-stack web application that detects whether text, images, videos, and documents are AI-generated or human-created using pre-trained AI models. It provides confidence scores, detailed reports, and a user-friendly dashboard for content authenticity analysis.
