# 📝 网文大纲生成器

一个简单好用的网络小说大纲生成工具，按照成熟的网文写作公式一步步引导你填写，最后自动生成完整的 Markdown 格式大纲。

## 🎯 这是什么？

这是基于《网络小说写作完全指南——落地版》制作的交互式工具，帮助新人作者一步步整理思路，不会遗漏任何关键设定，最后一键导出大纲。

特点：
- ✅ **分步骤引导**：一共 14 步，正好对应写作指南的 14 个核心环节
- ✅ **自动拼接**：一句话故事自动帮你拼好
- ✅ **动态增减**：配角和卷数可以随时添加删除
- ✅ **一键导出**：生成后直接复制 Markdown，或者下载 .md 文件
- ✅ **纯静态网页**：不需要后端，打开就能用，支持所有浏览器

## 📖 同时包含完整的《网络小说写作完全指南——落地版》

- `index.html` → 完整的写作指南，适合随时翻阅
- `outline-generator.html` → 交互式大纲生成器

## 🚀 怎么使用

1. 直接 clone 打开：
```bash
git clone https://github.com/你的用户名/web-novel-wiki.git
cd web-novel-wiki
open outline-generator.html
```

2. 或者直接用浏览器打开 `outline-generator.html` 就可以用了，不需要任何依赖。

## 📋 生成的大纲包含什么？

1. 写作目标 & 品类选择
2. 一句话核心故事
3. 完整人物设定（主角+配角+感情线）
4. 开篇设计（黄金三章）
5. 分卷故事大纲
6. 升级体系/世界观设定
7. 节奏规划
8. 投稿计划

全都给你整理好，直接就能用！
