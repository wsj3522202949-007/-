GPT-Enhanced Agent-Based Assistant System: Literature Lab

Literature Lab is an advanced, AI-powered creative writing assistant designed to enhance and inspire the writing process. Utilizing cutting-edge GPT technology, this intelligent system provides targeted, real-time assistance across various aspects of creative writing. Whether you're crafting a novel, essay, short story, or poem, Literature Lab offers personalized feedback and suggestions tailored to your specific needs. The system is equipped to help with grammar and structure, while also delivering insightful genre-specific recommendations, drawing from literary traditions and modern techniques to elevate your writing style.

With Literature Lab, writers can access genre-driven inspiration, creative prompts, and thematic advice, ensuring that their work not only adheres to the conventions of their chosen genre—whether it be fantasy, science fiction, mystery, or literary fiction—but also breaks new ground. From refining narrative arcs and dialogue to suggesting metaphorical language and improving sentence flow, Literature Lab serves as a collaborative tool, empowering writers to produce their best work.

This expanded description emphasizes the system's capabilities, user benefits, and focus on both technical writing improvements and creative support.


// Setup:
- clone the repository to your local machine
- run the following line in the terminal:  
  pip install -r requirements.txt


// AI Training:

- chatbot/dataset/my_dataset.json   -    Instructions that the AI is teaching itself from
- chatbot/config.py                 -    Parameters as to how fast the Ai learns, how many times, etc.
- chatbot/dataloader.py             -    'Tokenises' the dataset, converting it to a language the AI understands
- chatbot/fine_tune.py              -    Actual training file, must be run everytime the dataset is updated
- chatbot/inference.py              -    Testing file for the AI. technically not necessary, but if you wish to test the AI outside the Website
- chatbot/models (folder)           -    Parameters defining what the AI knows, auto-generated by the fine_tune.py file when ran

// Website
- chatbot/templates/index.html      -    this file is the HTML file for the UI of the website


// Website Testing:
  python manage.py migrate          
  python manage.py runserver

- run these two lines in the terminal
- once the runserver line is ran, it will give a WEB URL LINK.
- CTRL + CLICK on the link to launch the website

- if the two bash lines do not work, replace manage.py with the file path of the manage.py file
