# AI Text Detector

A machine learning project that detects whether a piece of text was written by a human or generated by AI.

## Project Structure

- `data/` – datasets
- `notebooks/` – experiments and exploration
- `src/` – reusable Python code
- `models/` – trained models
- `app/` – Streamlit web application

This project is being built as part of my Machine Learning learning journey.
