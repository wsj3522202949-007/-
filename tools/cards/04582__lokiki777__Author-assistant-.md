# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/15e95f7e-5ba0-4950-a2a2-944a4316ce90

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](https://github.com/lokiki777/Author-assistant-/tree/main/.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
