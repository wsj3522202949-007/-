# Story_Generator

![](https://github.com/napilkington/Story_Generator/blob/main/text-generation-webui.png?raw=true)

Interactive application that connects to the text-generation-webui API, a graphical user interface (GUI) that enables interaction with text generation models (LLMs). The code allows for generating a creative story based on the parameters entered by the user and the model selected in the GUI.
