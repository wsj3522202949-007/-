# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1XCKbkOOKwBFCpbIXM2fP5_N6Bdru9E2U

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](https://github.com/Kings-Mon/StoryFrame---AI-Storyboard-Generator/blob/main/.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
