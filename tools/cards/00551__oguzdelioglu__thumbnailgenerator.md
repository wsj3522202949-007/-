## 🇹🇷 Türkçe

### Proje Hakkında

**Thumbnail Studio**, YouTube içerik üreticileri için tasarlanmış, yapay zeka odaklı gelişmiş bir thumbnail prompt oluşturucusudur. Karmaşık prompt yazma sürecini ortadan kaldırarak, sadece butonlara tıklayarak yüksek tıklama oranına (CTR) sahip görsel tarifleri oluşturmanızı sağlar.

### ✨ Özellikler

| Özellik | Açıklama |
|---------|----------|
| 🤖 **Çift Dil Desteği** | Tek tıkla Türkçe ve İngilizce arayüz |
| 🎲 **Çift Mod** | Kendi fotoğrafınızı referans alın veya rastgele karakter |
| 🎨 **16 Hazır Şablon** | Clickbait, Gaming, Vlog, Horror ve daha fazlası |
| ✏️ **60+ Font Sistemi** | Google Fonts entegrasyonu, thumbnail'da canlı önizleme |
| 🎯 **8 Pozisyon Preseti** | Karakter ve yazı için hazır pozisyon kombinasyonları |
| ⭐ **Favoriler Sistemi** | Ayarlarınızı (font dahil) kaydedin ve tekrar kullanın |
| 📜 **Akıllı Geçmiş** | Tüm promptlar otomatik kaydedilir |
| 🎹 **Klavye Kısayolları** | Yön tuşlarıyla fontlar arasında hızlı geçiş |
| 📋 **Tek Tıkla Kopyala** | Midjourney, DALL-E, Stable Diffusion için optimize |
| 🎨 **Modern UI** | Cyberpunk/Glassmorphism tasarım |
| 🔄 **Tam Modüler** | ES6 modülleri ile temiz kod yapısı |

### 🆕 v3.0 Yenilikleri

- **🔤 Profesyonel Font Seçici**: 60+ Google Font, kategorilere ayrılmış (Popüler, Gaming, Horror, vb.)
- **🖼️ Canlı Canvas Önizleme**: Seçtiğiniz font canvas üzerinde anlık olarak görüntülenir
- **⌨️ Klavye Navigasyonu**: ← → ↑ ↓ tuşlarıyla fontlar arasında geçiş yapabilirsiniz
- **📍 Pozisyon Presetleri**: 8 farklı hazır pozisyon şablonu (Sol Odak, Klasik Üçte, Dramatik Diagonal, vb.)
- **🎯 Akıllı Presetler**: Her preset artık karakter ve yazı pozisyonunu da içerir
- **💾 Font Kaydetme**: Favorilere eklediğiniz ayarlar font seçiminizi de saklar
- **🏗️ Modüler Mimari**: Kod tam ES6 modüllerine ayrıldı, bakım ve geliştirme daha kolay

### 🚀 Kullanım

1. [thumbnail.odel.dev](https://thumbnail.odel.dev) adresini ziyaret edin
2. Mod seçin (Referans Fotoğraf veya Rastgele)
3. Kategorilerden seçimlerinizi yapın
4. "PROMPT OLUŞTUR" butonuna tıklayın
5. Oluşan promptu kopyalayıp AI aracınıza yapıştırın

## 🇺🇸 English

### About

**Thumbnail Studio** is an advanced AI prompt generator designed for YouTube content creators. Create high-CTR thumbnail prompts for Midjourney, DALL-E, and Stable Diffusion without writing complex prompts manually.

### ✨ Features

| Feature | Description |
|---------|-------------|
| 🤖 **Bilingual** | Switch between English and Turkish seamlessly |
| 🎲 **Dual Modes** | Use photo reference or generate random characters |
| 🎨 **16 Quick Presets** | Clickbait, Gaming, Vlog, Horror and more |
| ✏️ **60+ Font System** | Google Fonts integration, live thumbnail preview |
| 🎯 **8 Position Presets** | Ready-made position combinations for character & text |
| ⭐ **Favorites System** | Save and reuse your configurations (including fonts) |
| 📜 **Local History** | Auto-saves all generated prompts |
| 🎹 **Keyboard Shortcuts** | Navigate fonts with arrow keys (← → ↑ ↓) |
| 📋 **One-Click Copy** | Optimized for Midjourney, DALL-E, SD |
| 🎨 **Modern UI** | Sleek Cyberpunk/Glassmorphism design |
| 🔄 **Fully Modular** | Clean ES6 module architecture for easy maintenance |

### 🆕 What's New in v3.0

- **🔤 Professional Font Selector**: 60+ Google Fonts, categorized (Popular, Gaming, Horror, etc.)
- **🖼️ Live Canvas Preview**: Selected fonts render instantly on the canvas
- **⌨️ Keyboard Navigation**: Switch between fonts using arrow keys (← → ↑ ↓)
- **📍 Position Presets**: 8 ready-made position templates (Focus Left, Classic Rule, Dramatic Diagonal, etc.)
- **🎯 Smart Presets**: Each preset now includes character and text positions
- **💾 Font Saving**: Your font choice is saved when you add to favorites
- **🏗️ Modular Architecture**: Code restructured into ES6 modules for easier development

### 🚀 Usage

1. Visit [thumbnail.odel.dev](https://thumbnail.odel.dev)
2. Select mode (Reference Photo or Random)
3. Make selections from categories
4. Click "GENERATE PROMPT"
5. Copy and paste the prompt into your AI tool

## 🛠️ Tech Stack

- **Frontend:** Pure HTML5, CSS3, Vanilla JavaScript (ES6 Modules)
- **Fonts:** Google Fonts API integration
- **Hosting:** GitHub Pages
- **PWA:** Progressive Web App support
- **Storage:** LocalStorage for history & favorites
- **Architecture:** Modular ES6 modules (no build tools required)

## 📦 Deployment

This project is deployed on GitHub Pages with a custom domain.

### Local Development

Simply open `index.html` in your browser - no build step required!

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/thumbnailgenerator.git

# Open in browser
open index.html
```

### GitHub Pages Setup

1. Push code to `main` branch
2. Go to Settings → Pages
3. Select "Deploy from a branch" → `main` / `root`
4. (Optional) Add custom domain in CNAME file
