# AI Text Tools Directory

Live URL: https://aitexttools.net

A fast, curated, and ad-free directory of 70+ AI writing tools, copywriters, and text generators. Built to help writers and developers find the right writing tools without dealing with bloated affiliate blogs and popups.

## Problem
Finding reliable AI writing tools is difficult because search engine results are dominated by affiliate-heavy blogs. General AI directories are often too broad, slow, and hard to filter.

## Features
- **100% Focused on Text**: Hyper-focused categories for copywriters, text editors, and content generators.
- **Ultra-Fast Performance**: Built using static-site generation for sub-second page loads.
- **Clean UI/UX**: No ads, newsletter gates, or trackers.
- **Detailed Filters**: Easily filter by pricing models (including free tools) and specific use cases.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

## How to use
To run the project locally:
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the local development server.
