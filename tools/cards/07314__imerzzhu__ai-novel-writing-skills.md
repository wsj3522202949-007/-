# AI Novel Writing Skills

面向中文网文创作流程的 Codex Skills 集合，覆盖选题、大纲、章节写作、剧情审查、文笔润色、完稿校验，以及男频热梗/平台语感和女频情绪线/古风素材调用。

## English Summary

AI Novel Writing Skills is a public Codex Skills package for Chinese webnovel writing. It provides reusable skills for topic planning, outlining, chapter drafting, story logic review, prose polishing, final manuscript checks, hot-meme adaptation, and female-channel emotional pacing.

## Skill List

| Skill | 用途 |
| --- | related:
  - methods/QUICK_START.md
--- |
| `webnovel-topic` | 选题策划、市场化创意、金手指、卖点和风险提示 |
| `webnovel-outline` | 世界观、人设、剧情框架、分卷大纲和章节细纲 |
| `webnovel-write` | 根据大纲或细纲撰写、续写、扩写、重写章节 |
| `webnovel-review` | 检查时间线、逻辑漏洞、人物 OOC、伏笔回收和章节字数 |
| `webnovel-polish` | 优化文笔、节奏、爽点、对话和代入感 |
| `webnovel-finalize` | 完稿校验、错别字、标点、敏感内容和发布格式整理 |
| `webnovel-worldbuilder` | 串联选题、大纲、写作、审查、润色、完稿的全流程主控 |
| `webnovel-hot-memes` | 男频网文热梗、平台语感、弹幕/评论区/短视频文案适配 |
| `webnovel-female-radar` | 女频关系张力、情绪节奏、古风素材和平台语感适配 |

## Install

将需要的 skill 目录复制到 Codex skills 目录。Windows 示例：

```powershell
$codexSkills = "$env:USERPROFILE\.codex\skills"
New-Item -ItemType Directory -Force $codexSkills
Copy-Item -Recurse .\skills\webnovel-topic $codexSkills
Copy-Item -Recurse .\skills\webnovel-outline $codexSkills
Copy-Item -Recurse .\skills\webnovel-write $codexSkills
```

也可以复制整个 `skills/` 下的全部 `webnovel-*` 目录。


```text
Use $webnovel-female-radar to strengthen the relationship tension, emotional rhythm, and heroine agency in this gufeng romance scene.
```

## Open Source Boundary

This public package intentionally excludes source-limited work-study batches, monthly rank snapshots, local source cards, private file paths, caches, and generated bytecode. It keeps reusable craft guidance and safety rules, not chapter prose or material that can replace reading original works.

See [docs/open-source-policy.md](https://github.com/imerzzhu/ai-novel-writing-skills/blob/main/docs/open-source-policy.md) for the release boundary.
