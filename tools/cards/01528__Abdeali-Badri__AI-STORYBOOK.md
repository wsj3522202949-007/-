# Overview :-

AI Storybook is a multi-modal generative AI application that creates fully illustrated children's storybooks from a simple idea or gist. The user types a short story concept, and the system:



1) Writes a complete, age-appropriate story using an LLM

2) Splits the story into individual pages

3) Illustrates each page with a unique AI-generated image using Stability AI

4) Compiles everything into a beautifully formatted, downloadable PDF storybook



This project combines text generation, image generation, and PDF rendering into a single seamless pipeline — making it one of the most complete end-to-end generative AI projects you can build.



# Key Features :-



📝 Story generation from a gist — just give a one-line idea, the AI writes the full story

🎨 AI-illustrated pages — every page gets a unique illustration generated by Stability AI

📄 PDF export — download the complete illustrated storybook as a PDF

👶 Age-appropriate content — stories are tailored for children aged 4–7

🌐 Web interface — clean Flask-powered browser UI

💾 Story persistence — generated stories saved locally in the stories/ folder

☁️ Deployed on Vercel — live and accessible online

# How It Works :-

```

User enters a story gist (e.g. "A rabbit who wants to fly")

        │

        ▼

gist_to_story.py   ──→  LLM writes a full age-appropriate story

        │

        ▼

split_pages.py     ──→  Story is split into individual pages

        │

        ▼

image_generator.py ──→  Stability AI generates an illustration per page

        │

        ▼

pdf_generator.py   ──→  Story text + images compiled into a PDF storybook

        │

        ▼

app.py             ──→  Flask serves the UI & lets user download the PDF

```

# Getting Started Prerequisites :-



1) Python 3.11+

2) uv (recommended) or pip

3) OpenAI API key

4) Stability AI API key



# Installation :-

```bash

 # Clone the repository

git clone https://github.com/Abdeali-Badri/AI-STORYBOOK.git

cd AI-STORYBOOK

```

# Using uv (recommended) :-

```bash

uv sync

```

# Using pip :-



```bash

pip install -r requirements.txt

```

# Configuration :-

Create a .env file in the root directory:

```

OPENAI_API_KEY=your_openai_api_key_here

STABILITY_API_KEY=your_stability_api_key_here

```

# Run the App :-

```bash

python app.py

```

Then open your browser and navigate to ```http://localhost:5000```



# Usage :-



1) Open the app in your browser

2) Enter a story idea or gist (e.g. "A little elephant who is afraid of water")

3) Click Generate Story

4) Wait while AI writes the story, splits it into pages, and illustrates each one

5) Download your PDF storybook — ready to read or print!
