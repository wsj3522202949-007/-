# Turing Classifier

A Flask-based text classification application that detects whether a provided text sample is written by a human or generated by AI. The project includes a training pipeline, model artifacts, and a web interface for realtime prediction.

## Overview

The repository contains:

- `app.py`: Flask application entry point for the web interface.
- `classifier.py`: Core model training and feature extraction logic.
- `predict.py`: Command-line prediction helper.
- `templates/index.html`: Frontend template for the web interface.
- `dataset/ai_human.csv`: Source dataset for training the classifier.
- `model/`: Saved model and vectorizer artifacts after training.
- `static/screenshot-demo-1.png`: Application screenshot showing a human-written prediction.
- `static/screenshot-demo-2.png`: Application screenshot showing an AI-generated prediction.

## Key Features

- Detects AI-generated text versus human-written text.
- Uses TF-IDF vectorization and style-based text features.
- Supports a web UI for pasting text, viewing results, and checking confidence.

## Requirements

- Python 3.10 or later
- Flask
- pandas
- scikit-learn
- scipy
- numpy
- joblib

Install dependencies with:

```bash
pip install -r requirements.txt
```

## Running the Application

1. Ensure the model files exist in the `model/` directory.
2. Start the Flask application:

```bash
python app.py
```

3. Open a browser and navigate to `http://127.0.0.1:5000`.

## Training the Model

If you need to retrain the classifier, run:

```bash
python train.py
```

This script uses the dataset in `dataset/ai_human.csv` and saves trained artifacts under `model/`.

## Prediction

For command-line inference, use:

```bash
python predict.py
```

The script prompts for text input and returns the predicted label and confidence.

## Notes

- The model combines word-level and character-level TF-IDF features with handcrafted style signals.
- The frontend uses a simple Tailwind CSS layout to support text input and display prediction feedback.
- Screenshots are available in the `static/` directory to illustrate the user experience.
