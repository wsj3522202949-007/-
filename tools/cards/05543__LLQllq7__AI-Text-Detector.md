# README

## Detecting AI-Generated Text via Fine-Tuned LLMs

A deep learning system for detecting whether a given text is **written by a human or generated by a Large Language Model (LLM)**.  
This project achieved a **0.9571 F1-score** on the official leaderboard, outperforming most baseline models and avoiding overfitting through a combination of **LoRA fine-tuning, five-fold training, data augmentation, and ensemble voting strategies**.

---

### 📌 Task Description

Given an input text, the goal is to classify it into:

| Label | Meaning            |
| ----- | ------------------ |
| `0`   | Human-written text |
| `1`   | LLM-generated text |

The dataset contains balanced text from 7 mainstream LLMs (GPT-4o, DeepSeek, Llama3, ChatGPT, GLM-4, Qwen2.5, Claude-3) and human text from sources such as BBC News, IMDB, ROC Stories, Wikipedia, and ELI5.

Evaluation Metric: **F1-score**

---

### 🚀 **Key Features**

- ✅ **Qwen / LLaMA models for Sequence Classification**
- ✅ **LoRA PEFT fine-tuning (small GPU-friendly, only train 2M+ parameters)**
- ✅ **Five-fold cross-validation for better generalization**
- ✅ **One-vote veto & two-vote veto ensemble strategies**
- ✅ **Human-text–only data augmentation pipeline (synonym replacement, cropping, splitting)**
- ✅ **0.9571 F1-score** with final multi-model voting ensemble

### ⚙️ **Method Overview**

| Step                          | Technique                 | Purpose                 |
| ----------------------------- | ------------------------- | ----------------------- |
| Baseline                      | LoRA finetuning (Qwen-4B) | 0.85 F1 but overfitting |
| + Five-fold training          | 5 models voting           | ↑ to 0.91 F1            |
| + Data augmentation           | Expand label-0 samples    | ↑ to 0.94 F1            |
| + Ensemble (Qwen3B + LLaMA3B) | One-vote veto             | Final **0.9571**        |

### 🧪 **Training Example**

```python
peft_config = LoraConfig(
    task_type=TaskType.SEQ_CLS,
    r=2,
    lora_alpha=8,
    lora_dropout=0.5,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],
)
model = get_peft_model(model, peft_config)
```

Five-fold training (bash):

```
bash run_5fold.sh   # train & validate 5 models
python merge_5_fold.py
```

---

### 📌 **Takeaways**

- Overfitting → not only a model problem, but also **label distribution bias**
- For LLM-text tasks, **0/1 balance in predictions is strongly correlated with F1-score**
- Data augmentation on **human text only** is surprisingly effective
- Model ensemble > single large model
