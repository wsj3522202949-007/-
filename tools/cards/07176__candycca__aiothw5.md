# Advanced AI Content Detector 🤖

A sophisticated web application built with Python and Streamlit that analyzes text to determine if it was likely generated by an AI model or written by a human. This tool goes beyond simple binary classification by providing deep linguistic insights based on advanced NLP metrics.

## 🌟 Features

### Core Detection
- **AI Probability**: Uses the `roberta-base-openai-detector` model to predict the likelihood of AI generation.
- **Real-time Analysis**: Instant feedback on text input.

### Advanced Linguistic Metrics
- **Perplexity**: Measures how "surprised" a model is by the text. Low perplexity suggests AI; high perplexity suggests human.
- **Burstiness**: Analyzes the variation in sentence structure and length. Humans tend to have higher burstiness (more varied rhythm).
- **Type-Token Ratio (TTR)**: Calculates vocabulary diversity.
- **Zipf's Law Analysis**: Compares the text's word frequency distribution against the natural language power law.

### Interactive Visualizations
- **Perplexity Time Series**: A line chart showing how perplexity fluctuates sentence by sentence, helping to spot "human-like" spikes.
- **Sentence Length Histogram**: Visualizes the rhythm and structure of the text.
- **Zipf's Law Log-Log Plot**: A deep dive into the statistical properties of the vocabulary used.

## 🛠️ Installation

1.  **Clone the repository** (if applicable) or navigate to the project folder.

2.  **Install Dependencies**:
    Ensure you have Python installed (3.8+ recommended). Install the required packages using pip:
    ```bash
    pip install -r requirements.txt
    ```
    *Note: This project relies on `torch`, `transformers`, `streamlit`, `plotly`, `nltk`, and `numpy`.*

3.  **Download NLTK Data**:
    The app will attempt to download necessary NLTK data (`punkt`, `punkt_tab`) automatically on the first run.

## 🚀 Usage

1.  **Run the Streamlit App**:
    ```bash
    streamlit run app.py
    ```

2.  **Interact with the Interface**:
    - Open your browser to the URL provided (usually `http://localhost:8501`).
    - **Input Text**: Type or paste text into the text area (minimum 50 characters recommended).
    - **Sample Text**: Use the dropdown to try pre-loaded examples of AI and Human text.
    - **Analyze**: Click the "Analyze Text" button.

3.  **Explore Results**:
    - **Overview Tab**: See the main AI Probability gauge and summary metrics.
    - **Deep Dive Tab**: View the Perplexity line chart and Sentence Length distribution.
    - **Linguistics Tab**: Check TTR and Zipf's Law analysis.

## 📂 Project Structure

- `app.py`: The main application script containing the UI and logic.
- `requirements.txt`: List of Python dependencies.

## 🧠 Models Used

- **Detection**: `roberta-base-openai-detector` (Fine-tuned RoBERTa model for GPT-2 output detection).
- **Perplexity**: `gpt2` (Standard GPT-2 model for causal language modeling).
