# Test Cases

Tento priečinok obsahuje manuálne definované testovacie prípady pre stránku [Zoznam.sk](https://www.zoznam.sk), ktoré sú zároveň automatizované pomocou nástroja **Playwright**.

## Obsah

- **TC001** – Overenie načítania homepage a základných prvkov
- **TC002** – Overenie presmerovania na stránku s počasím
- **TC003** – Overenie vyhľadávania slova „auto“ a zobrazenia obrázkov

Každý test case obsahuje:
- Prioritu
- Predpoklady
- Kroky testu
- Očakávaný výsledok
- Informáciu o automatizácii

Test cases slúžia ako dokumentácia k pokrytiu testovacích scenárov v Playwrighte.
