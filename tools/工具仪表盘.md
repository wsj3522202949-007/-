## 一、任务 × 评级 交叉筛选

### 去 AI 味 · S/A 级精选

```dataview
TABLE
  tier AS "评级",
  stars AS "⭐",
  file.link AS "工具名",
  use_case AS "用途"
FROM "tools/cards"
WHERE contains(tags, "去AI味") AND (tier = "S" OR tier = "A")
SORT stars DESC
```

## 二、本周推荐（S 级高星工具）

```dataview
TABLE
  tier AS "评级",
  stars AS "⭐",
  tags AS "标签",
  use_case AS "用途"
FROM "tools/cards"
WHERE tier = "S" AND stars > 500
SORT stars DESC
```

## 四、标签分布统计

### 各任务维度卡片数

```dataview
TABLE
  length(rows) AS "卡片数"
FROM "tools/cards"
GROUP BY tags
FLATTEN tags
WHERE contains(tags, "task")
SORT length(rows) DESC
```
