## 方法区（methods/）

```dataview
TABLE
  type AS "类型",
  file.link AS "文档名",
  status AS "状态",
  tags AS "标签"
FROM "methods"
WHERE type = "guide" OR type = "ref" OR type = "index"
SORT type ASC, file.name ASC
```
