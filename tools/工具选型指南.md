# 🧭 工具选型指南（任务 → 工具地图）

> ↩ **回总地图**：[🗺️ 知识库总地图](../README.md)
> 本库已从「仓库堆」升级为「可用情报网」：**每篇工具卡都带分层(tier)、标签(tags)、使用场景(use_case)、避坑(pitfalls)**。
> 本指南教你按「想做什么」直接定位到该用的工具，而不是翻 3572 篇。

> ⚠️ **诚实说明**：列表由「README 正文 + Stars + 协议」**自动派生**，源库本身有少量误分类仓库（约 1–2%），可能混进个别不相关项。
> 进工具卡看 `category`（源分类）与 `use_case`（用途）即可一眼识别；空壳与 0★ 已默认排除在 S/A 列表外。

## 怎么用（30 秒）
1. 看下面「想做 X → 先看这些」找你的任务；
2. 列表里 **S/A 级** 是优先试用的（S=社区验证过的主力，A=靠谱备选）；
3. 点链接进工具卡，看 `use_case` 确认用途、`pitfalls` 避坑、`tags` 判断要不要 API Key / 能否商用；
4. 想自己筛 → 见文末 **Dataview 查询** 或 [标签体系说明](标签体系说明.md)。

## 分级总览（tier 含义）

- **S 主力推荐** `151` 篇：Stars≥200，社区验证过，优先试用
- **A 靠谱备选** `107` 篇：Stars 50–199，质量稳，S 不满足时选它
- **B 长尾观察** `1382` 篇：Stars 1–49，小众/新库，按需挖
- **C 存疑待验** `1949` 篇：0★ 或源仓库无 README，试用前先小范围测

## 两种常见约束的速筛

- **不想买/配 API Key（穷/怕麻烦）** → 只筛带 `本地优先` 标签的（正文未检出 API Key 依赖）：
  ```dataview
TABLE stars, use_case, tier FROM "tools/cards"
WHERE contains(tags, "本地优先") AND tier IN ("S","A")
SORT stars DESC
```
- **要商用（避坑协议）** → 排除 `协议传染`(GPL/AGPL) 与 `协议未明`：
  ```dataview
TABLE stars, tags, tier FROM "tools/cards"
WHERE contains(tags, "去AI味") AND !contains(tags, "协议传染") AND !contains(tags, "协议未明")
SORT stars DESC
```

## 通用 Dataview 查询模板（粘贴即用）

```dataview
TABLE stars, use_case, tier, tags FROM "tools/cards"
WHERE contains(tags, "<这里填标签，如 去AI味>") AND tier = "S"
SORT stars DESC
```
