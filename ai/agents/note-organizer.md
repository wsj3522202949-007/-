# 📁 笔记整理代理

> 整理笔记、修复链接、合并重复内容。保持知识库整洁。

---

## 一、代理说明

**用途**：
- 扫描孤立文件
- 修复断链
- 合并重复笔记
- 优化目录结构

**触发方式**：
- 手动触发：在 AI 对话中输入 `note-organizer`
- 定期执行：建议每周执行一次

**输出**：
- 生成整理报告
- 列出处理清单
- 提供优化建议

---

## 二、使用方法

### 2.1 直接调用
在 AI 对话中输入 `note-organizer`，AI 会：
1. 扫描知识库
2. 识别问题
3. 执行整理
4. 生成报告

### 2.2 指定范围
输入 `note-organizer [目录]`，如 `note-organizer methods/`，AI 会：
1. 扫描指定目录
2. 识别问题
3. 执行整理
4. 生成报告

---

## 三、工作流程

### 3.1 扫描阶段
1. 扫描知识库结构
2. 收集文件信息
3. 分析链接关系
4. 识别潜在问题

### 3.2 分析阶段
1. 识别孤立文件
2. 检测断链
3. 发现重复内容
4. 分析目录结构

### 3.3 整理阶段
1. 修复断链
2. 合并重复笔记
3. 移动孤立文件
4. 优化目录结构

### 3.4 报告阶段
1. 汇总处理结果
2. 生成整理报告
3. 列出剩余问题
4. 提供优化建议

---

## 四、检查项目

### 4.1 孤立文件检查
- 无 incoming 链接的文件
- 无 outgoing 链接的文件
- 不在任何 MOC 中的文件

### 4.2 断链检查
- 链接目标不存在
- 链接格式错误
- 相对路径错误

### 4.3 重复内容检查
- 标题相似的文件
- 内容相似的文件
- 标签重复的文件

### 4.4 目录结构检查
- 目录职责不清晰
- 文件放置位置不当
- 目录层级过深

---

## 五、处理策略

### 5.1 孤立文件处理
1. 分析文件内容
2. 寻找相关文件
3. 建立链接关系
4. 移动到合适目录

### 5.2 断链处理
1. 识别断链原因
2. 修复链接路径
3. 更新链接格式
4. 验证修复结果

### 5.3 重复内容处理
1. 比较重复内容
2. 选择最佳版本
3. 合并有用信息
4. 删除重复文件

### 5.4 目录结构优化
1. 分析目录职责
2. 移动错位文件
3. 合并空目录
4. 优化层级结构

---

## 六、整理报告

### 6.1 报告格式
```markdown
# 笔记整理报告

## 整理范围
- 目录：XXX
- 文件数量：X 个
- 整理时间：YYYY-MM-DD HH:MM

## 处理结果
- 孤立文件：X 个
- 断链修复：X 处
- 重复合并：X 个
- 目录优化：X 处

## 问题清单
| 文件 | 问题类型 | 处理方式 | 状态 |
|---|---|---|---|
| 文件1 | 孤立文件 | 移动到 methods/ | 已处理 |
| 文件2 | 断链 | 修复链接 | 已处理 |

## 剩余问题
1. 问题1
2. 问题2

## 优化建议
1. 建议1
2. 建议2

## 总结
整理完成，处理 X 个问题，剩余 X 个问题。
```

## 七、注意事项

1. **备份优先**：整理前建议备份
2. **谨慎操作**：删除操作需谨慎
3. **定期执行**：建议每周执行一次
4. **查看报告**：执行后查看整理报告
