# 约束文件索引

> AI 生成或修改内容时，必须先加载对应约束文件。约束不可跳过。

## 文件清单

| 约束文件 | 触发时机 | 核心内容 |
|---|---|---|
| [合规红线.md](合规红线.md) | 生成任何内容 | 法律底线、道德底线、平台红线 |
| [写作硬约束.md](写作硬约束.md) | 生成/修改正文 | 字数、结构、人物、情节约束 |
| [格式要求.md](格式要求.md) | 创建/修改文件 | 文件名、frontmatter、编码规范 |
| [禁忌清单.md](禁忌清单.md) | 执行任何操作 | 内容禁忌、操作禁忌、格式禁忌 |

## 使用方式

1. 生成正文前 → 读 `合规红线.md` + `写作硬约束.md`
2. 创建文件前 → 读 `格式要求.md`
3. 执行操作前 → 读 `禁忌清单.md`
