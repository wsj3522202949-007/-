# 🌐 全平台签约指南

> 覆盖所有主流网文平台的签约成功技巧——番茄、起点、晋江、知乎盐选、七猫、豆瓣、小程序、短剧。

---

## 一、平台定位速查

| 平台 | 商业模式 | 开篇偏好 | 字数节奏 | 更新要求 | 读者预期 |
|---|---|---|---|---|---|
| **番茄小说** | 免费+广告分账 | 强冲突、快节奏、前3章必出爽点 | 2000–4000/章 | 日更 | 「停不下来」爽感 |
| **起点中文网** | 付费订阅 | 金手指/世界观铺陈可稍缓 | 2000–4000/章 | 日更/隔日更 | 「成长+装逼+体系」 |
| **晋江文学城** | 付费订阅+版权 | 人设/感情/文笔优先 | 2000–3000/章 | 稳定更新 | 「嗑到了」情感满足 |
| **知乎盐选/盐言** | 会员/单篇 | 一个极抓人的「钩子问题」 | 单篇1–3万 | 一次性或短更 | 「原来如此」认知反转 |
| **七猫小说** | 免费+广告 | 类似番茄，更下沉 | 2000–4000/章 | 日更 | 爽+通俗 |
| **豆瓣阅读** | 出版向 | 文学性/真实感 | 不限 | 低 | 「被理解」共鸣 |
| **小程序/知乎短篇** | 短篇买断/分账 | 前100字定生死 | 3000–8000短篇 | 短平快 | 「看完即走」的爽点 |
| **短剧** | 版权售卖 | 前30秒定生死 | 单集1–3分钟 | 集中拍摄 | 「追剧」的爽感 |

## 二、番茄小说签约指南

### 2.1 签约门槛
- 写满2万字，后台开放签约申请入口
- 通过率约60%
- 8万字可主动申请"推荐评估"，最多3次

### 2.2 核心数据指标
| 指标 | 及格线 | 优秀线 |
|---|---|---|
| 前三章完读率 | ≥50% | ≥70% |
| 追读率 | ≥15% | ≥20% |
| 次日留存率 | ≥20% | ≥30% |
| 平均阅读时长 | 3-5分钟 | ≥5分钟 |

### 2.3 开篇铁律
- **前300字**必须有强冲突/动作/对话
- **前100字**有钩子
- **前3章**≥2个完整爽点闭环
- 禁止：环境描写/重生发呆/大段回忆/系统说明书

### 2.4 签约体检清单
- [ ] 开篇切入点≥13分
- [ ] 爽点密度≥14分
- [ ] 章末钩子≥13分
- [ ] 去AI味≥13分
- [ ] 无一票否决项

## 三、起点中文网签约指南

### 3.1 签约门槛
- 新书期四轮PK
- 首订1000：新人合格线
- 首订<200：斩杀线

### 3.2 核心数据指标
| 指标 | 说明 |
|---|---|
| 首订 | 上架第一章24小时订阅数 |
| 均订 | 上架后总订阅次数÷VIP章节数 |
| 收藏 | 加书架数，反映长线期待 |
| 月票 | 会员订阅/打赏换投票权 |

### 3.3 均订对应收入
| 均订 | 月入 |
|---|---|
| 1000 | 2000–3000元 |
| 3000 | 8000–12000元 |
| 10000 | 3–5万元 |
| 50000+ | 六位数起 |

### 3.4 开篇铁律
- **第1章**需立住主角处境与金手指雏形
- **前3章**可稍铺陈，但必须有明确冲突
- **简介**：世界观+金手指+主线目标

### 3.5 上架阈值
| VIP追读 | 上架字数 |
|---|---|
| <100 | 30万字 |
| >100 | 约20万字 |
| >300 | 约15万字 |

## 四、晋江文学城签约指南

### 4.1 签约门槛
- 入V硬门槛：收藏≥500，章末点击≥1000
- 连载字数20万字内
- 签约类型：分成签/买断签

### 4.2 核心数据指标
| 指标 | 说明 |
|---|---|
| 收藏 | 加书架数，入V参考线500 |
| 章末点击 | 入V参考线1000 |
| 霸王票 | 仅签约作者能收，地雷=100积分 |
| 积分 | 综合字数×点击×收藏×评论×打分 |

### 4.3 开篇铁律
- **人设与关系登场** > 事件密度
- **文笔与「拉扯感」**优先
- **简介**：人设反差+关系张力

### 4.4 签约体检清单
- [ ] 人设是否立体（有反差、有记忆点）
- [ ] 感情线是否有拉扯感
- [ ] 文笔是否细腻
- [ ] 是否有"嗑到了"的感觉

## 十、通用签约技巧

### 10.1 开篇铁律（通用）
1. **前100字**主角登场
2. **前300字**有强冲突/动作/对话
3. **前100字**有钩子
4. 主角有明确目标或困境

### 10.2 爽点营造公式
`
被欺负（抑）→ 读者代入情绪 → 出人意料反击（扬）→ 爽感拉满
`

### 10.3 章末钩子五类
1. **悬念**：留下未解之谜
2. **反转**：出乎意料的发展
3. **冲突**：新的矛盾出现
4. **情感**：强烈的情绪冲击
5. **信息**：关键信息揭示

### 10.4 去AI味铁律
1. 无14类禁用词
2. 无排比句/三段式
3. 节奏自然（长短句交替）
4. 配角反应差异化
5. 具体化（抽象→动作/物件/时间）

| 题材 | 推荐平台 | 原因 |

## 十二、签约体检表通用版

### 12.1 开篇切入点（≥13分）
- [ ] 前300字有强冲突/动作/对话
- [ ] 前100字有钩子
- [ ] 主角有明确目标或困境

### 12.2 爽点密度（≥14分）
- [ ] 前3章≥2个完整爽点闭环
- [ ] 每个爽点有铺垫
- [ ] 打脸章有配角差异化反应

- [ ] 每章章末有强钩子

### 12.4 去AI味（≥13分）
- [ ] 无禁用词/句式
- [ ] 节奏自然
- [ ] 配角反应差异化

### 12.5 平台适配
- [ ] 是否符合目标平台开篇偏好
- [ ] 是否符合目标平台字数节奏
- [ ] 是否符合目标平台更新要求
