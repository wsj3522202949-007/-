# 📅 每周维护工作流

> 每周维护任务，保持知识库健康。包括周回顾、笔记整理、目标检查。

---

## 一、工作流说明

**用途**：
- 执行周回顾
- 整理笔记、修复链接
- 检查目标进度
- 保持知识库健康

**执行时间**：
- 周六上午：笔记整理
- 周日上午：目标检查
- 周日晚上：周回顾

**输出**：
- 创建周回顾文件
- 整理笔记、修复链接
- 检查目标进度
- 生成维护报告

---

## 二、工作流程

### 2.1 周六上午（30分钟）
1. 笔记整理
   - 调用 `note-organizer` 代理
   - 扫描孤立文件
   - 修复断链
   - 合并重复笔记
2. 目录优化
   - 检查目录结构
   - 移动错位文件
   - 优化层级结构

### 2.2 周日上午（30分钟）
1. 目标检查
   - 检查周目标进度
   - 分析未完成原因
   - 调整下周计划
2. 进度更新
   - 更新月度目标进度
   - 更新年度目标进度
   - 生成进度报告

### 2.3 周日晚上（30分钟）
1. 周回顾
   - 调用 `weekly-reviewer` 代理
   - 回顾本周成果
   - 分析挑战和困难
   - 总结经验教训
2. 下周规划
   - 规划下周任务
   - 设定优先级
   - 分配时间块

---

## 三、维护任务

### 3.1 笔记整理
**执行频率**：每周一次
**执行时间**：周六上午
**执行步骤**：
1. 扫描知识库结构
2. 识别孤立文件
3. 检测断链
4. 合并重复笔记
5. 优化目录结构

### 3.2 目标检查
**执行频率**：每周一次
**执行时间**：周日上午
**执行步骤**：
1. 检查周目标进度
2. 分析未完成原因
3. 调整下周计划
4. 更新月度目标进度

### 3.3 周回顾
**执行频率**：每周一次
**执行时间**：周日晚上
**执行步骤**：
1. 回顾本周成果
2. 分析挑战和困难
3. 总结经验教训
4. 规划下周任务

## 五、维护报告

### 5.1 报告格式
```markdown
# 每周维护报告

## 维护时间
- 周数：第 W 周
- 日期范围：YYYY-MM-DD - YYYY-MM-DD
- 维护耗时：X 小时

## 周六任务
| 任务 | 状态 | 结果 |
|---|---|---|
| 笔记整理 | 完成 | 处理 X 个文件 |
| 孤立文件 | 完成 | 修复 X 个 |
| 断链修复 | 完成 | 修复 X 处 |
| 重复合并 | 完成 | 合并 X 个 |

## 周日任务
| 任务 | 状态 | 结果 |
|---|---|---|
| 目标检查 | 完成 | 检查 X 个目标 |
| 周回顾 | 完成 | 回顾本周成果 |
| 下周规划 | 完成 | 规划 X 个任务 |

## 本周成果
- 完成任务：X 个
- 未完成任务：X 个
- 新增内容：X 个

## 下周计划
- 重点任务：X 个
- 时间块：X 个
- 目标：X 个

## 总结
每周维护完成，处理 X 个任务，下周重点是 XXX。
```

## 六、注意事项

1. **坚持执行**：每周坚持执行维护任务
2. **时间控制**：控制维护时间，避免过长
3. **记录变化**：记录每次维护的变化
4. **持续优化**：根据维护结果持续优化
