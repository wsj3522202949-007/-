# 📅 每日维护工作流

> 每日维护任务，保持知识库整洁。包括收件箱处理、日记创建、进度更新。

---

## 一、工作流说明

**用途**：
- 处理收件箱内容
- 创建今日日记
- 更新目标进度
- 保持知识库整洁

**执行时间**：
- 早晨：创建今日日记
- 晚上：处理收件箱、更新进度

**输出**：
- 创建日记文件
- 处理收件箱内容
- 更新目标进度
- 生成维护报告

---

## 二、工作流程

### 2.1 早晨流程（5分钟）
1. 创建今日日记
   - 调用 `/daily` 技能
   - 设定今日重点任务
   - 分配时间块
2. 回顾昨日任务
   - 检查昨日未完成任务
   - 移动到今日任务
3. 设定今日目标
   - 从月度目标分解
   - 设定优先级

### 2.2 晚上流程（10分钟）
1. 处理收件箱
   - 调用 `inbox-processor` 代理
   - 分类处理内容
   - 归档已处理项
2. 更新进度
   - 更新今日任务状态
   - 记录完成情况
   - 更新目标进度
3. 规划明日任务
   - 设定明日重点任务
   - 分配时间块

---

## 三、维护任务

### 3.1 收件箱处理
**执行频率**：每日一次
**执行时间**：晚上
**执行步骤**：
1. 扫描 `drafts/inbox/` 目录
2. 分类处理内容
3. 移动到合适目录
4. 添加 frontmatter
5. 建立链接关系

### 3.2 日记创建
**执行频率**：每日一次
**执行时间**：早晨
**执行步骤**：
1. 创建 `goals/daily/YYYY-MM-DD.md`
2. 填写今日重点任务
3. 设定时间块
4. 设定优先级

### 3.3 进度更新
**执行频率**：每日一次
**执行时间**：晚上
**执行步骤**：
1. 更新今日任务状态
2. 记录完成情况
3. 更新目标进度
4. 更新月度目标

## 五、维护报告

### 5.1 报告格式
```markdown
# 每日维护报告

## 维护时间
- 日期：YYYY-MM-DD
- 早晨耗时：X 分钟
- 晚上耗时：X 分钟

## 早晨任务
| 任务 | 状态 | 结果 |
|---|---|---|
| 创建日记 | 完成 | 创建 goals/daily/YYYY-MM-DD.md |
| 回顾昨日 | 完成 | 移动 X 个未完成任务 |
| 设定目标 | 完成 | 设定 X 个重点任务 |

## 晚上任务
| 任务 | 状态 | 结果 |
|---|---|---|
| 处理收件箱 | 完成 | 处理 X 个项目 |
| 更新进度 | 完成 | 更新 X 个任务状态 |
| 规划明日 | 完成 | 设定 X 个重点任务 |

## 今日成果
- 完成任务：X 个
- 未完成任务：X 个
- 新增内容：X 个

## 明日计划
- 重点任务：X 个
- 时间块：X 个
- 目标：X 个

## 总结
今日维护完成，处理 X 个任务，明日重点是 XXX。
```

---

## 六、注意事项

1. **坚持执行**：每天坚持执行维护任务
2. **时间控制**：控制维护时间，避免过长
3. **记录变化**：记录每次维护的变化
4. **持续优化**：根据维护结果持续优化
