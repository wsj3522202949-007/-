# ✅ 人物卡校验

> AI 生成人物卡的校验规则。逐项检查，确保输出符合规范。

---

## 一、信息完整校验

### 1.1 检查项
- [ ] 基本信息完整
- [ ] 背景故事完整
- [ ] 人物关系完整

### 1.2 基本信息
- [ ] 姓名
- [ ] 年龄
- [ ] 身份
- [ ] 性格
- [ ] 外貌（可选）

### 1.3 背景故事
- [ ] 出身
- [ ] 成长经历
- [ ] 关键事件
- [ ] 动机和目标

### 1.4 人物关系
- [ ] 与其他人物的关系
- [ ] 关系变化
- [ ] 冲突和合作

### 1.5 检查方法
1. 逐项检查信息完整性
2. 确认无遗漏

### 1.6 不通过处理
- 缺少信息：补充信息
- 信息不完整：完善信息

---

## 二、逻辑一致校验

### 2.1 检查项
- [ ] 性格与行为一致
- [ ] 背景与能力一致
- [ ] 人物关系合理

### 2.2 检查方法
1. 检查性格与行为是否一致
2. 检查背景与能力是否一致
3. 检查人物关系是否合理

### 2.3 不通过处理
- 不一致：修改信息
- 不合理：调整关系

---

## 三、人设校验

### 3.1 检查项
- [ ] 主角有成长线
- [ ] 配角有记忆点
- [ ] 反派有破坏力

### 3.2 主角人设
- [ ] 不完美（有缺点）
- [ ] 有成长空间
- [ ] 有明确动机

### 3.3 配角人设
- [ ] 有记忆点（独特特征）
- [ ] 有功能（推动剧情）
- [ ] 有个性

### 3.4 反派人设
- [ ] 有破坏力（对主角构成威胁）
- [ ] 有动机（不是纯粹坏人）
- [ ] 有层次

### 3.5 检查方法
1. 检查主角成长线
2. 检查配角记忆点
3. 检查反派破坏力

### 3.6 不通过处理
- 主角太完美：增加缺点
- 配角无记忆点：增加独特特征
- 反派无破坏力：增加威胁性

---

### 4.1 检查项
- [ ] 文件名：人物名.md
- [ ] Frontmatter：包含必填字段

### 4.3 检查方法

## 五、结构校验

### 5.1 检查项
- [ ] 有清晰的章节结构
- [ ] 有标题
- [ ] 有分节

### 5.2 推荐结构
`markdown
# 人物名

## 基本信息
- 年龄：
- 身份：
- 性格：

## 背景故事
（背景内容）

## 人物关系
（关系内容）

## 能力/技能
（能力内容）

## 弱点/缺陷
（弱点内容）
`

### 5.3 检查方法
1. 检查是否有清晰结构
2. 检查是否有标题
3. 检查是否有分节

### 5.4 不通过处理
- 结构混乱：重新组织
- 缺少标题：补充标题
- 缺少分节：补充分节
