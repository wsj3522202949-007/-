# 🚀 /project 技能

> 新建项目，一键生成项目骨架。用于启动新书。

---

## 一、技能说明

**调用方式**：`/project [书名]` 或 `/project [项目名]`

**用途**：
- 创建新项目目录
- 生成项目骨架文件
- 初始化项目结构
- 配置项目模板

**输出**：
- 创建项目目录结构
- 生成 README.md、STATUS.md、framework.md、outline.md
- 创建 chapters/、entities/ 目录
- 配置项目模板

---

## 二、使用方法

### 2.1 直接调用
在 AI 对话中输入 `/project 我的新书`，AI 会：
1. 创建项目目录
2. 生成项目骨架文件
3. 初始化项目结构
4. 配置项目模板

### 2.2 指定类型
输入 `/project [书名] [类型]`，如 `/project 我的新书 玄幻`，AI 会：
1. 创建项目目录
2. 生成类型特定的模板
3. 初始化项目结构
4. 配置类型相关设置

## 四、项目结构

### 4.1 标准结构
```
projects/书名/
├── README.md           # 项目说明
├── STATUS.md           # 项目状态
├── framework.md        # 世界观框架
├── outline.md          # 大纲
├── chapters/           # 章节目录
│   ├── 第001章.md
│   ├── 第002章.md
│   └── ...
├── entities/           # 实体目录
│   ├── characters/     # 人物设定
│   ├── settings/       # 设定卡
│   └── locations/      # 地点设定
└── assets/             # 资源目录
    ├── images/         # 图片
    └── references/     # 参考资料
```

### 4.2 文件说明
- **README.md**：项目说明，包含书名、类型、平台、目标字数
- **STATUS.md**：项目状态，包含进度、阶段、里程碑
- **framework.md**：世界观框架，包含地理、历史、文化、力量体系
- **outline.md**：大纲，包含章节、剧情、人物发展

## 五、模板内容

### 5.1 README.md 模板
```markdown
# 书名

## 基本信息
- **书名**：书名
- **作者**：作者名
- **类型**：玄幻/都市/科幻等
- **平台**：起点/番茄/七猫等
- **目标字数**：XX 万字
- **状态**：筹备中/写作中/已完成

## 简介
[书籍简介]

## 目标
- [ ] 目标1
- [ ] 目标2
- [ ] 目标3

## 计划
- **开始日期**：YYYY-MM-DD
- **预计完成**：YYYY-MM-DD
- **当前阶段**：筹备/写作/修改/发布
```

### 5.2 STATUS.md 模板
```markdown
# 项目状态

## 当前阶段
- **阶段**：筹备中
- **进度**：0%
- **开始日期**：YYYY-MM-DD
- **预计完成**：YYYY-MM-DD

## 里程碑
| 里程碑 | 截止日期 | 状态 |
|---|---|---|
| 大纲完成 | YYYY-MM-DD | 待完成 |
| 初稿完成 | YYYY-MM-DD | 待完成 |
| 修改完成 | YYYY-MM-DD | 待完成 |
| 发布上线 | YYYY-MM-DD | 待完成 |

## 进度记录
| 日期 | 进度 | 备注 |
|---|---|---|
| YYYY-MM-DD | 0% | 项目启动 |
```
